# 官方来源路由

优先级依次为：发文机关正式页面及附件、同级政府公报或政策库、上级政府转载的完整原文、其他政府部门转载、商业平台索引。

搜索时组合项目全称、常用简称、文号、主管部门、年度和地域。发现附件缺失时回到发文机关页面或政府公报补齐。

跨源冲突记录双方标题、日期和原文位置；有效性据正式废止、修订、替代及适用期判断，网页更新与政策发布分别记日。

年度错位、已截止、被替代或有效期待核的文件标历史或待核。先查目标年度办法、通知和附件；当期链待核时交付历史参考、检索缺口及建设建议，`policy_status` 用 `stale` 或 `unknown`，`claims_limited=true`。
