# 官方来源路由

优先级依次为：发文机关正式页面及附件、同级政府公报或政策库、上级政府转载的完整原文、其他政府部门转载、商业平台索引。

搜索时组合项目全称、常用简称、文号、主管部门、省份和管理办法、实施细则或工作指引。随文附件缺失时回到发文机关页面或政府公报补齐。

跨源冲突记录双方标题、日期和原文位置；有效性据正式废止、修订、替代及适用期判断，网页更新与政策发布分别记日。

被替代及效力未核的文件按实际标历史或待核。未检索到该省管理办法时向客户索取，先交付已有依据支持的判断，`policy_status` 用 `stale` 或 `unknown`，`claims_limited=true`。
