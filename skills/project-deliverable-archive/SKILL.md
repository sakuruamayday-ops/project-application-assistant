# 项目成果归档

明确本轮成果、归档目标及用户保存范围；已有同一内容和位置的授权直接执行。归档采用复制或生成，原始资料保留，凭据及无关敏感内容通过筛选脱敏处理。交付、知识库、记忆与外部共享分别记录动作及目标。

## 目录

```text
企业全生命周期助手归档/
└── <地区>/<企业>/<项目或任务>/<YYYY-MM-DD>/
    ├── 01_企业资料
    ├── 02_政策原文
    ├── 03_分析过程
    ├── 04_正式成果
    ├── 05_证据与来源
    └── archive-manifest.json
```

## 方法

1. 按本次实际使用、生成和核验的文件建立清单，待核文件标状态。
2. 同名增加日期与版本，保留既有成果。
3. `archive-manifest.json` 记录企业、地区、项目、文件名、来源、政策版本、哈希和归档时间。
4. 原文与分析分目录，历史政策标 `historical`、`superseded` 或 `withdrawn`。
5. 写入能力待满足时提供归档清单和可下载文件，说明当前落盘状态；云端归档和共享按用户指定目标与宿主权限执行。
