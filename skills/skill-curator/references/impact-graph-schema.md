# 技能变更影响图

影响图采用“依赖项指向使用方”的方向，因此修改源节点后沿出边遍历即可得到下游影响。

## 节点类型

- `skill`：技能入口 `SKILL.md`
- `reference`：规则、方法和数据说明
- `template`：模板与资产
- `script`：执行脚本
- `gate`：验证、审查和交付核对
- `rule`：全局或平台配置
- `document`：其他说明及测试文件

## 关系类型

- `owned-by-skill`：资源属于某技能，资源变化需要复核技能入口
- `referenced-by`：目标文件被使用方显式引用
- `invoked-by`：一个技能被另一文件点名调用

图谱依文件结构和显式引用记录源、目标、类型和深度；关键词共现作候选线索，隐式关系注明判断依据。

## 发布核对

技能、模板、脚本和交付规则变化时，按变更路径或关键词生成影响报告，解释高影响节点；按当前已有授权完成候选修订、验证和对应签名发布步骤。
