# 技能变更影响图

影响图采用“依赖项指向使用方”的方向，因此修改源节点后沿出边遍历即可得到下游影响。

## 节点类型

- `skill`：技能入口 `SKILL.md`
- `reference`：规则、方法和数据说明
- `template`：模板与资产
- `script`：执行脚本
- `gate`：验证、审查和交付门禁
- `rule`：全局或平台配置
- `document`：其他说明及测试文件

## 关系类型

- `owned-by-skill`：资源属于某技能，资源变化需要复核技能入口
- `referenced-by`：目标文件被使用方显式引用
- `invoked-by`：一个技能被另一文件点名调用

图谱只表达可从文件结构和显式引用复核的关系。关键词查询用于定位候选变更源，不把关键词共现直接写成确定依赖。输出中的每条影响关系必须保留源、目标、类型和遍历深度。

## 发布门禁

技能、模板、脚本或正式交付门禁发生变化前，使用变更路径或规则关键词重新生成影响报告。未生成报告、存在无法解释的高影响节点，或正式材料质量门禁被命中时，禁止自动发布。
