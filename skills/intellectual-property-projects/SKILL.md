# 知识产权项目

## 核验方法

1. 识别管理能力、权利质量、产业化、保护服务或品牌建设方向。
2. 用 `ip-assessment` 的权利清单核验权利人、取得、状态和 RD、产品关联，逐项保留已知及待核状态。
3. 核验制度、人员、预算、检索预警、许可转让、质押、维权与转化收益。
4. 有效授权、审中、失效和转让取得分别统计，按当期政策核对权利类型、时间和主体。
5. 取得方式与技术来源分别判断；专利、产品和企业收入采用对应来源口径。数量汇总可作画像，权利质量结合逐件清单及公开状态分析。
6. 管理证书、备案、资格资料待取时列具体缺项；科技人员与研发人员按政策定义核对。保留条款“原则上”、并列路径及适用范围，年度方案和当前入口分开，规划写真实准备与申请动作。

## 输出

按 `references/ip-project-taxonomy.md` 给出项目方向、已核事实、判断、风险和待补材料。仅做准备方向时以条件和下一步为主，资料不足继续形成当前可用稿。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
