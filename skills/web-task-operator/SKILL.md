# 网页任务执行

按当前可用官方 API、连接器、宿主浏览器、本机浏览器、自动化和只读获取能力选择通道。现有能力直接使用，历史报告作参考；缺少操作能力时给可行替代或人工步骤，已有结果继续输出。方法见 [execution-protocol.md](references/execution-protocol.md)，企策顾问见 [aiqice-browser-profile.md](references/aiqice-browser-profile.md)。

## 会话与登录

使用用户已授权会话。需要登录时显示官方页面，由用户完成密码、扫码、验证码和二次验证，之后读取当前标题、URL 及可见状态，恢复任务。凭据、Cookie、认证 Header 和会话令牌由浏览器及宿主安全接口管理，日志及导出采用脱敏业务信息；网站权限与账号策略按实际服务执行。

临时独立标签页保持用户原页面，任务完成按用户要求保留页面或关闭临时页。浏览器访问范围对应当前任务。

## 定位与执行

1. 识别目标网站、数据或动作、范围和输出，采用本轮指令及已有授权推进。
2. 按当前可访问性角色、名称、标签及稳定文字定位，缺项时结合当前截图；动作后读取新状态，页面变化后更新控件与坐标。
3. 调用工具前按当前接口定义区分展示标识、运行标识、版本号和幂等键，参数只取该接口要求的真实返回字段并保持原始类型；同一逻辑写操作的重试沿用原幂等键，新逻辑动作使用新键，发送与发布沿本轮已有授权执行。
4. 登录、扫码及验证码交官方交互；定位反复失败时切换可用通道或人工接管，完成后重新读取状态。
5. 筛选、翻页、下载或提交核对实际数量、字段和返回页面，记录来源 URL、条件、时间及完成情况。
6. 发送、发布、上传、支付、删除、账号变更等按用户指令和宿主权限执行；账号安全与外部网站访问控制由对应接口处理。

## 浏览器本地导出

用户可在授权页面正常访问而宿主操作受限时，参考 [browser-local-replay.md](references/browser-local-replay.md)，用同源真实列表请求的路径、方法、参数和响应结构形成浏览器本地导出。浏览器 `fetch` 可通过 `credentials: "include"` 使用当前会话，结果以 JSON/CSV 等文件交后续处理，认证值留在浏览器安全会话。

数据权限、付费、频率及网站验证按正常服务流程处理。本地导出按下节记录通道和验收结果。

## 采集通道与数据提取验收

1. 按当前实际可用能力列采集主通道、备选通道和人工兜底。每次通道失败先记录通道、失败原因及已取得范围，切换后补记去向和结果。保留已有结果，用户限次、限速和停止指令同时约束全部通道，切换时沿用本轮剩余次数。
2. 每批标明实际取得方法及来源位置，同一批混合方法时逐记录标注。提取后按本轮字段、页面范围、筛选条件、数量和来源逐项记 `PASS`、`FAIL`、`WARN` 或 `N/A`，绑定对应 URL、页面位置或导出文件行号。
3. `PASS` 附达标证据，`FAIL` 写具体不符合项。未取得检查证据的适用项写 `WARN` 并列缺项，不适用项写 `N/A` 并写原因。动作执行成功与数据交付通过分别记录。

## 输出

交付提取数据时附采集记录及逐项验收结果，保留采集时间。操作结果附实际状态和核验来源。政策、企业和专利等专业判断按任务衔接对应技能，原文、第三方线索与推断分别标明。
