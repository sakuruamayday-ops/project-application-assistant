# 企策顾问浏览器执行档案

## 定位

企策顾问用于发现政策、项目、申报条件和奖补企业线索。其页面内容属于第三方索引，关键条件、日期、金额、企业名单和政策结论必须回到政府官方原文核验。

## 登录态识别

- 未登录页面通常显示“登录/注册”或微信扫码弹窗。
- 已登录页面顶部可见“消息”和用户入口，并可进入搜索结果页。
- 只依据可见页面判断登录状态，不读取Cookie、Local Storage、密码库或认证令牌。

企策顾问支持微信登录时优先由用户扫码。扫码完成后先尝试可访问性定位和截图定位；宿主因当前URL限制而停止，但用户仍能正常浏览时，改用浏览器本地请求重放规范导出数据。

## 已验证浏览器流程

2026-07-13 使用 macOS Safari 登录会话完成前向测试：

1. 搜索框可输入关键词并提交，结果页路径包含 `/search?keyword=`。
2. “综合、查政策、查项目、查奖补”标签可切换，结果列表可被可访问性树读取。
3. 地区等展开控件可能没有独立可访问性节点，可用当前截图定位“更多/收起”等视觉锚点。
4. 详情通常在新标签页打开，路径包含 `/policyDetail?id=...&indexId=...`，标题、地区、类型、发布日期、发文机构、文章来源和正文可读取。
5. 结果页提供页码和前后翻页控件；翻页后必须以首条标题变化或记录集合变化确认成功。

测试证明登录态下的检索、类别筛选、截图定位、详情读取和翻页可执行。页面结构会变化，运行时仍须重新观察，不能复用本次元素编号或坐标。

## 批量索引流程

批量索引前先取得用户对范围、页数、频率和输出位置的确认，然后：

1. 固定关键词、类别、地区和其他筛选条件。
2. 读取第一页样本，确认字段映射后再继续。
3. 逐页读取列表，记录页码、首条标题和末条标题，并先完成列表层去重。
4. 仅对缺少正文、官方原文链接或其他必要字段的记录打开详情页，处理后关闭临时标签页或返回结果页。
5. 申报通知必须提取完整申报条件；条件在附件中时记录附件链接和“附件待解析”，不得只保存摘要。
6. 公示公告、通过名单和奖补企业页面必须提取企业名称列表及页面标示数量；只记录页面或附件明确出现的企业，不从标题、摘要或数量反推企业名称。
7. 名单位于表格或附件时，保留名单与原记录的关联；无法读取时标记“名单待解析”，不得把“累计奖补数”当作已取得名单。
8. 每页去重并写入暂存结果；达到约定页数、时间、记录数或网站限制时停止。
9. 对准备进入知识库的记录补充官方原文核验状态，不把第三方AI解读当作政策事实。
10. 每次批量运行记录尝试页数、成功页数、列表记录数、详情请求数、页面间隔、验证码、限频和登录失效次数。

建议字段：

| 字段 | 说明 |
|---|---|
| `title` | 政策、项目或公示标题 |
| `region` | 页面显示的省市区 |
| `record_type` | 政策文件、申报通知、公示公告等 |
| `topics` | 页面标签或主题词 |
| `publish_date` | 发布日期 |
| `issuer` | 发文机构 |
| `article_source` | 文章来源 |
| `application_status` | 申报中、已截止或未标明 |
| `application_period` | 页面显示的申报起止时间 |
| `detail_url` | 企策顾问详情页链接 |
| `official_url` | 页面提供的官方原文链接，未取得则留空 |
| `query` | 本次关键词与筛选条件 |
| `page_number` | 来源页码 |
| `collected_at` | 采集时间及时区 |
| `verification_status` | 未核验、已核验或官方原文未命中 |
| `eligibility_conditions` | 申报通知中明确列出的主体、地区、行业、财务、研发、知识产权等条件原文 |
| `beneficiary_companies` | 通过、获批或公示企业名称数组 |
| `beneficiary_count` | 页面明确标示的企业数量，不得自行推算 |

首选 `detail_url` 中的 `id` 与 `indexId` 组合作为去重键。详情链接缺失时，使用规范化标题、发文机构和发布日期组合去重。

## 停止与降级

- 页面要求重新登录时交由用户扫码或输入凭据。
- 可访问性元素缺失时使用当前截图定位；操作后立即重新读取页面。
- 连续两次点击未造成预期状态变化时停止自动尝试并请求人工接管。
- 出现验证码、访问限制、付费限制或平台禁止自动化的提示时停止，不规避限制。
- 官方原文链接不可用时标记“当前检索层未命中”，不得写成政策不存在。
- 宿主禁止操作某个跳转URL时停止自动化；不得抓取Cookie继续重放，改由用户在浏览器本地导出脱敏业务数据。
