# 网页任务执行协议

## 任务定义

开始前确认：目标、网站、账号权限、读取或写入边界、数据范围、预期数量、输出字段、截止条件和允许的人工介入方式。

## 观察与动作

每轮按“观察—判断—动作—重新观察—核验”推进，依据当前可访问名称、文本、表单标签或结构状态定位控件。

使用本机浏览器时，每次界面变化后重新获取可访问性树或截图。优先使用元素标识执行操作；只有目标元素无法通过可访问性接口定位时才使用坐标，并在操作后截图核验。

## 会话隔离

不同客户、账号和任务使用独立会话、名称与输出目录，登录态、文件、表单及查询记录保留在对应任务范围。

## 数据提取

先抽取一页样本并校验字段，再扩展翻页。记录总页数、已处理页数、重复项、异常页和去重键。下载文件后核验文件名、大小、格式和页面来源。

## 表单与文件

填写前建立字段映射，区分用户提供、网页已有、计算所得和待确认值。任何提交动作前向用户展示关键字段摘要。上传文件前核对目标网站、客户、文件版本和敏感信息。

## 人工介入

登录、验证码、二次验证、电子签名、付款和授权由用户在官方界面完成；助手显示页面并等待，完成后重新读取状态，凭据始终留在本地安全会话。

按标题、URL、可见用户名或功能入口确认登录，凭据、密码库和浏览器存储由本地安全会话管理。

## 证据记录

保留必要 URL、标题、条件、时间、数量和错误状态；需证明页面时保存脱敏截图。技能包采用通用方法和中性示例，业务数据留在对应任务。

## 转人工与任务收束

- 用户权限不足或授权范围不清。
- 当前自动化超出网站允许范围时，转官方人工流程或其他授权来源。
- 出现账号安全、付款、法律或隐私风险。
- 结果无法核验或页面持续返回不一致内容。
- 用户调整执行意愿或达到约定范围时，保留结果并收束操作。
