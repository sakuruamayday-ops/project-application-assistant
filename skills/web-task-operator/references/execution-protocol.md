# 网页任务执行协议

## 任务定义

开始前确认：目标、网站、账号权限、读取或写入边界、数据范围、预期数量、输出字段、截止条件和允许的人工介入方式。

## 观察与动作

每轮遵循“观察—判断—单步动作—重新观察—核验”。不得在页面状态未知时连续点击，不得根据历史坐标猜测控件位置。优先使用可访问名称、稳定文本、表单标签和结构化页面状态定位元素。

使用本机浏览器时，每次界面变化后重新获取可访问性树或截图。优先使用元素标识执行操作；只有目标元素无法通过可访问性接口定位时才使用坐标，并在操作后截图核验。

## 会话隔离

不同客户、账号或任务使用独立会话。不得将一个客户的登录状态、下载文件、表单内容或查询历史带入另一个客户任务。并行任务必须使用可区分的会话名称和独立输出目录。

## 数据提取

先抽取一页样本并校验字段，再扩展翻页。记录总页数、已处理页数、重复项、异常页和去重键。下载文件后核验文件名、大小、格式和页面来源。

## 表单与文件

填写前建立字段映射，区分用户提供、网页已有、计算所得和待确认值。任何提交动作前向用户展示关键字段摘要。上传文件前核对目标网站、客户、文件版本和敏感信息。

## 人工介入

登录、验证码、二次验证、电子签名、付款和权限授予由用户亲自完成。需要登录时打开官方登录页并显示浏览器，暂停自动操作，等待用户输入账号密码或扫码。用户明确确认完成后重新读取页面状态，不要求用户提供密码、验证码、Cookie或会话令牌。

只允许通过页面标题、当前URL、可见用户名区域或目标功能入口判断是否登录成功，不检查密码输入框内容、浏览器密码库、Cookie、Local Storage或认证请求头。

## 证据记录

保留必要的URL、页面标题、查询条件、操作时间、结果数量和错误信息。截图仅在需要证明页面状态时保存，并尽量遮蔽无关个人信息。不得把网站完整数据库或受限制内容复制进Skill包。

## 停止条件

- 用户权限不足或授权范围不清。
- 网站明确禁止当前自动化行为。
- 出现账号安全、付款、法律或隐私风险。
- 结果无法核验或页面持续返回不一致内容。
- 用户要求停止或任务已达到约定范围。
