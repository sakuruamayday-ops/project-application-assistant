# 三首项目名单数据协议

## 一、适用范围

本协议用于浙江省制造业首台（套）装备、浙江省首版次软件产品、浙江省首批次新材料，以及各地市依法发布的市级首版次软件产品名单。

企策项目页用于发现企业、地区、行业和年份；逐产品事实回指年度公示、认定及官方附件。

## 二、两层实体

### 名单文档

每份年度通知或公示保存：

- 标准项目名、行政层级、主管部门、地区；
- 年份、批次、文档性质；
- 公示、拟认定、正式认定、撤销或奖励状态；
- 官方原文、官方附件、企策顾问发现页和抓取时间；
- 原文件哈希、替代关系和人工核验状态。

### 产品条目

每一行保存：

- 企业规范名称、统一社会信用代码或待补身份标识；
- 产品、装备、软件或材料名称；
- 设区市、区县、行业；
- 产品类别或装备类别；
- 拟认定档次、正式认定档次或目录层级；
- 名单序号、年度、文档状态和来源文档编号。

产品名待取时先保存企业、项目、年度及来源，复用用户材料并查官方原文；仍有缺项时提示：

> 当前检索范围内仅取得企业名称，尚未取得可核验的具体产品名称；请补充对应名单附件或产品资料。

首台套分别记国际、国内、省内档次及成套、整机、关键部件类别；首版次按省市层级分别保存；首批次保留材料名称、类别、档次及应用目录。

### 首批次指导目录

《浙江省重点新材料首批次应用示范指导目录》是材料范围、性能要求和应用领域的规则目录，不是企业获批名单。按年度分别保存目录条目、文号、生效日期、替代年度和效力状态，并与浙江省首批次新材料项目建立关联：

- 项目匹配使用当期现行目录，历史年度复盘使用对应年度目录；
- 企业公示、拟认定、正式认定或奖励结论仍以相应年度名单原文为准；
- 材料名称与目录条目精确一致时建立直接关联，近义名称标记为待确认；
- 指导目录说明可申报或支持范围，获评事实另据企业对应公示或认定名单确认。
- 相邻年度目录保存新增、删除、保留和修改四类差异；修改项同时保存变化字段、前值、后值及匹配分数。
- 产品匹配优先精确名称和包含关系；高置信结果按证据确认，中置信近义结果列候选及待核原因。

## 三、状态与去重

- 按企业—产品—项目建立公示、认定、奖励和退出时间轴，事件及原始证据分别留存。
- 当前视图显示同年同产品正式认定状态，公示原始证据留在事件历史。
- 奖励与首次认定各据相应事件记录。
- 目录退出据退出、移出或撤销的明确原文确认，有效期信息另列。
- 以标准项目名、行政层级、年度、企业身份、产品名称和档次组成业务去重键。
- 同企同年多产品逐产品保留行，分别记名称、层级、档次和年度。
- 同名企业的不同产品、档次及行政层级分别保存。

## 四、检索规则

- 查询企业是否获批时，返回企业、产品、年份、层级、状态和档次。
- 查询企业跨年变化时，按公示、认定、奖励、目录退出顺序返回状态时间轴，并附每个事件的独立来源。
- 查询同类产品或同行时，以产品名称、类别和档次为主检索字段，企业行业仅作辅助。
- 查询“首版次”但未说明层级时，先让用户选择浙江省级或企业所在地市级；已有默认城市时可同时返回省级与当地市级两个分组。
- 仅有项目汇总页时标待展开，先交付已知企业和来源，产品档次按原附件补取。
- 产品名待取时复用已有材料并查官方原文，仍缺项时集中列明。
- 最终结论优先正式认定文件；只有公示文件时明确写拟认定或公示中。
- 查申报条件或匹配先读当期目录及通知；查历年获评产品则读相应公示或认定名单。
- 三首项目统一调用 REST `POST /v1/three-first/analyze` 或 MCP `three_first_analysis`；服务端内部组合历年目录差异和企业产品目录匹配。
- 企业产品匹配默认不返回待人工核验候选；只有明确要求查看候选时才允许返回。
