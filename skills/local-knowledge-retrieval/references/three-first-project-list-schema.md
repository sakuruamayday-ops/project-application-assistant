# 三首项目名单数据协议

## 一、适用范围

本协议用于浙江省制造业首台（套）装备、浙江省首版次软件产品、浙江省首批次新材料，以及各地市依法发布的市级首版次软件产品名单。

企策顾问项目页中的公司名称、登记地区、行业和年份只作为发现索引。年度公示、认定通知及其官方附件才是逐产品事实来源，不得用项目页汇总记录替代产品明细。

## 二、两层实体

### 名单文档

每份年度通知或公示保存：

- 标准项目名、行政层级、主管部门、地区；
- 年份、批次、文档性质；
- 公示、拟认定、正式认定、撤销或奖励状态；
- 官方原文、官方附件、企策顾问发现页和抓取时间；
- 原文件哈希、替代关系和人工核验状态。

### 产品条目

每一行保存：

- 企业规范名称、统一社会信用代码或待补身份标识；
- 产品、装备、软件或材料名称；
- 设区市、区县、行业；
- 产品类别或装备类别；
- 拟认定档次、正式认定档次或目录层级；
- 名单序号、年度、文档状态和来源文档编号。

产品名称未从可核验原文中取得时，只保存企业、项目、年度和来源线索，不创建占位产品，不以项目名称冒充产品名称。对外固定提示：

> 仅检索到企业名称，未取得可核验的具体产品名称，请用户自行查找并补充对应产品名称。

首台套至少保留国际、国内、省内档次及成套装备、整机装备、关键零部件等类别。首版次必须区分省级与市级，不得把杭州市等市级首版次合并成浙江省首版次。首批次至少保留材料名称、类别、认定档次和应用目录信息。

### 首批次指导目录

《浙江省重点新材料首批次应用示范指导目录》是材料范围、性能要求和应用领域的规则目录，不是企业获批名单。按年度分别保存目录条目、文号、生效日期、替代年度和效力状态，并与浙江省首批次新材料项目建立关联：

- 项目匹配使用当期现行目录，历史年度复盘使用对应年度目录；
- 企业公示、拟认定、正式认定或奖励结论仍以相应年度名单原文为准；
- 材料名称与目录条目精确一致时建立直接关联，近义名称只能标记为待人工确认；
- 命中指导目录只能说明材料进入可申报或支持范围，不能单独证明企业已经获批。
- 相邻年度目录必须保存新增、删除、保留和修改四类差异；修改项同时保存变化字段、前值、后值及匹配分数。
- 企业产品自动匹配优先精确名称和包含关系；高置信结果可自动确认，中置信近义结果只能进入人工候选，不得直接输出为确定结论。

## 三、状态与去重

- 为每个企业—产品—项目建立“公示—认定—奖励—目录退出”状态时间轴；四类事件分别保存，不能用后续状态覆盖前序证据。
- 正式认定可在当前状态视图中替代同年度同产品的拟认定状态，但不得删除公示原始证据。
- 奖励只表示存在奖励或奖补依据，不等同于首次认定。
- 目录退出必须有退出、移出或撤销目录资格的明确原文证据；不得仅因超过通常有效期自动推断退出。
- 以标准项目名、行政层级、年度、企业身份、产品名称和档次组成业务去重键。
- 同一企业同年多个产品必须保留多行，不能压缩成一个“获批年份”。
- 企业名称相同但产品不同、档次不同或行政层级不同，不得合并。

## 四、检索规则

- 查询企业是否获批时，返回企业、产品、年份、层级、状态和档次。
- 查询企业跨年变化时，按公示、认定、奖励、目录退出顺序返回状态时间轴，并附每个事件的独立来源。
- 查询同类产品或同行时，以产品名称、类别和档次为主检索字段，企业行业仅作辅助。
- 查询“首版次”但未说明层级时，先让用户选择浙江省级或企业所在地市级；已有默认城市时可同时返回省级与当地市级两个分组。
- 只命中企策顾问项目汇总页时，标记为待展开，不输出产品名称、档次或精确获批结论。
- 查不到具体产品名称时，只更新企业名称和已有状态线索，明确提示用户自行查找对应产品名称。
- 最终结论优先正式认定文件；只有公示文件时明确写拟认定或公示中。
- 查询首批次申报条件或产品匹配时，先读取当期现行指导目录，再读取当期申报通知；查询历年企业名单时，不得用指导目录替代公示或认定名单。
- 三首项目统一调用 REST `POST /v1/three-first/analyze` 或 MCP `three_first_analysis`；服务端内部组合历年目录差异和企业产品目录匹配。
- 企业产品匹配默认不返回待人工核验候选；只有明确要求查看候选时才允许返回。
