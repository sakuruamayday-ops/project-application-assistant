# 能力委派协议

当前执行环境因网络、权限或沙箱限制无法调用已配置能力时，先区分“服务不可用”和“当前执行器不可达”。

1. 先由当前执行器调用健康或身份接口。
2. 如果是 TLS、DNS、出口策略或沙箱拦截，不记录为凭据错误或服务端故障。
3. 宿主存在已授权且可联网的执行器、工具或子任务时，只委派本次所需的最小调用，并要求返回结构化结果、来源和错误类型。
4. 主任务校验返回的企业、项目、地区、年份和文档编号；不得将“委派执行成功”等同于业务结论正确。
5. 无可用委派通道时，明确说明当前执行环境不可达，再按 Skill 的官方网页或用户文件降级路径执行。

本协议不绑定任何 Agent 平台、子 Agent 名称或专用配置格式。
