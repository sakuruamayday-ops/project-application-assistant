# 材料版本对比

## 流程

1. 确认旧版、新版、文件日期和比较范围，提取标题、段落、表格和附件清单。
2. 按章节标题和字段键对齐，结合内容相似度识别位置移动。
3. 将变化分为新增、删除、修改、移动和格式变化。
4. 数字变化同时显示前值、后值、单位、期间、差额和来源变化。
5. 单列企业名称、主导产品、知识产权法律状态、政策依据、申报年度和结论等级的变化。
6. 按关键、重大、一般或编辑性标记影响，列出需要联动的章节。
7. PDF、扫描件或复杂表格结合宿主 OCR、文档解析及逐页核对；待解析部分记录页码、对象类型和待核项，继续比较已解析内容。

## 输出

给出变更概览和结构、数字、表述、合规风险、联动修改表，附比较完整度及未覆盖范围。结论对应已解析范围。

结构化差异格式见 `references/version-diff-rules.md`；已有结构化文本可运行 `scripts/compare_material_json.py`，文件解析使用宿主文档能力。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
