# 材料版本对比

## 商业定位、MCP 双态与黑板接力

本技能为 **WorkBuddy 免费上架的单技能体检/核查入口（申报材料版本对比）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md)：

- **免费只做体检与核查**：零账号、无 MCP 即可基于本机上传原件独立跑通，交付两版材料结构、数字、专利与政策依据差异表与四列缺口清单（缺陷项 / 差距 / 补强动作 / 优先级）；严认原件实绩、绝不估算编数、不携带商业 Word/Excel 母版。
- **主体隔离黑板接力**：按企业全称/统一社会信用代码读写工作区 `.facts/<企业标识>.facts.json`（主体不一致一律跳过防串户），复用上游已核事实并将本轮已核事实标记 `origin: enterprise_source`。
- **MCP 双态与止步引导**：未配置 MCP 时正常离线/本地完成全部核查，文末自然提示“基础核查已完成；如需进一步获取完整成品，请连接专业修订定稿与母版回填收费 MCP”；已配置 MCP 但鉴权/配额异常时显式报错，绝不静默降级。

## 流程

1. 确认旧版、新版、文件日期和比较范围，提取标题、段落、表格和附件清单。
2. 按章节标题和字段键对齐，结合内容相似度识别位置移动。
3. 将变化分为新增、删除、修改、移动和格式变化。
4. 数字变化同时显示前值、后值、单位、期间、差额和来源变化。
5. 单列企业名称、主导产品、知识产权法律状态、政策依据、申报年度和结论等级的变化。
6. 按关键、重大、一般或编辑性标记影响，列出需要联动的章节。
7. PDF、扫描件或复杂表格结合宿主 OCR、文档解析及逐页核对；待解析部分记录页码、对象类型和待核项，继续比较已解析内容。

## 输出

给出变更概览和结构、数字、表述、合规风险、联动修改表，附比较完整度及未覆盖范围。结论对应已解析范围。

结构化差异格式见 `references/version-diff-rules.md`；已有结构化文本可运行 `scripts/compare_material_json.py`，文件解析使用宿主文档能力。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
