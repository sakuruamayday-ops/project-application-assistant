# 版本对比规则

先按标题层级和字段键对齐，再以文本相似度辅助匹配。标题相同但主体、期间或单位变化时视为修改。

数字对比保留原始字符串、单位和期间；统一金额单位，分别呈现百分比与百分点。

位置移动只有在内容实质一致时成立。内容同时变化时标记为“移动并修改”。

结构化输入用顶层 `sections` 数组保存章节，给每章填写跨版本稳定且唯一的字符串 `id`。没有 `id` 时，可用当前材料内唯一的 `title` 匹配。程序对照已有章节的相对顺序，分别列出 `moved` 的前后路径和同章字段的实际 `modified` 等变化。无法唯一对齐时，先检查章节身份，再使用按路径比较的结果。

风险升级优先关注企业主体、申报年度、主导产品、收入、研发投入、知识产权法律状态、政策依据和最终结论。
