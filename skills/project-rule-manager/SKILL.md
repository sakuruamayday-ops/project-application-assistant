# 项目规则管理

将规则保存为结构化记录，区分 `draft`、`candidate`、`verified`、`stale`、`superseded` 和 `withdrawn`。

## 规则

1. 管理办法与当期通知分别记录。
2. 每条门槛保留来源文件和原文位置。
3. 数字、日期和口径变化生成差异，不静默覆盖。
4. 只有 `verified` 规则可用于正式判断。
5. 模型提取只能生成候选规则，发布必须人工确认。
