# 绿色发展项目

## 商业定位、MCP 双态与黑板接力

本技能属于 **WorkBuddy 收费深度分析与成品交付能力（绿色工厂申报自评 · 收费 MCP 服务端 / 付费交付端）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md)：

- **业务范围**：承接绿色工厂自评价台账、能耗/水耗边界核验与整改提升方案；商业报告母版与服务端生成资产留在收费侧，严认原件实绩与可验证数据、绝不虚构财务/司法/实测指标、绝不输出废弃的内部估分，提供四列缺口与可执行整改动作。
- **主体隔离黑板与 MCP 故障显式报错**：按当前企业主体读写 `.facts/<企业标识>.facts.json` 实现组合包无缝接力并杜绝跨企业串户；已配置付费 MCP 若遇鉴权过期、配额归零或超时，显式向用户报错排查，绝不静默降级。

环保合规、绿色绩效、建设计划和已实现成效分别评价。国家、省、市区县绿色工厂及零碳、近零碳工厂分别记录主体、地区层级、年度、申报或复核类型、导则及模板；未知项标明对结论的影响，按已有资料继续。

## 核验方法

1. 版本卡记录项目全称、层级、年度、导则版本、机关、施行及核验日期、随文评价要求和客户表单版本；历史文件作预研对照。
2. 固定组织、生产、基准期、报告期、合格产品产量及适用分母。
3. 登记来源和计算血缘，核验能源、水、原材料、废弃物、排放、碳、管理体系及绩效。
4. 基本要求、必选项和分数分别判断；缺证、冲突、失效标对应状态，推荐建议明确成立条件。
5. 每条评价绑定要求、企业现状、正文小节、证据和附件编号。明确未满足与缺证据分开，逐项写实际差距、补强动作及优先级。
6. 复算总量、单位指标、三年趋势和改造前后数据，逐项对照基本要求、必选项和评价条款。缺口标明实际差距、单位、证据及补强动作。

指标见 `references/green-metrics-boundaries.md`，自评价见 `references/green-factory-self-evaluation.md`。结构化指标用 `scripts/validate_green_metrics.py`，完整台账用 `scripts/validate_green_factory_ledger.py`；脚本、政策效力、证据内容和现场状态分别记录检查结果。

## 输出

前期评估及可行性报告参考 `project-feasibility/references/two-report-contract.md`。前期突出政策明确且已有数据、明确差距或影响结论的条件，可行性按适用办法的评价要求拆解。

完整自评价或核稿提供版本卡、基本与必选要求对照、缺陷与差距、指标计算底稿、附件索引及补证清单。意见定位表格行、正文小节或附件编号，先补否决项与必选项。政策评分表保留项目、分值及权重结构供条款解释。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
