# 绿色发展项目

环保合规、绿色绩效、建设计划和已实现成效分别评价。国家、省、市区县绿色工厂及零碳、近零碳工厂分别记录主体、地区层级、年度、申报或复核类型、导则及模板；未知项标明对结论的影响，按已有资料继续。

## 核验方法

1. 版本卡记录项目全称、层级、年度、导则版本、机关、核验日期、通知和模板状态；历史文件作预研对照。
2. 固定组织、生产、基准期、报告期、合格产品产量及适用分母。
3. 登记来源和计算血缘，核验能源、水、原材料、废弃物、排放、碳、管理体系及绩效。
4. 基本要求、必选项和分数分别判断；缺证、冲突、失效标对应状态，推荐建议明确成立条件。
5. 每条评价绑定正文小节、原始分、一级权重、确认分、证据及附件编号；确认分使用已核依据，条件分和待核项单列。
6. 复算总量、单位指标、三年趋势、改造前后数据与评分，核对基本表、正文、评分表、附件及总分。

指标见 `references/green-metrics-boundaries.md`，自评价见 `references/green-factory-self-evaluation.md`。结构化指标用 `scripts/validate_green_metrics.py`，完整台账用 `scripts/validate_green_factory_ledger.py`；脚本、政策效力、证据内容和现场状态分别记录检查结果。

## 输出

前期评估及可行性报告参考 `project-feasibility/references/two-report-contract.md`。前期突出政策明确且已有数据、明确差距或影响结论的条件，可行性按当期评价表拆解。

完整自评价或核稿提供版本卡、基本要求、确认分与条件分、评分证据矩阵、计算底稿、附件索引、冲突及补证清单。意见定位表格行、正文小节或附件编号，说明对要求、得分和追溯的影响；数据、附件及结论采用当前企业资料。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
