# 绿色工厂自评价报告工作合同

## 适用范围

用于绿色工厂或绿色低碳工厂的前期盘点、自评价报告编制、指标与证据核验、证明材料整理和既有报告核稿。零碳或近零碳工厂、绿色供应链、清洁生产审核及单项节能技改使用各自当期规则。

## 一、先锁定项目版本

建立版本卡并保持到交付结束：

- 企业法定主体、统一社会信用代码、实际生产场所和工厂边界；
- 申报地区、行政层级、目标年度、批次以及新申报、升级或复核；
- 管理办法、评价导则、随文评分表及客户提供的报告模板；
- 每份文件的标题、文号、发布机关、发布日期、适用范围、原文位置、核验日期和替代关系；
- 核心与加分上限、推荐阈值、基本和必选条件的适用判断。

按项目全名和地区定位管理办法及随文评价表。未取得适用原文时先梳理企业证据，列缺规则和客户需提供的表单。

## 二、要求、现状与证据底稿

当期模板另有强制结构时以模板为准。没有冲突时，报告按以下对象组织，并与评分表细分栏目一一对应：工厂基本情况、基本要求、基础设施、管理体系、能源与资源投入、产品、环境排放、绩效、加分项、下一步工作、自评表和证明材料。

每条评价要求建立唯一 `criterion_id`，同时登记：

- 原文及原文位置、要求类型、最高原始分和一级指标权重；
- 正文小节、企业现状、要求是否满足和适用性；
- 证据记录编号、附件编号、证据状态和期间；
- 指标原始值、单位、公式和复核结果，量化与适用要求的差额；
- 缺证或冲突的具体事项、补强动作、优先级和责任节点。

基本要求用 `pass`、`fail`、`unknown`、`not_applicable`，评价项增加 `partial`。已核验事实和可复算指标支撑条件判断。自述、缺证、过期或冲突材料按各自状态列缺口。

## 三、证据矩阵

以下是常见证据类型，不是固定材料清单；当期导则和通知优先。

| 对象 | 重点核验 | 常见证据 |
|---|---|---|
| 基本要求 | 主体与实际生产、近三年经营和合规、环境信息披露适用性、现场管理、最高管理者职责、管理机构、三年以上规划、培训考评 | 营业执照、生产许可、环评及验收、排污许可或登记、信用记录、主管部门或企业事故核查材料、现场记录、任命与制度、目标方案、培训签到和考评 |
| 基础设施 | 建筑与用地、采光照明、设备准入及能效、分类计量、污染治理能力与生产负荷匹配 | 权属和总平图、建筑材料或声明、现场照片及测量、设备台账和铭牌、淘汰目录核对、计量器具清单和检定、治理设施设计运行记录 |
| 管理体系 | 建立、实施并保持与第三方认证分别成立；社会责任报告是否真实公开 | 体系手册、程序文件、内审管理评审和运行记录、有效认证证书、公开网页及发布日期 |
| 能源与资源 | 能源结构、绿电或可再生能源、余能利用、用水定额和循环利用、原材料减量、绿色采购 | 能源账单和计量台账、绿证或合同、光伏发电记录、节能诊断或技改验收、水量平衡、材料台账、采购制度和供应商评价 |
| 产品 | 产品边界、生态设计、有害物质、用能产品适用性、碳足迹、可回收利用 | 产品标准、设计评审、检测报告、物料声明、能效检测、碳足迹核算或核查、改进记录 |
| 环境排放 | 许可范围与实际产污一致、总量控制、废水去向、一般固废与危废、噪声、温室气体核算核查和改进 | 排污许可或登记、监测报告、在线和运行台账、处置合同资质及联单、噪声检测、温室气体清单和核查声明、公开记录 |
| 绩效 | 用地、绿色物料、污染物与废气废水强度、原材料、固废和水循环、综合能耗、碳排放 | 分子分母原始记录、法定报表、计量和检测数据、附录公式底稿、行业限额或先进值、可比样本来源 |
| 加分项 | 亩均最近评价、碳管理、三年强度变化、碳效档位或信息系统、诊断与技改投资及入库 | 官方评价结果、制度和年度报告、三年工业增加值与碳排、碳效码或系统运行记录、诊断报告、合同发票付款验收、储备库文件 |

同一附件支持多个要求时，在 `supports` 逐项注明。编号按本企业定稿材料生成，正文、表和目录对应同一材料。

## 四、缺陷与差距

按导则保留评分表结构，包括评价项、每项上限、一级权重、适用档位、加分上限和推荐线。政策中的加权口径为条目原始分乘对应一级权重。

逐项对照企业现状与要求，写清未满足项、实测差额及单位、缺哪份证据、怎么补和先补哪项。优先处理基本要求、必选项、真实性冲突和关键材料缺口。

推荐条件逐项核对基本要求、必选项、当期政策与正式评价结果。缺正式评价依据时，登记其证据缺口并继续编制可用部分。

绩效结合 `green-metrics-boundaries.md` 计算。行业位置据可比来源，基准待核时先保留企业指标和对标缺口；年均变化注明公式与完整期间。

## 五、交付前回查

1. 基本信息表、正文、自评表、加分表和附件中的企业名称、期间、数值、单位、产品名称和分母一致。
2. 指标对应原始记录和当期公式，差额可复算且单位一致。政策评分表中的上限、档位和权重回指原文。
3. 满足条件的判断回指已核验证据或可复算指标。“无数据”“待补”“不符合”分别保留其实际状态。
4. 每个被引用附件真实存在并支持对应要求；附件目录、页码和正文引用无断链。
5. 管理制度、计划、设计值和建设照片不冒充持续运行记录或已实现绩效。
6. 先进性、认证、披露和入库回指原件，口头咨询标线索。
7. 使用 `scripts/validate_green_metrics.py` 检查指标边界，再执行 `scripts/validate_green_factory_ledger.py 台账.json --rules 导则规则.json` 校验评分、台账和证据。在 `items` 中逐项查看要求、现状、差距和补强动作。

## 六、校验台账最小结构

业务输出统一用 `items`，每条登记要求、现状、差距、证据、动作和优先级。下面演示使用原始指标写差额。

```json
{
  "items": [
    {
      "item": "环境监测记录",
      "requirement": "覆盖报告期且对应许可项目",
      "actual": "许可证已取得，缺报告期自行监测原件",
      "gap": "缺报告期监测记录和异常处置台账",
      "evidence": "排污许可证及已收材料登记",
      "action": "按许可项目补齐报告期报告与记录",
      "priority": "高"
    }
  ]
}
```

校验器读取 `policy`、`factory`、`evidence`、`basic_requirements`、`score_rows`、`metrics`、`summary`。`ledger_scope=partial` 用于逐段核稿，评价行可仅登记条款、状态及证据，政策分值、行分值及汇总分值可省略。`complete` 用于核对完整的正式台账和推荐条件。证据标 `verified`，`supports` 与评价行对应。条款和差距可随行写入 `requirement`、`actual`、`gap`、`action`。比值用 `calculation` 记录分子、分母和倍率，`value` 填实际复算的指标。

完整台账使用 `--rules` 传入从适用导则独立整理的条款清单，填 `region`、`level`、`target_year`、`guide_version`、`source_ref` 和 `criteria`。`criteria` 以条款 ID 为键，逐项含 `name`、`section`、`max_raw_score`、`weight`。废气条款单独登记并保留对应行。适用导则有不适用分支时，在该行记录 `not_applicable` 及依据。缺行、挪动分值上限和改权重均在回执定位。

按指标分档的条款含 `metric_rule`，填写 `metric_id`、`unit`、`direction`（`at_least` 或 `at_most`）、`tiers`（每档含 `threshold`、`raw_score`）和最低条件未满足时的 `floor_raw_score`。指标实际值、单位和证据关联通过后，分值须落在规则给定的档内且不超过实测允许上限。分段核稿若填写量化分档，使用同一规则文件。

复盘工信厅节函〔2025〕390号第二部分（二）时，使用国家层级、2025 年和 `historical_audit`。在 `historical_results` 填「年」「自末位起排名」「参评工厂」「当年在名单」，`dynamic_review` 回执分别给出连续触发移出、完整三年未连续触发、缺年度数据。当前申报继续按对应年度规则。

## 七、不同任务的输出

- 前期盘点写版本、基本与必选要求对照、实际差距、补强动作和优先级。
- 正式编制：交付正文、自评表、计算底稿、材料索引、证据台账和待核项；按证据分别记录已完成事项、计划事项及需要确认的事项。
- 核稿按位置、原值、问题、影响、修正及证据输出，区分资格、指标、索引和编辑问题。

样本用于结构和失败模式分析；公共技能、测试及其他客户材料使用脱敏或合成示例，本轮企业数据来自本轮资料。
