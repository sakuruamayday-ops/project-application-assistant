# 数字化项目

## 商业定位、MCP 双态与黑板接力

本技能属于 **WorkBuddy 收费深度分析与成品交付能力（工厂数字化评估 · 收费 MCP 服务端 / 付费交付端）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md)：

- **业务范围**：承接数字化车间/智能工厂/未来工厂成熟度评估与改造建设方案；商业报告母版与服务端生成资产留在收费侧，严认原件实绩与可验证数据、绝不虚构财务/司法/实测指标、绝不输出废弃的内部估分，提供四列缺口与可执行整改动作。
- **主体隔离黑板与 MCP 故障显式报错**：按当前企业主体读写 `.facts/<企业标识>.facts.json` 实现组合包无缝接力并杜绝跨企业串户；已配置付费 MCP 若遇鉴权过期、配额归零或超时，显式向用户报错排查，绝不静默降级。

地方条件按[省级管理办法检索指引](references/policy-lookup.md)核对适用办法。申报时间、截止日期与当年申报范围由客户按当期通知确认。

## 七维核验

1. 设备与自动化基础。
2. 网络连接和设备数据采集。
3. 业务系统实际运行。
4. 系统与数据集成。
5. 数据驱动的计划、质量、设备或能源闭环。
6. 改造前后可复核绩效。
7. 网络与数据安全。

每项区分已运行、试运行、在建、计划和供应商方案；自主技术、集成实施及外购产品分别描述，知识产权按实际权属记录。办公软件采购对应办公能力，制造数字化评价对应生产业务能力。

认定、转型示范和补助项目分别使用适用管理办法或评价标准。投资额、软件比例等专项口径由客户提供，仍可先核对生产数字化证据。预算建议对应真实改造任务。成熟度和证据要求见 `references/digital-maturity-model.md`。
