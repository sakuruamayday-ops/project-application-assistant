# 报告结构与视觉规范

写作与精简沿[共享报告方法](../../_runtime/report-writing.md)：保留本文件章节和表型，直接交付可用稿，资料缺口集中说明。

## 页面与专题结构

沿 `report-input-schema.md` 的页面顺序和九专题生成，来源按实际内容续页，页面数以本次产物为准。

先摘要，再财务事实、风险和动作，末尾集中计算、来源与范围；沿用生成器九专题，收入确认、存货进项等结论归入对应专题或风险表。

默认 PDF；用户需 Word 时由同一 HTML 生成可编辑 DOCX，沿九专题、原表、数值、来源、缺项和金色品牌，按各格式实际分页检查。

## 金色顾问视觉

- 全篇沿用深度顾问版：深棕黑承重、香槟金强调、米金铺底，封面与正文保持一致。
- 封面：深墨黑、古铜和香槟金渐变，增加细金框、金色侧脊和半透明金色信息格。
- 封面标题：象牙白；分隔线：由古铜到香槟金的渐变。
- 正文：页顶使用深棕至香槟金色带；章节标题使用深棕文字、左侧金条和底部短金线。
- 表格：深棕黑表头、香槟字色、米金隔行底纹、古铜金顶线。
- 卡片：象牙白或浅米金渐变、细金边、顶部金色高光和克制阴影；KPI 数字统一深棕金。
- 图表主序列深棕金、次序列亮金，风险项酒红，沿用顾问色彩层级。
- 金色通过层级、线条、底纹和材质贯穿全篇，正文使用克制的浅底与清楚对比。
- 全篇使用包内金色居中水印，位置和绝对尺寸固定。
- 页脚仅列企业、报告名和日期，不新增未经授权的联系人或宣传口号。

## 内容规则

- 先结论，后数据、风险和动作。
- 每个精确金额标明来源页码；每个比例给公式。
- “高优先”表示优先核验，不表示违法概率。
- 报告末尾保留数据缺口、OCR不确定性和非税务鉴证声明。
