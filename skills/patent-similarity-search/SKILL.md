# 相似专利检索

依次使用 `patent-data-foundation` 和 `patent-search-core`。

## 分析步骤

1. 获取并确认目标专利文本版本。
2. 提取独立权利要求必要技术特征；没有权利要求时明确只能进行主题初筛。
3. 执行关键词、分类号、引证和申请人多轮检索。
4. 读取 [similarity-model.md](references/similarity-model.md) 对候选专利逐项评分。
5. 核验候选专利申请人、当前权利人、集团关系、同族和法律状态。
6. 输出相似原因、关键差异、公开时间和是否可能构成在先技术。

不得用单一向量百分比作法律结论，也不得把摘要相似直接认定为权利要求相同。
