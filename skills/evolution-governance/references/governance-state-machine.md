# 技能进化治理状态机

| 状态 | 进入条件 | 允许动作 | 退出条件 |
|---|---|---|---|
| `observed` | 收到纠错或改进线索 | 记录、去敏、归类 | 形成候选 |
| `candidate` | 有可复现问题 | 生成差异 | 完成 dry-run |
| `dry-run` | 未修改正式核心 | 影响分析、测试 | 影响审查通过 |
| `impact-reviewed` | 依赖和受保护节点明确 | 建快照、回归 | 测试全部通过 |
| `tested` | 强制测试通过 | 申请审批 | 审批绑定哈希 |
| `approved` | 审批范围与差异一致 | 签名候选 | 验签通过 |
| `signed` | 产物签名有效 | 隔离安装 | 安装回归通过 |
| `installed` | 安装自检通过 | 宿主端验证 | 标记稳定 |
| `stable` | 当前发布版本及必要安全验证完成 | 按已授权范围分发 | 新变更开始 |
| `blocked` | 登录、隔离、密钥、签名或回滚相关问题待恢复 | 修复受影响机制，保留可用结果 | 可信状态恢复 |
| `rollback-required` | 安装或运行回归失败 | 恢复稳定快照 | 回滚验证通过 |
