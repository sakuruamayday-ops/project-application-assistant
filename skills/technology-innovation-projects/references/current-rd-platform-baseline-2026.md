- 2026年度适用《杭州市科学技术局关于组织开展2026年度市重点企业研究院、市企业研究院申报建设工作的通知》，落款2026年9月4日。项目状态为 `current`，适用年度为2026。
- `user-supplied-reviewed` 表示用户提供且已审阅。2026年10月4日取得协会转载扫描件，政府网页访问受限，转载和官方访问状态分别标明。
- “杭州研发中心”“杭州市研发中心”“市高企研发中心”统一路由到“市级研发中心（四市属地版）”的杭州属地版本，普通市企业研究院与市重点企业研究院分开判断。
- 2026年5月29日至6月27日征求意见稿用于历史追溯；正式颁布、废止和认定身份变化分别以对应正式文件确认。
- 企业截止按所在区县市通知核对。10月9日和20日分别为重点院、普通院的区县报送节点；数据截至2025年12月31日。未来年度查对应批次及时间。

### 2026市企业研究院条件

依托企业须在杭注册且具有独立法人资格，申报领域为“296X”先进制造业集群以及现代服务业、现代农业相关领域。

| 条件 | 要求 |
| --- | --- |
| 主体 | 有效期内科技型中小企业、好苗子、高新、新雏鹰、科技领军企业，或规上工业企业 |
| 人员 | 上一年度研发人员≥10人，软件企业≥15人 |
| 设备 | 科研设备原值≥100万元；农业、软件企业科研专用设备≥50万元；租赁设备按上年度支付租金凭证金额150%计入 |
| 场地 | 相对集中研发场地≥100平方米 |
| 研发 | 上年度研发费用≥100万元或占营收≥3% |
| 知识产权 | 近三年Ⅰ类≥1件或Ⅱ类≥3件 |
| 管理 | 制度健全、研发活动单独建账核算，未列入严重失信名单 |

普通市企业研究院按其条件核验；重点院创新能力60分要求按重点院对象适用。

市重点企业研究院：原则上已建市企业研究院，含原市研发中心；有效期内科技型中小企业、好苗子、高新、新雏鹰或科技领军企业；上年度营收≥2亿元，农业≥5000万元；研发费用占比≥4%或费用≥5000万元，农业费用≥800万元；创新能力评价≥60分，并符合人才、知识产权、研发条件、管理和信用要求。按当期附表1、附表2核对，农业与非农业分别使用适用档位。

## 浙江省

- 原省高新研发中心并入省企业研究院序列，后续沿复核及更高层级路径安排。
- 新申报应优先匹配“浙江省企业研究院”；更高层级匹配“浙江省重点企业研究院”。执行浙经信高新〔2025〕169号及当期通知。

省企业研究院基本条件：浙江省注册独立法人；原则上建有市级企业研发机构；营业收入5000万元以下时研发强度不低于5%且研发费不低于100万元，5000万元至2亿元时研发强度不低于4%或研发费不低于250万元，2亿元以上时研发强度不低于3%或研发费不低于800万元；创新能力评价60分以上；具备人才、知识产权和研发基础；无规定重大违法失信情形。

省重点企业研究院基本条件：原则上建有省企业研究院、原省高企研发中心或省级企业技术中心；营业收入2亿元以上，农业企业5000万元以上；研发强度不低于4%或研发费不低于5000万元，农业企业研发费不低于800万元；创新能力评价60分以上；具备核心自主知识产权、人才和研发基础；无规定重大违法失信情形。
