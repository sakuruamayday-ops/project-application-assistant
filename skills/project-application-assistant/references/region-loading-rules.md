# 地区加载与记忆规则

## 默认范围

用户首次设置默认地区时只需填写省和地级市，默认加载该市、所属省和国家级政策。

例如“浙江省杭州市”的默认范围是：

1. 杭州市。
2. 浙江省。
3. 全国。

政策结果按本轮地区筛选，跨区或待核项目另列候选及适用条件。

## 市级与区级项目

- 市级项目沿当前企业地级市，按实际主管部门和地区规则查证。
- 区级项目沿已明确注册区或本轮区县；待确定时集中核对，本轮地区与长期偏好分别处理。
- 默认地区待定时按企业登记先定位，再核影响判断的具体地区。
- 用户在当前问题中明确其他城市或区县时，以本次显式地区为准，不修改默认地区。
- 省和国家项目按各自范围检索，并注明属地组织层级。

## 临时切换

- 用户明确要求检索其他地区时，在当前任务临时使用新地区，不更改默认地区。
- 已确认企业注册地与用户默认地区不同时，先提示差异，询问是否本次临时切换。
- 用户说“查全国”时可扩大范围，但仍需在结果中分区域标注。
- 只有“修改默认地区”、“以后默认查某地”等明确指令才更新持久记忆。

## 持久化顺序

1. 宿主平台的用户持久记忆。
2. 宿主无持久记忆时，使用 `scripts/user_region_profile.py` 管理的单一本地用户画像文件。
3. 宿主写入受限时，本轮继续应用，并说明跨会话保存状态。

地区偏好不包含密钥、密码或客户数据。
