# 地区加载与记忆规则

## 默认范围

用户首次设置默认地区时只需填写省和地级市，默认加载该市、所属省和国家级政策。

例如“浙江省杭州市”的默认范围是：

1. 杭州市。
2. 浙江省。
3. 全国。

不加载其他区县、其他地级市或其他省份的政策。地区标记为“待确认”的项目不进入默认结果。

## 市级与区级项目

- 用户只说“市企业技术中心”“市级绿色工厂”等市级项目时，默认使用画像中的地级市，不把“市级”固定解释为杭州市。
- 用户只说“区级绿色工厂”等区县级项目时，优先使用当前企业注册区或本次对话已明确的区县；仍无法确定时追问区县，不把区县写入长期默认画像。
- 默认地区尚未设置时，市级项目先问城市；区级项目先取得城市，再问本次适用区县。
- 用户在当前问题中明确其他城市或区县时，以本次显式地区为准，不修改默认地区。
- 省级和国家级项目不因默认城市、区县而缩小适用范围，但结果仍应提示企业所在地与申报组织层级。

## 临时切换

- 用户明确要求检索其他地区时，在当前任务临时使用新地区，不更改默认地区。
- 已确认企业注册地与用户默认地区不同时，先提示差异，询问是否本次临时切换。
- 用户说“查全国”时可扩大范围，但仍需在结果中分区域标注。
- 只有“修改默认地区”、“以后默认查某地”等明确指令才更新持久记忆。

## 持久化顺序

1. 宿主平台的用户持久记忆。
2. 宿主无持久记忆时，使用 `scripts/user_region_profile.py` 管理的单一本地用户画像文件。
3. 宿主不允许写入时，仅在当前会话保留，并明确告知用户无法跨会话记住。

地区偏好不包含密钥、密码或客户数据。
