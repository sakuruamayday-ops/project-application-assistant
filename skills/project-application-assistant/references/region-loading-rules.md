# 地区加载与记忆规则

## 默认范围

用户选择区县时，默认加载该区县、所属地级市、所属省和国家级政策。

例如“浙江省杭州市余杭区”的默认范围是：

1. 余杭区。
2. 杭州市。
3. 浙江省。
4. 全国。

不加载其他区县、其他地级市或其他省份的政策。地区标记为“待确认”的项目不进入默认结果。

## 临时切换

- 用户明确要求检索其他地区时，在当前任务临时使用新地区，不更改默认地区。
- 已确认企业注册地与用户默认地区不同时，先提示差异，询问是否本次临时切换。
- 用户说“查全国”时可扩大范围，但仍需在结果中分区域标注。
- 只有“修改默认地区”、“以后默认查某地”等明确指令才更新持久记忆。

## 持久化顺序

1. 宿主平台的用户持久记忆。
2. 宿主无持久记忆时，使用 `scripts/user_region_profile.py` 管理的单一本地用户画像文件。
3. 宿主不允许写入时，仅在当前会话保留，并明确告知用户无法跨会话记住。

地区偏好不包含密钥、密码或客户数据。
