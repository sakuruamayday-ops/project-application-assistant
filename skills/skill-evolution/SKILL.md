# 技能进化

在候选目录优化，稳定版本保留回滚点。比较事实准确、来源、任务完成、专业质量、自然表达及上下文成本，按用户当前目标直接形成差异并执行相称验证。

## 方法

1. 汇集 `experience-recorder` 和本轮已核问题，个人地域、语气、术语及格式偏好使用个人覆盖层，通用方法形成技能候选。
2. 批量任务可由 `skill-curator` 去重，读取 `evolution-batch.json` 的实际聚合结果；用户点名问题按当前范围处理。
3. 用 `skill-curator/scripts/build_impact_graph.py` 分析影响，候选包记录信号、任务、技能、规则键、预期差异、案例、测试和回滚点；未解析影响继续查证。
4. 使用独立样本比较旧版和候选，报告通过项、失败项和待验证项。共享运行时、身份权限、凭据、验签及发布行为衔接治理与宿主执行层。
5. 模型采用用户当前选择及宿主已有能力，外部评判与 GEPA 按实际任务、可用接口和费用授权使用；模型待配置时继续本地差异与规则测试。

输出候选及验证结果，正式合并、保存、签名、安装、发布和回滚按 `evolution-governance` 与用户指令执行。
