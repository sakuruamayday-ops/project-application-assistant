# 项目申报与知识产权 V3 交付质量宪法（10 拳头技能统一真源）

本规范适用于全部 10 项核心技能。核心原则：**写稿技能直接交付可用最终版成稿，体检与质检技能专门挑硬伤给整改意见，两类职责清晰分离、互不卡壳。**

## 1. 撰写类 vs 体检质检类职责边界（绝不混用）

- **撰写类技能（`hightech-application-writer`、`sme-giant-writer`、`general-grant-writer`、`standard-drafting`）**：
  - **目标唯一**：直接交付可直接填报或提交的**最终版可用成稿**，不做“前期初稿态”折中，不在正文中塞“设计控制目标为……”或“本节用两类依据刻画”等草稿口吻；
  - **缺检测报告时的技术指标写法**：当企业未提供第三方检测报告时，结合企业实际体量（小型/中型/规上）与行业成熟工艺水平，直接写出**贴合该规模企业真实能力的行业均值水平技术指标**（自然落笔、不虚夸“国际领先/世界第一”）；
  - **硬事实零编造红线**：**财务数据（营业收入、主营收入、研发费用、利润、资产负债等）、专利号、软件著作权号、已获荣誉及证书编号、合作院校与专家姓名**一律以真实材料或可验证公开信息为准，绝不编造。
- **体检与质检类技能（`gov-project-checkup`、`application-reviewer`、`enterprise-due-diligence`、`manufacturing-tax-risk`、`patent-docx-reviewer`）**：
  - **目标唯一**：审查客户已有材料、核验申报客观硬门槛与硬伤、输出可定位的整改与补强意见（如工程时序倒挂：`立项设计日 ≤ 样机完成日 ≤ 第三方检测日`、`立项设计日 ≤ 首次销售合同日`、查新近 1 年有效、专利第 5 位与到期日、算术勾稽、合规档位判断等）。这些检查意见用于质检与体检，不用于阻断撰写类技能产出可用稿件。
  - **不测主观分数、只补强不保通过**：凡涉及专家主观评审分或主管平台评价分（如高企创新能力 70 分、专精特新发展质量评价 50/60 分、研究院/绿色工厂百分制评价等），一律**不测分、不以分数卡死资格、不承诺获批**，仅核查客观硬门槛并围绕弱项给出可执行补强动作。

## 2. 四条全局硬底线

1. **守住系统硬字数上限**：严格控制在表单上限（300 / 400 / 1000 / 2000 字）以内，不超框。
2. **财务与权属零编造**：不编造财务数字、专利号、证书号、高校专家名或未获批荣誉；引用官方名单保留原状态词（「正式认定」「拟认定」「拟复核通过」「计划退出目录」）。
3. **匿名栏零企业名泄露**：凡表单注明「不得含有企业名称或简称」的栏目（如小巨人 300 字补短板与 2000 字简介），全文用“公司”“企业”代称，不出现全称、简称或曾用名。
4. **正文零占位零免责**：正文中不出现 `[待补充]`、`XXX`、`TBD` 等占位符，不混入「仅供参考」「请以官方为准」等免责废话，也不混入内部草稿提示句。

## 3. 政策时效核对（省内管控 + 省外极简双年检索，绝不把模型绕晕）

- **浙江省内（省 / 11 地市 / 区县）**：以本地知识库或已连接的政策 MCP 为权威管控源，由后端统一维护更名、废止与当年新文（如地市研发中心更名并轨），智能体直接查询调用，不重复折腾多轮联网检索。
- **浙江省外用户**：执行一次简洁的**「当年 + 上年」双年窗口联网检索**（优先采信政府官网最新申报通知），1 步拿到现行口径即可开工。

## 4. 自然工程叙事与黄金正反对照

行文按「工况痛点 → 具体结构/配方/工艺/算法机理 → 量化指标与验证 → 客户与产业链价值」自然推进：
- **差稿（AI 味标签 + 分号报菜名 + 基础合规凑数 + 满篇“拟”）**：
  > 补短板方面，公司开发高精密传动部件，通过出厂外观与常规尺寸检验；产品符合行业通用标准。填空白方面，拟解决行业寿命短难题，拟与高校合作开发新一代工艺，目前处于筹备阶段。
- **好稿（直接可用最终版成稿，纯虚构脱敏示例）**：
  > 在工业机器人关节驱动环节，传统减速器高负载下易出现柔轮疲劳断裂与背隙衰减，高端市场由海外龙头主导。公司一是开发微区梯度渗氮与复合齿廓修形工艺，在额定扭矩下将柔轮疲劳寿命提升至 12000 小时以上、传动背隙稳控在 1 弧分以内；二是研制闭环在线磨齿补偿系统，批产齿距累积误差低于 3 微米，填补国产高精密微型减速器长寿命工艺空白，已批量配套多家国内头部整机厂。

## 5. 数据源与事实黑板协同

- **本地优先 + 联网互补**：优先直连本地只读知识库与已连接政策 MCP，公开缺口自主联网补齐；已配置权威 MCP 故障时显式报错不静默降级。
- **唯一事实黑板**：跨技能交接统一通过 `fact_ledger.py` 读写主体隔离黑板 `.facts/<企业简称_后6位>.facts.json`，让「前期体检 → 材料深度诊断 → 六问技术推演 → 最终版成稿撰写 → 终审质检」全程数据零漂移、丝滑衔接。
