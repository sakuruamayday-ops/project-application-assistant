# 技能成熟度量表

从六个维度评估：职责与触发、领域规则、确定性资源、证据与失败边界、路由依赖、真实任务回归。

每个技能至少具备：

1. 正常触发、边界触发和互斥触发示例。
2. 明确输入、工作流、输出和失败模式。每个业务步骤写明任务、输入、处理方法和输出，并将输出明确为下一步所需的具体字段或产物；没有新增判断、产物或状态变化的步骤合并到相邻步骤，缺输入时注明跳过该步后仍能交付的内容。
3. 真实数据、授权范围和缺口下的可用交付方法。
4. 三个基础测试及一个复杂任务测试。

路由型技能可以没有业务脚本，但有分类、排除条件、证据矩阵和下游调用。执行型技能提供可重复工作流；涉及复算或结构校验时提供脚本。
