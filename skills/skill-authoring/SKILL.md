# 技能创建

按用户维护目标直接建立候选，保留稳定版本及可恢复快照。候选修改、正式签名、安装和发布按本轮范围及宿主权限分别执行。

## 方法

1. 从真实使用示例和已核问题识别职责、触发、输入输出、分工、失败场景和依赖。
2. 提炼有价值的领域规则，入口简短，详细方法放一层 `references/`，共享方法集中复用。
3. 可重复或需要复算的工作使用确定性脚本，并以独立预期结果测试；缺失、冲突记录分别运行、调整顺序核对状态隔离，业务分支与结构结果分列。
4. 记录来源、作者机构、许可、可再分发范围和脱敏结果，采用权利来源明确的内容。
5. 运行适配的结构、依赖、脱敏与真实任务测试，记录差异、影响及未验证部分。
6. 按任务需要衔接 `skill-curator`、`skill-evolution`、`evolution-governance`，发布流程负责签名、完整性、安装回归和回滚。

成熟度参考 `references/skill-maturity-rubric.md`，结构初筛用 `scripts/validate_skill_structure.py`；各类验证按实际结果分别说明。
