# 分类与映射规则

## 两套口径

《产业基础创新发展目录（2021年版）》使用五类：基础零部件和元器件、基础材料、工业基础软件、基础制造工艺及装备、产业技术基础。

部分专精特新“小巨人”申报表使用六个勾选项：核心基础零部件、核心基础元器件、关键软件、先进基础工艺、关键基础材料、产业技术基础。

输出同时保留“目录五基类别”和“申报表六基建议”，分别注明原名、版本及对应关系。

## 映射表

| 目录五基类别 | 申报表六基建议 | 判定要求 |
|---|---|---|
| 基础零部件和元器件 | 核心基础零部件或核心基础元器件 | 根据产品是否属于机械、液压、传动等零部件，或芯片、传感器、电子器件等元器件二选一；证据不足时写无法确认 |
| 基础材料 | 关键基础材料 | 核对企业主导产品本身的材料属性，生产耗材另作工艺事实。 |
| 工业基础软件 | 关键软件 | 企业主导产品应是目录所列软件或直接对应的软件产品 |
| 基础制造工艺及装备 | 先进基础工艺 | 核对企业实际掌握和应用的工艺；装备产品结合当期表单及通知确定选项。 |
| 产业技术基础 | 产业技术基础 | 企业应提供检测、计量、标准、认证、试验验证或公共技术服务等直接证据 |

## 实质匹配六要素

1. 对象一致：企业主导产品或技术与目录对象相同。
2. 功能一致：解决的问题和核心功能相同。
3. 材料一致：目录限定材料时，企业材料体系相符。
4. 工艺一致：目录限定工艺时，企业拥有并实际应用该工艺。
5. 场景一致：应用行业和使用环境没有实质冲突。
6. 环节一致：企业位于该产品技术对应的产业链环节，而非仅服务于该行业。

关键词命中后逐项核对六要素；关键冲突列候选匹配、差异和待核动作。
