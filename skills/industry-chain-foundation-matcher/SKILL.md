# 产业链与产业基础匹配

## 分类依据

产业链采用 `references/industry-chain-index.jsonl` 原层级路径，产业基础采用 `references/industry-foundation-index.jsonl` 的领域、五基和产品技术词；原始 PDF 在 `references/source-documents/`，疑点结合原文核对。

《产业基础创新发展目录（2021年版）》为五基口径，申报表六个勾选项按 `references/classification-rules.md` 映射，来源口径与表单口径分列。两份资料共同采用、共同更新，按用户指定作为默认有效分类依据；官方最新状态另行核验。目录匹配和项目资格分别判断。

## 匹配方法

1. 汇集产品名称、用途、材料或软件属性、工艺、客户行业、上下游及证据。
2. 用 `scripts/search_catalogs.py` 或两个 JSONL 索引检索，分别核对产业基础及产业链。检索数量说明词与范围，引用 `search_summary`；`normalized_term_matches` 表示规范化整词包含数，业务匹配另判断。
3. 比较对象、功能、材料、工艺、场景和环节；已检出且存在实质差异的词保留原词、位置及差异，整词命中与模糊召回分列。
4. 输出精确、近似、未命中，附文件、页码和原分类。专精特新或小巨人结合产品、技术、客户、补短板和有效 I 类权利作交叉佐证。

## 判断

精确匹配对应目录对象、实质功能及企业已形成的产品技术，限定属性逐项核验。例如力传感器需进一步确认机器人用途和六维属性；视觉检测需确认工业 3D 视觉传感器形态。

内嵌软件、自产自用部件可通过终端产品商业化，按实质技术功能评价；CAM 候选核对加工编程、路径生成等功能。IP 作为对应证据之一。

近似匹配同时给出最相似原目录项、相似点、差异和推定产业链及依据；可靠近似项待发现时写“当前目录未命中可靠近似项”。原目录与推定结果分列，原始层级和词项保持原文。

企业自述和目录冲突保留两种表述及待核点；多路径优先与产品收入、核心技术及客户对应者，其他列备选。当期通知分类另列适用性。

## 输出

| 字段 | 内容 |
|---|---|
| 匹配等级 | 精确、近似或未命中 |
| 产业链路径 | 原始完整路径或标明推定的路径 |
| 产业基础 | 领域、五基类别、产品技术原词 |
| 表单勾选 | 六个勾选项映射或待确认 |
| 依据与差异 | 对象、功能、材料、工艺、场景、环节及证据 |
| 待补项 | 合同、检测、专利、项目或产线资料 |
| 来源 | 两份文件、页码、2021 年版本及索引记录 |
| 来源状态 | 默认有效，更新状态随用户通知或核验记录填写 |

- `classification-rules.md`：五基与表单映射。
- `source-manifest.json`：来源、哈希、统计及许可。
- `source-documents/产业链架构(2).pdf`、`source-documents/工业六基领域目录(2).pdf`：原件，以上路径均位于 `references/`。
- `scripts/search_catalogs.py`：候选检索；`scripts/build_catalog_indexes.py`：按合法原件重建索引。
