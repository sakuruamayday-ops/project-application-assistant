# 高新技术企业认定政策工作基线

## 使用规则

本文件是便于预评估的工作基线，不替代当期政策核验。每次涉及精确门槛、截止日期、材料清单、知识产权使用次数或地方执行差异时，按以下顺序重新核验：

1. 科技部、财政部、国家税务总局现行文件；
2. 高新技术企业认定管理工作网及国家主管部门通知；
3. 申报地区当期认定通知、申报指南和系统提示；
4. 地方答疑或实务说明；
5. 咨询经验仅作风险参考，不得覆盖上位政策。

截至 2026-07-24 核验的国家工作基线：

- 《高新技术企业认定管理办法》，国科发火〔2016〕32号，科技部页面标注有效：
  <https://www.most.gov.cn/xxgk/xinxifenlei/fdzdgknr/fgzc/gfxwj/gfxwj2016/201602/t20160205_123998.html>
- 《高新技术企业认定管理工作指引》，国科发火〔2016〕195号，国家税务总局系统公开文本：
  <http://heilongjiang.chinatax.gov.cn/art/2016/6/22/art_4912_153619.html>

若检索到更新、废止、修订或属地特殊要求，以较新且层级更高的有效文件为准，并在报告中说明变化。

## 硬门槛

现行国家基线要求同时满足：

1. 申请认定时注册成立一年以上；
2. 通过自主研发、受让、受赠、并购等方式获得对主要产品或服务发挥核心支持作用的知识产权所有权；
3. 核心技术属于《国家重点支持的高新技术领域》；
4. 科技人员占企业当年职工总数比例不低于 10%；
5. 近三个会计年度研发费用总额占同期销售收入总额比例达到对应档次：
   - 最近一年销售收入不超过 5,000 万元：不低于 5%；
   - 5,000 万元至 2 亿元：不低于 4%；
   - 2 亿元以上：不低于 3%；
6. 境内研发费用占全部研发费用比例不低于 60%；
7. 近一年高新技术产品或服务收入占同期总收入比例不低于 60%；
8. 创新能力评价达到要求；
9. 申请认定前一年内未发生重大安全、重大质量事故或严重环境违法行为。

地区、年度和企业经营期口径以当期指南为准。

## 创新能力评价

总分 100 分，综合得分超过 70 分：

| 指标 | 满分 |
|---|---:|
| 知识产权 | 30 |
| 科技成果转化能力 | 30 |
| 研发组织管理水平 | 20 |
| 企业成长性 | 20 |

### 知识产权

主要评价项：

| 子项 | 分值 |
|---|---:|
| 技术先进程度 | 不超过 8 |
| 对主要产品或服务的核心支持作用 | 不超过 8 |
| 数量 | 不超过 8 |
| 获得方式 | 不超过 6 |
| 参与标准、检测方法或技术规范 | 参考加分不超过 2，且知识产权总分不超过 30 |

数量档：

- Ⅰ类 1 项及以上：7—8 分；
- Ⅱ类 5 项及以上：5—6 分；
- Ⅱ类 3—4 项：3—4 分；
- Ⅱ类 1—2 项：1—2 分；
- 0 项：0 分。

发明专利等按Ⅰ类评价；实用新型、外观设计、软件著作权等按Ⅱ类评价。具体分类、有效性和共有权属按当期工作指引核验。

主人于 2026-07-24 确认的实务口径：

- 曾申报未通过时使用的Ⅱ类知识产权不消耗使用次数，可以在后续申报再次使用；
- 曾在通过认定中使用的Ⅱ类知识产权按已使用处理，后续不能重复使用。

若后续出现层级更高、时间更新且明确冲突的官方口径，保留本规则及来源，提示冲突并请主人决定，不得静默覆盖。

### 科技成果转化

由技术专家结合总体情况和近三年年平均转化数量综合评价：

| 年平均转化数 | 分数区间 |
|---:|---:|
| 不低于 5 项 | 25—30 |
| 不低于 4 项 | 19—24 |
| 不低于 3 项 | 13—18 |
| 不低于 2 项 | 7—12 |
| 不低于 1 项 | 1—6 |
| 0 项 | 0 |

同一科技成果在不同地区、国内外或形成多个产品、服务、工艺、样品、样机时，不因此重复计数。

### 研发组织管理

四项现行国家基线：

1. 研发组织管理制度、研发投入核算体系和研发费用辅助账，不超过 6 分；
2. 内部研发机构、科研条件及产学研合作，不超过 6 分；
3. 成果转化组织实施、激励奖励及开放创新平台，不超过 4 分；
4. 人员培养培训、人才引进及绩效评价奖励，不超过 4 分。

### 企业成长性

分别评价净资产增长率和销售收入增长率，每项不超过 10 分。正常三年正数口径下：

`增长率 = 1/2 × (第二年 ÷ 第一年 + 第三年 ÷ 第二年) - 1`

每项评分档：

| 增长率 | 分数区间 |
|---:|---:|
| 不低于 35% | 9—10 |
| 不低于 25% | 7—8 |
| 不低于 15% | 5—6 |
| 不低于 5% | 3—4 |
| 大于 0 | 1—2 |
| 不大于 0 | 0 |

第一年为 0、第二年为 0、负净资产、合并范围变化或报表重述等特殊情况按工作指引和财务专业意见处理，不为了获得有利分数自行改造公式。
