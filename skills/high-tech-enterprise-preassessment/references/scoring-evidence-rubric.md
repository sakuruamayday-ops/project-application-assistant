# 非财务三项保守评分与证据规则

## 目录

1. 通用评分方法
2. 知识产权
3. 科技成果转化
4. 研发组织管理
5. 压力测试

## 1. 通用评分方法

对每个评分点建立四列表：

| 评分档 | 已确认事实 | 直接证据 | 缺口及影响 |
|---|---|---|---|
| 官方或属地评分档 | 不带评价的事实 | 可定位的原始材料 | 缺失后降到哪一档 |

评分规则：

1. 目标分取材料完整时可合理达到的分数。
2. 保守分逐项取直接证据支持的分档，说明争议和条件。
3. 压力分聚焦明确争议项逐项调整，同一原因集中说明。
4. 按关联性、真实性和时间线确定证据支持的分档，数量与关键技术链同时评价。
5. 内部细分标为预评估方法，官方规则逐条回指已公布原文。

## 2. 知识产权

### 2.1 技术先进程度

| 保守分 | 可支撑判断 | 典型证据 |
|---:|---|---|
| 7—8 | 解决明确行业问题，方案有实质创新，关键效果经验证并可与既有技术比较 | 权利要求、研发报告、试验或检测数据、工艺验证、公开技术基线 |
| 5—6 | 改进明确且有量化效果，但行业比较或验证链不完整 | 技术说明、内部试验、产品指标 |
| 3—4 | 一般结构、配方、参数或流程优化，效果主要依赖企业说明 | 专利文本、产品说明 |
| 1—2 | 改进轻微，指标与效果对应待核 | 零散说明 |
| 0 | 无有效知识产权或与申报技术无关 | — |

先核对技术问题、权利要求特征、指标、验证结果和相对改进，再确定技术先进性的证据支持分档。

### 2.2 对主要产品的核心支持作用

| 保守分 | 可支撑判断 |
|---:|---|
| 7—8 | 权利要求覆盖主导产品核心机制，并与主要高新收入形成闭环 |
| 5—6 | 支撑关键模块、工序或部分主要型号，收入映射仍有缺口 |
| 3—4 | 主要用于外围结构、辅助工艺或少量产品 |
| 1—2 | 主题相关，技术因果待补充 |
| 0 | 无实质关联 |

建立：

`知识产权 → 研发项目 → 核心技术 → 成果转化 → 高新产品或服务 → 收入`

以一件核心Ⅰ类 IP 为主轴，其他权利按结构、工艺、软件和应用关联程度选用。

### 2.3 数量

按当期指引分类评价，保守分采用官方区间下沿，上沿结合充分证据和组合判断；审中、失效、权属或使用待核项单列状态。

### 2.4 获得方式

| 保守分 | 可支撑判断 |
|---:|---|
| 6 | 自主研发，发明人、项目、人员、费用、试验和专利时间线完全一致 |
| 4—5 | 自主研发成立，但项目、人员或费用链存在非关键缺口 |
| 2—3 | 受让取得，但有真实消化吸收和产业化 |
| 1 | 仅有受让手续，与企业研发活动关联弱 |

检查专利申请时间是否落在项目实施过程中，避免“专利先取得、项目后补立”等时间线倒挂。

### 2.5 知识产权补强

证据补强：

- 权利要求—核心技术特征对照表；
- 技术问题—方案—指标—效果说明；
- 研发项目、人员、费用、试验、定型和量产时间线；
- 检测、试验、生产或客户应用记录；
- 知识产权法律状态、权属和Ⅱ类使用记录；
- 与高新产品和收入的映射。

Ⅱ类使用记录区分：

- 曾在未通过的高企申请中使用：仍可再次使用；
- 曾在通过认定中使用：标为已使用，后续评价选择符合使用规则的其他权利。

事实补强：

- 开展真实对比试验、检测或生产验证；
- 形成与主营产品核心技术匹配的新知识产权；
- 完成受让技术的消化吸收和产业化记录。

未授权 IP 按实际状态列入后续布局，当前评分使用适格有效权利。

## 3. 科技成果转化

### 3.1 四段证据链

每项成果至少核对：

1. 成果来源：专利、技术诀窍、配方、软件、研发项目成果或工艺；
2. 转化过程：试制、中试、工艺验证、部署或生产导入；
3. 转化载体：产品、工艺、材料、服务、样机、软件或装备；
4. 应用成效：检测、生产、销售、验收、客户应用或降本增效。

### 3.2 保守计数

| 状态 | 处理 |
|---|---|
| 四段闭环、边界与时间清楚 | 计 1 项 |
| 有成果、载体和应用，过程证据稍弱 | 可计 1 项并标记中等证据 |
| 只有证书、照片或自述 | 转化实施证据待核，先列布局与补证 |
| 同一成果形成多个型号、产品或地区应用 | 原则上只计 1 项 |
| 同一专利用于多个产品 | 按同一成果归集，分别说明应用 |
| 一个项目产生多项独立成果 | 技术边界和应用载体独立时分别判断 |
| 计划研发、尚待应用 | 列未来转化任务 |

先计算近三年保守有效数量和年平均数，再进入官方分数区间。处于同一区间时，根据闭环比例、成果独立性、应用成效和跨表一致性决定区间内分数。保守分通常从区间下沿起评。

### 3.3 成果转化补强

证据补强：

- 项目结题、成果确认和技术评审；
- 试制单、中试记录、样品和生产任务单；
- 工艺变更、配方版本或软件上线记录；
- 检测、验收、生产和销售材料；
- 首次应用时间及成果独立性说明。

事实补强：

- 完成新的研发成果、试制、验证和生产导入；
- 形成可追溯的首次应用和成效记录。

同一成果统一归集，转化年度、次数和应用按实际记录统计。

## 4. 研发组织管理

按“制度—执行—结果”核验，分档与实际执行及结果证据相称。

### 4.1 研发管理与投入核算

内部参考拆分：

| 核查点 | 参考上限 |
|---|---:|
| 制度正式发布、职责清楚 | 1 |
| 真实立项、评审、过程和结题管理 | 2 |
| 研发核算体系和辅助账 | 2 |
| 项目、人员、费用、成果对应 | 1 |

### 4.2 研发机构、条件与产学研

核查研发机构、固定人员、场地设备、试验条件、合作协议、付款、技术交付和验收。只有挂牌机构或框架协议时降低保守分。

### 4.3 成果转化与激励

核查转化制度、成果确认、奖励办法、实际奖励记录及开放创新活动。制度未执行时只支持低档分。

### 4.4 人才培养与绩效

核查培训计划、签到和结果，人才引进，研发人员绩效办法、真实考核和奖励。

### 4.5 组织管理补强

证据补强：

- 组织架构、岗位职责和人员名单；
- 立项、评审、阶段检查和结题记录；
- 研发辅助账及项目费用归集；
- 研发设备及使用记录；
- 产学研技术交付和验收；
- 成果奖励、培训和绩效执行记录。

事实补强：

- 建立并持续运行项目管理、辅助核算、产学研、奖励、培训和绩效机制；
- 从当前日期开始真实留痕。

新建制度注明建立日期；历史执行按当时真实记录说明。

## 5. 压力测试

模拟三类审查：

1. 技术专家：质疑先进性、核心支持作用、成果独立性和应用效果；
2. 财务及材料审查：核对研发费用、高新收入、销售、人员和成果时间线；
3. 合规审查：核对权属、法律状态、Ⅱ类使用、重复成果和制度真实性。

压力分按具体子项的证据定位和实际缺口调整，逐项说明原因。
