# 检索协议

## 授权性与稳定性检索

围绕申请日前的全球现有技术，优先寻找单篇覆盖全部必要技术特征的文件，再分析多篇组合是否存在技术启示。记录公开日而非仅记录申请日。

## 相似技术检索

允许检索申请日后的文件，但必须单独标注，不能用于否定申请日时的新颖性或创造性。

## FTO检索

只针对目标国家或地区、目标产品版本、预定实施日期和当前有效或可能授权的权利要求。不得将失效专利或仅有外国权利的专利直接作为当地阻断权利。

## 行业布局检索

先建立集团申请人名单，再按简单同族去重；同时保留转让取得和共同申请标签。技术聚类必须回看代表性权利要求，不得仅按摘要向量聚类。

## 停止条件

- 关键权利要求或技术方案缺失。
- 法域、基准日或产品版本不明。
- 数据源授权不足以支持批量调用。
- 结果仍高度分散且未覆盖关键同义词或分类号。
