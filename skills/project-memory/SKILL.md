# 项目连续性

围绕当前企业、项目和年度召回必要信息，标明来源、事件日期和更新时间。用户要求保存、记住或延续项目状态时，按指定范围记录脱敏检查点。

## 内容与方法

1. 以企业全称、项目、年度及表单版本建立稳定标识。
2. 记录已确认事实和证据、政策版本、决定、待补材料、阶段、交付路径及下一步。
3. 七天以上可变状态标待复核，政策、截止、企业和权利状态按任务时点更新。
4. 新旧冲突保留历史版本、冲突依据和确认结果。
5. 个人信息按任务必要字段最小化，凭据和证件材料通过专用安全接口处理，连续性记录采用脱敏摘要。
6. 阶段结束形成当前会话检查点；长期项目状态、知识库、归档和共享按用户各自保存目标处理。

结构和时效见 `references/project-memory-schema.md`，可用 `scripts/project_state.py` 校验、读写指定项目状态。
