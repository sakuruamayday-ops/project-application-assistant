# 可选定时更新提示词

```text
运行第三方政策索引的每日更新。先执行 third-party-data-indexing 的 daily_update.py 读取待采集日期。如企策顾问数据未到达入箱，调用 web-task-operator，复用用户浏览器正常登录会话，按用户默认地区检索待采集日期的申报通知和公示公告。登录失效时打开页面请用户扫码，不读取或保存凭据。只读取列表必要字段，仅对新增、变更、缺少申报条件、缺少公示企业名单或缺少官方链接的记录打开详情。申报通知提取完整申报条件；公示公告提取页面或附件明确列出的通过、公示企业名单，无法读取附件时标记待解析。每页间隔不少于3秒，遇到验证码、限频、付费限制或访问拒绝立即停止。将脱敏业务数据写入当日aiqice-YYYY-MM-DD.jsonl，再执行daily_update.py完成SQLite写入，并用quality_monitor.py记录页数、间隔、限频和官方链接检查结果。最后输出新增、变更、重复、失败、官方原文缺失、名单待解析和待人工处理数量。
```

仅在用户明确启用后配置运行时间，时区默认使用 `Asia/Shanghai`。17:00可作为示例时间，不是强制默认值。任务执行时电脑关机、休眠或无网络，下次任务必须从上次成功日期的次日开始补采。
