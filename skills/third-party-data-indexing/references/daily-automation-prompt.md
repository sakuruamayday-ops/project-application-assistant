# 可选定时更新提示词

```text
执行已授权每日索引：`daily_update.py` 取日期；数据待入箱时以 `web-task-operator` 复用正常登录会话，按地区查通知、公示和必要详情。凭据留安全会话，条件及名单按原页附件记录，缺项标待解析；按网站允许频率处理，访问受限转人工或授权来源。脱敏数据写当日 JSONL 后入 SQLite，以 `quality_monitor.py` 记录质量，输出增量及待核数量。
```

仅在用户明确启用后配置运行时间，时区默认使用 `Asia/Shanghai`。17:00可作为示例时间，不是强制默认值。任务执行时电脑关机、休眠或无网络，下次任务从上次成功日期的次日开始补采。
