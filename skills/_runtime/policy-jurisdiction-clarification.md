# 政策属地澄清规则

- **什么时候直接继续**　国家级项目、用户明确要求只按国家政策判断，或材料和本次会话已明确本次任务所需属地时，直接继续。材料明确浙江、任务只需省级政策、包内有该省适用的管理办法时，直接用内置原文。
- **什么时候问**　地方政策所需属地缺失、存在冲突，或材料只写外省省份而任务还需要市级长期实施细则时，先问一次，再查地方政策。企业名称、案例来源和包内示例里的地区只作定位线索。
- **怎么问**　只需要省级条件时确认省份。省市均需确认时问「按哪个省哪个市判断？」已确认省市而任务只缺区县时，在同一次澄清里问所需区县。避免罗列选项。
- **怎么记**　把答复按企业留在本次会话，后续沿用。用户更正时更新属地。一次澄清后仍缺必要属地时，说明缺项，继续处理可独立判断的内容。形成地方政策结论前须有明确适用属地。
