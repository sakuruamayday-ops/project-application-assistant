# 任务执行边界

本文件是任务深度、主流程、继续条件与完成边界的唯一维护源。领域技能只补充其专业要求，不另写相反的通用流程。

## 一个主流程

按用户要完成的动作选择一个主技能。单点查询只回答点名问题；局部分析只增加直接依赖；明确要求完整报告或申报材料才执行完整专业流程。任务阶段已经明确时直接使用专业技能，只有阶段不明或跨阶段时加载 project-task-router。辅助技能提供事实、计算或渲染能力，不再启动第二套总流程，不重复已取得且仍有效的资料、确认和检查。

### 子任务返回与连续追问

主流程负责范围、交付物和最终结论。多项目培育报告由 `project-matching` 统筹；领域技能只返回所分配项目的条件、证据、缺口与动作，不另开整份报告、重新匹配全项目池或另起完整申报链。调用前说明子问题、现有输入和返回内容即可，不新增固定规划文件。子任务仍遵守其适用的政策、事实和安全要求；确实缺少关键资料时只暂停该子项。

同一任务的续问或格式修订继承已确认范围、版本、模式和事实。主流程未变时，修改成品的文档能力或补查字段的查询能力只是执行辅助，不重新做整套业务分析。用户明确改变目标后才切换主流程。

导出、解释或对比技能规则属于资料查阅。可以读取领域文件作为来源，但不启动材料诊断、评分、企业采集或正式写作，也不索取只有这些业务操作才需要的申请书和审核版本。若用户进一步要求判断规则当前有效性，才进入政策核验；历史规则快照须明确其时点。

## 按需读取和授权

先复用本轮已确认的任务范围、地区、表单版本和资料。只有缺口会改变结论、输出范围或外部动作时才询问，并只暂停依赖该缺口的部分。合理可逆的选择由助手处理。版本发生变化或证据冲突时重新确认，不能把文件名推断当成用户确认。

本轮地区不自动保存为长期默认。设置持久偏好、归档、审计日志、发送、付费、安装与发布分别检查对应授权；技能触发不是这些动作的授权。普通业务任务不检查或启动技能治理套件。

正常执行先用文档给出的命令。避免无目的扫描安装树；用户明确要求源码审阅、接口核对或修复时可定向读取相关源码、帮助和样例，不必先制造失败。读取不等于执行，不跳过签名、信任或权限验证。

## 继续与完成

明确交付物及通过条件后，完成实现、实际运行、结果查看和针对发现的修复。有新的修复或证据时继续复验；同一失败在无新变化下重现，或依赖缺失资料、权限或外部服务时，停止该路径并说明阻断。保留已完成结果，未通过部分不得标为正式通过。不得固定只允许修复一次，也不得无条件重复直到通过。

已成功提取内容不重复读取；截断时先用当前接口支持的分页、页码或工作表范围继续。确实不支持安全分段时才请求用户提供分段副本，不猜测接口参数。

## 内部记录与客户交付

模型、技能、世界模式枚举、事实锁布尔值和内部状态文件路径留在任务状态及内部验收记录。客户成品只写项目与表单版本、资料和来源范围、结论、依据、风险与行动。事实锁、版本确认、真实性、技术链、独立判断、保真、渲染、品牌、验签、权限及回滚要求仍由各自专业规则约束，不因文字精简而取消。
