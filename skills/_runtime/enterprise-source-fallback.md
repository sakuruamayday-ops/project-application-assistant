# 企业数据源有限降级协议

企业公开事实沿“天眼查→企查查→本轮可核验资料→政府或法定机构”取证；后序来源补缺口和冲突，成功结果直接复用。

瞬时错误可重试一次；授权、401/403、额度、限流或工具受限时记录实际响应，直接沿替代来源继续。

商业源调用失败时沿替代链继续。主体身份、资格、法律状态、关键数字或正式结论仍有缺口时，交付“待完善”稿并汇总字段和补证动作；其余缺口标为“未核验”。如实区分未命中、部分覆盖和已核验，只复查失败或冲突的环节。

多个来源冲突时保留差异，并以市场监管、司法、知识产权主管机关、项目主管部门或其他相应官方原文裁决。商业平台只提供其实际返回的字段，不推测免费额度、更新时间、未公开规则或失败原因。
