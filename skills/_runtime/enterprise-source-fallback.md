# 企业数据源有限降级协议

企业工商、股权、人员、风险、经营、融资、招投标、知识产权及资质等公开事实，按“天眼查 → 企查查 → 用户当前提供且可核验的资料 → 政府或法定机构官方来源”顺序执行。后续来源只补齐前序来源未覆盖、状态不明、相互冲突或会改变结论的字段；同一任务已取得的成功结果直接复用，不重复调用刷新回执。

同一提供商、工具和参数发生超时、连接中断或服务端临时错误时最多重试一次，第二次失败立即转下一来源。用户取消授权、拒绝登录、返回 401／403、额度或限流错误、工具未知或不支持时不重试，也不再次弹出授权；直接记录实际状态并转下一来源。

任一商业源不可用都不得单独终止任务。替代链结束后，缺口会改变主体身份、资格、法律状态、关键数字或正式结论时，交付状态为“待完善”，列明缺少的字段和可执行补证动作；缺口不改变核心结论时，只把对应字段标为“未核验”。不得把未命中写成不存在，不得把部分覆盖写成全维核验，不得因校验失败自动重新开始整条采集链。

多个来源冲突时保留差异，并以市场监管、司法、知识产权主管机关、项目主管部门或其他相应官方原文裁决。商业平台只提供其实际返回的字段，不推测免费额度、更新时间、未公开规则或失败原因。
