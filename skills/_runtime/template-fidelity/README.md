# 模板原样填充门禁

当用户提供 Word 模板并要求“按原格式生成”“完全按照模板”或同义表达时，默认进入严格原样填充模式：

- 复制并填充原母版的 OOXML，沿用其段落、表格、样式、页眉页脚和页面结构。
- 只允许替换 `word/document.xml` 中既有的 `w:t` 文字节点。
- 字体、字号、颜色（包括红字）、加粗、下划线、段落、制表位、抬头、页眉页脚、表格网格、列宽、行高、合并单元格、边框、节属性、页面边距、图片和关系文件保持不变。
- 原样填充时保留既有段落、文本运行、表格、行列、单元格、分页符、分节符、内容控件及媒体。
- 文本长度导致分页、行高或表格边界发生视觉漂移时，优先压缩文字；沿用原字号、行距、边距与版式。

交付前运行：

```bash
python3 skills/_runtime/template-fidelity/scripts/validate_docx_text_only.py \
  原模板.docx 输出文件.docx \
  --report 模板保真审计.json
```

只有返回 `status=pass`，并完成逐页视觉检查后，才可报告“按原模板生成”。逐页视觉检查至少覆盖页数、抬头、页眉页脚、红字、表格边界、合并单元格、分页、溢出、重叠和空白页。

如果用户明确要求增加 RD、PS 等重复表格，属于“结构扩展模式”，记录为结构扩展，深拷贝模板中完整的同类 OOXML 片段，沿用原版式；扩展后按需要查看页面并记录新增结构。
