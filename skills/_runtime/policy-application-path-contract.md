# 前期评估政策申报路径合同

## 适用范围

本合同适用于企业前期评估、培育规划、项目匹配、多项目矩阵和年度申报路线图。报告不得只回答“现在能报什么”，还必须回答“企业未来应建设什么、沿什么梯度申报、何时重新判断”。

## 完整性闸门

1. 先按企业注册地区、行业、产品、研发、知识产权、制造场地、数字化、绿色发展、质量品牌和投资计划建立“理论相关项目池”，再判断当前成熟度。
2. 与企业经营和培育目标相关的项目，即使当前不具备条件、近期不准备申报或优先级较低，也必须保留在正文政策路径中。常见建设型项目包括研发机构、绿色工厂、数字化车间、智能工厂、知识产权示范、高价值专利组合、制造精品和首台套。
3. “暂不建议申报”只能降低优先级，不能删除路径。必须同时写明当前起点、缺口、先行建设、触发条件和建议重检年度。
4. 只有与企业地域、行业、产品、经营实质和规划目标均无合理关联的项目，才能排除。排除时写明边界，不为凑数量混入人才、农业或其他无关项目。
5. 报告摘要可以突出重点，但正文必须保留完整项目池和建设路径。不得把“优先级清单”冒充“政策申报路径”。

## 项目路径卡固定字段

每一个正文项目至少包含以下十二项字段；同一梯度的连续项目可以合并成一张路径卡，但不得省略中间建设阶段。

1. 标准项目名称、稳定 `project_id`、主管部门和政策级别；
2. 政策状态、适用地区、政策基准年度、官方来源和时效说明；
3. 对企业目标的作用，包括前置资格、能力建设、质量评价、产业链叙事或资金支持；
4. 企业当前起点和证据状态，区分已具备、企业自述、冲突、缺失和待系统判断；
5. 先行建设任务，包括组织、人员、场地、设备、制度、数据、产品、知识产权、项目备案或第三方评价；
6. 梯度路径和依赖关系，明确先做什么、后报什么；
7. 建议申报年度、准备起止时间和当期通知发布后的重检节点；
8. 典型申报流程，包括企业填报、属地审核、推荐、专家评审、现场或系统核查、公示和认定；
9. 核心证据和材料清单；
10. 关键门槛、当前差距、停项条件和重新启动条件；
11. 优先级和与目标项目的关系；
12. 下一步动作、责任人和最晚完成节点。

当前年度官方通知尚未发布时，允许使用现行管理办法和最近一年度已核验通知作为建设参考，但必须标注“规划参考”，不得复制历史截止日、奖补金额或年度特有门槛。发布当期通知后须整体复核。

## 输出分层

- `立即申报`：当期政策已核验，企业硬门槛和材料基本闭合；
- `建设后申报`：项目相关，但须先完成明确的能力建设；
- `条件触发`：只有场地、投资、产品成熟度、收入规模或产业化边界达到触发值后启动；
- `长期梯度`：两年以上才具备现实申报条件，仍须列出前序建设；
- `排除`：与企业经营和规划均无合理关联，写明排除理由和重新纳入条件。

优先级与适用性是两个维度。低优先级不等于不适用，长期梯度不等于可以省略。

## 三类校验示例

### 正常案例

制造企业尚无研发中心、绿色工厂。报告必须保留“内部研发机构建设—区县或市级研发机构—更高层级研究院”和“制造边界确认—能源环境数据建账—地方绿色制造培育—国家绿色工厂”的路径，并把当前结论写为建设后申报或条件触发。

### 边界案例

目标年度通知尚未发布。报告使用现行办法和最近已核验通知说明建设方向，标注政策基准年度，给出通知发布后的重检节点，不填写未经核验的截止日、奖励金额或确定资格结论。

### 拒绝案例

环保装备制造企业没有农业经营、农业设施或涉农投资计划。不得为了“政策全量”混入未来农场、农产品加工等项目；应写明本轮范围是与企业经营和目标相关的完整路径，而不是跨行业政策百科。

## 交付前自检

- 是否同时覆盖当前可报、建设后可报、条件触发和长期梯度；
- 是否因“企业暂时不需要”“优先级低”而删除了相关项目；
- 是否至少覆盖研发平台、绿色发展、数字化、知识产权、质量品牌和主目标梯度中的适用方向；
- 是否每个项目都有建设动作、依赖、年度、证据、门槛和停项条件；
- 是否把历史通知明确标为规划参考，并设置当期重检节点；
- 是否把与企业完全无关的项目排除并说明边界。
