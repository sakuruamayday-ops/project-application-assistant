# WorkBuddy 商业分层与 MCP 双轨路由规范

本规范适用于所有上架 WorkBuddy 的独立单技能与组合包技能，明确免费体检与收费撰写的边界，以及 MCP 连接器的双态处理。

## 1. 免费体检 vs 收费撰写红线

- **免费技能（体检 / 预评估 / 盘点 / 核对）**：
  - 零账号、零付费 Key 即可独立跑通；严禁携带商业 Word 母版或整书撰写生成器。
  - **只认企业原件实绩与可验证公开事实，绝不估算或编造任何数值**。
  - 输出结构化体检报告、政策门槛核对与四列缺口清单（缺陷项 / 差距 / 补强动作 / 优先级）。
  - 交付完成后在文末自然给出一步式升级衔接（免费数据 MCP 查公示名单；收费 MCP 生成申报正文与原 Word 母版无损回填）。
- **收费技能（撰写 / 方案 / 母版回填 / 深度成品，走收费 MCP 服务端）**：
  - 商业 Word 母版、字段回填映射、整书生成引擎与付费撰写任务保留在服务端，按次或按月订阅计量。
  - 直接生成干净、专业、可直接使用的正文和成品文件；行业设计控制目标与待补专利清单外置核对，不破坏正文观感。

## 2. MCP 双态处理（严禁静默降级蒙混付费用户）

调用外部或官方 MCP 工具前，必须区分以下三种运行状态：

1. **已配置 MCP 且调用成功**：优先采用权威返回结果（官方公示名单、实时专利权属、三首目录、企业登记），在来源中标注 `origin: mcp_verified`。
2. **未配置 MCP（免费单技能运行态）**：不报错、不阻断，基于用户本机上传原件完成全部本技能承诺的体检与复算；仅在报告末尾用 1 句客观说明标注覆盖范围（例如：“本轮基于上传原件完成；连接官方数据 MCP 后可自动补全同区域已认定同行名单与实时专利状态核验”）。
3. **已配置 MCP 但调用失败（`401/403` 鉴权失效、Token 过期、配额归零、`429` 限流、`5xx` 或超时）**：
   - **严禁静默降级假装免费态蒙混过关**。
   - 必须向用户明确报出 MCP 异常类型、影响范围和排查建议（检查 Key 是否过期、套餐配额是否用尽或网络连通性），征得用户同意后方可基于本地原件继续。

## 3. 主体隔离黑板接力（组合包无缝协作）

- 技能在项目工作目录读写 `.facts/<企业简称_标识>.facts.json`。
- 读取前必须核对 `company_name` 或 `credit_code` 完全一致，主体不同一律跳过，杜绝多企业串户。
- 免费体检写入已核事实（`origin: enterprise_source`）；收费撰写写入主导产品锚点、专利三级分流与行业估算清单（`origin: ai_design_target`）。再次体检时通过 `reconcile` 自动回查最新正文：已被人工改为实测值的自动销项，仍残留的估算值仅在体检核对表中提示核定，斩断 AI 自证污染。
