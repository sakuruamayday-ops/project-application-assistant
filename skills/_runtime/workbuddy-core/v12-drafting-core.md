# 申报正文撰写共用底座（v1.2 定稿口径）

本底座供收费撰写引擎（高企申请书撰写、专精特新撰写与培育、后续省级企业研究院与三首申报撰写）共用，保持“去过度防御、直接出专业可用正文”的统一标准。

## 1. 直接交付干净专业正文（优先级高于旧版占位规则）

- 本底座在收费撰写任务中**优先级高于历史参考文档中的旧“填 `null` / 填 `XXX`”占位规定**：直接输出可直接贴入申报系统或回填 Word 母版的专业正文，**不在正文中插入刺眼括号提示、免责声明或刷黄底纹**。
- 严禁出现 `RD01/PS01/IP01` 内部编码、`fact_id`、“资料未提供”“仅供参考”等审校口吻。
- 所有需要企业核对的估算指标、缺失原件和待补专利，统一外置到独立的《交付核对与补强清单》（固定含 `estimatedMetrics`：`metricName / suggestedValue / snippet / origin: ai_design_target / calibrationHint` 及四列补强表），绝不污染正文。

## 2. 主导产品双字段锚定与业态三分支

1. **双字段锁定（纯技术与产品实质导向，与发票无关）**：
   - `rawAnchor`：企业真实生产并对外销售的产品实体或核心技术载体（依据技术资料、产品目录、官网、专利与企业自述锁定边界，不依赖也不强求开票明细，例如“精密传动部件”“功能性复合包装容器”）。
   - `formalDeclarationName`：结合工业“六基”、产业链卡位与真实/成熟工艺特征升维后的申报规范名（如“基于精密热处理与自润滑表面调控工艺的高耐久传动部件”）。
   - 升维引入但企业尚无授权发明专利覆盖的工艺特征词，记入 `unpatentedProcessTags`，在交付清单中直接转化为《主导产品发明专利补强建议》（闭环六问 Q2）。
2. **业态预判三分支**（防止误杀设备厂，也防止制品厂拿设备充数）：
   - `equipment_or_mold_maker`（装备/模具制造型）：设备/模具专利直接作为核心主导产品依据，不降权不过滤。
   - `product_or_material_maker`（制品/材料制造型）：自用生产设备/模具专利降权归入 `production_support`，严禁用于主导产品定名，仅在工艺与组织能力段作加分支撑。
   - `ambiguous`（信息不足或冲突）：给出“终端制品方向”与“装备/模具方向”双候选供快速确认。

## 3. 专利业务向三级分流与兜底

- `direct_support`（一档）：直接支撑主导产品核心结构、配方或机理的有效专利，展开写核心技术。
- `production_support`（二档）：自用工装、模具、检测或生产设备专利，写入制造工艺支撑，不冒充主导产品。
- `weak_or_unrelated`（三档）：凑数或跨领域专利，仅计入数量汇总，不污染核心技术叙事。
- **全凑数兜底**：当 `direct_support` 为空时，死锁 `rawAnchor` 不跑偏，转用企业官网工艺、实用新型/软著与行业典型工艺窗口成稿，并在外置补强清单里给出发明专利挖掘主题，绝不清空正文。

## 4. 技术指标与行业典型工艺窗口

- 有企业实测/检测数据时：原样保留指标名、数值、单位、测试方法与工况，表述为“〈指标〉实测为〈数值与单位〉（〈方法/条件〉）”。
- 缺第三方检测数据时：结合该企业实际规模与行业成熟工艺实践，直接写入贴合行业均值水平的务实技术指标与工艺窗口（直接出最终版成稿，不在正文里加“设计控制目标为……”等草稿标签，也不伪造检测机构、报告编号或财务数字）。
- 传统制造业按材料、结构、模具、工艺参数、温湿度/压力/公差控制与过程检测写作，不堆砌无依据的 AI/数字孪生术语。

## 5. 字数与结构红线

- **只设上限、不凑下限**：资料有限时写透已有事实即可，宁短勿凑、宁短勿编。
- 高企 RD 核心技术及创新点、PS 三栏、企业创新能力四栏：按网报系统口径，**整栏（含“所属技术领域：...”行与小标题）总计不超过 400 字**。
- 专精 06 / 企业简介八段：企业基本情况三段 + 主导产品及技术五段，**精细化管理固定在产品技术第 4 段（全篇第 7 段）**。

## 6. 正向黄金示范样段（锚定多模型质量下限）

> **示例（高企 RD/PS 关键技术及主要技术指标 · 食品连续化加工装备）**
> 所属技术领域：先进制造与自动化—先进制造工艺与装备—轻工、食品加工专用设备制造技术—连续化食品热加工与成型装备技术。
> 关键技术：
> 1、分区温湿联动预热定型技术：针对冷冻面坯在连续输送中受热不均导致的起酥分层与边缘翘曲问题，采用多温区独立 PID 加热与动态蒸汽补湿联动机构，稳定面团筋度与水分分布，预热腔温控范围 60—90℃、温区均匀性偏差 ≤±2℃，动态相对湿度稳定控制在 55%—75% RH。
> 2、伺服同步成型压制技术：通过双轴伺服同步驱动与快换模腔结构实现批产节拍稳定与厚度一致，批产饼坯直径与厚度公差控制在 ±1.5 mm 以内，产线连续稳定运行时间 ≥16 小时/班次。
