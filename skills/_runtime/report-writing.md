# 报告写作

沿用当前任务已确认的章节、表格、字段和母版，用本轮资料直接形成可用稿并交付。

- 先给本企业结论，再写支持它的事实、数据、来源、风险含义和行动。行业通识、通用政策背景和过程说明压到必要程度。
- 同一事实、判断和资料清单优先集中呈现，跨章用短引用承接；法定表单或模板重复必填的字段照常填写。
- 已取得内容先写，事实、计算、推断及待核状态标清。缺口汇总为 `待取事项｜影响的判断｜补充或核验动作`，与现有结论一同交付；当前模型根据证据强度选择合适措辞。
- 股东、持股、实控人与关联主体等基础事实照常保留。股权服务按四类公开信号选择相关访谈线索：持股集中且兼任经营职务；控制多类主体；关联主体共用业务资源；新设、投资扩建、融资、接班、激励或资本计划。用 `信号｜讨论价值｜下一步` 简写，具体方案结合访谈及财税测算形成。
- 未分配利润等财税议题依据用户提供的资料和实际需求展开，缺项并入待取表。其他服务机会同样从企业实际信号引出。
- 内容、来源、品牌和视觉检查按任务需要进行，发现问题随稿说明并修订；交付状态以实际检查范围和结果表述。
