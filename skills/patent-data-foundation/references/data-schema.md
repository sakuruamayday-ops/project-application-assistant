# 标准专利记录

## 必填字段

| 字段 | 含义 |
|---|---|
| publication_number | 公开号或公告号 |
| application_number | 申请号 |
| jurisdiction | 法域 |
| document_kind | A公开版、B授权版或其他文本版本 |
| title | 发明名称 |
| filing_date | 申请日 |
| priority_dates | 优先权日列表 |
| applicants_original | 原始申请人 |
| owners_current | 当前权利人 |
| inventors | 发明人 |
| ipc | IPC分类号及版本 |
| cpc | CPC分类号及版本 |
| legal_status | 审中、有效、失效、终止、届满或无法确认 |
| status_sources | 官方登记簿、官方公报、第三方数据库及核验日期 |
| simple_family_id | 简单同族标识 |
| extended_family_id | 扩展同族标识 |
| source_url | 原始来源 |
| retrieved_at | 获取时间 |

## 主体归一化

保留原始名称和规范名称。集团归属必须给出工商关系、地址、统一社会信用代码、转让记录或其他可核验证据。曾用名、子公司、参股公司和合作申请人不得混为一类。

## 统计口径

任何专利数量结论同时说明去重层级和法律状态基准日。默认以简单同族统计独立技术主题，以扩展同族发现关联申请，以中国有效授权统计国内现行权利。
