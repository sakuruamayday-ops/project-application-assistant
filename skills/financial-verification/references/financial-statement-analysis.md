# 三表联读与财务健康分析

本方法用于在可靠财务资料已经锁定后联读资产负债表、利润表和现金流量表。它不提供无来源的行业阈值，也不替代审计或税务鉴证。

## 固定顺序

1. 先核对资产等于负债加所有者权益、期初期末衔接及合并范围。
2. 再分析收入、成本、期间费用、利润总额、所得税和净利润的变化。
3. 最后比较经营活动现金流、投资活动现金流和筹资活动现金流，判断利润是否转化为现金。
4. 将应收账款、存货、预付款、其他应收款、短期借款和应付账款与收入、成本及现金流联动解释。

## 可复算指标

- 毛利率 = 营业收入减营业成本，再除以营业收入。
- 净利率 = 净利润除以营业收入。
- 经营现金净流量利润比 = 经营活动现金流量净额除以净利润。
- 流动比率 = 流动资产除以流动负债。
- 速动比率 = 流动资产减存货，再除以流动负债。
- 利息保障倍数 = 息税前利润除以利息费用。
- 应收账款周转天数 = 平均应收账款除以营业收入，再乘以期间天数。
- 存货周转天数 = 平均存货除以营业成本，再乘以期间天数。
- 总资产周转率 = 营业收入除以平均总资产。

分母为零、平均数缺期初或期末、期间不连续、单位或合并范围不同的，不计算或不横向比较。

## 风险信号

以下内容只形成核验线索，不直接认定异常、造假或违法：

- 应收账款或存货增速持续高于营业收入增速；
- 净利润增长但经营活动现金流持续恶化；
- 短期有息负债上升而货币资金下降；
- 其他应收款、预付款或关联方往来占比明显上升；
- 毛利率、费用率或现金周期发生无法由业务结构解释的突变；
- 审计意见、会计政策、合并范围或前期差错发生变化。

## 行业比较边界

行业基准必须注明来源、年度、行业分类、样本范围和统计口径。没有可追溯基准时，只做企业自身趋势和结构分析，不使用固定的“健康值”、统一十分制或跨行业排名。
