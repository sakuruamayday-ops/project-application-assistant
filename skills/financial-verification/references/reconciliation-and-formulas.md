# 财务勾稽与公式

## 勾稽

- 资产总额应与负债和所有者权益合计一致；
- 利润表净利润与权益变动、现金流量关系只作一致性核验，不在资料不足时强行调平；
- 期初数原则上与上年期末数一致，不一致时记录重述或合并范围变化；
- 同一指标跨资料冲突时保留来源，不自动取平均。

## 常用公式

- 营业收入增长率 = 本期营业收入减上期营业收入，再除以上期营业收入；
- 研发投入占营业收入比例 = 政策认可口径的研发投入除以同口径营业收入；
- 资产负债率 = 负债总额除以资产总额；
- 净资产 = 资产总额减负债总额。

基期为零、分母缺失、期间不连续或口径不同，公式状态标为不可计算。财务核算研发费用、加计扣除归集额和专项申报认定额分别保存。
