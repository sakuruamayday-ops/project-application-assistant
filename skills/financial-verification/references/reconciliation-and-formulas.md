# 财务勾稽与公式

## 勾稽

- 资产总额应与负债和所有者权益合计一致；
- 利润表净利润与权益变动、现金流量关系按原始数据作一致性核验，差异记录为补充材料与追溯事项；
- 期初数原则上与上年期末数一致，不一致时记录重述或合并范围变化；
- 跨资料冲突并列原值、来源和采用理由。

## 常用公式

- 营业收入增长率 = 本期营业收入减上期营业收入，再除以上期营业收入；
- 研发投入占营业收入比例 = 政策认可口径的研发投入除以同口径营业收入；
- 资产负债率 = 负债总额除以资产总额；
- 净资产 = 资产总额减负债总额。

基期为零、分母缺失、期间不连续或口径不同，公式状态标为不可计算。财务核算研发费用、加计扣除归集额和专项申报认定额分别保存。

## 公式与派生汇总

| `formula_id` | `inputs` 顺序 |
| --- | --- |
| `revenue_growth` | 本期营业收入、上期营业收入 |
| `rd_ratio` | 同口径认可研发投入、营业收入 |
| `main_revenue_ratio` | 主营业务收入、同口径营业收入 |
| `high_tech_income_ratio` | 高新技术产品或服务收入、同期总收入 |
| `debt_ratio` | 负债总额、资产总额 |
| `net_assets` | 资产总额、负债总额 |
| `sum` | 按同一会计口径纳入合计的项目 |

录入前核验期间、币种和口径，复算按同单位数值计算。比率指标的 `unit` 为 `%` 时，输出百分数。按原报表舍入时用 `round_to` 指定小数位。`recomputed_metrics.result` 以十进制字符串返回。未提供 `formula_id` 的历史指标继续执行原字段及来源校验。
