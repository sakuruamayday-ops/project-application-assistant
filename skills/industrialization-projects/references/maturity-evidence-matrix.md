# 成熟度与证据矩阵

| 阶段 | 可接受证据 | 相关资料的证明范围 |
|---|---|---|
| 原理与研发 | 研发记录、设计、实验数据 | 说明研发阶段，样机状态另核 |
| 样机或小试 | 样机、小试和内部测试 | 测试主体与第三方检测分别说明 |
| 检测鉴定 | 检测、鉴定或验收文件 | 应用情况另据用户记录 |
| 试用验证 | 试用、应用及现场记录 | 销售状态另据交易资料 |
| 首单销售 | 合同、发票、交付和回款 | 批量能力另据持续供应情况 |
| 产业化 | 连续订单、产能、质量与供应链 | 首次性按专项记录判断 |

七类证据分别判断：创新性、技术成熟度、知识产权、检测鉴定、用户应用、交易闭环和产业化能力。缺少政策要求的关键证据时只输出补证建议。

材料列明销售收入或销售归集时，保留已发生销售的事实；合同、发票另列交易凭证待核。批量稳定供应能力据连续订单、产能等判断，技术验证层级与商业化阶段分别呈现。
