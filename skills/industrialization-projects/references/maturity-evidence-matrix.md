# 成熟度与证据矩阵

| 阶段 | 可接受证据 | 不得替代 |
|---|---|---|
| 原理与研发 | 研发记录、设计文件、实验数据 | 不等于样机完成 |
| 样机或小试 | 样机记录、小试报告、内部测试 | 不等于第三方检测 |
| 检测鉴定 | 检测报告、鉴定或验收文件 | 不等于用户应用 |
| 试用验证 | 用户试用、应用报告、现场记录 | 不等于销售合同 |
| 首单销售 | 合同、发票、交付和回款证据 | 不等于批量应用 |
| 产业化 | 连续订单、产能、质量体系和供应链 | 不等于首次性 |

七类证据分别判断：创新性、技术成熟度、知识产权、检测鉴定、用户应用、交易闭环和产业化能力。缺少政策要求的关键证据时只输出补证建议。
