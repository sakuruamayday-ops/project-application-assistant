# 产业化项目

## 商业定位、MCP 双态与黑板接力

本技能属于 **WorkBuddy 收费撰写与专业方案能力（新产品申报方向评估 · 收费 MCP 服务端 / 付费交付端）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md) 与 [申报正文撰写共用底座（v1.2）](../_runtime/workbuddy-core/v12-drafting-core.md)：

- **业务范围**：承接首台套、首批次、首版次（三首）产品申报方向论证、成熟度证据链与申报正文撰写；商业母版与整稿生成资产留在收费服务端，免费初筛/盘点由对应免费体检技能承接。
- **v1.2 撰写与体检分离**：撰写正文/建设方案时直接生成干净、专业、可直接使用的成品（不在正文插括号或免责兜底）；缺实测数据时允许按行业成熟工程常识表述为“设计控制目标为……”，并将估算项外置至《交付核对与补强清单》及黑板（`origin: ai_design_target`）；涉及主导产品与专利时严格执行双字段锚定、业态三分支与专利三级分流。做门槛核验/体检时严认原件不估算。
- **主体隔离黑板与 MCP 故障显式报错**：启动前按企业主体读取 `.facts/<企业标识>.facts.json` 复用上游免费体检事实；已配置付费 MCP 若出现鉴权过期/配额用尽/超时，必须显式报错排查，绝不静默降级。

## 分类与核验

1. 识别产品、地区、年度及批次，按申报对象和政策定义分类。项目名称待明时可衔接 `project-matching`。
2. 按 `references/project-type-decision-tree.md`，装备及关键部件核验首台套，新材料核验首批次，独立工业软件核验首版次，鉴定、验收或备案成果核验工业新产品；扩产、复购和纯研发分别对应投资或研发路径。
3. 装备、材料、软件组合按合同、收入、核心创新载体及政策定义选主项目，其他方向列备选；同一合同的应用事实统一记录。
4. 按 `references/maturity-evidence-matrix.md` 核验技术成熟、创新、IP、检测鉴定、用户应用、合同发票和产业化能力，分别标记样机、送检、试用、首单、销售及批量应用。
5. 按适用管理办法核验首批次新材料的产品、性能和应用，项目专用目录及表单由客户提供。
6. 政策、分类或成熟度缺项时继续形成候选、技术建议和补证清单，政策条件保持待核。权利人、状态、RD 和产品关联逐字段沿用输入，明确已知与待核部分。

输出主备项目、依据、阶段和七类证据，体检列缺陷、差距、补强、优先级。工业新产品按产品边界、迭代、检测、应用和销售证据给方向；批次征集资格由客户确认。结构化结果可用 `python3 scripts/validate_industrialization_assessment.py <结果.json>`。

## 报告

前期评估及可行性参考 `project-feasibility/references/two-report-contract.md`，按对象、目录、创新、成熟、检测查新、首次应用、IP 和产业化给出建议层级。工业新产品方向体检按四列直接成稿。研发机构、检测及认定等资料待取时标明范围，建设周期按企业实际任务估算。

研发机构培育衔接 `technology-innovation-projects`；浙江省级平台参考其 `references/current-rd-platform-baseline-2026.md` 的管理办法。已销售产品及拟开展 RD 分别按真实状态组织。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
