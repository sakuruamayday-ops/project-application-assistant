# 申报章节组织

企业基本情况默认分为经营管理概况、细分领域地位、经营战略三段。

主导产品及技术情况默认分为核心技术突破、技术攻关与产业化、产业链供应链价值、精细化管理、知识产权积累与运用五段。

每段优先采用“结论式小标题＋证据链正文”。证据链依次回答行业问题、企业方法、技术或管理机制、量化结果、客户或产业化验证、对申报项目的价值。

当期申请书表头、章节或字数另有强制要求时，以已确认的当期表单为准，不强行套用默认结构。

各段落按已取得资料填写，缺项保留段落并列明所缺信息；精细化管理体系、客户、技术指标和知识产权采用可核验材料。申请书列示事实与现实客观基线冲突时保留原值并指出，不静默改写。
