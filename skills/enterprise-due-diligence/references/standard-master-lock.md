# 标准分析版母版锁定规则

## 已确认视觉基准

- 用 `assets/standard-master-template.html` 核对版式。
- 私有原件只在本机用于视觉核对，套件不包含原客户报告和其企业、财务或经营事实。
- 固定生成源 `assets/standard-master-template.html` 与 `assets/standard-style.css` 配套，模型只提供[业务数据](standard-html-input.md)。
- 参考工商信息和分析页预览，核对实际产物分页、字体、图标和来源。


## 章节与内容

保留母版十三章顺序及原章节图标，第七章为“经营数据与财务概况”。只填用户提供的可靠经营财务资料，无资料待补，不估算营收、利润、研发费、产能或未分配利润。工商注册及实缴字段可按本次真实来源填写，不与内部经营财务混同。

既有风险整改表、同行项目对比表、可申报项目表和五年规划表不省略。工商表固定原十五字段、两列；核验与来源说明放原有提示及来源区域。摘要、四种callout、绿色/红色竞争双卡、渐变评级卡保留原布局，评级未知留“待核”，不继承样张等级。

## 视觉参数

| 项目 | 固定参数 |
|---|---|
| 纸张 | A4，上下15mm、左右12mm |
| 正文与表格 | 13px，line-height 1.75 |
| 一级标题 | 20px、原章节图标、3px橙底线 |
| 二级标题 | 15px、4px橙左线、12px左内边距 |
| 表格 | th 9px/12px、td 8px/12px，1px #ddd边框 |
| 表色 | th #f8f9fa、隔行 #fcfcfc；td #2d3436、th #495057 |
| 字体 | 宋体、Songti SC、SimSun、Noto Serif CJK SC、serif，按系统可用字体顺序匹配 |
| 状态 | 验证用CSS真圆点与文字，严重程度用原彩色底标签 |

封面沿用橙色独立布局、公司名字距和保密片，图标保持原像素比例及标题槽位。以实际 PDF 像素对照核验母版、字体、图标和分页；页数随内容自然形成。
