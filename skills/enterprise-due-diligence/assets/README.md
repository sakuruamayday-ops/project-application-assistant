# 标准分析版视觉资产

版式见 `standard-master-template.html` 与 `standard-style.css`。

`standard-master-template.html` 为固定 DOM 占位源；`standard-style.css` 保存 A4、原橙色封面、章节标题、表格、摘要、关注提示、竞争双卡及评级卡的版式参数。模板企业数据不得继承到实际报告。当前候选需要真实成品视觉验收，源码参数或生成器测试通过不能声称已完成 1:1 对照。

`icons/section-01.png` 至 `section-13.png` 和 `callout-warning.png`、`callout-success.png`、`callout-danger.png`、`callout-info.png`、`callout-negative.png` 来自原件图形像素，保留各自比例，不统一拉伸为方形，不使用模型另绘或系统 emoji 字体。

HTML 使用系统字体，按宋体、Songti SC、SimSun、Noto Serif CJK SC、serif 的顺序匹配。标准分析版 PDF 将浏览器打印文字保存为矢量轮廓，同时保留可搜索的文字。
