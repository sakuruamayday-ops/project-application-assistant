# 新公司法下企业合规自查与风险防范

核验基准日：2026年7月21日

## 使用边界

本清单用于企业内部自查、项目申报前风险排查和律师沟通准备，不替代执业律师针对具体交易、争议或诉讼出具的法律意见。先确认公司类型、设立日期、章程版本、股东结构和待审行为发生日期；涉及2024年7月1日前的行为必须核验时间效力规则。

## 一、注册资本与出资

1. 核对有限责任公司股东认缴额、出资方式和出资日期是否写入章程，新设公司的认缴期限是否符合五年内缴足要求。
2. 对2024年6月30日前设立的有限责任公司，检查剩余认缴期限自2027年7月1日起是否超过五年；超过的，应在2027年6月30日前调整至五年内并修改章程。
3. 检查注册资本和出资期限是否明显脱离经营规模、股东能力、主营项目和资产规模，防止被登记机关要求调整。
4. 逐股东建立出资台账，保存银行流水、资产评估、权属转移、验收、记账和完税资料；非货币出资须能证明权属、价值和实际交付。
5. 核查逾期出资后的书面催缴、宽限期、董事会核查和失权程序。公司不能清偿到期债务时，评估未届期出资被要求提前缴纳的风险。
6. 注册资本、认缴与实缴额、出资方式和期限发生变化后，在法定期限内完成登记或通过国家企业信用信息公示系统公示，确保真实、准确、完整。

## 二、章程、登记与信息公示

1. 将现行章程与营业执照、登记档案、股东名册、出资证明书和公示信息逐项核对。
2. 核查名称、住所、法定代表人、注册资本、经营范围、股东和主要人员变化是否及时办理登记或备案。
3. 检查登记材料是否真实、合法、有效；严禁冒名登记、虚假签名、虚假地址、虚假出资和代持关系隐瞒。
4. 建立年度报告、即时信息公示、联络员和登记档案责任人制度，留存提交回执及版本。

## 三、治理机构与决议程序

1. 核对公司采用股东会、董事会、监事会、监事或董事会审计委员会的哪种治理模式，并与章程和登记备案一致。
2. 对股东会、董事会建立权限清单，明确召集人、通知期限、表决比例、回避事项、签署方式和会议记录保管。
3. 重大投资、担保、借款、关联交易、资产处置、增减资、利润分配和股权激励须先核对章程授权和决议层级。
4. 检查电子会议、书面决议和全体股东一致同意事项是否留有完整、可验证的证据链。
5. 定期核对股东知情权资料，保证章程、名册、会议记录和财务会计报告可依法查阅。

## 四、董事、监事、高级管理人员与实际控制人

1. 建立任职资格、忠实义务和勤勉义务承诺及年度利益冲突申报。
2. 关联交易必须事前报告，按章程和法律履行审议、回避和记录程序，交易条件应可证明公允。
3. 公司商业机会和同业竞争事项须有披露、授权和利益冲突处理记录。
4. 控股股东、实际控制人虽不担任董事但实际执行公司事务的，按实际履职风险纳入董事责任管理。
5. 董事会对股东出资核查、催缴情形、违法分配利润、违法减资和清算义务建立责任到人记录。

## 五、股权转让与股东退出

1. 转让前核查拟转让股权对应的认缴、实缴、出资期限、瑕疵出资和权利负担。
2. 合同中明确未届期出资、逾期出资和出资不足的责任分配，但不得把对外法定责任简单转嫁给公司或债权人。
3. 核对股东名册、出资证明书、章程和变更登记的衔接；股权交割条件应包含税务、登记和资料移交。
4. 2024年7月1日前发生的股权转让，尤其涉及公司法第八十八条第一款时，必须核对最高人民法院关于时间效力及不溯及适用的现行规则。

## 六、公司资金、分配与担保

1. 严格区分公司财产与股东、实际控制人个人财产，禁止长期无依据占款、抽逃出资和账外资金循环。
2. 利润分配前核对可分配利润、法定公积金、股东会决议和支付记录；违法分配应评估返还及责任风险。
3. 对外担保、为股东或实际控制人提供担保、财务资助和关联借款须核查决议权限、回避程序、商业合理性和信息披露。
4. 增资、减资、回购和合并分立应建立债权人通知、公告、清偿或担保及登记材料清单。

## 七、解散、清算与注销

1. 出现章程约定期限届满、决议解散、吊销或其他解散事由时，立即判断清算义务是否触发。
2. 明确清算义务人、清算组组成、财产清册、债权申报、职工安置、税务清算和剩余财产分配责任。
3. 不满足简易注销条件时不得虚假承诺无债权债务；长期停业或失联公司应评估被特别标注或强制注销风险。
4. 保存注销公告、债权人通知、清算报告、税务和登记回执，防止注销后责任追索。

## 八、自查输出矩阵

每个问题按以下字段记录：

| 字段 | 要求 |
|---|---|
| 事实 | 公司类型、设立日期、行为日期、责任主体 |
| 证据 | 章程、决议、合同、流水、凭证、登记及公示截图 |
| 规则 | 现行法律、行政法规、规章或司法解释 |
| 风险级别 | 红色为已违法或期限临近，黄色为证据不足或程序瑕疵，绿色为已核验 |
| 整改动作 | 责任人、完成期限、登记或公示动作、复核人 |
| 剩余风险 | 无法补正事项、争议事项及是否转律师处理 |
