# 行业专项法规动态路由

行业路由只决定“去哪里查、查什么”，不预设结论。每次使用时追加产品名称、工艺、用途、地域和项目名称。

| 行业或场景 | 优先监管机关与官方来源 | 首轮检索词 |
|---|---|---|
| 食品、农产品 | 市场监管总局、国家卫健委、农业农村部、海关总署及省市对应部门 | 食品安全、生产许可、食品添加剂、标签、执行标准、保健食品、农产品质量安全、冷链 |
| 医疗器械、生物医药 | 国家药监局、国家卫健委、国家医保局及省药监局 | 医疗器械监督管理、注册备案、生产质量管理规范、临床评价、创新医疗器械、药品管理 |
| 软件、人工智能、数据 | 国家网信办、工信部、国家数据局、市场监管总局 | 网络安全、数据安全、个人信息、算法备案、生成式人工智能、软件产品、数据出境、强制性国家标准 |
| 机械装备、首台套 | 工信部、市场监管总局、应急管理部及省经信厅 | 生产许可、特种设备、强制性认证、机械安全、首台套、重大技术装备、可靠性 |
| 新材料、化工 | 工信部、应急管理部、生态环境部、市场监管总局 | 危险化学品、生产许可、环境影响评价、排污许可、新化学物质、首批次材料、强制性标准 |
| 新能源、储能、电池 | 国家能源局、工信部、市场监管总局、消防救援部门 | 电力法、并网、储能安全、锂电池、运输、回收利用、能效、消防、强制性标准 |
| 环保、节能、资源循环 | 生态环境部、国家发展改革委、工信部 | 环境保护、固废、危废、排污许可、节能审查、清洁生产、绿色工厂、再生资源 |
| 建筑、工程、房地产 | 住建部、国家发展改革委、自然资源部 | 建筑法、资质、施工许可、招标投标、工程质量、安全生产、规划许可、绿色建筑 |
| 军工、涉密、两用物项 | 国家国防科工局、国家保密局、商务部、海关总署 | 武器装备科研生产许可、保密资格、军工事项审查、出口管制、两用物项、数据安全 |
| 电子信息、集成电路 | 工信部、国家网信办、国家知识产权局 | 无线电、进网许可、强制认证、集成电路布图设计、软件和集成电路税收政策 |
| 纺织、消费品 | 工信部、市场监管总局 | 产品质量、消费品安全、纺织品标签、强制性标准、绿色产品、工业设计 |
| 跨境贸易、技术进出口 | 商务部、海关总署、国家外汇管理局、国家知识产权局 | 技术进出口、出口管制、海关知识产权、原产地、外汇、数据出境、制裁合规 |

## 查询组合

使用以下组合构造查询：

`产品或工艺 + 行为 + 文件类型 + 地域 + 年份`

文件类型至少轮换：法律、条例、管理办法、实施细则、目录、强制性标准、申报通知、资金管理办法、废止、清理结果。

示例：

- `医用敷料 注册 监督管理条例 浙江 2026`
- `工业机器人 首台套 认定办法 杭州 2026`
- `生成式人工智能 数据出境 规定 现行`
