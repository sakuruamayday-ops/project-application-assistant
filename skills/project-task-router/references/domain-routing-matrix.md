# 领域路由矩阵

| 主任务 | 主技能 | 排除或转路由 |
|---|---|---|
| 高新技术企业申报前评估、今年或明年申报、成长性和创新能力评分 | high-tech-enterprise-preassessment | 普通科技项目匹配转technology-innovation-projects；正式申报正文转application-writing |
| 专精特新或小巨人申报前评分、测分、差距分 | sme-score-preassessment | 已形成申请书的后期体检转sme-development-projects |
| 农业基地、农产品、联农带农 | agriculture-and-rural-projects | 纯食品制造转industrialization-projects |
| 制造设备联网、系统集成、智能工厂 | digitalization-projects | 纯软件研发转technology-innovation-projects |
| 节能、绿色工厂、清洁生产 | green-development-projects | 单纯环保处罚查询转企业风险能力 |
| 知识产权类政府项目 | intellectual-property-projects | 权利事实核验转ip-assessment |
| 设备投资、技改补助 | investment-subsidy-projects | 研发任务转technology-innovation-projects |
| 制造精品、质量奖、冠军、品牌 | quality-brand-projects | 知识产权品牌专项转intellectual-property-projects |
| 临时区县或园区通知 | regional-special-projects | 已有固定领域模型时使用对应领域技能 |
| 人才、团队、博士后 | talent-projects | 普通企业研发团队转technology-innovation-projects |
| 研发机构、科技计划、奖励 | technology-innovation-projects | 产品认定或示范应用转industrialization-projects；设备、产线和固定资产投资转investment-subsidy-projects |
| 外贸、跨境、服务贸易、境外业务 | trade-and-open-economy-projects | 国内电商不适用 |
| 去AI味、降低机器腔、中文自然化润色 | gongchuang-humanizer-zh | 资格判断转project-feasibility；正式正文尚未成稿时先转application-writing |

先选择一个主领域。跨领域任务按“主项目条件→专项证据→最终可行性”的顺序调用，不因关键词重合同时启动全部技能。
