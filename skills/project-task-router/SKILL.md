# 任务路由

作为 `project-application-assistant` 的阶段识别能力，明确当前阶段、上游依赖和交接内容。意图对应的专业技能见[领域路由矩阵](../project-application-assistant/references/domain-routing-matrix.md)。范围与完成条件参考[共享任务说明](../_runtime/task-execution.md)，主体资料由当前材料、企业接口和官方来源补齐并标状态。

企业来源使用[企业数据源说明](../_runtime/enterprise-source-fallback.md)，名单参考[名单来源说明](../_runtime/recognition-source-routing.md)。共享财务事实核验主体、期间及口径后复用。

报告前期突出核心判断与补强，可行性展开硬门槛对照、实际差距、证据、动作和验收。各任务保留对应完成状态，按当前可用资料持续交付。政策待核、部分来源、名单覆盖及企业字段缺项在对应结果中如实说明。
