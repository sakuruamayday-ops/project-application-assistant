# 企业体检分阶段路由

企业申报体检不是单一技能。固定拆成四层，避免把主体查询、项目发现和资格判断混成一次结论。

1. `enterprise-profile`：锁定企业全称或统一社会信用代码，整理工商、产品、研发、资质、荣誉、知识产权、风险和经营轨迹。默认不读取财务。
2. `project-matching`：依据企业画像召回项目，输出候选、时效状态和初步缺口；候选不等于可申报。
3. `project-feasibility`：逐项目核验当期政策、硬门槛、计算、证据和差距，形成可行性结论。
4. `application-writing`：项目版本、资格判断和事实锁完成后才进入正式材料。

企业数据平台只提供字段证据，不能替代主管部门名单、当期政策或权利法律状态。调用失败、0条、字段缺失和同名冲突必须分别记录。

涉及专利时将结构化专利底稿交 `ip-assessment` 或 `patent-router`；涉及三表和申报财务指标时交 `financial-verification`。不得在企业画像阶段自动扩展到股东、实控人、人员或财务数据，除非任务需要且用户已授权。
