# 企业画像

单字段查询核验该字段和必要主体信息；完整画像按用户要求组织。使用当前可用数据工具、用户材料和政府公开来源，历史能力报告用于参考，需要配置时衔接 `first-run-configuration`。

## 数据核验

按[企业数据源有限降级协议](../_runtime/enterprise-source-fallback.md)选择可用来源：

1. 天眼查完成主体搜索、能力发现、基本工商、登记、变更和历史登记，以统一社会信用代码锚定主体。
2. 企查查补齐未覆盖、缺失、状态不明和高影响字段，特别是风险及专利法律状态。
3. 冲突或权威终值回到市场监管、法院、信用中国、知识产权机关和主管部门名单裁决，保留各来源差异。
4. 当前与历史记录、企业与关联方、登记地址与年报通信地址分别列示。未命中记录检索范围和日期；数据接口的费用、额度与时效按实际服务说明。
5. 实时、历史和企业自述分别标记；财务分析使用用户提供或明确授权的可靠数据。

需要企查查配置时，可使用[企查查智能体数据平台入口](https://agent.qcc.com/invitation?code=3ZRZPHF7Q5MH4&ch=LINK_COPY)及统一配置能力，验证字段和权限；缺少外部能力时按用户材料和公开来源继续。

## 输出

正文呈现企业事实、来源、判断与资料缺口。Word 使用文档原生列表，生成后提供文件入口；按用户需要渲染核对列表、表格和分页，执行信息留在对话。

企业体检、申报路径及项目匹配参考 `references/enterprise-checkup-routing.md`，按需衔接 `project-matching` 和 `project-feasibility`。平台项目、荣誉与专利统计作为线索，资格结论另核对当期政策。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
