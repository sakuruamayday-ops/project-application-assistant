# 深度澄清

在当前会话与用户形成共同理解，产品文档按工作区要求维护。用户显式选择本技能时进入访谈；普通任务沿当前目标继续，客户端建议和选择状态由客户端管理。

## 决策树与分轮

1. 将目标、范围、输入、约束、流程、依赖、风险、验收和发布事项组织成决策树。
2. 标记决策依赖，每轮集中提出当前能够决定的问题，后续问题随答案展开。
3. 事实优先从当前会话、工作区和可用工具核验；涉及目标、范围、优先级及风险承担的选择交用户决定。
4. 每题编号并给出推荐及理由：

   ```text
   ❓ 问题1｜<标题>
   <需要决定的内容与互斥选项>

   ➡️ 推荐：<答案>。<简短理由>
   ```

5. 答复后更新决策树，以确认、排除、新增分支或事实核验记录进展；其他已可执行工作同步推进。

## 收敛与执行

用户可随时选择“按推荐继续”“跳过澄清”或“取消任务”。按推荐继续时采用已给出的低影响、可逆选择；跳过时带上已确认事项返回原任务；取消时结束该任务。

问题反复仍未解决时，合并列出已确认事项、高影响待决项和当前可执行范围，采用低影响默认值继续；依赖工具或外部条件的部分记录待办，其他部分照常完成。

形成“共同理解与执行清单”：目标与价值、范围、关键决定及理由、输入与核验结果、风险与验收、执行步骤和外部依赖。按用户当前指令及已有授权推进，发送、提交、发布、删除、权限和费用等动作由宿主权限与用户指令处理。
