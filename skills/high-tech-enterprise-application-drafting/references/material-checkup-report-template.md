# 高新材料体检报告

来源：高新体检报告模板与算法实现说明_V1.0.md，V1.0。适用于已提交材料的体检报告，不是前期培育、可行性分析或申请书模板。完整体检按以下章节和表头输出，按实际 RD、PS、IP、年度及发现扩展行。未取得的资料在对应位置写“未检查”及原因，不补造企业事实；单项咨询只输出实际请求的相关部分。
