# 整表字段回填

输入为扩缩并完成RD正文回填后的原母版副本。输出必须是新路径。所有金额单位为万元；缺值用null，不猜测0。省略模块保留原样。字段名使用母版原文，不接受模型提供行列坐标。

顶层`schema_version`可省略或填整数1。PS、创新能力等字段的`（限400字）`后缀可省略，但同一字段不可同时传两种名称；程序仍执行400字上限。输出嵌入随套件分发的中文字体，保留母版表格、字号及合并关系，不依赖用户另行安装字体。

`registration`是字段名到值的对象，包含企业名称、注册时间、注册类型、外资来源地、注册资金、所属行业、企业规模、统一社会信用代码、行政区域、邮政编码、企业所得税征收方式、通信地址、企业是否上市、上市时间、股票代码、上市类型、是否属于国家级高新区内企业、高新区名称、技术领域、经营范围、企业简介。企业名称同步封面；注册时间不会写入企业名称栏。

`cover`可填企业名称、企业所在地区、认定机构、申请日期。签名、盖章不自动生成。

`summary`字段为技术领域、Ⅰ类、Ⅱ类、职工总数、科技人员数、基础研究投入费用总额（万元）、近一年企业总收入（万元）、近一年高新技术产品（服务）收入（万元）、申请认定前一年内是否发生过重大安全、重大质量事故或严重环境违法行为。企业总收入与销售收入分别输入，不自行视为同一口径。

`annual_financials`为连续三个实际年度的数组，每项含year、net_assets、sales、profit、rd、domestic_rd。profit为母版的利润总额，不接受净利润替代；没有对应口径填null。不填预测年度。近三年研发支出与境内支出由程序求和。

`rd_financials`为RD编号到三项年度金额数组，如`{"RD01":[84,55,0]}`；三年项目合计自动为139。`rd_external`和`rd_external_domestic`分别采用相同结构，只有明确无委外时填0。所有RD分年合计必须与annual_financials的rd一致；费用细项未提供则留空，不分摊。超过费用母版五个项目列时按年度分表，保留原列宽；分表标题标注RD范围，合计列仅为该表项目小计，不冒充全年总额。

`ps`按PS表顺序提供对象，字段使用母版完整表头：产品（服务）名称、技术领域、技术来源、上年度销售收入（万元）、是否主要产品（服务）、知识产权编号、关键技术及主要技术指标（限400字）、与同类产品（服务）的竞争优势（限400字）、知识产权获得情况及其对产品（服务）在技术上发挥的支持作用（限400字）。记录数量须与PS表一致。

`innovation`四项为知识产权对企业竞争力的作用（限400字）、科技成果转化情况（限400字）、研究开发与技术创新组织管理情况（限400字）、管理与科技人员情况（限400字）。按已确认事实写作，不扩展未知专利用途、制度全称、人员岗位或转化明细。

`personnel`使用人力资源总体情况行标题，如`{"总   数（人）":[60,12]}`，两值分别为企业职工、科技人员。分项未提供则不填。

`ip`为有权利状态依据的知识产权记录数组，每条可含知识产权名称、类别、授权日期、授权号、获得方式；编号由程序连续生成。日期、编号未确认用null；审中不纳入授权列表。只能回填空白IP表，不能覆盖已填事实。`ip_counts`按知识产权数量表的原始名称填已确认数量，不因未提供某类知识产权就填0。

仅程序回填成功不代表事实或申报资格通过。交付前继续对主文件核对内容、版式与适用专业检查。
