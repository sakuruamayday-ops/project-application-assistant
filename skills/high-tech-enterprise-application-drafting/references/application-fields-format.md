# 整表字段回填

输入用扩缩并回填 RD 的母版副本，输出另存；金额用万元，缺值 `null`，省略模块保留原样，现有回填器按母版字段定位。

顶层 `schema_version` 可省略或填整数1；字段名称可使用带或省略 `（限400字）` 后缀的一种写法，程序按400字上限处理。输出嵌入随套件分发的中文字体，沿用母版表格、字号和合并关系。

`registration`是字段名到值的对象，包含企业名称、注册时间、注册类型、外资来源地、注册资金、所属行业、企业规模、统一社会信用代码、行政区域、邮政编码、企业所得税征收方式、通信地址、企业是否上市、上市时间、股票代码、上市类型、是否属于国家级高新区内企业、高新区名称、技术领域、经营范围、企业简介。企业名称同步封面；注册时间不会写入企业名称栏。

`cover` 填企业名称、地区、机构和日期；签章由实际签署流程完成。

`summary` 按母版原字段填技术领域、Ⅰ/Ⅱ类、人员、基础研究、总收入、高新收入及重大事件；企业总收入和销售收入分别输入。

`annual_financials` 填连续三个实际年度，含 year、net_assets、sales、profit、rd、domestic_rd。`profit` 对应利润总额，缺项 `null`，研发及境内支出由程序汇总。

`rd_financials`为RD编号到三项年度金额数组，如`{"RD01":[84,55,0]}`；三年项目合计自动为139。`rd_external`和`rd_external_domestic`分别采用相同结构，只有明确无委外时填0。所有RD分年合计与annual_financials的rd一致；费用细项未提供则留空，不分摊。超过费用母版五个项目列时按年度分表，保留原列宽；分表标题标注RD范围，合计列仅为该表项目小计，不冒充全年总额。

`ps`按PS表顺序提供对象，字段使用母版完整表头：产品（服务）名称、技术领域、技术来源、上年度销售收入（万元）、是否主要产品（服务）、知识产权编号、关键技术及主要技术指标（限400字）、与同类产品（服务）的竞争优势（限400字）、知识产权获得情况及其对产品（服务）在技术上发挥的支持作用（限400字）。记录数量须与PS表一致。

`innovation`四项为知识产权对企业竞争力的作用（限400字）、科技成果转化情况（限400字）、研究开发与技术创新组织管理情况（限400字）、管理与科技人员情况（限400字）。按已确认事实写作，不扩展未知专利用途、制度全称、人员岗位或转化明细。

`personnel`使用人力资源总体情况行标题，如`{"总   数（人）":[60,12]}`，两值分别为企业职工、科技人员。分项未提供则不填。

`ip` 填有状态依据的知识产权数组，可含名称、类别、授权日期、授权号和获得方式，编号连续生成；待核日期、编号填 `null`，审中项单列。回填空白 IP 表并保留已有事实；`ip_counts` 按原数量表填已确认值，缺资料项保持待核。

仅程序回填成功不代表事实或申报资格通过。交付前继续对主文件核对内容、版式与适用专业检查。
