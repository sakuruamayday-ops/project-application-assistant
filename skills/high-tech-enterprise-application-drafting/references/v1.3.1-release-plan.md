# V1.3.1 发布计划与工作区增量

## 发布目标

形成可复用的高新技术企业认定申请书撰写能力，覆盖空白表单、动态扩表、RD、PS、企业创新能力和成果转化汇总，保证格式一致、内容充分、数字可追溯。

## 发布门禁

1. 母版不得含企业名称、统一社会信用代码、人员、收入、项目或知识产权等客户数据。
2. 新增表格与母版列宽、合并单元格、边框、行高和分页属性一致。
3. RD核心技术仅两条，且均以“XXXX技术：”展开。
4. RD核心技术与创新点合计不少于400字，阶段成果不少于400字。
5. PS三项正文原则上各不少于400字，技术指标必须含数值、单位和适用条件。
6. 创新能力四栏原则上各不少于390字，人员和制度资料缺失时不得补造。
7. 技术领域必须到四级；无法准确匹配时明确提醒企业确认。
8. 生成文件全部渲染并逐页视觉检查。
9. 缩表默认关闭；仅允许删除末尾完全空白的RD、PS表，名称、周期、正文、经费、销售收入、知识产权、勾选状态或其他填写值任一非空时整体阻断。
10. 缩表成功后必须连续编号，并在JSON中记录删除位置、原编号、删除原因和编号状态。
11. RD核心技术及创新点必须按“所属领域—两条核心技术—两条创新点”生成，核心技术以“XXXX技术：”展开，两条均含具体数值、单位或阈值。
12. 核心技术栏所属领域必须与各RD表头四级领域逐项一致，不得以统一领域批量覆盖。
13. 写作前必须形成企业规模与公开专利校准记录；人工智能、深度学习、数字孪生、大数据平台等高阶术语没有直接证据时禁止进入正文。
14. 知识产权、高新技术产品和科技成果转化汇总表只写原表字段的核对级简要内容；缺收入、RD或IP事实时留空，不写“待核定”“XXX万元”或自造编号。
15. 科技成果转化汇总表必须保持一张连续表并自然跨页，禁止按成果一项一页拆表。
16. 最终候选必须由WPS Office逐页检查，逐页截图及验收清单绑定当前DOCX SHA-256；使用其他渲染器不得标记为WPS验收通过。
17. 最终回执必须同时验证原模板复制、汇总表字段粒度、WPS逐页截图、当前文件哈希和品牌交付闸门。任一项缺失或哈希变化即失败关闭。
