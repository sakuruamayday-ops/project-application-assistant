# V1.3.1 发布计划与工作区增量

## 发布目标

形成可复用的高新技术企业认定申请书撰写能力，覆盖空白表单、动态扩表、RD、PS、企业创新能力和成果转化汇总，保证格式一致、内容充分、数字可追溯。

## 发布核对

1. 母版使用中性字段，客户数据留在对应任务资料与成品。
2. 新增表格与母版列宽、合并单元格、边框、行高和分页属性一致。
3. RD核心技术仅两条，且均以“XXXX技术：”展开。
4. RD 核心技术与创新点合计、四项阶段成果合计各按400字上限处理。
5. PS 三项正文各按400字上限处理，技术指标注明数值、单位和适用条件。
6. 创新能力四栏各按400字上限处理，人员和制度据本企业已取得资料填写，缺项集中列明。
7. 技术领域到四级；无法准确匹配时明确提醒企业确认。
8. 生成文件全部渲染并逐页视觉检查。
9. 缩表按明确范围处理末尾全空白 RD、PS；已有填写值的表保留并列差异。
10. 缩表成功后连续编号，并在JSON中记录删除位置、原编号、删除原因和编号状态。
11. RD核心技术及创新点按“所属领域—两条核心技术—两条创新点”生成，核心技术以“XXXX技术：”展开，两条均含具体数值、单位或阈值。
12. 各 RD 核心技术栏与本表头四级领域逐项对应。
13. 写作时结合规模和公开专利校准技术边界，人工智能、深度学习、数字孪生、大数据等术语据本 RD 直接证据使用。
14. IP、高新产品及成果表按原字段简写，缺项留空并集中列明。
15. 科技成果转化汇总表保持一张连续表，按内容自然跨页。
16. WPS 验收以 WPS Office 逐页查看及截图为依据，清单关联当前 DOCX SHA-256；使用其他渲染器时如实记录工具和验证状态。
17. 原表结构、字段粒度、分页、品牌和当前文件对应情况按需核对，发现问题随稿提示并修订，真实检查状态一并交付。
