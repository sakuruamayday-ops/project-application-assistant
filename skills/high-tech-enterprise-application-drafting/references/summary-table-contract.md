# 高企汇总表字段粒度契约

## 核心边界

汇总表用于核对映射关系，申请书正文用于解释技术逻辑。汇总表不得承载RD、PS正文中的长段技术机理、竞争优势、知识产权作用或证据缺口说明。

## 高新技术产品（服务）汇总表

| 字段 | 填写规则 |
|---|---|
| 产品（服务）名称 | 使用企业实际销售或提供的可核算产品、服务名称；不得写研发项目名称替代产品边界。 |
| 高新收入 | 仅填写企业或专项审计已确认数值；无可靠数据时留空。 |
| 关键技术 | 使用两至四项简短具名技术；不得复制PS正文。 |
| 所属高新领域 | 写到四级；无法匹配时留待企业确认，不强行编造。 |
| 对应RD | 只列已确认的RD连续编号。 |
| 知识产权 | 只列已确认的IP编号或表内要求的知识产权名称。 |
| 技术指标 | 列有来源的实测指标或任务中已明确标为拟定的指标；包含数值、单位或阈值。 |
| 证明材料 | 只列实际具备或计划补充的材料类别，不展开证据说明。 |

禁用写法包括“XXX万元”“待核定”“待审计”“名称详见”“指标待实测”“2026项目”等把事实缺口伪装成表内内容的表达。

## 知识产权汇总表

1. 一项知识产权占一行，IP编号从IP01连续编号。
2. 只填写知识产权名称、类别、授权或登记日期、授权或登记号和取得方式，不在单元格内追加技术作用长文。
3. 发明或实用新型的申请号、公开号和授权号应按表头口径填写；软件著作权使用登记号，不得把受理或审中写成授权。
4. 未核实的日期、编号、权利状态和取得方式留空；不得根据名称推测。

## 科技成果转化汇总表

1. 每项成果占一行，序号从1连续编号。
2. 所有成果保持在一张连续表内，允许表格自然跨页并重复表头；禁止拆成一项一页或每项一张表。
3. 成果名称可为已授权或在审知识产权、软件、装置、工艺、配方或可独立识别的技术成果；状态必须如实区分。
4. “涉及关键技术”和“转化所取得成效”使用核对级短句；详细技术机理仍回到RD或PS正文。
5. 无法确认的RD、IP、收入、数量和效果指标留空。禁止自造年度项目编号、授权状态或量化成效。
6. 证明材料只列实际可提供的材料名称；申请、受理、授权、登记和销售证据不得混写。

## 门禁结果

自动门禁检查结构和明显违规，不代替事实审计。脚本未识别模板表头时必须失败关闭；必须先扩展识别规则并完成回归后才能继续。
