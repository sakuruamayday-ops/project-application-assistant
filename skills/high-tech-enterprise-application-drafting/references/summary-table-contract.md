# 高企汇总表字段粒度契约

## 核心边界

汇总表简写映射关系；技术机理、竞争优势和 IP 作用在 RD、PS 正文展开，资料缺口统一汇总。

## 高新技术产品（服务）汇总表

| 字段 | 填写规则 |
|---|---|
| 产品（服务）名称 | 填企业实际销售或提供、可核算的产品或服务名称，并明确与 RD 的关系。 |
| 高新收入 | 仅填写企业或专项审计已确认数值；无可靠数据时留空。 |
| 关键技术 | 填两至四项简短具名技术，具体机制在 PS 正文说明。 |
| 所属高新领域 | 写到四级；无法匹配时留待企业确认，不强行编造。 |
| 对应RD | 只列已确认的RD连续编号。 |
| 知识产权 | 只列已确认的IP编号或表内要求的知识产权名称。 |
| 技术指标 | 列有来源的实测指标或任务中已明确标为拟定的指标；包含数值、单位或阈值。 |
| 证明材料 | 只列实际具备或计划补充的材料类别，不展开证据说明。 |

禁用写法包括“XXX万元”“待核定”“待审计”“名称详见”“指标待实测”“2026项目”等把事实缺口伪装成表内内容的表达。

## 知识产权汇总表

1. 一项知识产权占一行，IP编号从IP01连续编号。
2. 只填写知识产权名称、类别、授权或登记日期、授权或登记号和取得方式，不在单元格内追加技术作用长文。
3. 按表头分别填申请号、公开号、授权号或软著登记号，状态按申请、受理、授权、登记实际记录标明。
4. 日期、编号、状态和取得方式据相应记录填写，待核项留空并汇总缺口。

## 科技成果转化汇总表

1. 每项成果占一行，序号从1连续编号。
2. 所有成果沿用一张连续表，按内容自然跨页并重复表头。
3. 成果名称可为已授权或在审知识产权、软件、装置、工艺、配方或可独立识别的技术成果；状态如实区分。
4. “涉及关键技术”和“转化所取得成效”使用核对级短句；详细技术机理仍回到RD或PS正文。
5. RD、IP、收入、数量和效果按本企业已确认记录填写，待核项留空并汇总。
6. 证明材料列实际可提供名称，分别注明申请、受理、授权、登记或销售证据类型。

## 核对结果

结构检查与事实复核按需进行。表头待识别时保留原文件，定向修正识别或按原表人工核对，继续交付可用部分。
