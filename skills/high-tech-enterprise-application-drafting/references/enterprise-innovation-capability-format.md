# 企业创新能力四栏固定格式与证据契约

## 一、固定顺序与篇幅

申请书第七部分固定使用以下顺序：

1. 知识产权对企业竞争力的作用；
2. 科技成果转化情况；
3. 研究开发与技术创新组织管理情况；
4. 管理与科技人员情况。

每栏400个中文字符以内，先保留证据链，再压缩重复背景。参考材料提供结构与表达密度，本企业名称、IP、客户、财务、人员、合作及制度取自本轮资料。

## 二、四栏写作顺序

### 1. 知识产权对企业竞争力的作用

按 IP 管理、授权登记、申请审中、覆盖及 RD/PS 对应和保护作用展开；各状态分别统计，融资、估值、许可及客户认可据本企业资料写。

### 2. 科技成果转化情况

按近三年 RD 方向、已核定成果数量和形态、转化方式、IP 与 PS 对应、实施环节及待核成效展开；数量据成果列表，销售、客户、合作及财税数据据本企业资料。

### 3. 研究开发与技术创新组织管理情况

从原件提制度名，按机构、立项、预算、过程、变更、验收、转化、培训、人才和开放创新说明职责；设计据制度，执行据实际记录。

### 4. 管理与科技人员情况

按已核定人员数量、岗位分工、研发负责人职责、设备与工艺岗位协同、测试和资料归档、培训绩效及人才引进制度依次展开。总人数、科技人员数、比例和学历分布须相互勾稽；存在冲突时只使用能够独立核定的字段，并在交付说明中列出冲突。

## 三、制度名称取证流程

1. 读取每份详细制度文件的标题页、正文标题和发布文件名；
2. 以正文正式标题为准建立制度名称清单，保留《关于》《办法》《制度》等完整字样；
3. 将制度具体条款映射到项目、经费、成果、培训、绩效、人才或合作管理功能；
4. 正文书名号引用清单中的全称；
5. 制度设计与实际执行分别取证，正文按执行记录描述完成情况。

## 四、证据JSON契约

正式核稿至少提供以下字段：

```json
{
  "allowed_corporate_names": ["某制造有限公司"],
  "policy_titles": [
    "关于成立企业研发中心的通知",
    "科研项目研究开发组织管理制度",
    "研发经费投入核算制度"
  ],
  "allowed_personnel_claims": ["现有科技人员8名"],
  "allowed_result_claims": ["近三年形成10项科技成果转化记录"],
  "allow_financing_claims": false
}
```

`allowed_corporate_names`用于跨企业事实隔离；`policy_titles`逐字绑定制度原件；`allowed_personnel_claims`登记可以进入正文的人员数量、比例和学历主张；`allowed_result_claims`登记可以进入成果栏的市场、合作或政策成效；`allow_financing_claims`默认为否。

## 五、脱敏示例

### 正常示例

示例中4项授权登记、10项转化及8名科技人员按资料分别入四栏，审中单列，制度名称对应原件，岗位职责据实际记录。

### 边界示例

样例中57名职工、8名科技人员和13.79%存在勾稽差异。正文可先用独立可核定的8名科技人员及职责，人数和比例冲突集中列待核。仅有制度文件时用“建立”“明确”“规定”，实施成效据执行记录说明。

### 事实校准示例

参考企业数据、审中专利和待取得制度分别留在参考、审中及缺口状态；正文使用本企业已取得的对应事实。先交付成立部分，补齐企业依据后再完善相关段落。
