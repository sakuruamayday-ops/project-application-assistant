# 企业创新能力四栏固定格式与证据契约

## 一、固定顺序与篇幅

申请书第七部分固定使用以下顺序：

1. 知识产权对企业竞争力的作用；
2. 科技成果转化情况；
3. 研究开发与技术创新组织管理情况；
4. 管理与科技人员情况。

每栏建议390至450个中文字符。篇幅用于形成完整证据链，不以重复语句凑字。参考材料只学习结构和表达密度，禁止复制参考企业名称、知识产权数量、客户、收入、融资、人员学历、合作单位或制度名称。

## 二、四栏写作顺序

### 1. 知识产权对企业竞争力的作用

按知识产权管理逻辑、已核定授权或登记成果、申请或审中成果、技术覆盖范围、与RD及PS的对应关系、成果保护和风险防范作用依次展开。申请、受理和审中成果单独列示，并明确不计入授权或登记数量。融资、估值、许可收益和客户认可只有在企业资料直接支持时才能写入。

### 2. 科技成果转化情况

按近三年RD方向、已核定成果数量和形态、转化方式、成果到知识产权再到PS的对应关系、实施环节和待核验应用成效依次展开。成果数量以成果转化列表及支撑材料为准；销售、收入增长、客户数量、高校合作、政府资助和税收优惠不得从参考范文移植。

### 3. 研究开发与技术创新组织管理情况

先从制度原件逐字提取正式名称，再按研发机构、项目立项、预算和费用辅助账、过程评估、变更、结题验收、成果转化、培训绩效、人才引进和开放式创新说明制度职责。制度文本证明的是规则设计；没有辅助账、评审记录、培训记录、绩效记录或验收记录时，不写成已经全面执行。

### 4. 管理与科技人员情况

按已核定人员数量、岗位分工、研发负责人职责、设备与工艺岗位协同、测试和资料归档、培训绩效及人才引进制度依次展开。总人数、科技人员数、比例和学历分布须相互勾稽；存在冲突时只使用能够独立核定的字段，并在交付说明中列出冲突。

## 三、制度名称取证流程

1. 读取每份详细制度文件的标题页、正文标题和发布文件名；
2. 以正文正式标题为准建立制度名称清单，保留《关于》《办法》《制度》等完整字样；
3. 将制度具体条款映射到项目、经费、成果、培训、绩效、人才或合作管理功能；
4. 正文书名号内只能引用清单中的全称；
5. 另行核验执行记录，禁止把制度存在直接写成制度已执行完毕。

## 四、证据JSON契约

正式核稿至少提供以下字段：

```json
{
  "allowed_corporate_names": ["某制造有限公司"],
  "policy_titles": [
    "关于成立企业研发中心的通知",
    "科研项目研究开发组织管理制度",
    "研发经费投入核算制度"
  ],
  "allowed_personnel_claims": ["现有科技人员8名"],
  "allowed_result_claims": ["近三年形成10项科技成果转化记录"],
  "allow_financing_claims": false
}
```

`allowed_corporate_names`用于跨企业事实隔离；`policy_titles`逐字绑定制度原件；`allowed_personnel_claims`登记可以进入正文的人员数量、比例和学历主张；`allowed_result_claims`登记可以进入成果栏的市场、合作或政策成效；`allow_financing_claims`默认为否。

## 五、脱敏示例

### 正常示例

某制造企业材料能够核定4项授权或登记知识产权、10项成果转化和8名科技人员，详细制度文件提供了研发中心、项目管理和研发经费制度。四栏分别写入上述事实，申请中知识产权另行说明不计入授权数量，制度名称与原件逐字一致，人员栏只写8名及材料列示的岗位职责。该示例可通过门禁。

### 边界示例

人员说明同时写有职工总数57人、科技人员8名和科技人员占比13.79%，但三者不能相互复算。正文可保留独立可核定的8名科技人员及岗位职责，不写职工总数和比例；交付说明列出勾稽冲突并要求企业核定。制度文件仅能证明规则设计时，正文使用“建立”“明确”“规定”等表述，不写“已全面落实并取得显著成效”。

### 拒绝示例

参考范文中的另一家企业名称、营业收入增长率、客户数量、博士硕士人数、核心人员留任率、融资估值和高校合作不在本企业证据中；受理专利被写成已授权成果；组织管理栏引用了企业未提供的《通用科研管理制度》。上述内容必须阻断，不得通过改写措辞保留，须删除或取得对应企业证据后重新核验。
