# RD核心技术及创新点批量回填规范

## 执行顺序

1. 先用 `plan_hightech_inputs.py` 复用总控技能的内容嗅探器一次盘点全部输入；旧 `.doc` 只允许签名提取尝试一次，宿主返回转换状态后只请求一次另存，同一指纹再次进入立即停止；
2. 用 `expand_rd_ps_tables.py` 将RD、PS数量调整为实际数量；
3. 核验企业规模、主营产品、生产方式、研发基础和公开专利；
4. 按本规范准备结构化JSON；
5. 用 `fill_rd_core_innovation.py` 同批回填RD核心技术、创新点与四项阶段性成果；
6. 脚本重新打开输出DOCX并核对每个目标单元格后，再运行 `audit_application_docx.py` 和逐页视觉检查。

## 输入JSON

资料盘点清单先标注每个文件是 `essential` 还是 `supporting`，再执行：

```bash
python3 scripts/plan_hightech_inputs.py \
  输入清单.json --state 输入状态.json --report 输入盘点.json
```

第一次命中必需旧 `.doc` 时只返回一次转换清单。文件大小、修改时间和格式状态都没有变化时，第二次返回 `stopped_no_progress`，不再启动新的解析方案。

```json
{
  "schema_version": 1,
  "enterprise_profile": {
    "name": "某中小制造企业",
    "scale_summary": "中小企业，主要采用常规机械加工与装配工艺",
    "main_business": "精密结构件制造",

    "patent_evidence": ["专利检索：以企业完整名称检索，2026-08-11"],
    "verified_advanced_terms": []
  },
  "items": [
    {
      "rd_id": "RD01",
      "core_technologies": [
        {
          "name": "弹性夹持与重复定位技术",
          "description": "通过弹性夹爪和定位销孔配合限制工件位移，兼顾夹持稳定性与边缘保护。",
          "indicators": "重复装夹位置偏差不大于0.2毫米，换型时间不超过30分钟"
        },
        {

        }
      ],

        "采用双面镂空载具减少翻面与重复定位，目标使单件加工时间缩短35%以上。",
        "将遮挡件与载具主体分体设计，使通用载具通过更换薄片适配不同型号，目标使载具投入成本降低50%以上。"
```

## 技术复杂度门禁

脚本默认检查人工智能、深度学习、机器学习、神经网络、数字孪生、大数据平台、区块链、云边协同、自主决策和预测性维护。正文命中这些词而`verified_advanced_terms`未逐项列明时，整份输出阻断，不写入DOCX。

该门禁只防止无证据抬高技术复杂度，不替代业务判断。企业确有相关技术时，应在证据项中写明专利、产品、人员或测试材料，再允许使用。

## 三类真实使用示例

### 正常任务

中小制造企业已提供工装夹具专利和加工记录。采用结构、定位、遮挡、节拍与换型指标撰写，脚本回填并生成通过审计。

### 边界任务

软件企业资料明确有机器学习算法软著、算法工程师和测试集记录。在`verified_advanced_terms`列入“机器学习”，并保留证据来源后，可以使用该词，但识别准确率仍标为拟定或引用实测来源。

### 应阻断任务

传统加工企业只有项目名称，没有专利、人员或产品材料，却在正文写“数字孪生”“深度学习”。脚本必须阻断，并提示补充直接证据或改写为真实采用的传感采集、阈值规则、PLC控制、数据库管理或可视化。

## 命令

```bash
python3 scripts/fill_rd_core_innovation.py \
  输入申请书.docx RD核心技术.json 输出申请书.docx \
  --report RD核心技术审计.json
```

输出不得覆盖输入。已有输出只有显式使用 `--overwrite` 时才会先生成可恢复备份，再写入新文件。
