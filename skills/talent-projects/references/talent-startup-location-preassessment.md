# 人才创业落地前期评估方法

## 适用范围

部分人才画像下比较多个地区创业政策，学历、职称、经历、成果、团队及项目据资料组合判断，先推荐方向并说明后续核验。

## 默认分析框架

### 一、只锁定已知条件

已知学历、经历、成果、团队、企业、股权、社保、融资和地区列为事实，其他字段标未知并继续现有画像分析。

只有缺失信息会改变“能否给出方向”时才提问。若仍可根据已知条件形成区域排序，先完成前期评估，把详细核验留到执行阶段。

### 二、区域比较顺序

先判断用户画像可能进入哪类入口，再比较地区：

1. 学历、职称、职业资格、工作经历或境内外经历通道；
2. 技术成果、奖项、知识产权、市场业绩或行业贡献通道；
3. 创业项目、团队评审、融资、持股或产业化通道；
4. 紧缺急需、举荐、等效认定或其他政策明示的破格通道；
5. 企业侧科技、产业和载体项目等替代通道。

地区比较按人才匹配、政策确定性、产业生态、落地成本及用户所需专项资源选维度，顾问权重明示并按实际维度归一；政府评分另据官方规则。

### 三、常规、破格与替代路线

1. 逐条核对常规条件，学历、经历、劳动或创业关系等共同判断。
2. 常规条件不满足时，检索政策原文是否存在破格、举荐、等效认定、紧缺急需、团队项目制或创业项目评审条款。
3. 破格入口有官方条款，个人是否具备破格资格仍需成果、推荐主体、评审或主管部门确认。
4. 破格依据待取得时，优先找适配的人才层级、地区、团队或企业项目路径。

### 四、专项资源触发器

| 资源 | 触发条件 | 未触发时处理 |
|---|---|---|
| 算力券 | 训练、推理、租用算力或明确询问 | 按本轮需求保留为可选资源 |
| 模型券 | 第三方调用、采购或模型开发需求 | 按本轮需求保留为可选资源 |
| 语料或数据券 | 合规采购、治理或标注需求 | 按本轮需求保留为可选资源 |
| 创新券 | 检测、技术或研发服务支出 | 按本轮需求保留为可选资源 |
| 场景或首用支持 | 项目需要政府场景开放、首购首用或示范应用 | 仅作为生态信息，不假定可获奖补 |

用户仅要求人才落地方向、且业务事实没有触发专项资源时，报告只比较人才政策、政策确定性、生态与成本。

### 五、金额分层

| 类型 | 含义 | 前期评估处理 |
|---|---|---|
| 人才现金补助 | 入选人才项目后按分档、任务书或验收拨付 | 作为选区核心，但写“最高口径” |
| 费用报销 | 按研发、算力、语料、模型或房租实际支出补助 | 未发生支出前按零进入现金预算 |
| 年度资金池 | 某区域全年安排的预算规模 | 不换算为单企额度 |
| 贷款贴息 | 本金或利息补助 | 本金和补助分别列示 |
| 股权投资 | 政府或市场基金 | 投资额、稀释与补贴分别核算 |
| 场地减免 | 租金优惠或面积支持 | 单列，不与现金补助相加 |

### 六、券类历史分配分析

仅在专项资源被触发时执行：

1. 优先使用政府公示的企业级名单和金额附件。
2. 完整名单至少计算企业数、总额、中位数、最大值、前一名占比、前五名占比。
3. 企业规模集中与金额集中分别核对，规模据企业资料。
4. 只有数量时先报告批次数量，金额集中度待明细取得后计算。
5. 相邻券种作为旁证时注明券种和适用范围，算力券结论另据对应资料。
6. 资金池与兑付记录分别展示，实际获得结合申报、支出及兑付条件判断。

## 推荐结论格式

- 默认推荐：现有已知条件下，政策确定性和直接匹配度最高的地区。
- 高收益备选：政策上限更高，但仍有一至两个关键条件待确认的地区。
- 破格机会：官方存在破格、举荐、等效认定或紧缺急需入口，但个人资格仍待评审或确认。
- 条件型备选：团队、融资、产业化、特定履历或专项资源需求成立后进入复选的地区。
- 观察地区：只有方向性新闻、历史政策或完整政策链未命中的地区。

## 三至五年成长路径

| 阶段 | 政策重点 | 判断目标 |
|---|---|---|
| 注册前 | 人才项目、企业成立窗口和地区选择 | 选定主区，避免空耗成立年限 |
| 第一年 | 人才创业项目、科技型中小企业、券类补助 | 建立研发、人员、知识产权和财务基本账 |
| 第二年 | 人才项目阶段支持、高企准备、研发投入 | 形成可核算收入和真实研发支出 |
| 第三年 | 高企、新雏鹰、应用场景、研发平台 | 从个人优势转为企业创新能力 |
| 第四至五年 | 专精特新、企业研究院、产业基金和重点研发 | 建立规模、融资和市场信用 |

## 失败边界

- 现行政策链缺失时，交付条件分析并把资格结论标待核。
- 企业级兑付金额缺失时，将券类集中度列为待取事项。
- 企业预算缺失时，先列五年建设方向及补充测算所需数据。
- 最高支持、贷款、投资、面积及资金池按各自口径列示；
- 入选可能性综合实际条件和证据说明；
- 破格路径据明文条件逐项核对；
- 区域比较聚焦本轮人才与业务资源需求。

## 固定来源附录

报告末尾固定设置“附录：主要政策来源”，至少记录标题、文号或发布机关、发布日期、适用地区、有效状态、官方链接和核验日期。第三方页面作为失效原文地址或附件线索，注明取得范围。
