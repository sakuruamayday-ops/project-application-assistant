# 人才创业落地前期评估方法

## 适用范围

用于只掌握部分人才画像时，对多个区县的人才创业政策进行前期比较。学历、职称、经历、成果、团队和创业项目都只是可能的画像字段，不设置统一的学历起点。目标是推荐落地方向，不是形成申报资格结论或执行方案。

## 默认分析框架

### 一、只锁定已知条件

把学历、年龄、职称、职业资格、境内外属性、工作经历、成果、团队、是否已设企业、持股、社保、融资和拟落地区域等用户已经明确的信息列为事实。任何字段未提供时保持未知，不用默认学历或假设值补齐。

只有缺失信息会改变“能否给出方向”时才提问。若仍可根据已知条件形成区域排序，先完成前期评估，把详细核验留到执行阶段。

### 二、区域比较顺序

先判断用户画像可能进入哪类入口，再比较地区：

1. 学历、职称、职业资格、工作经历或境内外经历通道；
2. 技术成果、奖项、知识产权、市场业绩或行业贡献通道；
3. 创业项目、团队评审、融资、持股或产业化通道；
4. 紧缺急需、举荐、等效认定或其他政策明示的破格通道；
5. 企业侧科技、产业和载体项目等替代通道。

地区比较通常考虑人才项目直接匹配度、政策确定性、创新与产业生态、落地成本，以及被用户需求触发的专项资源。不得固定使用含券类资源的统一权重；未触发的维度从评分中删除，其余维度重新归一。任何顾问权重都不是政府评分标准，必须明确标注。

### 三、常规、破格与替代路线

1. 先逐条核验常规申报条件，不能只看学历。
2. 常规条件不满足时，检索政策原文是否存在破格、举荐、等效认定、紧缺急需、团队项目制或创业项目评审条款。
3. 破格入口必须有官方条款，个人是否具备破格资格仍需成果、推荐主体、评审或主管部门确认。
4. 没有明文破格依据时，不能自行放宽门槛；应转向更匹配的人才层级、地区政策、团队项目或企业项目。

### 四、专项资源触发器

| 资源 | 触发条件 | 未触发时处理 |
|---|---|---|
| 算力券 | 有模型训练、推理、算力租用或云算力合同需求，或用户明确询问 | 不检索、不列示、不计分 |
| 模型券 | 有第三方模型调用、模型服务采购或模型开发需求 | 不检索、不列示、不计分 |
| 语料券或数据券 | 有合规数据、语料采购、治理或标注需求 | 不检索、不列示、不计分 |
| 创新券 | 有检验检测、技术服务、研发服务等合规支出 | 不检索、不列示、不计分 |
| 场景或首用支持 | 项目需要政府场景开放、首购首用或示范应用 | 仅作为生态信息，不假定可获奖补 |

用户仅要求人才落地方向、且业务事实没有触发专项资源时，报告只比较人才政策、政策确定性、生态与成本。

### 五、金额分层

| 类型 | 含义 | 前期评估处理 |
|---|---|---|
| 人才现金补助 | 入选人才项目后按分档、任务书或验收拨付 | 作为选区核心，但写“最高口径” |
| 费用报销 | 按研发、算力、语料、模型或房租实际支出补助 | 未发生支出前按零进入现金预算 |
| 年度资金池 | 某区域全年安排的预算规模 | 不换算为单企额度 |
| 贷款与贴息 | 贷款本金或利息补助 | 贷款本金不计为补贴 |
| 股权投资 | 政府基金或市场化基金投资 | 不计为补贴，另算股权稀释 |
| 场地减免 | 租金优惠或面积支持 | 单列，不与现金补助相加 |

### 六、券类历史分配分析

仅在专项资源被触发时执行：

1. 优先使用政府公示的企业级名单和金额附件。
2. 完整名单至少计算企业数、总额、中位数、最大值、前一名占比、前五名占比。
3. 判断“大企业集中”前，必须另外核验企业规模；金额集中不等于大企业集中。
4. 只取得批次数量而没有金额时，不计算集中度。
5. 使用创新券等相邻券种作旁证时，必须明确“不能直接代表算力券”。
6. 资金池较大但历史兑付名单很少时，只能提示“实际获得取决于申报和支出”，不能推断资金足额或平均分配。

## 推荐结论格式

- 默认推荐：现有已知条件下，政策确定性和直接匹配度最高的地区。
- 高收益备选：政策上限更高，但仍有一至两个关键条件待确认的地区。
- 破格机会：官方存在破格、举荐、等效认定或紧缺急需入口，但个人资格仍待评审或确认。
- 条件型备选：团队、融资、产业化、特定履历或专项资源需求成立后进入复选的地区。
- 观察地区：只有方向性新闻、历史政策或完整政策链未命中的地区。

## 三至五年成长路径

| 阶段 | 政策重点 | 判断目标 |
|---|---|---|
| 注册前 | 人才项目、企业成立窗口和地区选择 | 选定主区，避免空耗成立年限 |
| 第一年 | 人才创业项目、科技型中小企业、券类补助 | 建立研发、人员、知识产权和财务基本账 |
| 第二年 | 人才项目阶段支持、高企准备、研发投入 | 形成可核算收入和真实研发支出 |
| 第三年 | 高企、新雏鹰、应用场景、研发平台 | 从个人优势转为企业创新能力 |
| 第四至五年 | 专精特新、企业研究院、产业基金和重点研发 | 建立规模、融资和市场信用 |

## 失败边界

- 没有现行完整政策链，不形成“可申报”结论。
- 没有企业级兑付金额，不判断券类集中度。
- 没有企业预算，不测算未来五年补贴总额。
- 不把最高标准、贷款本金、基金投资、房租面积和资金池相加。
- 不因任何学历、职称或单项成果直接推定人才项目入选。
- 不把“存在破格条款”写成“能够破格入选”。
- 未触发专项资源时，不把算力、模型、语料或创新券纳入地区排名。

## 固定来源附录

报告末尾固定设置“附录：主要政策来源”，至少记录标题、文号或发布机关、发布日期、适用地区、有效状态、官方链接和核验日期。第三方页面只能作失效原文地址或附件线索，并注明限制。
