# 项目前期评估与可行性分析双报告合同

写作与精简沿[共享报告方法](../../_runtime/report-writing.md)：保留本文件章节和表型，直接交付可用稿，资料缺口集中说明。

## 适用范围与冻结边界

本合同统一两类报告的呈现、状态和补强表达。领域资格、技术、预算、评价和验收仍按对应项目；已有专项报告使用同源事实与原分析结构。

核心判断沿领域方法：高企四关联，三首产品与成熟度，研发中心当期评分，专精现行梯度，绿色、数字化、质量和科技各自口径；统一模板承载共同展示结构。

## 项目与版本确认

1. 先确认企业主体、地区、申报年度、项目全称、申报层级、批次以及新申报或复核。
2. 层级影响条件、评分或日期而输入待明确时，说明差异并集中提最少问题，同时继续基础事实及可用稿。
3. 三首先核所在地、产品、目录、创新、成熟度、检测查新、首用销售和 IP，据证据推荐首选及备选层级；暂缺项给建设或其他适用层级路径。
4. 按现行办法、指引和当期通知核对。通知待发布时标“规划参考，待当年通知”，历史年度特有日期、金额和门槛留作历史信息。

## 当年度截止日期

当年度项目在项目路径表和项目详表中增加“申报截止日期”字段，并以报告基准日判断窗口状态：

- 仍在申报期：写完整日期和批次，例如“2026年9月10日截止”；
- 已截止：写“2026年7月17日已截止”，并把行动改为受理跟踪、反馈补正、转下一批、复评通过或下一年度重启；
- 分批申报：分别列地方网、国家网或第一批、第二批截止日期，不合并为一个日期；
- 常年或滚动受理：写明“常年受理”或具体批次规则；
- 未来通知待发布：写“待当年通知”，列发布后核对节点。

已截止、临近截止、重新认定、复核和在审项目聚焦本轮补正、结果跟进和状态闭合，再按实际需要安排后续建设。

## 证据状态与补强表达

每个通知条件逐条映射以下状态，并给出补强动作：

- `已具备`：企业材料或已核验来源足以支撑；
- `企业提供待核`：企业陈述或材料尚未完成交叉核验；
- `待企业确认`：资料未提供，当前无法判断；
- `当前检索层未命中`：记录已查范围，申报证据列待核并给确认动作；
- `明确未具备`：企业资料或企业确认能够证明尚未完成；
- `存在差距`：已有可比数据低于通知条件；
- `冲突待核`：两个来源、期间或口径不一致；
- `不适用`：通知条件经核验不适用于本项目或企业。

例如：检索未命中研发机构时写“当前检索层未命中，待企业确认；如需建设，建议补组织、人员、设备场地、制度、项目及成果台账”。检测、产学研、转化、人员和 IP 缺项同样区分检索状态与企业事实。

## 通用科技咨询补强包

所有项目的两类报告均增加两份建议交付物：

1. 国内产品技术水平评价咨询报告；
2. 国际产品技术水平评价咨询报告。

两份科技咨询围绕拟申报产品或技术开展同类检索、结构功能、指标、先进性、替代和产业链价值分析；目标可写“经检索对标评价，争取形成国内领先或国际先进结论”，当前水平据实际证据说明。

科技咨询报告按当期通知确定作用：通常为软提升与证据补强，明确要求时按相应条件核对；说明对本项目的实际价值。

## 报告一：项目前期评估报告

定位是首次接洽和谈单，默认简洁清爽。固定包含：

1. 总结结论：项目版本、窗口状态、总体判断、核心优势、关键差距和立即动作；
2. 申报条件对照：现行核心门槛、企业数据、证据状态和补强建议；
3. 项目专属核心对象：按项目路由切换，不机械使用主导产品或专利章节；
4. 实施路径：当年度截止日期、补数补证、补强项目和下一次判断节点；
5. 科技咨询补强：国内、国际两份报告的对象、目标和项目作用。

评分制项目在前期报告中只列决定可行性的核心门槛和关键得分项，不铺开完整评分表。没有数据的关键条件写“待企业确认”；与项目无关的合规套话不展开。

## 报告二：项目申报可行性分析报告

定位是合作后的实施决策。固定包含：

1. 项目版本、现行通知、申报层级、批次、截止日期和当前状态；
2. 三档结论：可申报、有条件申报、不可申报或暂无法判断，并说明依据；
3. 现行条件或完整评分表逐项拆解；
4. 企业值、证据来源、证据状态、确定得分、条件得分和差距；
5. 项目专属核心对象及跨证据链一致性；
6. 每项补强动作、材料、验收标准和完成节点；
7. 当年申报、补正、审核、复核或下一年度倒排计划；
8. 国内、国际科技咨询报告的实施内容和成果使用方式。

评分细则已经公布的项目拆完整评分表；评分细则未公布时分析条件和竞争力；企业数据缺失项标待补。政策合格线与内部安全目标分别列示。

## 专项补强接口

- 专精线额外核验“数字化转型诊断报告”：整体档次，发展战略、业务创新转型、新型能力、系统性解决方案、治理体系，全国和同行对标、优势弱项及提升路径。未提供时写“待企业确认，建议补强”，不预写档次、指数或排名。
- 高企额外关联“研发费用加计扣除规范化服务”：立项可研、项目清单、人员设备清单、工时记录、材料领用、小试中试、项目变更、结题成果、专利关联、月度费用分配、研发辅助账和研发明细账，并与高企研发项目、专项审计和纳税申报口径一致。

## 水印与文件格式

分析与体检默认 PDF，沿共享品牌和同源正文；申请书交付可编辑 DOCX。用户要求报告可编辑时，从同一内容追加 Word，保留数值及来源。客户端用静态 HTML 和统一 PDF 工具，其他宿主用可用渲染能力，过程文件留本地。

Word 正文保持可编辑，PDF 使用页面水印；水印沿各格式可实现的方式保留。

## 对外交付的数据来源

报告附录沿用“序号、文件名称、链接”三列，官方文件提供直达链接，知识库资料写“来源共创知识库”。哈希、回执、本机路径、内部定位和候选标记留在内部验证资料。

政策表按管理办法、年度通知、指南评分和截止时间分别对应真实文件；待取得项标明缺口。补强任务分别写状态、时间和成果，引用与任务直接相关的企业事实。
