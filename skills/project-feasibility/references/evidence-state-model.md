# 证据状态模型

| 状态 | 含义 | 可否支撑硬门槛 |
|---|---|---|
| `verified` | 已有可定位原件或高等级来源，主体、期间和口径一致 | 可以 |
| `computed` | 基于已核验原始值按政策公式复算通过 | 可以 |
| `claimed` | 企业自述、未核验填报或低等级线索 | 不可以 |
| `missing` | 要求存在但未取得证据 | 不可以 |
| `conflicting` | 多来源对同一事实冲突 | 不可以 |
| `not-applicable` | 经规则确认不适用 | 不参与 |

专精特新和小巨人任务先承接 `sme-development-projects/references/application-version-gate.md` 的已确认审核版本和事实锁。申请书确已列示的财务、经营、技术、客户、产能、指标及专利法律状态，经核对主体、期间、口径和材料内部一致性后，可在本轮推导中映射为 `verified`，并记录“申请材料列示、本轮推导事实”的依据边界；这不表示已获外部独立证明。不得仅因缺少登记簿或额外证明将已确认材料重置为 `claimed`，也不得扩展到材料未列示的专利、状态和指标。材料内部矛盾、计算不成立或更高等级现实来源明确冲突时，保留原值并标记 `conflicting`；政策、目录、企业登记及现实对标仍独立核验。

每个证据记录来源文件、页码或字段、主体、期间、口径和取得时间。不得用多个低等级线索拼成 `verified`。冲突存在时保留全部来源，列出裁决所需材料。
