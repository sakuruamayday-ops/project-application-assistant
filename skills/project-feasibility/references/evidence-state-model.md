# 证据状态模型

| 状态 | 含义 | 可否支撑硬门槛 |
|---|---|---|
| `verified` | 已有可定位原件或高等级来源，主体、期间和口径一致 | 可以 |
| `computed` | 基于已核验原始值按政策公式复算通过 | 可以 |
| `claimed` | 企业自述、未核验填报或线索 | 先作条件判断并列核验动作 |
| `missing` | 要求存在、证据待取得 | 交付缺口与补证路径 |
| `conflicting` | 多来源对同一事实冲突 | 保留各值，列裁决依据与动作 |
| `not-applicable` | 经规则确认不适用 | 不参与 |

专精特新和小巨人沿用本轮确认版本及事实锁。申请书已有财务、经营、技术、客户、产能、指标和专利状态，经主体、期间、口径及内部一致性核对后，可映射 `verified`，注明“申请材料列示、本轮推导事实”。外部独立证明另记状态；内部矛盾、计算差异或高等级现实来源冲突时保留原值并标 `conflicting`。政策、目录、登记和现实对标分别核验。

证据记录来源文件、位置、主体、期间、口径和取得时间，状态随实际取得情况标记；冲突保留全部来源并列裁决资料。
