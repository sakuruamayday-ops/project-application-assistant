# 投资证据链

每笔投资至少记录合同、发票、付款、设备或服务、验收、资产入账、含税金额、不含税金额和发生日期。

按适用资金管理办法核对主体、地域、建设投资期、设备和费用类别。建设投资期是费用归属口径。

关联交易、二手设备、融资租赁、进口设备、软件和安装费分别标记，按适用资金管理办法核定。缺项目专用资助口径时，先列实际投入、可核金额和凭证缺陷，项目适格金额及补助比例待客户提供专项文件后计算。

总投资、固定资产、设备及补助基数按各口径分别列示。

## 管理办法

缺属地资金管理办法时，见[省级管理办法检索指引](policy-lookup.md)。

## 台账核验输入已有逐笔数组沿用原入口。核验项目期或表列合计时，台账 JSON 使用对象，`records` 放原逐笔数组，`project_period` 用 `start`、`end` 登记项目起止日，`table_totals` 按明细金额字段登记原表合计。日期使用 YYYY-MM-DD，单位以字段登记为准。

凭证号登记为 `voucher_number`，旧台账取 `id`。相同凭证号、含税金额和日期视为重复。税率按单笔填写 `tax_rate`，也可在台账对象统一填写。税率使用百分数或 0 至 1 的小数。已提供税率时按分反算未税额。回执列出实际校验税率的笔数和每项合计差额。

逐笔填写 `invoice`、`acceptance`、`payment` 关联编号与 `bank_paid_yuan` 实付金额，精确到分。实付必须与该笔发票含税额一致。

已提取原凭证时，执行 `scripts/reconcile_investment_ledger.py 台账.json --invoices 发票.json --acceptances 验收.json --payments 银行流水.json`。三份均用凭证数组，逐条含 `id`、`row`、`contract`。发票填 `gross`，银行付款填 `invoice` 和 `installments`，每条流水的「金额」用元。到账金额按银行分笔流水求和。

只将回执 `verified_record_ids` 中的记录纳入适格性判断，仍按适用政策判断设备、项目期、主体及费用类别。表列合计继续与全部明细对账。
