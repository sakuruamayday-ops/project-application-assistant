# 投资补助项目

按用户给定规则核算时，直接比较合同、发票、付款期间和设备类别，交付可复算结果并说明适用规则。补贴资格或正式申报按对应当期政策分析。

## 核验方法

1. 核验备案主体、地点、建设期、投资期和截止。
2. 关联合同、发票、付款、到货、验收和入账。
3. 分列设备、软件、安装、土建、研发、流动资金和其他费用。
4. 区分含税与未税、已投与计划、新旧设备及关联交易；逐科目核对税口径，汇总、摘要和来源使用同一范围。
5. 按适用规则记适格、待核验、不适格金额，列排除依据及后续核实项。
6. 对应产能、效率、质量、就业和节能绩效。

文件数据取实际读取结果。合计、合同减实付、发票减实付、排除归零及其他差额分别登记公式、原始证据 ID 和结果。

费用规则见 `references/investment-evidence-chain.md`；结构化台账用 `scripts/reconcile_investment_ledger.py` 检查金额与凭证链。按当前可用证据完成核算，审计及资格结论分别注明来源与状态。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
