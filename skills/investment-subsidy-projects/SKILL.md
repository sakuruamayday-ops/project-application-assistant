# 投资补助项目

## 商业定位、MCP 双态与黑板接力

本技能属于 **WorkBuddy 收费深度分析与成品交付能力（技改补助投资核算 · 收费 MCP 服务端 / 付费交付端）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md)：

- **业务范围**：承接技改设备合同/发票/付款/资产逐笔归集核算与补助测算报告；商业报告母版与服务端生成资产留在收费侧，严认原件实绩与可验证数据、绝不虚构财务/司法/实测指标、绝不输出废弃的内部估分，提供四列缺口与可执行整改动作。
- **主体隔离黑板与 MCP 故障显式报错**：按当前企业主体读写 `.facts/<企业标识>.facts.json` 实现组合包无缝接力并杜绝跨企业串户；已配置付费 MCP 若遇鉴权过期、配额归零或超时，显式向用户报错排查，绝不静默降级。

地方条件按[省级管理办法检索指引](references/policy-lookup.md)核对适用办法。申报时间、截止日期与当年申报范围由客户按当期通知确认。

按用户给定规则核算时，直接比较合同、发票、付款期间和设备类别，交付可复算结果并说明适用规则。补贴资格或正式申报按对应当期政策分析。

## 核验方法

1. 核验备案主体、地点及建设投资对应的合同、付款、验收和入账事实。
2. 关联合同、发票、付款、到货、验收和入账。
3. 分列设备、软件、安装、土建、研发、流动资金和其他费用。
4. 区分含税与未税、已投与计划、新旧设备及关联交易；逐科目核对税口径，汇总、摘要和来源使用同一范围。
5. 按适用规则记适格、待核验、不适格金额，列排除依据及后续核实项。
6. 对应产能、效率、质量、就业和节能绩效。

文件数据取实际读取结果。合计、合同减实付、发票减实付、排除归零及其他差额分别登记公式、原始证据 ID 和结果。

费用规则见 `references/investment-evidence-chain.md`；结构化台账用 `scripts/reconcile_investment_ledger.py` 检查金额与凭证链。按当前可用证据完成核算，审计及资格结论分别注明来源与状态。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
