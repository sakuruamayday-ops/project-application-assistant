# 优质中小企业申请版本闸门

先从材料识别项目层级、地区、申报年度、批次、申请类型和申请书版本，再取得用户对本轮审核版本的确认。不得把文件名或模型推断直接当成用户确认。

- 项目层级：创新型中小企业、专精特新中小企业、专精特新“小巨人”或地方培育项目；
- 申请类型：新申报、复核、简单更名或其他专项；
- 版本证据：当期通知附件、官方申报系统导出表或明确版本号。

文件名、历史培训资料和企业自述只能作为线索。识别失败、多个版本并存或与用户确认不一致时，暂停依赖该版本的评分、达标结论和正式正文；不依赖版本的资料读取、事实整理和冲突清单可以继续，不得把局部缺口扩大为整项停工。

## 版本确认后的事实锁

版本确认只决定适用表单与政策规则，不重写企业材料。政策、目录、企业登记和现实对标以可核验现实资料为准；申请书列示的财务、经营、技术、客户、产能、指标和专利法律状态作为本轮推导事实使用，已列示专利法律状态不得仅因未取得登记簿而降级。出现材料内部矛盾、计算不成立或更高等级现实来源明确冲突时，保留原填写并指出冲突，不得静默修正。主导产品、补短板、填空白和国产替代可以依据企业自述形成申报主张，但仍须分别通过产品边界、技术因果、同类环节和跨章节一致性审查。
