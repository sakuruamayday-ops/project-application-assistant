# 主导产品命名与收入边界门禁

## 核心原则

主导产品名称必须同时回答三个问题：卖的是什么、核心技术落在哪里、收入按什么边界统计。不得用“高精度”“高耐久”“高性能”“高品质”“智能化”“先进型”等泛化形容词充当技术定义。

主导产品不得机械等同于发票上最末端、最通用的商品名称。企业自主研发、稳定生产并内部使用的核心配方、基材或部件，如直接决定终端产品性能、构成企业技术壁垒且已随终端产品实现规模商业化，可以作为申报主导产品的技术实体；不得因其不单独外售而否定。应选择：

> **真实可核算销售边界内，能够完整承载核心技术、知识产权和产业链价值的最小充分产品单元。**

这一定义称为“申报战略选层”。它要求同时区分四个层级：

1. **销售交付物**：企业最终对外出售并形成营业收入的材料、部件、容器、设备、系统或服务。发票主要用于确认该层级和收入总量。
2. **核心技术载体**：承载关键配方、基材、结构、机理或工艺的中间材料、部件或制造环节。
3. **申报主导产品**：在商业化收入可归因的前提下，最能体现专精特新和小巨人先进性、补短板价值的产品口径。可以是独立销售产品，也可以是稳定嵌入终端销售产品的自研核心基材或部件。
4. **补短板与填空白对象**：主导产品内部真正解决产业问题的基材、核心部件或关键工艺，可以下沉到技术载体层，不要求与销售交付物逐字同名，但必须形成“技术载体→主导产品→销售收入→产业链价值”的强因果链。

## 申报战略选层三路径

| 情形 | 主导产品选层 | 收入口径 | 补短板与填空白写法 |
|---|---|---|---|
| 自研基材、核心部件或中间产品具有独立对外销售和可归集收入 | 可以直接选择该基材、部件或中间产品 | 使用该产品真实对外销售收入 | 直接围绕该产品的材料、结构或工艺短板展开 |
| 自研基材或核心部件由企业批量生产，主要内部用于终端产品，属于配方保密、逆向破解防护或差异化壁垒 | 可以直接以核心基材或部件作为申报主导产品，也可以采用“基于自研核心载体的终端产品”复合口径；根据哪个层级更能承载项目先进性选择 | 不确认内部转移收入；将稳定使用该核心载体的终端产品销售收入作为商业化贡献收入，并说明归因边界 | 直接围绕自研基材、核心部件或关键工艺展开，说明其如何决定终端产品性能和供应链价值 |
| 基材、配方或工艺仍处研发、中试，未形成稳定生产或实际产品应用 | 不得作为主导产品或复合名称中的既成事实 | 不得归集收入 | 仅能作为未来研发方向，不得写成已补短板、已填空白 |

## 战略选层硬门禁

每个候选层级必须依次回答：

1. **项目适配**：该层级能否直接解释专精特新、小巨人要求的专业化、创新性、补短板、填空白或产业链关键作用。
2. **生产实质**：企业是否真实研发并稳定生产该材料、部件或产品，而非仅外购后加工或概念性描述。
3. **商业化归因**：该层级是否具有独立对外收入；没有时，是否已通过申请书、技术文件、产品结构、工艺流程或企业自述，与使用该核心载体的终端产品收入建立清晰、可复算的归因关系。核心基材不单独外售不得作为否定理由。
4. **技术承载**：核心技术、量化指标和I类知识产权是否主要落在该层级。
5. **市场可比**：市场分母、领军企业和国产替代对象能否按该层级找到同类同环节对象。

前三项为硬门禁。只要生产实质或商业化归因不能成立，不得仅因“听起来更先进”选择上游材料口径；但企业为保护配方、避免竞争对手逆向破解而自产自用核心基材，属于合理商业模式，不构成缺陷。

## 固定战略选层表

每次诊断主导产品前，必须先输出“主导产品战略选层表”：

| 候选层级 | 候选产品 | 是否自主稳定生产 | 商业化承载方式 | 收入归因路径 | 核心技术承载度 | 项目适配度 | 市场可比性 | 选层结论 |
|---|---|---|---|---|---|---|---|---|
| 基础材料或配方 | | 是／否／材料未说明 | 独立外售／内部嵌入／研发中 | | 高／中／低 | 高／中／低 | 高／中／低 | |
| 功能基材或中间产品 | | 是／否／材料未说明 | 独立外售／内部嵌入／研发中 | | 高／中／低 | 高／中／低 | 高／中／低 | |
| 部件或终端制品 | | 是／否／材料未说明 | 直接销售／内部嵌入 | | 高／中／低 | 高／中／低 | 高／中／低 | |
| 复合口径 | 基于自研核心载体的终端产品 | | 核心载体内部嵌入，终端产品对外销售 | | 高／中／低 | 高／中／低 | 高／中／低 | |

不得未经选层就因为终端产品名称通用而判其不适合，也不得因为基材技术更先进就自动把基材定为主导产品。

## 命名结构

优先使用以下结构，按材料实际取舍：

`关键结构、机理或工艺特征＋适用工况或对象＋产品实体或产品族`

可接受的技术特征包括：

- 结构：密封储油、顶部散热、多层共挤、渐变刚度、双气路、复合传动。
- 机理：自润滑、温流联动、闭环寻优、微压增氧、界面相容增强。
- 工艺：梯度微相调控、在线压接监测、自适应灌装、低温补偿控制。

泛化形容词只有在后接可验证技术特征时才能保留。例如“高耐久密封储油自润滑转向中间轴”仍以“密封储油自润滑”为技术定义，“高耐久”只是结果描述。

## 五步命名门禁

1. **业务实质**：在完成战略选层后，完整读取 `core-formula-process-performance-matrix.md`，优先依据申请书、技术文件、产品结构、工艺流程、产品目录和企业自述判断核心技术载体是否真实研发、稳定生产并嵌入终端产品。销售台账和发票只核对终端商业化收入及总量，不得仅因发票没有核心基材名称而否定基材。
2. **技术实质**：从材料和专利中提取结构、机理、工艺、控制或材料特征，不得只摘录效果词。
3. **专利支撑**：把候选名称中的每个技术限定词映射到专利权利要求、说明书实施方式或材料明确技术点。只在专利标题中出现相近名词，不等于直接支撑。
4. **收入边界**：明确统计单元是零部件、总成、系列产品、平台还是制造能力。候选名称比原名称更宽或更窄时，必须重做分产品收入归集和占比复算。
5. **全文联动**：名称或边界变化后，同步修改产业链、市场占有率、知识产权、补短板、填空白、国产替代、领军企业、产学研、企业简介和终稿。

## 核心配方技术矩阵与审核顺序

内部自产、自用且不独立外售的核心配方、基材或部件，必须输出“核心配方版本—工艺窗口—终端应用性能对应矩阵”。矩阵使用匿名版本代号，至少包含技术目标、可公开技术路线、可公开工艺窗口、终端应用产品或产品族、终端应用性能、技术资料或申请书依据和保密边界。

审核顺序固定为：

1. 从申请书和技术资料建立产品层级；
2. 建立核心版本、生产窗口、终端嵌入和性能结果的技术因果链；
3. 再用销售资料核对稳定搭载该核心版本的终端产品收入；
4. 汇合为“核心技术载体→稳定生产→终端嵌入→性能贡献→终端销售收入”。

不得为了证明先进性披露配方精确比例、原料牌号、添加顺序、关键单点温压时间或能够复现工艺的连续步骤。已公开区间可以引用；未公开参数写“企业内部受控窗口”。

## 收入边界判定

| 变更情形 | 处理要求 |
|---|---|
| 零部件改为总成 | 不得沿用零部件收入；重新核对总成销售台账、合同和发票 |
| 单品改为系列产品 | 汇总同一技术平台下各产品收入，并排除仅因客户或规格相近而拼接的产品 |
| 产品改为平台或系统 | 证明软件、硬件、实施和服务收入属于同一可交付产品边界 |
| 制造设备专利改写成销售产品 | 先证明设备本身对外销售；仅用于内部生产时不得作为主导产品 |
| 名称仅增加技术限定词 | 核对限定词是否覆盖全部计入收入的产品；不能只覆盖少量高端型号 |
| 内部自产基材改为主导产品 | 不以独立外销为必要条件。技术文件或申请书能够说明自主研发、稳定生产、内部嵌入、性能决定作用和商业化应用时，可直接采用基材口径；收入使用稳定搭载该基材的终端产品销售收入，不得确认内部虚拟转移收入 |
| 补短板对象下沉到基材或工艺 | 允许与主导产品名称不同层级，但必须说明该基材或工艺如何决定主导产品性能、收入和产业链价值 |

## 固定输出表

每次体检必须按以下顺序输出：“主导产品战略选层表”→“核心配方版本—工艺窗口—终端应用性能对应矩阵”→“技术链先行、收入链后置审核流程”→“主导产品命名与收入边界门禁表”。命名门禁表至少包含：原名称、泛化词识别、核心结构机理或工艺、专利支撑位置、原收入边界、建议收入边界、是否触发重算、首选名称、启用条件和结论。

当触发重算时，在取得新口径分产品收入前，首选名称只能给出“补证后启用”，不得把旧收入静默带入新名称。

## 判退情形

- 候选名称删除泛化词后只剩通用产品名，仍看不出技术特征。
- 名称中的技术限定词在材料或专利中没有支撑位置。
- 用内部生产设备专利把主导产品改成并不对外销售的设备。
- 内部自产基材没有独立销售收入，却把内部耗用量或转移价格当成主导产品收入；正确做法是归因到稳定搭载该基材的终端产品销售收入。
- 仅依据发票未出现基材名称，就否定技术文件或申请书已经讲清的自产自用核心基材。
- 只因终端产品名称常见就直接上移到基材，没有比较核心基材口径与“自研核心载体＋终端产品”复合口径的项目适配度。
- 只因基材、配方或工艺听起来先进就选择上游口径，没有核对稳定生产、商业化归因和终端应用。
- 从零部件扩大为总成、系统或产品族后仍直接沿用原收入。
- 名称改变后继续使用旧市场分母、旧领军企业或旧国产替代对象。
