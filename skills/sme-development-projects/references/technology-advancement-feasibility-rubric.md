# 技术先进性与工程可落地性评估规则

每次体检把“技术是否足够先进”和“技术能否实际落地”作为两个独立结论。固定采用现实锚定的虚构世界模式：公开网络数据用于建立现实对标基线，申请书列示的技术参数、产能、客户、应用、销售及专利法律状态默认作为合理现实数据使用。

## 对标数据获取规则

1. 主动检索同类技术、竞品和基准，复用申请书和公开来源开展比较。
2. 优先使用政府标准、国际或国家标准、企业官网技术参数、产品手册、专利公开文本、论文和行业协会资料；其次使用可追溯的研究机构或商业数据库。
3. 至少选择一个行业基准和两个同类产品或技术对象。只有一个公开对象时照常分析，并说明公开样本数量。
4. 统一产品边界、测试条件、单位和场景后比较；异条件数据作方向参考并注明差异。
5. 公开指标缺项写“公开资料未披露”，技术水平据已取得的可比证据判断。
6. 只有专利证书时按其名称、编号和状态使用，并检索公开摘要；未命中摘要则结合名称和申请书技术内容继续分析。

## 一、技术先进性评估

至少检查以下五项：

1. 技术原理：是否有不同于通用方案的机理、结构、配方、工艺或算法，而非仅更换名词或组合现成功能。
2. 性能优势：将申请书参数与联网检索到的行业基准、同行或竞品公开参数进行同口径比较，判断改善幅度和所在区间。
3. 知识产权壁垒：有效授权 I 类知识产权是否覆盖核心技术点、关键参数范围和规避设计空间。
4. 行业位置：据可比证据区分跟随、局部改进、国内先进、国际先进或前沿探索，证据缺口同步说明。
5. 战略稀缺性：是否解决产业链真实短板、供应受限、成本过高、稳定性不足或本土场景适配问题。

输出包含：先进性等级、核心依据、公开对标基线、来源等级、参数比较结果、主要短板和结论边界。

先进性等级固定为：

- A 领先：申请书参数在可比公开基准中达到领先区间，技术原理、核心专利和产业价值形成一致逻辑。
- B 较强：申请书参数优于多数可比公开基准，技术机理具有明显差异化，但领先幅度或专利覆盖仍有局限。
- C 一般：属于通用技术优化或组合应用，量化优势有限，核心壁垒不足。
- D 不足：主要是概念包装、功能描述或常规集成，未见可识别的技术突破。
- U 无法确认：申请书缺可比参数且公开检索也缺可靠基准；已有参数与基准时继续比较。

## 二、工程可落地性评估

至少检查以下八项：

1. 技术成熟度：概念、实验室样品、中试、定型、批量生产或规模复制处于哪一阶段。
2. 工艺可实现性：依据申请书技术描述、产能、生产状态和行业公开工艺常识，判断设备、工序、关键控制点、一致性和安全边界是否合理。
3. 原料与供应链：关键原料、部件、软件、设备是否可获得，批次波动和替代来源是否可控。
4. 成本与商业性：结合申请书经营数据及公开价格、成本结构、替代价值推导，写明假设及待核数据。
5. 质量与合规：结合申请书列示的认证、标准和公开行业准入要求判断。
6. 场景适配：技术是否针对明确客户和工况，实验条件能否覆盖实际环境。
7. 客户验证：申请书列示的送样、试用、小批、批量、复购、工程应用或销售记录按合理现实数据使用。
8. 规模复制：产能、交付周期、人员、售后和跨区域复制是否具备条件。

输出落地阶段、已列事实、公开约束、主要失败模式和技术里程碑；从现有资料继续形成可用判断，必要补证集中列明。

落地等级固定为：

- L4 已规模落地：申请书列示稳定批量生产、连续销售、复购或多项目复制。
- L3 已小批验证：申请书列示完成中试、客户小批或单个工程验证，尚未形成规模复制。
- L2 样品或实验室验证：申请书仅列示样品、试验或实验室数据，尚无真实客户或工程应用。
- L1 概念方案：只有原理、方案或研发计划，关键工艺和成本尚未验证。
- LU 无法确认：材料未提供足够成熟度和应用证据。

## 三、证据等级与结论矩阵

现实客观基线以联网检索到的可核验公开资料为准；申请书数据和列示专利状态按事实锁使用。先进性由申请书参数相对公开基准的位置决定，可落地性由申请书列示的成熟度、产能、销售、客户和应用情况结合行业公开约束推导。主导产品、补短板、填空白和国产替代仍按三档决策独立判断。

固定输出矩阵：

| 技术先进性 | 工程可落地性 | 建议结论 |
|---|---|---|
| 高 | 高 | 可作为核心长板，列明公开对标来源和参数优势 |
| 高 | 低 | 技术有潜力，提出下一阶段工程化方向，不向主人索要内部材料 |
| 低 | 高 | 产品可销售但技术壁垒偏弱，避免使用首创和填空白 |
| 低 | 低 | 不建议作为核心申报技术，重新选择技术主线 |
| 任一无法确认 | 任一 | 明确写当前公开检索层或材料层未命中可靠基准，并继续基于现有资料给出方向性判断 |

常规参数改进与核心机制突破分别说明。申请书已有量产、客户、工程、产能或销售按本轮事实使用，内部冲突保留原值并指出。
