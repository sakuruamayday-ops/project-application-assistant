# 细分领域关键技术首创等情况写法

## 主人确认的标准范式

采用两段式，不把六个要素机械摊成流水账。

第一段依次写：

1. 应用对象及核心器件或部件
2. 使用场景中的两至三项并行要求
3. 传统方案的主要技术路径
4. 传统方案造成的结构性矛盾，以“难以兼顾”收束

第二段以“本企业突破……协同难题”起笔，依次写：

1. 首创结构、工艺或技术路线
2. 两项以上可溯源量化指标
3. 检测、可靠性试验、客户应用或准入验证
4. 明确的竞品型号、同类产品或替代对象
5. 对国内产业链供给短板的具体补位

不得用“形成技术、开发产品、解决问题、起到作用”的机械串联代替上述叙事。不得在正文中加入“材料列示、根据申请书、证据不足、待补材料”等体检报告口吻。

## 起草前证据卡

动笔前先完成以下证据卡，任一核心项缺失时降低结论强度，不得用空话补位：

| 项目 | 必填内容 |
|---|---|
| 应用对象 | 具体设备、器件、材料、系统或工序 |
| 并行要求 | 两至三项必须同时满足且存在张力的要求 |
| 传统路径 | 现有产品或工艺通常如何实现 |
| 失效机理 | 传统路径为什么无法兼顾，落到结构、材料、控制或工艺原因 |
| 协同突破 | 两至三项相互配合的核心结构、机理或工艺 |
| 量化锚点 | 至少两项有材料来源的性能、效率、寿命、尺寸、成本或可靠性指标 |
| 产业化验证 | 具体客户、准入、检测、批量供货、产能或应用项目 |
| 对标与补位 | 同类产品、具体型号或产品族，以及国内供给短板 |

## 结论强度降级

- 有专利、查新或同类对比，且有客户或产业化验证时，可按证据使用“首创”“填补空白”或“实现替代”。
- 技术方向成立但缺查新、客户切换或进口采购记录时，改为“形成自主技术路径”“补足国内供给能力”或“可面向某产品开展国产配套替代”。
- 只有研发设想、没有样机或产业化事实时，不得写成已经开发、已经应用或已经替代。
- 降低强断言时只改结论强度，不得删掉应用场景、传统路径、结构性矛盾和协同突破。

## 判退示例

- 以企业历程、专利数量或荣誉起笔，没有产业链短板。
- 只罗列三项技术，没有说明三项技术解决的共同矛盾。
- 使用“高性能、国际领先、客户认可、效果良好”等不可核验表述代替指标与验证。
- 只满足字数，不具备两段式因果结构。

## 标准样稿

智能电能表使用SMA、SMB等底部散热肖特基整流二极管，器件须同时满足大电流整流、低热阻散热、薄型封装三重要求。传统封装主要经引脚和PCB散热，热路径长、热交叠突出，功率密度与寿命难以兼顾。

本企业突破散热、功率与小型化协同难题：首创顶部裸露主散热、底部引脚辅助散热结构，功率密度较SMA提升约120%，支持8A产品，寿命提升约42%；封装体积降至SMA的33%，厚度仅0.9mm。产品通过零下55℃至150℃的500次冷热冲击及125℃高温蒸煮96小时验证，通过国家电网全项测试并准入，可升级替换onsemi MBRA、MBRS等传统表贴产品，补足国内智能电表用顶部散热肖特基器件供给能力。

## 写后检查

- 第一段是否说清应用、三重要求、传统路径和核心矛盾。
- 第二段是否以企业突破起笔，并连贯写完首创、指标、验证、替代和补位。
- 是否存在至少两个量化锚点。
- 替代对象是否具体，无法落实型号时至少写明现实同类产品族。
- 结尾是否落到具体供给能力，不使用“助力高质量发展”等空话。
