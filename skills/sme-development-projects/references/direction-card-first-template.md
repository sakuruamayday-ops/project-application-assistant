# 前期培育报告方向卡先行模板

## 固定方法

方向比较任务按现有、用户、建议方向及比较推荐、政策适配、成熟度组织；展开实际存在的方向，前期简报沿其既定结构。

## 方向卡字段

每个方向分别写明：

1. 方向名称与产品内容；
2. 好处；
3. 坏处；
4. 培育建议；
5. 专利布局；
6. 申报角色。

## 边界与证据

- 共享算法或技术能力不代表同一行业或同一主导产品。客户、交付物、收入边界或产业环节不同的，拆卡分析。
- 同一可核算产品、客户问题和商业闭环成立时可合并方向；其他方向分别保留并说明关联。
- 用户方向单列；分析者发现的更优方向单列并标注“建议新增方向”。
- 按已有材料分析，缺口集中列，继续形成有依据的建议。
- 内部矛盾、技术产品脱节、收入边界冲突和计算错误仍须指出。
- 只有方向确定后，才开展政策门槛、平台质量分、成熟度和正式证据链核验。
