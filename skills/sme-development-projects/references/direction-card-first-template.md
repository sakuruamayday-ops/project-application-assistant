# 前期培育报告方向卡先行模板

## 固定方法

专精特新和小巨人前期培育报告必须先完成方向卡，再进入政策适配和申报成熟度。固定顺序为：企业现有方向、用户给定方向、建议新增方向、方向比较与推荐、政策适配、申报成熟度和培育路线。缺少某类方向时直接跳过，不为凑数量编造内容。

## 方向卡字段

每个方向分别写明：

1. 方向名称与产品内容；
2. 好处；
3. 坏处；
4. 培育建议；
5. 专利布局；
6. 申报角色。

## 边界与证据

- 共享算法或技术能力不代表同一行业或同一主导产品。客户、交付物、收入边界或产业环节不同的，必须拆卡分析。
- 不得用抽象“技术母体”把不相关方向硬合并。可合并的最低条件是同一可核算产品单元、同一客户问题和同一商业闭环。
- 用户方向单列；分析者发现的更优方向单列并标注“建议新增方向”。
- 方向卡阶段有资料就分析，没有就跳过，不输出证据缺口，不因缺少外部证明暂停。
- 内部矛盾、技术产品脱节、收入边界冲突和计算错误仍须指出。
- 只有方向确定后，才开展政策门槛、平台质量分、成熟度和正式证据链核验。
