# 专精与小巨人材料体检报告

写作与精简沿[共享报告方法](../../_runtime/report-writing.md)：保留本文件章节和表型，直接交付可用稿，资料缺口集中说明。

前期评估沿下方原结构，已填申请书核稿按受托字段展开；单点咨询直接答所问，企业事实各据本轮资料。

## 行动型报告

生成器与交付检查使用同一章节顺序：第五章“财务情况简析”在“5.1 补强任务表”之前。已有数据对照表标题固定为“只对照企业已有数据的指标”，表头为“关键指标、企业现有数据、判断、谈单时怎么说”。

专精培育围绕主导产品和佐证作用推荐工业新产品及适用三首，写项目、产品、顺序、支撑和下一步。装备部件对应首台套，独立软件对应首版次，材料对应首批次；固件、软著和产品属性据事实分别判断，认定及评价作用按各项目条件说明。

研发机构沿已有内部筛选方法：基准年度固定资产期末额×50%作为设备测算参考上限，再与适用档位比较。该比例用于内部推荐，实际设备原值据清单核定；固定资产待取得时先给建设方向。客户正文写具体层级或建设建议及创新能力作用，资料缺口集中列明。

报告沿五章19块：结论、路径、产品、发明布局和财务。保留原摘要、对照表和内容位置；省级及小巨人按各自展示规则说明资格。5.1 用“补强动作、补强价值、建议节点”，详细材料与内部验收留底稿。

同行表列“对象或产品体系、已核产品能力、本企业异同、启示”，据企业记录与厂商原文填写。科咨说明先进性证据，数字诊断说明短板改进，PCT 说明海外申请路径，质量管理和 CE 说明交付与适用市场合规，各任务按实际价值列行动。

客户报告聚焦产品、差距、动作及价值，质量分和输入留后台核验；政策原文和实际资格状态照常记录。

“5.1 补强任务表”和“两年软提升项”同步写现行指标、作用及动作。PCT 对应国际拓展，质量管理与适格产品认证对应质量控制，适格数字评测对应数字化；CE 核机构、评定方式和范围，科咨、咨询诊断与正式评价结果分别说明。计分据当期官方口径，PCT 以实际申请及授权法域表述。

先给决策、差距和下一步，再据企业数据对照条件；缺口集中用简表写事项、影响和补齐动作。明确未满足与待核分别呈现，跨报告复用结构，本企业数据和政策口径分别核对。

生成模块：激活 project-feasibility，沿用 `project-feasibility.generate-report`，事实 JSON 指定 `report_layout: "sme-action"`、`report_date` 和 `report_sections`。内容块键依次为 conclusion、policy、known、roadmap、current_tasks、next_tasks、acceptance、soft、product、product_boundary、peers、ip、ip_topics、ip_time、finance、metrics、finance_conclusion、finance_missing、tasks。每块包含文本数组 paragraphs、表格行数组 rows、可选文本数组 notes；准确列数和列序见 [报告内容输入](../../project-feasibility/references/sme-action-workflow.md#报告内容输入)。章节标题与表头由 sme_action_report.py 的 SECTIONS 定义，不在业务输入中随意重写。finance_conclusion 为文字块，无表格。适用项目 id 为 specialized-sme 或 little-giant，报告类型沿用实际 preassessment 或 feasibility。

保留金额、期间和单位，复算比率；主动据企业及技术资料给产品首选、理由、备选和收入边界。跨年条件、主营与主导收入、授权与Ⅰ类资格分别核对；专利标布局建议，PCT、CE 据产品市场安排，缺口集中列。

正文写企业事实、判断和动作；局部修订更新相应 JSON 并生成新 HTML/PDF，其他已确认内容复用。申请书沿独立 Word 回填编辑。
