# 四项判断三档决策

申请书列示内容沿本轮事实锁，政策、目录、登记及对标查现实来源；冲突保留原值及影响。产品、补短板、填空白和替代分别按边界、因果、同环节与跨章一致性判断，补证聚焦实际缺口。

对主导产品、补短板、填空白和国产替代分别输出：

- `保留`：对象明确，主营和收入边界合理，与核心技术、知识产权、客户验证及产业链环节一致，证据足以支撑；
- `替换`：对象与主营实质、收入、技术、知识产权或产业链明显错位，给出首选替换对象和全材料联动修改；
- `补证后保留`：逻辑可能成立但关键证据不足，列出缺失证据、验证标准和未补证前的使用限制。

补短板、填空白和替代按同类同环节说明原问题、改进及验证；锻长板按已有优势、同口径指标、创新和产业化说明。先进称谓及入选经历各按实际证明范围使用。

市场地位先按 `industry-positioning/references/market-boundary-and-substitution-gate.md` 确定细分边界；行业标准、海关和协会分类作为辅助，项目指定分类据当期目录填写。

国产替代底稿记录国外企业、产品或型号、应用、指标矩阵、客户项目、状态及收入和 IP 关系。采购、进口、验收和检测按其证明范围使用，政策明确要求的材料据当期条款核对；未知字段标待核。
