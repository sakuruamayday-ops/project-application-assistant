# 中国专利工作流参考

## 目录

1. 检索与查新
2. 专利性初评
3. 权利要求与说明书
4. FTO 与规避设计
5. 项目申报衔接
6. 质量门禁

## 1. 检索与查新

先把方案拆成对象、部件、关系、步骤、参数、效果和应用场景。为每个核心特征建立中文、英文、同义词、上位词和分类号组合。至少记录：检索日期、数据库、检索式、时间范围、同族处理和筛选规则。

优先比较公开日在相关临界日之前的文献。对每篇关键文献记录公开号、标题、申请人、优先权日、公开日、法律状态来源、相关段落或权利要求及其与目标方案的对应关系。

## 2. 专利性初评

分别分析，不把结论合并成模糊的“可申请”：

- 新颖性：单一现有技术是否直接、无歧义地公开全部必要技术特征。
- 创造性：最接近现有技术、区别特征、实际解决的技术问题、技术启示与预期效果。
- 实用性：方案能否制造或使用并产生积极效果。
- 充分公开与支持：说明书是否足以使本领域技术人员实现，权利要求是否获得说明书支持。
- 客体与排除风险：按具体法域的当期法律和审查指南核验。

结论用“较强、一般、较弱、信息不足”表达，并绑定证据与假设。

## 3. 权利要求与说明书

先形成特征矩阵：商业必要特征、技术必要特征、可替换特征、效果增强特征和证据支持位置。独立权利要求覆盖最小可保护组合，从属权利要求建立材料、结构、参数、控制逻辑、用途和实施方式的梯度。

中文申请初稿通常包括：发明名称、技术领域、背景技术、发明内容、附图说明、具体实施方式、权利要求书和摘要。章节应根据专利类型和当期规范调整，不照搬美国申请结构。

检查：术语一致、标号一致、引用关系有效、每项权利要求有支持、实施方式可实现、效果有依据、范围没有被无意缩窄。不得为了扩大保护范围补造未披露方案。

## 4. FTO 与规避设计

先限定产品版本、制造地、销售地、目标日期和法域。只对已核验的相关权利要求做要素表：目标权利要求要素、产品对应特征、是否满足、证据、解释争议、风险等级。

规避方案要改变可能构成必要限定的技术特征或组合关系，并评估等同风险、性能、成本、供应链和新增专利机会。FTO 是范围受限的风险分析，不等同于全球不侵权保证。

## 5. 项目申报衔接

区分有效授权、审中、失效或终止、转让取得。有效授权是否可计入项目以当期政策为准；审中只用于技术储备说明；转让取得要分析取得时间、主营关联、自主性、稳定性和项目认可风险。

专利与主导产品的关联必须落到权利要求或说明书支持的技术特征，不以标题相似代替关联证明。

## 6. 质量门禁

- 所有编号、日期、状态和权利人均有来源。
- 最接近文献与目标技术完成逐项特征映射。
- 法律结论标明法域、时间与限制。
- 引用文本不超出许可范围，来源链接可访问。
- 数值、实施例和技术效果来自用户材料或可验证资料。
- 申请初稿明确供执业代理师审阅，不标注“可直接提交”。
- 专利附图的结构、比例、标号和文字与说明书一致。
