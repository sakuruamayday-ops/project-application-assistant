# 预审与优先审查规则

## 动态注册字段

记录保护中心、服务区域、备案条件、产业领域、发明IPC范围、实用新型IPC范围、不受理情形、官方文件、发布日期、生效日期、IPC版本和最后核验时间。

## 核验顺序

1. 查保护中心官方发布页面或主管知识产权局文件。
2. 查企业注册地址和备案状态。
3. 查当期产业领域与IPC目录，不沿用历史截图。
4. 用当前IPC版本核验分类定义。
5. 对跨区域预审单独核验试点资格和流程。
6. 把保护中心实际反馈标为“实践反馈”，注明日期和适用个案。

## 输出措辞

- 可以写“按当前公开目录初步匹配”。
- 不得写“保证进入预审”或“保证快速授权”。
- 优先审查与保护中心预审必须分栏说明。
