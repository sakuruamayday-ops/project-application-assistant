# P1 检索与法律分析

## 输入

- 技术材料、申请文件或现有权利要求；
- 法域与基准日；
- 检索目标：查新、无效风险、FTO、审查意见或布局。

## 流程

1. 先生成 `technical-feature-map/v1`，提取保护客体、必要技术特征、技术效果和来源定位。缺少出处的候选特征不得自动进入正式权利要求。
2. 从证据图生成单项特征、核心组合和分类号交叉检索单元。同义表达、外文表达、IPC/CPC、申请人和发明人线索分字段记录，不将模型推荐词写成已核验分类。
3. 保存检索库、检索式、访问日、结果数量和未覆盖范围。
4. 将命中文献按公开日过滤，并回到权利要求、说明书段落和附图核对。
5. 生成权利要求引用图、必要技术特征树和 claim chart；把申请文件特征编号与证据图特征编号保持可追溯对应。
6. 新颖性按单一文件逐项判断；创造性记录最接近现有技术、区别特征、技术效果、实际技术问题和技术启示。
7. FTO 只分析目标市场内有效或待决权利要求，明确不等同于可实施法律意见。

## 输出

每条结论附公开文本定位、权利要求号、段落号、附图标记、法律状态来源和查询日期。未命中只能写“当前检索范围未命中”。
