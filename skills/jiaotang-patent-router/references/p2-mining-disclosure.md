# P2 专利挖掘与技术交底

## 技术资产拆解

按“问题—约束—措施—机理—效果—验证—替代方案”拆解技术材料。先建立专利点清单，再决定哪些进入专利、哪些保留为商业秘密。

每个候选专利点至少记录：

- 保护客体和应用场景；
- 核心必要特征与可选特征；
- 特征之间的结构、步骤或因果关系；
- 相对于已知方案的区别及预期技术效果；
- 可替代实施方式、参数范围和上下位概念；
- 当前证据、待补实验和发明人贡献线索；
- 与其他专利点的组合、分案和规避关系。

## 取舍

- 容易逆向、可检测且具有稳定边界的方案优先专利保护。
- 难以逆向、依赖内部工艺窗口且泄露后难以恢复的内容评估商业秘密保护。
- 不为增强专利性补造实施例、参数、效果或实验数据。
- 交底正文只使用用户确认的技术事实；不确定内容进入问题清单。

## 交底结构

技术领域、背景技术、待解决问题、技术方案、工作原理、有益效果、附图说明、具体实施方式、替代方案、拟保护点、发明人信息和待确认事项。
