# 三层标识关系图规范

股权、人员任职、担保质押、业务合作和风险传导尽量在同一关系图中呈现，并同时编码企业状态、风险标签和证据等级。

## 企业状态

| 状态 | 节点样式 | 使用规则 |
|---|---|---|
| 存续、在业、开业 | 绿色浅底 | 当前投资版图只保留此类企业 |
| 迁出、清算、经营异常或状态冲突 | 琥珀色浅底 | 注明登记状态与日期 |
| 注销、吊销 | 灰色浅底 | 只在历史沿革或风险传导确有必要时出现 |
| 状态待核 | 白底斜纹 | 不得默认视为存续 |

## 风险标签

- `执`：被执行、失信、限高或终本。
- `诉`：重大诉讼、开庭或裁判。
- `行`：行政处罚、经营异常或严重违法。
- `税`：欠税、税收违法或非正常户。
- `权`：股权冻结、出质、动产抵押或担保。
- `知`：知识产权权属、无效、终止或侵权争议。
- `传`：关联风险存在已取得证据的传导路径。

标签旁写明当前、历史或待裁决。未命中只能写本轮未命中。

## 证据等级

| 等级 | 含义 |
|---|---|
| E1 | 主管机关、法院、法定披露或用户原始证明直接支持 |
| E2 | 天眼查与企查查同主体、同编号、同时间窗一致 |
| E3 | 单一商业源或单一公开线索支持 |
| E4 | 来源冲突、同名待核、状态待裁决或算法关联 |

证据等级表示可验证程度，不表示风险严重程度。

## 关系边与范围

- 股权、控制和当前任职使用实线，历史任职使用虚线。
- 担保、质押或冻结注明登记编号和状态。
- 业务、项目或知识产权合作必须有合同、公告、项目或专利编号。
- 名称相似、同地址或平台算法关联不得画成事实关系。
- 默认展示目标企业、第一层股东和关键人员、第二层当前投资控制或任职企业；超过第二层仅保留实质控制、担保、资金、重大业务或明确风险传导路径。
- 图旁列明数据截止日、来源覆盖、未覆盖项和状态口径。
