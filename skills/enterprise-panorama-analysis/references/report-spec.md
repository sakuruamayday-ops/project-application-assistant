# 版本B三视图内容与评分口径

写作与精简沿[共享报告方法](../../_runtime/report-writing.md)：保留本文件章节和表型，直接交付可用稿，资料缺口集中说明。

正文结构、标题与综合判断呈现以 `version-b-advisory.md` 为准。本文件只补充内容范围和既有评分维度；同一事实底稿只计算一套评分，全部分项与信息置信度在首页统一呈现，不在各部分重复生成驾驶舱或评分图。

## 建议篇幅

封面与结论1至2页，尽调准入3至4页，全景视图3至4页，科技视图3至4页，顾问机会视图1页，总体控制12至16页。

## 封面与执行摘要

- 企业全称、统一代码、成立年份、注册资本、参保人数、实控人表决权。
- 一段核心结论。
- 首页综合评价沿本版口径呈现一次，注明信息覆盖和置信度。
- 非公开或待取得数据记为资料缺口，评价仅说明现有证据覆盖。

## 第一部分：尽调准入

### 推荐章节

1. 准入结论、关键证据和动作。
2. 工商基本信息与历史沿革。
3. 股权、实控人、核心人员与关联企业。
4. 司法、劳动、行政环保、融资担保及准入条件。

### 默认维度

主体稳定性20%、信用与合规25%、司法与劳动20%、融资与担保20%、经营连续性15%。评价以实际查得的公开事实为依据。

## 第二部分：全景视图

### 推荐章节

1. 经营发展结论、关键证据和动作。
2. 主营产品、业务结构和发展阶段。
3. 土地厂房、设备投资与区域布局。
4. 同行竞品、产业位置和差异化方向。

### 默认维度

治理稳定性20%、业务清晰度20%、土地设备信号20%、市场公开信号20%、经营发展轨迹20%。

营收、利润、客户和产能等未公开时记资料缺口，按已取得的进出口、商标、招投标、公开客户和区域布局信号判断。

## 第三部分：科技视图

### 推荐章节

1. 科技与项目结论、关键证据和动作。
2. 专利、软著、商标和标准的有效性及产品关联。
3. 历史资质、项目与政策补助复盘。
4. 可申报项目矩阵。
5. 未来五年发展与项目申报规划。

### 默认维度

创新基础20%、知识产权20%、数字化能力20%、绿色技术20%、项目成熟度20%。

专利按当前有效授权、审中、终止、驳回、转入或转出分类；当前有效权利范围以现时权属和法律状态核定。

## 置信度

置信度评价“应当公开且本次可检索”的证据覆盖：

- 高：关键结论大部分有官方或两源证据，覆盖率不低于80%。
- 中：核心主体和方向可确认，但部分案件、投资或成果细节缺失，覆盖率50%至79%。
- 低：主体或核心业务仍有重大不确定，覆盖率低于50%。

企业内部财务、客户、毛利和产能不属于合作前公开信息覆盖率的分母。

## 风险表达

按“公开事实—实际影响—核验动作”组织，风险等级与事实及影响强度相称。

## 项目矩阵

项目表列名称、已有基础、待核条件、优先级及时间窗口；财务条件据用户可靠资料比较，缺项并入待取表。

## 五年规划

从公开现状逐年安排技术经营、治理、项目及交付目标，标明规划建议和启动条件。

## 最终结论与客户沟通建议

末页用经营者易懂的话写清问题、实际影响和下一步动作，综合评价集中呈现一次。

1. 先用一段白话说明：企业有没有合作价值、当前处于什么阶段、为什么建议先整改再申报或可以直接推进。
2. 将最需要解决的事项按优先级排列，原则上控制在5至8项。
3. 每项固定写清四件事：`需要解决的问题｜对企业的实际影响｜建议怎么处理｜可落地服务`。
4. 服务动作可以包括股权架构、关联交易治理、法律劳动合规、融资担保清理、体系认证、知识产权布局、土地投资合规、研发管理和项目申报培育，并与前文已核验事实对应。
5. 再给出3至4阶段合作顺序，例如风险清理、基础建设、项目落地、能力升级。
6. 可增加一段“可直接向客户说明”的口语化总结，方便顾问现场展示和讲解。
7. 财务、司法明细和内部数据缺口集中列为待核事项；风险及服务建议以本企业事实、影响和核验动作说明。

## 图表

- 首页集中综合评价，各板块直接给事实、判断和动作。
- 可增加参保人数趋势、专利状态结构、项目优先级矩阵、发展时间轴。
- 连续数值缺失时，以现状表和数据缺口说明替代趋势图。
- 图表旁说明口径、时点和公式。
