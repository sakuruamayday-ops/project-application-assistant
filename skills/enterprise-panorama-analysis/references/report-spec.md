# 版本B三视图报告规范

## 建议篇幅

封面与结论1至2页，尽调准入3至4页，全景视图3至4页，科技视图3至4页，顾问机会视图1页，总体控制12至16页。

## 封面与执行摘要

- 企业全称、统一代码、成立年份、注册资本、参保人数、实控人表决权。
- 一段核心结论。
- 三板块公开信息表现分、综合分及信息置信度。
- 明示“未知非公开数据不计零分、不扣分”。

## 第一部分：尽调准入

### 推荐章节

1. 准入驾驶舱与评分图。
2. 工商基本信息与历史沿革。
3. 股权、实控人、核心人员与关联企业。
4. 司法、劳动、行政环保、融资担保及准入条件。

### 默认维度

主体稳定性20%、信用与合规25%、司法与劳动20%、融资与担保20%、经营连续性15%。只能评价实际查得的公开事实。

## 第二部分：全景视图

### 推荐章节

1. 全景经营驾驶舱与评分图。
2. 主营产品、业务结构和发展阶段。
3. 土地厂房、设备投资与区域布局。
4. 同行竞品、产业位置和差异化方向。

### 默认维度

治理稳定性20%、业务清晰度20%、土地设备信号20%、市场公开信号20%、经营发展轨迹20%。

不得因为营收、利润、客户、产能等未公开而降低分数。市场公开信号可来自进出口、商标、招投标、政府客户、公开客户披露和区域布局。

## 第三部分：科技视图

### 推荐章节

1. 科技驾驶舱与评分图。
2. 专利、软著、商标和标准的有效性及产品关联。
3. 历史资质、项目与政策补助复盘。
4. 可申报项目矩阵。
5. 未来五年发展与项目申报规划。

### 默认维度

创新基础20%、知识产权20%、数字化能力20%、绿色技术20%、项目成熟度20%。

专利必须分为当前有效授权、审中、终止、驳回和转让取得或转出。已转出、已终止和驳回成果不得作为当前有效权利。

## 置信度

置信度评价“应当公开且本次可检索”的证据覆盖：

- 高：关键结论大部分有官方或两源证据，覆盖率不低于80%。
- 中：核心主体和方向可确认，但部分案件、投资或成果细节缺失，覆盖率50%至79%。
- 低：主体或核心业务仍有重大不确定，覆盖率低于50%。

企业内部财务、客户、毛利和产能不属于合作前公开信息覆盖率的分母。

## 风险表达

采用“公开事实—影响判断—核验动作”三列。风险等级只来源于明确事实与合理影响，不因资料少自动升高。

## 项目矩阵

至少列示：项目名称、公开基础、待企业确认条件、建议优先级、合理时间窗口。财务门槛统一写“合作后由企业提供数据再核验”，不推算达标。

## 五年规划

从公开现状出发，按经营技术主线、合规治理、项目申报目标和可验证交付物逐年安排。规划是建议，不把未来目标写成企业既有事实。

## 最终结论与客户沟通建议

报告末页必须让不熟悉企业尽调和项目申报的经营者也能直接看懂，不得只重复综合得分或专业判断。

1. 先用一段白话说明：企业有没有合作价值、当前处于什么阶段、为什么建议先整改再申报或可以直接推进。
2. 将最需要解决的事项按优先级排列，原则上控制在5至8项。
3. 每项固定写清四件事：`需要解决的问题｜对企业的实际影响｜建议怎么处理｜可落地服务`。
4. 服务动作可以包括股权架构、关联交易治理、法律劳动合规、融资担保清理、体系认证、知识产权布局、土地投资合规、研发管理和项目申报培育，但只能与前文已核验事实对应。
5. 再给出3至4阶段合作顺序，例如风险清理、基础建设、项目落地、能力升级。
6. 可增加一段“可直接向客户说明”的口语化总结，方便顾问现场展示和讲解。
7. 未取得的财务、司法明细或内部数据不得包装成确定风险，也不得为了推销服务夸大问题。

## 图表

- 三个板块分别配置一张横向红色评分条或雷达图。
- 可增加参保人数趋势、专利状态结构、项目优先级矩阵、发展时间轴。
- 没有连续数值时不制作伪趋势图。
- 图表旁必须说明口径、时点和公式。
