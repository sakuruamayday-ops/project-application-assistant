# 版本B：GCIP深度顾问版

## 定位

用于研判、诊断和服务设计。沿既有章节自然分页，以决策摘要、事实判断和行动组织，综合评价集中一次。正文方法见 [报告写作](../../_runtime/report-writing.md)。

## 固定结构与标题体系

首页为决策摘要，正文沿“部分—小节”两级编号：

1. `第一部分｜尽调准入`
   - `1.1 主体事实核验`
   - `1.2 股权、核心人员与关联企业`
2. `第二部分｜全景视图`
   - `2.1 战略布局`
   - `2.2 同行竞争与行业定位`
   - `2.3 土地、厂房、设备融资与投资`
   - `2.4 企业风控与90天整改`
   - `2.5 股权、资金与财税一致性核验`
3. `第三部分｜科技视图`
   - `3.1 科技与项目基础`
   - `3.2 已做项目与资质复盘`
   - `3.3 可申报项目矩阵`
   - `3.4 未来五年发展与申报规划`
4. 最终客户沟通结论采用无编号结语。

企业类型对应的小节可按适用性取舍，其余编号连续重排；正文保持“部分—小节”两级标题。

工商首页沿必要字段和范围；经营专项根据企业原始资料与需求展开，结论放相关小节。

同行按 [peer-selection-rules.md](peer-selection-rules.md) 动态选取五家，正文直接呈现对象与差距；中小企业层级及高企、研发平台、绿色制造、数字化、标准、知识产权、单项冠军、上市状态和政府项目统一列入“已有荣誉资质及项目”，注明来源状态。

有财税原始资料时按收入、采购成本、费用、研发、工资社保和资产工程六链核对；缺资料时先写已有事实，缺口、影响和动作集中列一次。

风险整改与项目申报的关系集中写入现有企业风控、项目矩阵和五年规划：风险表列整改作用，矩阵列资料或能力条件，规划列完成时间。

## 股权架构机会识别

公开信息出现下列信号时列为“建议访谈”，风险另据实际问题判断：

- 实控人持股高度集中且兼任主要经营职务。
- 实控人控制多家同业、贸易、研发或资产主体。
- 关联主体共用地址、电话、邮箱、人员、客户、供应商或知识产权。
- 企业存在新设主体、跨区域投资、买地扩建、融资、接班、员工激励或未来资本计划。

输出 `公开信号｜讨论价值｜需核资料｜服务方向`。持股平台、业务与资产分层、关联交易制度、控制权、接班和激励等作为访谈线索；具体方案结合企业目标、访谈和财税测算形成。

## 未分配利润机会识别

财务报表、利润分配或纳税资料待取时并入统一缺口表；有分红、再投资或股权安排信号时，再简写相关访谈问题。

企业提供资料且相关服务适用时，按问题选择以下核验内容：

- 最近三年资产负债表、利润表、所有者权益变动及未分配利润形成过程。
- 历年股东会利润分配决议、实际分红、代扣代缴和自然人股东情况。
- 股东借款、其他应收应付、个人卡、公私账户、关联交易和历史账务调整。
- 存货、固定资产、土地房产、资本公积、实收资本与未来投资计划。
- 股权转让、增资、减资、持股平台、家族传承或员工激励的真实目的。

内部案例和培训资料用于访谈框架与字段核验；正文写本企业结论、依据和动作。票货款、合同、存货、人员研发及股东往来按实际业务核对；税率、征管和分红结论回指现行法律、税务机关文件或专业税务意见。

## 顾问机会表

使用以下字段：

`业务机会｜触发信号｜当前判断｜请企业提供的资料｜建议服务｜合规边界`

按企业实际信号选择股权、关联、资金、融资、IP、认证、投资、劳动或项目服务，用相关行说明讨论价值与下一步。基础股东事实沿1.2节保留。

## 总结页

按 `问题—实际影响—解决动作—可落地服务` 汇总本企业重点，按实际依赖给合作顺序，并用白话说明预期成果。

## 视觉与交付

- 使用金色顾问风格和 `assets/report-style.css`。主色采用金色 `#D49134`，深色采用棕金 `#7B4C12`，浅底采用米金 `#F6EAD9`；减少色框、评分卡和重复结论。
- 首页集中综合判断，各部分直接写结论、证据和动作。
- 项目矩阵、风险和五年规划按实际比较需要制图。
- 沿用金色水印 `variant="gold"` 及 `assets/report-style.css`；品牌、分页和可打开性可随稿核对，发现问题提示并修订，待取事项集中列表。
