# 标准销售版母版锁定规则

## 已确认基准

- 基准企业：杭州壮大纱业有限公司。
- 基准文件：`assets/sales-master-reference.pdf`。
- 现行整合规范：本文件与 `version-a-sales.md`；不依赖未随包提供的外部样张。
- 报告人：共创知识产权。
- 视觉：白底、蓝灰表格、红黄绿圆点、无水印。

## 章节锁定

1. 保留母版第一至第六章。
2. 将母版原第七章替换为“经营基础与资料核验”，不得沿用“财务数据估算”等旧标题，也不得估算营收、利润、产能、研发费或其他内部经营数据。
3. 在第七章后加入“同行竞品与行业定位”。
4. 其后加入“已做项目与资质复盘”。
5. 其后加入“可申报项目分析”。
6. 其后加入“未来五年发展与项目规划”。
7. 母版原第八章顺延为第十二章“综合评价与风险等级”。
8. 母版原第九章顺延为第十三章“结论与建议”。

不得将第八至第十一章置于总结之后。不得为减少页数而缩小新增章节，必须让其自然分页。

## 视觉锁定

| 项目 | 固定参数 |
|---|---|
| 纸张 | A4 |
| 页边距 | 四边20毫米 |
| 一级标题 | 15磅 |
| 二级标题 | 12磅 |
| 正文与表格 | 10.5磅 |
| 表格内边距 | 水平10磅、垂直7.5磅 |
| 页脚 | 深蓝单线、当前页/总页数 |
| 风险提示 | 红黄绿圆点与文字并用 |

生成后至少对比检查新增章节首页与母版相邻页面，确认字体层级、表格密度、表头颜色、边框和页脚一致。
