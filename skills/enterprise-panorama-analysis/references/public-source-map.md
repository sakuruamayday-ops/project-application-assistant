# 公开来源路由

## 来源优先级

1. 用户本轮提供的文件与明确事实。
2. 政府、法院、国家知识产权局、交易所、企业年报等官方来源。
3. 当前可用的天眼查、企查查及其他合法商业企业数据库与企策顾问页面。
4. 企业官网、公众号、招聘、招投标、环评、土地和行业协会信息。
5. 新闻与聚合页面，仅作线索并回到原始来源核验。

商业平台不可访问时，不停止报告，也不把“未命中”写成“不存在”。

## 可并行采集端口

- 企业登记与商业数据库：国家企业信用信息公示系统、信用中国、当前可用企查查工具，以及天眼查、爱企查、启信宝、水滴信用等可访问页面。
- 司法与劳动：人民法院公告、中国执行信息公开网、裁判文书公开层、地方人民法院及仲裁公开信息。
- 知识产权：国家知识产权局、商标与版权公开信息、Google Patents及商业数据库知识产权模块。
- 经营与市场：企业官网、微信公众号、BOSS直聘等招聘平台、招投标与政府采购、海关与进出口、行业协会、产业网站和公开客户披露。
- 投资与合规：发改备案、自然资源土地公示、规划、环评、排污许可、应急管理、消防、能评及节能节水名单。
- 项目与政策：政府管理办法、当期通知和公示名单，桌面企策JSON、本地RAG及历史项目档案。

端口数量不等于证据质量。相同数据被多家商业平台转载不算多源交叉验证；优先回到工商年报、法院、政府公示或知识产权登记等原始来源。

## 模块与替代链

| 模块 | 首选来源 | 替代来源 | 关键限制 |
|---|---|---|---|
| 工商股权 | 天眼查主体分诊、国家企业信用信息公示系统 | 企查查补齐、企业年报、信用中国、地方市监公示 | 锚定完整主体名称和代码 |
| 关联企业 | 股东、高管、实控人穿透工具 | 工商公示逐一核验 | 区分公司对外投资与个人关联 |
| 司法执行 | 天眼查风险分诊、中国执行信息公开网、法院公告 | 企查查风险补齐、地方法院公开信息 | 聚合数量不等于案件结论 |
| 劳动风险 | 裁判文书、开庭与仲裁公示 | 招聘、参保人数变化 | 未公开仲裁不作不存在结论 |
| 行政环保 | 信用中国、生态环境与应急部门 | 排污许可、环评、企业数据库 | 无处罚不等于手续齐全 |
| 土地投资 | 自然资源、项目备案、环评与规划公示 | 企业数据库土地和融资租赁记录 | 土地成交不等于产权登记或投产 |
| 经营发展 | 年报、招投标、进出口、招聘、官网 | 商业平台标签与行业新闻 | 不据侧面信号推算财务数值 |
| 知识产权 | 国家知识产权局、版权与商标官方信息 | 企查查 IPR、Google Patents | 区分有效、审中、终止、驳回和转让 |
| 资质奖补 | 政府名单、政策原文与公示附件 | 企策顾问奖补记录 | 同名同日记录必须去重核验 |
| 同行竞品 | 政府名单、上市公司年报、企业官网 | 商业平台推荐 | 说明是直接竞品还是对标对象 |
| 项目政策 | 当期管理办法和申报通知 | 本地 RAG、政策索引 | 正式申报前重新核验时点和地域 |

## 可用公开经营信号

- 参保人数及年度变化。
- 招聘岗位、地点、频率和工种结构。
- 土地取得、项目备案、环评、厂房建设。
- 融资租赁、动产抵押、知识产权质押。
- 招投标、中标、政府采购和客户公开披露。
- 进出口备案、海关信用和海外商标。
- 专利、软著、标准、检测及认证。
- 高新、专精特新、绿色制造等资质。
- 政策补助、技改、节能和清洁生产项目。
- 关联企业新设、注销、区域扩张。

这些信号只能支持经营方向、发展阶段和风险特征判断，不得反推营收、利润、毛利、产量或市场份额。
