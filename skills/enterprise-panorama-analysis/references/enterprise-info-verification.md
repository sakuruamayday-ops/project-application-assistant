# 企业信息检索与验证框架

本框架吸收 `enterprise-info-search v1.3` 的主体锚定、来源分级、字段交叉验证和风险检索方法，但只使用当前实际可用的浏览器、企业信息工具、政府网站与公开来源。

## 一、主体准入

1. 目标企业必须取得完整18位统一社会信用代码并完成格式检查。
2. 企业名称与统一社会信用代码至少通过两项独立来源核对；国家企业信用信息公示系统或地方市监官方公示优先。
3. 无法确认代码时停止正式报告生成，请用户确认主体；不得用简称、品牌名或同名企业代替。
4. 关联企业和同行进入正式对标表前，至少确认企业全称、存续状态和地区；涉及风险传导时还须确认统一社会信用代码。

## 二、来源等级

| 等级 | 来源 | 用法 |
|---|---|---|
| T0 | 国家企业信用信息公示、法院执行公开、信用中国、知识产权官方、政府公示 | 冲突裁决和核心事实 |
| T1 | 当前可用的天眼查、企查查及其他合法结构化商业库 | 工商、股权、风险和知识产权索引 |
| T2 | 地方市监、税务、环保、自然资源、招投标、政府采购、交易所与企业年报 | 专项事实补充及验证 |
| T3 | 企业官网、招聘、产业网站、公众号、行业协会与新闻 | 经营、产品、销售和战略信号，只作辅助 |

多个商业平台转载同一条记录不视为多个独立原始来源。通用新闻和自媒体不得作为工商、司法和处罚结论的唯一依据。

默认商业源路由为：天眼查先完成主体、工商、股权、人员、风险、经营、资质和知识产权分诊；企查查补齐天眼查工具未覆盖、字段缺失、状态不明或高影响事项。当前记录与历史记录、企业自身风险与关联风险分别查询和呈现，不混合统计。调用失败或限流时串行重试并保留实际错误，不猜测供应商未公开的免费次数或上限。

## 三、核心字段验证

以下字段逐项记录 `字段｜当前值｜来源一｜来源二｜查询日期｜验证状态`：

1. 统一社会信用代码。
2. 企业名称。
3. 法定代表人。
4. 注册资本与实缴信息。
5. 成立日期和经营状态。
6. 被执行、失信和限制高消费。
7. 行政处罚和环保处罚。
8. 经营异常和严重违法。
9. 知识产权权利人及法律状态。

验证状态固定为：

- `已验证`：官方单源，或两个独立来源一致。
- `单源待核`：仅取得一个非官方来源；可以作为线索，但不能形成重大否定结论。
- `冲突待裁决`：不同来源不一致，报告保留差异并以官方最新记录裁决。
- `当前未命中`：只表示本次检索层未发现，不等于不存在。

## 四、八维采集

| 维度 | 必查内容 |
|---|---|
| 工商股权 | 主体、历史变更、股东、实控人、高管、关联企业 |
| 司法信用 | 执行、失信、限高、裁判、立案、开庭、冻结、破产公告 |
| 经营合规 | 异常、处罚、税务信用、欠税、环保、安全、许可、质量体系 |
| 知识产权 | 专利、商标、软著、标准、权利状态、转让及侵权 |
| 战略布局 | 产品组合、区域、主体、土地、产能方向、数字化、绿色、未来投资 |
| 经营销售 | 客户与行业、渠道、出口、招投标、品牌、招聘、价格与回款信号 |
| 同行竞争 | 按目标企业专精特新层级动态选取五家同行，将专精特新层级与其他荣誉项目合并采集，并分析产品、销售、技术、绿色差距及追赶动作；选择过程不写入报告 |
| 项目政策 | 历史资质奖补、可申报项目、证据缺口、时间窗口和五年路径 |

## 五、战略与经营分析边界

- 战略布局只从公开投资、区域、产品、主体、土地、招聘、技术和绿色信号推断，不把建议写成企业既有战略。
- 经营销售只评价公开可见的产品、客户披露、渠道、进出口、招投标、品牌和招聘信号；未公开的销售额、客户集中度、订单、产能利用率、毛利和回款应明确写“请企业提供对应资料后判断”。
- 同行选择执行 [peer-selection-rules.md](peer-selection-rules.md)。报告不披露筛选方法，不显示“对标类型”，不单设“优质中小企业成长线”栏目，也不把商业平台推荐列表直接当作竞品。每家必须核验创新型中小企业、专精特新中小企业、专精特新“小巨人”、高企、研发平台、绿色制造、数字化、标准、知识产权、单项冠军、上市状态和其他政府项目，并统一写入已有荣誉资质及项目；名单未命中不得写成未认定。
- 风控结论采用 `风险事项｜证据状态｜传导路径｜可能影响｜核验动作｜控制措施`，关联方风险没有传导证据时只列观察项。

## 六、报告落地

- A版正文可省略验证过程，但工商、风险和知识产权关键表应显示简短来源或验证状态，末尾保留来源清单。
- B版设置“事实核验摘要”，列核心字段验证状态、覆盖范围和信息缺口。
- 每项重大风险必须至少有一个可核验事实；单源待核事项不得标为高风险。
- 报告生成前检查企业代码、名称、风险主体、案号、专利权利人和同行名称是否串线。
