# 浙江省隐形冠军、单项冠军培育与质量品牌项目实战申报模板规则

本规范提炼自真实过审的《浙江省隐形冠军企业申报书》《制造业单项冠军培育企业培育发展方案》《浙江制造精品申报书》《浙江制造“品字标”工厂审查申请书》及《政府质量奖申报表》，为 `sme-giant-writer` 提供标准章节骨架与写稿红线。

---

## 一、浙江省隐形冠军企业申报书（7 大章标准骨架）

1. **一、企业基本情况**：成立时间、股权性质、基地规模、深耕年限、主营占比（≥70%）、代表性主导产品与核心技术链条总览。
2. **二、主导产品及市场占有情况（核心得分章，6 节必填）**：
   - （一）产品主要用途、在产业链中的位置及地位；
   - （二）近三年产品销售情况及效益、主要客户群及销售地（含国内外区域分布）；
   - （三）主要竞争对手及对比情况（**点名国内外直接竞争对手，列明规模、市占率、价格、交期、技术对比表**）；
   - （四）产品国际化实施情况（出口额、海外认证、海外客户或分支机构）；
   - （五）产品关键性能指标与国际国内领先水平的对比（**附检测报告/标准数值对比表**）；
   - （六）产品主要加工工艺、技术与国际国内领先水平的对比情况（工艺路线图 + 关键装备与工序壁垒）。
3. **三、企业研发创新情况（6 节必填）**：
   - （一）技术研发机构建设、研发经费保障及激励机制；
   - （二）研发带头人、创新团队与创新人才培养；
   - （三）知识产权积累和运用情况（按发明/实用/软著/审中分列，附核心专利清单）；
   - （四）参与或主导国际国内技术与工艺标准制定情况；
   - （五）重要技术或质量奖情况；
   - （六）关键领域补短板锻长板及具体情况。
4. **四、企业高端化智能化绿色化发展情况（3 节必填）**：
   - （一）高端化发展和品牌培育成效；
   - （二）数字化转型实施情况（ERP/MES/PLM 落地与指标提升）；
   - （三）绿色低碳发展情况（节能降碳工艺、能耗指标、绿色工厂/体系认证）。
5. **五、企业未来三年发展的战略思路**：战略思路、应对风险机制（供应链/技术迭代/汇率与贸易风险）、总体目标（**必须区分 1 年目标与 3 年目标定量表**）、工作任务及时间进度。
6. **六、具体计划**：融资计划、人才培养计划、产学研项目合作计划、创新激励机制建设。
7. **七、实施措施**：组织措施、资金投入、人力资源、评价考核、技术资源。

> **特别防串户提醒**：多客户复用框架时，务必核验第二章及全文产品描述与企业名称完全一致，杜绝混入其他企业产品段落。

## 二、制造业单项冠军培育企业培育发展方案（3 年量化培育骨架）

依据浙江省经信厅单项冠军培育方案编制提纲（注：正式认定申报书需对照当年度工信部/省经信厅 179 号文通知表格，以下为培育发展方案标准结构）：
1. **一、目标任务**：
   - `1.1 企业未来 3 年发展的战略思路`（围绕单一细分产品做深做强、产业链延链补链及国内外市场布局）；
   - `1.2 总体目标（含 1 年目标及 3 年目标定量表）`：分年列示四大板块定量指标——① 经营目标（主营业务收入、利润总额及各自增长率）；② 品牌培育目标（品字标、浙江制造精品、权威榜单）；③ 细分领域主导产品发展目标（国内市占率及排名、全球市占率及排名、出口占比、产品合格率、性能指标水平、万元产值能耗 tce/万元）；④ 创新能力提升目标（新产品数、关键技术/工艺突破数、核心发明专利申请与授权数、年度研发投入）；
   - `1.3 工作任务及时间进度`：按单项冠军战略、创新能力（资质/引才/设备/知产/新产品）、产品质量提升、国际品牌培育、经营管理制度 5 条线给出精确到年月日的里程碑节点。
2. **二、具体计划**：融资计划（资金需求额 vs 资金供给额）、人才培养计划（分层人才梯队）、产学研合作计划与激励机制。
3. **三、保障措施**：组织、资金、人力、考核与技术保障，切忌目标定得过高过空，须与近三年复合增速逻辑衔接。

## 三、浙江制造精品申报书（4 大章 14 节标准骨架）

按申报类别（先进制造类—高端新材料/高端装备/数字经济等）单产品申报，全篇紧扣该**单一申报产品**展开：
1. **一、产品技术水平**：
   - `1. 产品开发背景`（政策/国标升级倒逼 + 进口品牌“价格高/交期长/服务滞后”三大卡点 + 技术代际延伸前瞻）；
   - `2. 产品技术先进性情况`：① 核心技术体系（分模块写透技术原理）；② 技术先进性综合评价（科技查新/新产品鉴定/学会鉴定结论）；③ 产品技术创新性（相对现有工艺的实质改进）；④ 产品技术主导性（关联发明专利 + 主导/参与国家、行业或团体标准）。
2. **二、产品质量水平**：
   - `2.1 产品可靠性`：产品关键技术指标表 + 权威第三方（CMA/CNAS/国家计量院等）检测验证 + 与国内外同类龙头产品多维度参数对比表；
   - `2.2 产品安全性`：企业安全生产基础 + 本产品特有安全保障措施 + 绿色设计与绿色制造；
   - `2.3 质量管理体系`：ISO/行业体系认证、全流程质控与追溯节点。
3. **三、产品品牌价值**：`3.1 品牌建设`（商标/品字标/质量奖） → `3.2 品牌美誉度`（头部客户评价、抽检合格率、零质量事故） → `3.3 市场占有率`（细分市场规模与本产品占比）。
4. **四、综合竞争力**：`4.1 产品竞争力`（性价比、交期、定制服务与近三年该产品销量/营收/毛利） → `4.2 企业竞争力`（整体财务表现、行业领先地位、研发机构建设）。

## 四、浙江制造“品字标”认证与政府质量奖核心交付骨架

### 1. 浙江制造“品字标”工厂审查申请与材料闭环
- **硬前置门槛**：已导入并运行卓越绩效模式（GB/T 19580，近三年获政府质量奖或近一年卓越绩效自评报告）、三体系有效运行、建有省级及以上研发机构（技术中心/设计中心/研究院或省技术中心评价表）、**合格供应商源自浙江的份额说明**（体现区域产业链带动）、发布年度《质量诚信报告》与《社会责任报告》。
- **22 项核心审查材料闭环**：申请书与营业执照/商标 → 生产工艺流程图与产品结构原理图 → 组织机构图与生产许可 → 三体系证书与运行证据 → 生产与检测设备清单 → 卓越绩效自评/质量奖 → 带产地与产值的合格供方名录 → 研发投入与认证产品收入占比 → 核心专利/科技进步奖/标准创新奖 → 质量诚信与社会责任报告 → 产品检验与抽送样报告 → **认证产品“浙江制造”团体标准及实施细则** → 省级研发机构证明。

### 2. 政府质量奖（区/市/省级）五大交付件规范
1. **申报表**：连续近三年经营、质量、纳税、出口及体系认证数据（均需统计/税务/海关/环保主管部门证实性文件支撑）；
2. **组织概述（简介）**：严格按 GB/Z 19579 附录 B 编写，**字数限 3000 字以内**；
3. **自我评价报告**：严格对照 GB/T 19580《卓越绩效评价准则》七大类目（领导、战略、顾客与市场、资源、过程管理、测量分析与改进、结果），每条按 **ADLI（方法-展开-学习-整合）与 LeTCI（水平-趋势-对比-整合）** 用事实与数据评价，**字数限 6 万字以内（含图表）**；
4. **导入工作总结**：说明导入卓越绩效的时间、推进过程、特色做法与量化成效；
5. **证实性材料汇编**：合法经营、税务/统计/环保合规、首席质量官任命文件与近三年审计报告。
