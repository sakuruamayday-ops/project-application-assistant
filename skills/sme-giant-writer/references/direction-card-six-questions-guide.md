# 专精特新“小巨人”唯一六问六答推演与五大栏位映射指南

本指南彻底统一专精模块的逻辑主线：**先选定培育方向卡 → 内部走唯一一套六问六答（Q1–Q6）把专利、核心技术、补短板、成果与国际对标打透 → 再直接映射生成五大申报栏位最终版成稿**。全链条只围绕同一个主导产品展开，零编号打架、零发票依赖。

---

## 一、总控原则（政策口径见 `current-policy-baseline-2026.md`）

1. **纯技术与产品实质锚定（与发票无关）**：依据企业技术说明、专利全文/摘要、产品目录、官网、历史申报材料与企业自述确认真实产品实体（`rawAnchor`）与规范申报名称（`formalDeclarationName`），不依赖也不强求发票明细；装备厂写装备，制品/材料厂的自用设备专利归入制造工艺支撑。
2. **直接交付最终版成稿**：不在正文中出现占位符、免责套话或“设计控制目标为……”等草稿口吻；缺第三方检测报告时结合企业体量直接写入贴合行业均值水平的务实技术指标，财务数字、专利号、证书号与专家名严守真实绝不编造。
3. **三层专利分流**：`direct_support`（直接保护主导产品结构/配方/算法）进入 Q1/Q2 主体；`production_support`（自用工装/模具/检测设备）归入制造工艺与精细化管理；`weak_or_unrelated` 不硬凑。

---

## 一·补、方向卡先行（选定方向后再走六问）

- **方向比较**：按“现有方向 / 用户提出方向 / 分析建议新增方向”分别建卡，每卡写明：方向名称与产品内容、好处、坏处、培育建议、专利布局、申报角色；配套母版 `assets/专精特新小巨人前期培育方向卡模板.docx`。
- **拆卡与合卡**：共享算法或技术能力不等于同一主导产品；客户、交付物、收入边界或产业环节不同的拆卡分析，同一可核算产品与商业闭环成立时可合卡。
- **方向未定时**：分别形成候选六问，不混写；方向确定后再开展政策门槛与证据链核验。

## 二、唯一一套六问六答（Q1–Q6 内部技术推演主线）

每套 Q1–Q6 死锁同一个主导产品，各问需要细化时只读对应的一份细则：

- **Q1｜专利与核心技术载体归类**（细则：`main-product-naming-and-boundary-gate.md`；内部自用基材/配方另读 `core-formula-process-performance-matrix.md`）：基于企业实际业务与有效发明/专利全文，抽取技术对象、解决问题、措施机理与产品对应关系，完成三层专利筛选，锁定唯一主导产品实体及规范名称、10 位统计产品分类代码与工业“六基”归属。
- **Q2｜核心技术簇与优势短板归纳**（细则：`technology-advancement-feasibility-rubric.md`）：围绕主导产品归纳 2–3 项具名核心技术簇（机理 + 实测或贴合企业体量的行业均值指标），理清现有技术优势、性能边界与可继续攻关方向。
- **Q3｜补短板、填空白与国外替代因果链**（细则：`four-judgment-decision-table.md`、`key-technology-first-innovation-method.md`）：将“补短板、填空白、国外替代”严格限定在**同类产品、同一产业环节**，独立判断四项结论（不互相自动推定），建立「行业痛点 → 核心技术措施 → 量化性能结果 → 产业链替代价值」闭环；若早期技术源于境外引进许可，立足“消化吸收再创新与国产化突破”表述。
- **Q4｜核心技术与研究成果应用叙事**：承接 Q1–Q3 已确认的产品与技术链，凝练 400 字主导产品技术介绍与 300 字研究领域已获得成果及应用情况（自动适配产学研三档自然分支：有合同有教授 / 有合同无教授不补造 / 无合同切企业自主研发团队）。
- **Q5｜国际与同行对标及细分市场边界**（细则：`market-boundary-and-substitution-gate.md`、`market-share-grading.md`、`market-share-workpaper-method.md`）：在同一产品与产业环节下，检索并确认国外具体替代企业及产品型号、三家行业领军企业、可比同行与同口径细分市场边界（浙江省内走本地库/MCP 管控，省外做「当年 + 上年」双年窗口联网检索）。
- **Q6｜综合优势、短板培育与回写方向卡**：在同一比较口径下汇总企业优势、核心短板与未来 3 年研发、知产、标准及产能培育动作，同步回写《前期培育方向卡》。

## 三、六问推演结果 → 五大申报栏位最终成稿一键映射

完成 Q1–Q6 推演后，直接按以下映射生成可直接提交的申请书正文（全程同一主线，不另起炉灶）：

| 推演来源 | 直接映射的申报书栏位 | 字数上限与匿名硬线 | 详细写法规范 |
|---|---|---|---|
| **Q1** | 主导产品定名 + 10 位分类代码 + 工业“六基” + 3 项直挂自主有效 I 类知产 | 精确规范名，不超 3 项 I 类知产 | `enterprise-introduction-method.md` 第二节 |
| **Q5** | 细分市场占有率自证说明（固定三段式） | ≤1000 字 | `enterprise-introduction-method.md` 第三节 |
| **Q4** | 研究领域已获得成果及应用情况（产学研三档分支） | ≤300 字 | `enterprise-introduction-method.md` 第四节 |
| **Q3** | 产业链关键环节“补短板”“填空白”说明 | **≤300 字，匿名（零企业名/简称/曾用名）** | `enterprise-introduction-method.md` 第五节 |
| **Q1–Q6 汇总** | 企业总体情况简要介绍（基本情况三段 + 产品技术五段 + 稳增长声明） | **≤2000 字，匿名（零企业名/简称/曾用名）** | `enterprise-introduction-method.md` 第六节 |
