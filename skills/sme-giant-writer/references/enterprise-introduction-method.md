# 专精特新“小巨人”五大核心文字栏位实战写法（最终版成稿口径）

本规范服务于自主智能体（WorkBuddy / Antigravity 等），融合真实过审“小巨人”申报逻辑与一线工程叙事经验。**核心定位：直接产出可直接填报的最终版成稿**（不写草稿口吻或“设计控制目标为……”；缺检测报告时按企业实际规模写入贴合行业均值水平的务实技术指标，财务数字、专利号、证书号与专家名严守真实绝不编造）。

---

## 一、自主联网取证与防政策更名漏检（资料不全时直接执行）

当客户未提供完整材料时，智能体先查本地画像与事实黑板，再**自主联网补齐**公开信息，绝不卡死或甩锅让用户去查：
1. **查官网与主营产品**：还原真实业务、技术原理与代表应用场景；
2. **查曾用名、实控人/关联方与早期技术来源**：核对是否存在关联上市公司/同集团控股相似产品风险，区分自主原创与引进消化吸收再创新；
3. **查公开专利、首台套与标准**：提取真实公开专利号与已认定荣誉（保留原文状态词）；
4. **防改名漏检查最新政策与行业大盘**：用「当年 + 上年」双年窗口叠加「主管局（经信/科技）+ 职能上位词 + `.gov.cn`」反查，确保即使项目更名也能抓出最新文件，并检索行业协会大盘与国外直接竞品型号短板。

## 二、主导产品名称定名与 10 位分类代码（纯技术与产品实质导向，与发票无关）

- **标准定名结构**：`[关键规格 / 工况场景 / 核心工艺特征] + [核心性能或功能属性] + [真实技术实体产品或规范技术系列]`
- **通用合成示例（仅示结构）**：
  - 核心零部件：`微型高精度耐疲劳谐波减速器总成`
  - 关键基础材料：`耐高温低介电损耗复合绝缘薄膜材料`
  - 关键软件：`离散制造产线数字孪生协同排程与能耗优化软件`
  - 先进基础工艺：`薄壁高强轻质合金一体化精密成形工艺系列`
- **产品锚定要点**：
  1. 完全从**技术实体、结构/配方/工艺特征、专利核心落点与产业链节点**出发定名（依据技术资料、官网产品、历史申报书或企业自述，**与增值税发票无关**）；
  2. 区分业态防倒置：装备/模具厂把装备本身定为主导产品；制品/材料厂的自用生产设备专利归入制造工艺支撑，不抢占主导产品名；
  3. 同步给出 10 位《统计用产品分类目录》代码、工业“六基”归类及不超过 3 项直接保护该产品的自主有效 I 类发明专利（本地目录检索若提示 `match_confidence: low`，结合技术实质与联网目录核定，不硬套低分无关条目）。

## 三、细分市场占有率自证说明（1000 字以内 · 固定三段式）

1. **一、细分市场范围界定（约 250–300 字）**：写清主导产品、国民经济行业 4 位代码、工业“六基”与核心应用场景，讲清**为何区别于传统大类通用产品**（合理收窄分母，符合行业共识）。
2. **二、细分市场规模情况（约 300–350 字）**：优先**自主联网检索权威数据源**（工信部/国家统计局/行业协会白皮书/上市公司年报/头部咨询报告），按「当年细分规模 → 往年规模加增速推算 → 上位行业总量加占比测算」三级推导；公网确无单类装备精确分母时，围绕权威行业大盘与替代趋势成文，绝不在正文里写“本节用两类依据刻画”等自言自语句，也不编造分母。
3. **三、本企业细分市场占有率情况（约 250–300 字）**：有企业经审计主导产品销售额时给出精确除法算式并叠加头部客户/装机量印证；尚未提供企业财务数据时，聚焦已落地产线、首台套与头部客户实绩成文，不编造营收与百分比（缺项留在正文外提醒补充）。

## 四、研究领域已获得成果及应用情况（300 字以内 · 三档自然分支）

围绕「细分领域 → 时间节点 → 研发主体 → 核心技术与成果 → 落地应用与成效」组织，按企业实际资料自动选择对应分支（**不拒答、不编造专家名、不插占位符**）：

- **分支 A · 有产学研合同且含学院/专家名**：写全高校、具体学院/重点实验室及教授或院士团队，突出联合攻关突破的量化指标、专利/鉴定及已配套或预计创收。
- **分支 B · 有产学研合同但未写教授或学院名**：只写合同里真实记载的高校/院所全称，不补造专家姓名，技术、成果与应用照常组织。
- **分支 C · 未提供产学研合同 / 企业暂无产学研合作**：自然切入**企业自主研发团队分支**——`在[细分领域]，[年份/阶段]由企业研发团队自主开展[核心技术]攻关，突破[具体痛点]，形成[技术/工艺/专利/首台套成果]，应用于[典型场景或产线]，实现[性能、效率或环保改进]。`
- **在研项目写实原则**：先写已完成的配方、样件、小试或专利申请进展，再自然衔接目标指标与拟应用客户，避免通篇“拟解决/拟开发/拟达到”。

## 五、“补短板”“填空白”300 字说明（匿名栏 · 零企业名与曾用名）

- **表七前置三栏**：填补短板产品名、填补空白具体领域，以及**经联网核实的国外具体竞争对手与产品短板**；早期核心技术源于境外引进许可时，立足**“消化吸收再创新与国产化工程突破”**撰写，不将引进原技术包装为原始首创。
- **高分写法（目标 250–295 字）**：全部篇幅留给**核心工艺/结构机理 → 行业级量化代差 → 填空白/进口替代 → 头部客户批量配套与产值**（常规行业基础准入检测，如普通危包型式检验或出厂基础抽检，放进 2000 字简介的“精细化管理”段，不占用补短板突破篇幅）。
- **两套常用展开**：多点突破用「一是……二是……（三是……）」递进；单一主工艺突破用「行业矛盾痛点 → 核心技术与量化指标 → 填空白与替代龙头客户」两段破局。

## 六、企业总体情况简要介绍（2000 字以内 · 匿名栏 · 零企业名与曾用名）

采用「结论先行的小标题 + 自然工程因果段落」，按评委打分逻辑直接出最终版成稿（目标 1600–1950 字，资料有限时以事实完整为准，不强凑字数；**不反复在多段重复罗列同一组营收和专利数**）：

1. **一、企业经营管理概况（三段）**：经营管理概况 → 细分领域地位 → 经营战略（无详细财务数据时先据业务与技术成文，绝不编造营收利润）。
2. **二、企业主导产品及技术情况（五段）**：核心技术突破 → 技术攻关与产业化 → 产业链供应链价值 → 精细化管理 → 知识产权积累与运用。
3. **三、工业稳增长和转型升级成效明显市（州）声明**：按申报当年度工信部名单据实写一句。

## 七、黄金正反对照（所有模型生成前对照看一眼）

- **差稿（机械标签 + 分号报菜名 + 基础合规凑数 + 满篇“拟”）**：
  > 补短板方面，公司开发微型精密传动件，通过出厂外观及常规尺寸检验；产品执行通用行业标准。产学研方面，2025年拟与某高校合作，拟解决寿命不足难题，拟达到10000小时目标，目前处于筹备阶段。
- **好稿（最终版可用成稿：自然工程因果 + 贴合企业规模的务实指标 + 自主研发顺滑落笔）**：
  > 在工业机器人关节驱动环节，传统微型减速器高负载下易出现柔轮疲劳断裂与背隙衰减，高端供给长期依赖海外龙头。公司一是自主研发微区梯度渗氮与复合齿廓修形工艺，将额定负载疲劳寿命提升至 12000 小时以上、传动背隙稳控在 1 弧分以内；二是开发在线闭环磨齿补偿系统，批产齿距累积误差低于 3 微米，填补国产长寿命微型减速器工艺空白，已批量配套国内多家头部机器人整机厂。
