# Playbook 04：数字化车间、智能工厂、未来工厂与 5G 工厂

本手册整合《智能制造能力成熟度模型》（`GB/T 39116`）、《数字化车间/智能工厂通用技术要求》（`GB/T 37393` / `GB/T 41255`）及《杭州市“未来工厂”评定申报书（2024 版）》真实申报骨架。

## 一、成熟度等级（L1—L5）与三档梯度定位

围绕七大维度核验：**人员、技术、资源、制造（设计/生产/物流/销售/服务）、数据集成、业务闭环、绩效与工控安全**。
- **数字化车间（对应 L2–L3）**：离散型/流程型车间级设备数控化与联网采集，ERP+MES 贯通生产排程与质量追溯；
- **智能工厂（对应 L3–L4）**：关键设备联网率高，ERP+MES+PLM+WMS/SCADA 多系统闭环，落地 AI 视觉质检、能耗优化或预测性维护并产生可审计经营绩效；
- **链主工厂 / 省级未来工厂（对应 L4–L5）**：企业须具“雄鹰/单项冠军/小巨人”等龙头基础，建有“双跨”或省级工业互联网平台/产业互联网平台/AI PaaS 底座，形成**“1+N”产业链协同改造**，须定量填报**带动供应链企业总数量、本地企业数、本地化采购金额占比及近三年增速、产业链企业平台应用比例**。

## 二、“未来工厂”评定申报书（6 大部分标准骨架与排版规范）

1. **一、评定申报表（按链主工厂 / 智能工厂 / 数字化车间三选一填报）**：
   - **近三年财务指标**：主营业务收入、亩均税收（万元/亩）、利润、税金、资产负债率、成本费用利润率；
   - **近三年数字化改造投入指标**：数字化改造总投入 = 设备投入 + 软件及云服务投入（若为晋档企业，单列规定时间段新增投入）；
   - **近三年 7 项核心定量对比表**（逐年列示改造前后趋势）：① 关键设备国产化使用比例（%）；② 关键设备数控化率（%）；③ 关键设备联网率（%）；④ 全员劳动生产率（万元/人）；⑤ 万元产值能耗（tce）；⑥ 产品研发周期（天/月）；⑦ 产品一次性合格率（%）；
   - **核心摘要框限字**：工厂概况（含链主“1+N”模式或智能化特征）**不超过 600 字**；实施成效 **不超过 300 字**。
2. **二、“未来工厂”基本情况**：（一）概述 → （二）建设基础条件 → （三）实施的先进性（对比行业痛点与智能制造标杆）。
3. **三、“未来工厂”实施现状**：（一）总体目标 → （二）建设方案（系统架构、网络与数据集成、核心场景清单） → （三）建设现状（已上线模块运行截屏与业务流闭环）。
4. **四、“未来工厂”取得成果**：（一）经济效益 → （二）社会效益（节能降碳、行业复制推广） → （三）创新成果（软著、专利、标准、省部级示范案例）。
5. **五、近三年数字化改造投入清单**：逐笔列明自动化设备、工业软件、云服务采购合同、不含税发票金额与上线验收时间。
6. **六、其他证明材料**：审计报告、合同发票、系统架构与现场照片、真实性承诺书与区县初审意见。

> **官方格式提醒**：正文字体一般要求仿宋 GB2312 四号、单倍行距、一级标题黑体小三号，双面装订建议不超过 100 页。

## 三、反吹牛写作铁律与验收命令
1. 必须提供真实系统清单（软件名称、供应商、上线日期、采购金额、接口集成方式），**严禁把“计划购买/在谈方案”写成“已上线运行”**；
2. 改造前后对比必须落到 7 项定量表中的真实业务数据，并与投入清单和审计财务数据保持一致；
3. **强制验收命令**：`python3 scripts/validate_grant_deliverable.py --track digitalization --input <json> --text-file <正文.md>`。
