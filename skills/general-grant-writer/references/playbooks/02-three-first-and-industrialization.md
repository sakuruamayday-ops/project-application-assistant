# Playbook 02：首台套装备、首批次新材料、首版次软件与省工业新产品

本手册整合浙江省“三首”（首台套/首批次/首版次）与省级工业新产品（`T/ZJCX 0001—2022`）核心选型与实战写作骨架。**核心定位：撰写阶段直接交付可直接使用的最终版申请报告或申报书成稿**（政策核对：浙江省内直接走本地库/MCP 管控，省外做一次「当年 + 上年」双年窗口联网检索，并按需联网补齐国外对标型号；缺检测报告时结合企业体量直接写入贴合行业均值水平的务实技术指标，财务数字与专利/证书号严守真实不编造；关于工程时序倒挂与证据定位的逐条审查属于质检技能 `application-reviewer` 的工作，不用于阻断本技能出稿）。

---

## 一、四类赛道选型决策树

- **整机 / 成套装备 / 关键核心部件** → 浙江省装备制造业重点领域首台（套）装备（国际/国内/省内三档）；
- **新材料（配方/成分/工艺突破、尚未取得重大市场业绩但打破垄断）** → 浙江省重点新材料首批次应用示范；
- **独立或嵌入式软件（基础/工业/信创/信息安全/新兴技术软件）** → 浙江省/杭州市首版次软件产品；
- **已投产验证、需先拿专家鉴定背书的新产品** → 浙江省工业新产品立项与鉴定评价（`T/ZJCX 0001—2022`，常作为冲刺“三首”与“小巨人”的前置跳板）。

---

## 二、首台（套）产品申请报告书（7 大章标准骨架）

1. **一、申请企业基本情况**：规模产能、制造与检测装备能力、执行标准、行业/国际认证、战略客户与资质荣誉。
2. **二、国内外发展现状和趋势**：进口卡点（价格高、交期长、售后响应慢）与下游国产替代趋势（自主联网补充权威行业数据）。
3. **三、技术开发及产业化水平（核心得分章）**：开发背景 → 开发过程与检测/鉴定/查新情况 → 生产工艺与主要装备 → 关键技术突破与行业意义 → 自主核心知识产权与品牌 → **与国内外同类代表型号的多维性能定量对比表**。
4. **四、关联度分析**：上下游配套关系、核心原材料/部件国产化地域分布、典型用户应用反馈。
5. **五、市场前景**：供需与价格趋势、产品档次定位、内外销与竞争优势。
6. **六、经济效益和社会效益**：产销利税与用户降本测算 + 节能降碳、补链安全社会效益。
7. **七、总体评价和申报首台（套）的理由**：技术水平综合评价 + 逐条对应当年认定条件陈述理由。

---

## 三、首批次新材料、首版次软件与工业新产品写作要点

1. **首批次新材料 6 模块写法**：独立法人与良好信用 → 内部研发场所与制度（产学研加分） → 省级以上 CMA/CNAS 检测报告（商业化销售合同加分） → **核心先进性三要件（权威技术水平评估、高质量授权发明 ≥5 项且申报相关 ≥1 项、科技成果/省级工业新产品鉴定）** → 三体系与国家/行业/团标/企标 → 绿色化生产（加分）。
2. **首版次软件申报表要点**：
   - 核对软件全称及精确版本号（软著、测评报告与合同一致）；
   - 突出**国产软硬件生态适配**（国产 CPU、操作系统、数据库及互认认证）；
   - **功能描述与性能指标**（并发数、TPS/QPS、响应延迟 ms、CPU/内存占用率与兼容性）紧扣已测或行业常规工程表现，不虚夸未实现功能；
   - 研发团队按贡献度排序并明确具体模块分工。
3. **省级工业新产品（T/ZJCX 0001—2022）**：立项阶段填附录 A《立项表》，鉴定阶段按附录 B《评价表》组织研制总结、技术总结、检测报告、查新报告、用户使用报告与环保安全说明。

## 四、“三首”关键技术与对标段黄金正反对照（纯虚构脱敏示例）

- **差稿（空洞夸大 + 无具体对标对象与测试工况）**：
  > 本产品采用行业领先的先进制造工艺，具有精度高、效率快、寿命长、节能环保等显著优势，各项指标均达到国际领先水平，打破国外垄断，填补国内空白，深受广大客户一致好评。
- **好稿（最终版可用成稿：具名机理 + 贴合企业规模的务实指标 + 定量对标国外代表产品）**：
  > 针对精密电子流体输送管路内壁粗糙度偏高、易析出金属离子导致晶圆良率波动的问题，产品采用在线多道次冷轧整形与高纯惰性气体光亮退火工艺，配合电解抛光闭环控制，使焊缝区域与母材晶粒度保持一致，内壁表面粗糙度 Ra 控制在 0.25 微米以下，洁净度与耐腐蚀性能满足半导体特气输送要求。相较海外同类进口洁净焊管，在关键洁净指标平齐的前提下，交货周期由 12 周缩短至 4 周，单米综合采购成本降低约 30%，已进入多家国内半导体设备与厂务配套体系。

## 五、交付后质检提示
若需对客户已有全套证明材料开展**工程时序（立项日 ≤ 样机完成日 ≤ 检测日 / 首次销售日、查新有效期）与逐条证据定位核查**，转交 `application-reviewer` 出具质检意见。
