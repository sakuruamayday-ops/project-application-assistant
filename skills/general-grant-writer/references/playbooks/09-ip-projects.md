# Playbook 09：知识产权示范/强企、专利导航与高价值专利培育

## 一、核心政策与数量质量双门槛
- 覆盖国家知识产权优势/示范企业、浙江省知识产权示范企业、杭州市知识产权强企与高价值专利培育中心（如 `杭市管〔2025〕93号` 等地方现行资助细则，执行前通过 `gov-project-checkup` 核验当年度有效批次）。
- **核心专利核验红线**：
  1. 逐件通过专利号第5位校验（`1`/`8` 为发明、`2` 为实用新型、`3` 为外观），杜绝实用新型误填为发明；
  2. 核验法定保护期（发明20年、实用新型10年）与年费有效状态，过期专利一律剔除；
  3. 核验受让专利转让登记生效日满 1 年与企业主营产品强关联；
  4. 同步整理 PCT 国际专利申请、贯标（GB/T 29490 / ISO 56005 创新与知识产权管理能力分级评价）、知识产权质押融资与专利密集型产品备案记录。

## 二、强制验收命令
`python3 scripts/validate_grant_deliverable.py --track ip-project --input <json> --text-file <正文.md>`。
