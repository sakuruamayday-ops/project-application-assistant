# Playbook 05：绿色低碳工厂、绿色供应链与节能降碳改造

本手册基于《绿色工厂梯度培育及管理暂行办法》（`工信部节〔2024〕13号`）及浙江省经信厅《绿色低碳工厂自评价报告》官方范本编写。

## 一、一票否决合规红线（附表 1.1 基本要求自评）

申报企业必须为浙江省内注册且从事实际生产的独立法人或独立核算制造企业，并满足全部前置底线：
1. 近三年未发生安全、质量、环境污染等较大及以上事故，无偷漏税、失信被执行人、工业节能监察未整改完毕或被动态调出绿色制造名单记录；
2. 属于依法披露环境信息主体的，已按规定完成环境信息公开；
3. 现场布局整洁、功能区标线清晰、安全防护到位；最高管理者明确绿色低碳领导承诺与职责分工；建有绿色工厂管理机构、不少于 3 年的中长期规划及年度量化目标与全员培训考核机制。

## 二、绿色低碳工厂自评价报告（5 大部分标准骨架）

### 基本信息表必核字段
- 信用等级、环境评价信用等级、**近两次亩均绩效评价级别**、**碳效评价等级**；
- 近 3 年经营与能碳表：工业总产值（亿元）、工业增加值（万元）、利润总额、纳税总额、**碳排放总量（吨 CO₂）**、**年综合能耗（吨标准煤 tce）**；
- 体系认证（质量/环境 ISO 14001/职业健康安全/能源 ISO 50001）与信息化应用（ERP/MES/能源管理平台）。

### 正文五大模块
1. **一、工厂基本情况**：企业发展现状、主导产品与工艺流程、绿色低碳重点工作与成效总览。
2. **二、绿色低碳工厂创建情况（对照《浙江省绿色低碳工厂建设评价导则（2024 版）》6 节逐项写实）**：
   - `1. 基础设施`（权重约 20%）：建筑合规、节能评估与环保“三同时”、室内装饰有害物质达标、危废/有毒操作间独立设置、钢/低碳建筑材料、透水地面占比 ≥30%、可再生能源建筑能耗占比 >10%、节水器具 100% 覆盖、照明与计量/治污设备配置；
   - `2. 管理体系`：质量/环境/职业健康安全/能源管理体系建设与内审运行实绩；
   - `3. 能源资源投入`：绿电/光伏等清洁能源占比、绿色物料与原辅料替代、绿色采购及正在实施的节能节材技改项目；
   - `4. 产品`：产品生态设计、有毒有害物质替代/RoHS/食品接触等合规、轻量化节能减碳、可回收利用与碳足迹核算；
   - `5. 环境排放`：大气污染物、废水、一般固废与危废、厂界噪声及温室气体（范围一/范围二）监测达标与减排现状；
   - `6. 加分项`：综合绩效（亩均/碳效）、碳排放管理体系与碳排放强度下降、数字化能碳管理平台、重大节能降碳技改。
3. **三、下一步工作**：持续绿色低碳重点计划、拟实施重大技改项目及向“零碳工厂”演进路线图。
4. **四、绿色低碳工厂创建自评表**：逐项填写附表 1.1（基本要求）、附表 1.2（评价指标逐条自评打分与得分依据）、附表 1.3（加分项）。
5. **五、9 项必附证明材料（加盖公章）**：① 营业执照；② 生产许可证（适用时）；③ 能评批复或验收文件；④ 工厂建设批复；⑤ 环保“三同时”验收文件；⑥ 环评验收文件；⑦ 厂区平面图；⑧ 国家企业信用信息公示系统/信用中国/信用浙江查询记录；⑨ 近三年审计报告关键页（含工业总产值、纳税总额）。

## 三、定量指标口径与强制验收命令
- 所有绩效指标必须填报**非空实测值 + 规范计量单位**（`%`、`tce/万元`、`kWh/万元`、`tCO2e/万元`、`m³/t` 等），并标明与国家/地方行业能耗限额先进值或基准值的对标位置；
- **强制验收命令**：`python3 scripts/validate_grant_deliverable.py --track green --input <json> --text-file <正文.md>`。
