# Playbook 03：技术改造、工业领域设备更新与生产制造方式转型示范

本手册整合《工业重点领域设备更新项目资金申请报告》与《浙江省生产制造方式转型（工业领域设备更新）示范项目申报书》真实过审模板及合规审计边界。

## 一、核心合规与审计铁律

1. **备案与建设期窗口**：项目必须先通过全国投资项目在线审批监管平台完成备案，取得《浙江省企业投资项目备案（赋码）信息表》；所有计入补助基数的设备增值税专用发票开票日期必须落在**备案建设起止期内**（提前或超期一律剔除）。
2. **不含税纯设备基数红线**：固定资产投资口径**不含土地支出、不含厂房及土建基建投资、不含可抵扣增值税进项税额**；1 类更新改造项目须核算淘汰老旧设备与新增产线占总设备投资的合理比重。
3. **四单闭环勾稽**：每台（套）设备必须形成 `采购合同 ↔ 增值税专用发票（不含税价） ↔ 银行付款回单 ↔ 固定资产卡片与现场铭牌照片` 四单闭环；**严禁 0 元占位行、关联方无公允定价采购、二手翻新设备及办公非生产设备混入基数**。
4. **质保金（5%—10%）实务处理**：正常设备采购保留 5%—10% 质保金（实付 90%—95%）时，登记 `retention_ratio`（0.01—0.10）或 `retention_note`，校验器按**实际已付款金额与不含税发票孰低原则**计入适格投资额；实付低于 90% 的设备不得计入当期验收基数。

## 二、工业重点领域设备更新资金申请报告（8 大章标准骨架）

1. **一、项目单位基本情况**：（一）单位概况（含安全生产近三年零事故、无严重失信、纳税信用等级 A 等合规声明） → （二）企业介绍（基地面积、产能、研发平台、荣誉、授权专利清单） → （三）近三年财务状况。
2. **二、项目基本情况**：项目概况 + **7 项前期建设条件落实情况**（① 经信/发改在线备案赋码；② 不动产权证/用地许可；③ 节能审查或节能承诺备案表编码；④ 环评批复或技改无需办理说明；⑤ 安评批复或技改无需办理说明；⑥ 施工许可证或技改无需办理说明；⑦ 截至申报日实际付款进度与开工现状）。
3. **三、在线审批监管平台与国家重大建设项目库填报情况**：核对赋码与重大项目库入库截图。
4. **四、申请投资支持的主要理由和政策依据**：对照国家大规模设备更新与省市制造业技改专项文件。
5. **五、项目建设方案（核心工程章，8 节）**：必要性 → 选址 → 建设规模和内容 → **工艺方案（必须把“原工艺流程”与“优化后新工艺流程”逐工序对比）** → 产品方案（产能与新增产能） → **设备方案（设备更新概况 + 淘汰/更新设备对照方案 + MES/SAP/PLM 数字化管理优化方案）** → 工程方案 → 环保、节能、安全方案。
6. **六、项目投资估算**：主要工程量表 + **三大分表**（一、拟更新关键生产设备表；二、新增检测及辅助生产设备表；三、工业软件购置表） + 投资估算总表。
7. **七、项目建设资金保障情况**：资金筹措方案（自筹/银行贷款明细及资金证明） + 拟申请补助/预算资金测算。
8. **八、项目实施进度**：总体分月进度安排 + 已完成建设内容及投资占比 + 淘汰/更新设备清单对照。

## 三、生产制造方式转型示范项目申报表核心填报点

- **改造方式二选一**：
  - `1 类`：淘汰落后低效/超期服役老旧设备，更新应用先进高效设备与检验检测设备，推进绿色化、智能化改造（须填报新增产线占总设备投资比重）；
  - `2 类`：提升工业设计中心、计量检验检测中心、认证中心、共性技术平台、中试验证基地专业化服务能力。
- **项目绩效目标定量模板**：必须同时给出经济效益（新增销售收入、新增利润、新增税金）与精益智能量化指标（关键设备数控化率提升 %、生产效率提升 %、产品一次合格率提升 %、订单交付周期缩短天数、库存周转率提升 %、物料利用率提升 %）。
- **必附证明闭环**：营业执照、不动产权证、能评/环评/安评/施工许可（或无需办理说明）、资金证明、近三年审计报告、设备采购合同与询价单、备案表、现场进度照片、信用中国查询与真实性承诺声明。
