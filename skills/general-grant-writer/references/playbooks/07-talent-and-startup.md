# Playbook 07：领军人才、高层次人才与杭州人才/算力政策

本手册结合浙江省“万人计划”科技创业领军人才真实申报表模板及杭州人才/算力政策要点编写（注：海外高层次引才计划、博士后设站及杭州算力券具体申请表须按当年度官方最新通知表单适配）。

## 一、时间线与资格硬红线（全量核验）

1. **年龄红线**：按申报截止日精确核算申报人周岁（如青年人才 ≤ 40 周岁、创业/创新领军人才 ≤ 55 周岁）。
2. **回国/来华窗口**：海外引才须核对护照出入境记录、教育部留学服务中心学历认证及首次国内全职社保/个税缴纳月，严防超期申报。
3. **社保与博士后衔接**：连续在申报主体缴纳社保月数须达政策最低要求；博士后资助须核验进站日 < 出站日与留杭/留浙签约窗口。
4. **创业类持股与实缴**：科技创业领军人才一般须为企业主要创办人、法定代表人或核心技术所有者，精确核验**持股比例、持股排名、实缴注册资本、研发投入强度（= 研发费用 / 主营业务收入）**及投资机构参股情况。

## 二、浙江省“万人计划”科技创业领军人才申报书核心结构

1. **一、基本信息**：
   - `（一）推荐人选情况`：姓名、职务、职称、学历学位、推荐人选类型（创新创业大赛入选者 / 高企主要创办人 / 其他）、按时间顺序排列的完整学习经历与工作经历；
   - `（二）企业基本情况`：信用代码、注册资金、主营业务、控股股东类型与控股比例、上市公司/投资机构参股与融资规模、研发人员占比、授权发明专利与软著数、近三年总资产/净资产/毛利率/总收入/净利润/主营业务收入/研发费用与研发强度、创业项目名称与技术来源（自有/购买/合作）。
2. **二、科技创业领军人才申报自荐书（核心叙事区）**：
   - `1. 创业者自我评价（不超过 500 字）`：按「专业背景与创办初心 → 带领团队突破关键技术/打造核心产品的里程碑 → 营收/市占率增长与头部标杆客户合作实绩 → 在细分行业中的引领作用与产业带动」自然叙事，严禁空泛自我吹捧；
   - `2. 企业核心技术、商业模式与成长规划`：紧扣“人—技术—企业—产业”四位一体逻辑，说明推荐人选对企业核心技术与商业成功不可替代的主导作用。
3. **三、公示与附件闭环**：“所在企业意见”必须写明企业内部公示时间、公示范围和公示结果；表中无内容栏一律规范填“无”，不得留白。
