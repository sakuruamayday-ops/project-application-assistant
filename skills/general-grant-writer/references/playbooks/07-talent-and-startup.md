# Playbook 07：海外高层次人才、领军人才与杭州人才/算力政策

## 一、时间线与资格硬红线（全量核验）
1. **年龄红线**：按申报截止日精确核算申报人周岁（如青年人才 ≤ 40 周岁、创业/创新领军人才 ≤ 55 周岁）。
2. **回国/来华窗口**：核对护照出入境记录、教育部留学服务中心学历认证及首次国内全职社保/个税缴纳月，严防超期申报。
3. **社保与博士后衔接**：连续在申报主体缴纳社保月数必须达政策最低要求；博士后资助项目须核验进站日 < 出站日与出站留杭/留浙签约时间窗口。
4. **创业类持股与实缴**：人才本人一般须为企业第一大股东或核心创始人（持股比例 ≥ 20%—30%，依区县细则），并核验实缴注册资本与场地租赁合同。
