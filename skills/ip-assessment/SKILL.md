# 知识产权评估

## 事实与关联

1. 锚定权利人、法域和截止日期，统一申请号、公开号、授权号、类型及状态。
2. 分列有效授权、审中、失效、转让、许可、质押和争议；商标软著采用各自状态。
3. 核验权利人变更、取得日期、共有及目标项目的认可范围。
4. 逐项映射产品、技术、工艺和项目任务，名称线索结合实际技术关系判断。
5. 按任务区分可使用权利事实、技术分析、待补证及申报适用性待核的项目。

每项记录编号、权利类型、技术主题、当前权利人、法律状态、取得方式、状态日期及产品关联。字段沿用该项原文，缺项记“未提供”；审中、授权、取得方式、技术来源分别填写。例如“审中发明申请，服务控制方法”记录状态审中、主题控制方法、取得方式未提供。

取得方式汇总、逐项表、分类和缺项使用同一取值；清单记载权利人与变更证明状态分列，原权利人、转让日期、实施和 RD 关联分别核验。

项目待选时统计状态与取得方式，申报认可数量对应明确项目及政策。公开记录待取时保留已知清单和具体待核项。

## 输出与衔接

规则见 `references/ip-assessment-rules.md`，结构化清单可用 `scripts/validate_ip_inventory.py`。专利工程使用 `patent-router` 并沿用主体、法域、基准日和来源；Word 申请文件核稿使用 `checking-patdocx-cn-single-agent`。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
