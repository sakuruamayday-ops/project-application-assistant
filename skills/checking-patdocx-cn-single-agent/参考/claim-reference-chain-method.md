# 权利要求引用链检查方法

本方法从原 `patent-review` 的核查标准中提炼，只保留引用关系的逻辑检查，不继承其中绝对化禁用词或未经核验的法律结论。

## 累积特征集

从属权利要求的完整技术方案包括自身新增特征以及沿每条引用路径继承的全部上位特征。多项引用产生多条路径，必须逐路径检查，不能把不同路径的特征混成一个总集合。

对路径 `N → … → 1`：

1. 穷举从权利要求N到独立权利要求的每条完整路径。
2. 累积路径上所有上位权利要求引入的技术特征。
3. 检查N中每个回指特征在对应路径上是否具有基础。
4. 仅报告实际缺少基础的路径和特征。

## 边界

- 同一权利要求内先引入实体、后用“所述”回指，不要求该实体出现在上位权利要求中。
- “所述A的B”应先判断B是A的属性还是独立技术实体，不能机械拆词。
- 多项从属权利要求不得引用另一项多项从属权利要求，结论需按基准日有效的实施细则原文复核。
- 产品通过方法限定时，引用基础分析应同时考虑产品明示特征和被引用方法链，但保护范围解释仍需结合现行审查指南和个案语境。

每条核稿意见仍须注明依据层级；本文件是分析方法，不单独构成法定禁止依据。
