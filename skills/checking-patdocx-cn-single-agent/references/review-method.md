# 申请文件核稿方法

## 依据层级

1. 现行法律与实施细则。
2. 基准日有效的专利审查指南及修改决定。
3. 目标保护中心公开规则。
4. 撰写质量建议。

现行官方依据待定位的项目标记“待核验”或“撰写建议”。

## 核查矩阵

| 对象 | 核查重点 |
|---|---|
| 摘要 | 名称、技术领域、技术问题、方案要点、用途、字数和附图标记 |
| 独立权利要求 | 保护客体、必要技术特征、清楚性、支持、单一性和保护范围 |
| 从属权利要求 | 引用对象、逐路径累积特征、附加限定及引用基础 |
| 说明书 | 背景、发明内容、实施方式、公开充分性、术语和数据一致性 |
| 附图 | 图号、部件名称、附图标记和正文引用一致性 |
| 文件结构 | 表格、文本框、脚注、尾注、公式、嵌入对象、媒体和关系完整性 |

## 引用关系

核稿先对照原始输入和工作副本，区分原文、新增内容与缺失材料。缺图记为“附图未提供”，文字已记载的结构照常分析；已有丝杆调节描述时，聚焦支承、限位等具体实施缺口。同一引用错误合并一条，正常项列入覆盖说明。

名称、摘要与权利要求按保护客体和实质技术关系核对；功能修饰词或摘要概括实施特征需结合全文判断。建议并入从属特征时，说明解决技术问题的必要性和保护范围代价。保护策略、缺图、节选与确定错误分别统计，同一事实合并评价。

先解析每项权利要求直接引用的权利要求，再展开到独立权利要求的全部合法路径。对每条路径分别检查：

- 当前项新增特征是否有引用基础；
- 同一术语是否在路径上保持同一技术含义；
- 多项引用是否继续以多项引用方式被引用；
- 择一关系、并列关系和马库什变量是否被错误压平。

复杂嵌套、多组择一或边界待定时保留原文，列人工复核点，继续清楚部分。
