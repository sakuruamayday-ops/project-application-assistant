# 前期培育报告方向卡先行模板

## 适用范围

本模板用于方向比较、详细培育和逐方向专利规划；前期谈单、首次评估和合作判断沿 `pre-sale-assessment-report-contract.md` 四部分交付。正式核稿、财务和后期体检按对应专项流程。

## 固定顺序

1. 企业现有方向；
2. 用户另行给出的方向；
3. 检索或分析发现的建议新增方向；
4. 方向横向比较和推荐；
5. 当期或指定口径的政策适配；
6. 申报成熟度、差距和培育路线。

已有方向按实际类别逐一列卡，再做政策和成熟度分析；缺某类方向时直接进入下一类。

## 单张方向卡固定字段

1. 方向名称与产品内容：用客户可理解、可形成收入边界的产品名称，说明交付物、核心技术载体和主要应用场景。
2. 好处：说明与现有业务、客户、收入、技术、专利和政策叙事的协同，以及可形成的差异化价值。
3. 坏处：说明产品边界、跨行业跨度、商业化、知识产权、同质化和申报叙事风险。
4. 培育建议：给出产品收口、技术路线、研发项目、场景验证、收入归集和时间安排。
5. 专利布局按产品相关材料、结构、工艺、设备、算法或应用选择技术簇，并说明具体技术问题。
6. 申报角色：标明主方向、过渡方向、备选方向或不建议纳入。

## 方向边界核对

- 共享算法或数据作为共用能力，产品方向按客户、交付、收入及产业环节分别组织。
- 同一可核算产品、客户问题和商业闭环成立时合并；其余行业分别列方向并说明关联。
- 保留用户新方向的业务意图，说明利弊和收口建议；调整建议明确标为建议。
- 分析者新增方向明确标注“建议新增方向”，并说明为什么优于或补充现有方向。

## 证据分工

- 方向判断复用已有资料和陈述，缺项集中列明，继续交付成立部分。
- 发现材料内部矛盾、技术与产品脱节、不同产品被混写或计算不成立时，仍须指出，因为这会改变方向结论。
- 方向确定后，才在政策适配、成熟度评估和正式申报阶段建立政策、财务、知识产权、客户及市场证据链。
