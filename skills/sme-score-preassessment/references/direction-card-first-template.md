# 前期培育报告方向卡先行模板

## 适用范围

本模板用于用户明确要求比较产品方向、详细培育规划或逐方向专利布局的任务。默认前期谈单、首次评估和合作判断按 `pre-sale-assessment-report-contract.md` 的四部分结构交付，不自动展开方向卡；本模板不能覆盖该分流。已经进入正式申报书核稿、财务复算或材料后期体检时，仍按对应专项流程执行。

## 固定顺序

1. 企业现有方向；
2. 用户另行给出的方向；
3. 检索或分析发现的建议新增方向；
4. 方向横向比较和推荐；
5. 当期或指定口径的政策适配；
6. 申报成熟度、差距和培育路线。

没有某一类方向时直接跳过，不设置空卡，不为凑齐数量编造方向。政策与成熟度分析不得提前到方向卡之前。

## 单张方向卡固定字段

1. 方向名称与产品内容：用客户可理解、可形成收入边界的产品名称，说明交付物、核心技术载体和主要应用场景。
2. 好处：说明与现有业务、客户、收入、技术、专利和政策叙事的协同，以及可形成的差异化价值。
3. 坏处：说明产品边界、跨行业跨度、商业化、知识产权、同质化和申报叙事风险。
4. 培育建议：给出产品收口、技术路线、研发项目、场景验证、收入归集和时间安排。
5. 专利布局：按当前产品的材料配方、结构部件、制造工艺、设备、软件算法或应用闭环选择相关技术簇，不机械套用软件维度，不把功能名称直接当成专利题目。
6. 申报角色：标明主方向、过渡方向、备选方向或不建议纳入。

## 方向边界门禁

- 共享算法、模型或数据能力不等于同一主导产品。若客户、交付物、收入边界和产业环节明显不同，必须拆成不同方向卡。
- 不得用“技术母体”“平台底座”等抽象概念把不相关行业硬合并；只有在同一可核算产品单元、同一客户问题和同一商业闭环成立时才可合并。
- 用户给出的新方向必须原样保留其业务意图，再给出利弊和收口建议；不得静默改造成其他方向。
- 分析者新增方向必须明确标注“建议新增方向”，并说明为什么优于或补充现有方向。

## 证据分工

- 方向卡阶段只使用当前已有资料和企业陈述。没有证据就跳过对应证据分析，不列“证据缺口清单”，不因缺少第三方证明中断方向判断。
- 发现材料内部矛盾、技术与产品脱节、不同产品被混写或计算不成立时，仍须指出，因为这会改变方向结论。
- 方向确定后，才在政策适配、成熟度评估和正式申报阶段建立政策、财务、知识产权、客户及市场证据链。
