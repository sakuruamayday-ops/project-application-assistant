# 评分输出规范

## 五层分值

| 层级 | 含义 | 是否进入已核验分 |
|---|---|---|
| 已核验分 | 有可靠事实和明确口径，可直接计算 | 是 |
| 公开代理分 | 以统计局行业数据或可追溯公开事实替代不可得系统参数 | 进入粗评分，不进入官方系统分 |
| 条件分 | 关键证书、关联说明或分类待补证 | 否，单列 |
| 待系统评价分 | 系统自动生成或依赖不可得行业比较 | 否，单列 |
| 目标分 | 完成明确行动后可新增的分值 | 否，作为行动情景 |

## 摘要句式

“本次前期预评估的直接事实与统计局代理保守分为 X 分；采用公开事实代理系统专属指标后的基准粗评分为 Y 分；关键条件成立时为 Z 分。该结果用于申报前差距识别和对标提升，不等同于主管部门系统得分。”

财务数据未提供时改为：

“当前仅完成非财务预评估，尚不能形成完整总分。已核验非财务得分为 X 分，财务相关指标待用户提供数据后计算。”

## 禁止句式

- “官方评分为……”
- “一定能通过……”
- “按无来源行业平均值假设……”
- “根据未核验的桌面评分来源……”
- “没有该资质……”

最后一句应改为“当前检索层未发现公开记录，建议补充证书原件或主管部门公示信息复核”。

## 目标反推输出

费用率、毛利率和利润增长率必须同时展示当前档位、下一目标、当前值、目标值、需改善金额、金额含义和计算式。反推金额统一使用最新财务年度万元口径。

不得把静态反推金额写成企业必须削减或必须实现的预算承诺。统一表述为“在营业收入等其他条件保持不变的静态情景下，进入下一档所需的最低改善量”。
