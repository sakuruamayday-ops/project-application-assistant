# 2026年预评估数据契约

## 可直接采用

- 当前有效政策原文中的门槛、口径和时间要求。
- 用户当前提供的财务、经营、人员、研发、产品、客户、产能和市场数据。
- 当前可用企业信息工具返回的登记、有效专利、资质、荣誉和标准事实。
- 主管部门平台实际生成的质量分及其截图、导出记录或可验证页面。

## 可计算但不得转成内部评分

营收增长率、研发投入占比、研发人员占比、主导产品收入占比、资产负债率等指标必须展示公式、期间、单位和输入来源。计算结果只用于硬门槛和质量评价输入检查，不得按自建权重折算成总分或通过概率。

## 不得采用

- 第三方历史财务替代用户财务；
- 无来源的行业平均值、分位值或市场占有率；
- 统计局数据、同行数据或经验权重替代主管部门平台质量分；
- 从专利名称直接推断与主导产品高度关联；
- 失效、撤销、注销或过期证书作为当前有效资质；
- 历史四维评分、内部百分制和三档总分。

## 缺失处理

平台质量分缺失时写 `pending-platform-evaluation`，数值保持 `null`。企业数据不足时，逐项列出最小补充清单；已知硬门槛不通过时明确提示，但不能用其他优势抵消。只有平台实际分数及来源同时存在时，才能写 `verified-platform-score` 并与当期门槛比较。
