# 数据契约

## 可直接采用

- 企查查返回的企业登记、当前有效专利、资质证书、荣誉和标准信息。
- 用户当前提供文件中的财务、经营、人员、研发、产品、客户、产能和市场数据。
- 当前有效政策原文中的门槛、口径和时间要求。
- 国家统计局、地方统计局和正式统计年鉴发布的同行业公开统计值，仅用于建立行业代理基准，不得替代企业自身数据。

## 只能计算后采用

计算必须展示公式、期间和单位。包括营收增长率、研发投入占比、研发人员占比、主导产品收入占比、资产负债率、人均营业收入和净资产收益率。

行业代理基准也必须展示原始统计字段和公式。例如：

- 人均营业收入＝行业营业收入÷行业平均用工人数。
- 净资产收益率代理值＝行业利润总额÷行业净资产，行业净资产＝资产总计－负债合计。
- 成本利润率＝行业利润总额÷行业营业成本。
- 销售和管理费用率＝销售费用与管理费用之和÷营业收入。
- 毛利率＝营业收入减营业成本后的差额÷营业收入。
- 行业近两年增长率均值优先使用同一行业、同一统计范围的两年可比增速。

## 不得采用

- 企查查或网络来源的第三方历史财务数据替代用户财务数据。
- 没有来源的行业平均值、分位值或市场占有率。
- 未经官方或企查查核验的内部估分资料作为事实来源。
- 从专利名称直接推断其与主导产品高度关联。
- 已失效、撤销、注销或过期证书作为当前有效资质。

## 行业代理基准等级

| 等级 | 口径 | 用法 |
|---|---|---|
| A | 主管部门系统同批次、同项目、同细分行业评价值 | 可作为正式系统校准基准 |
| B | 统计局同国标四位行业、同地区、同规模范围 | 可直接进入公开数据粗评分 |
| C | 统计局同国标大类行业、全国规模以上企业 | 可进入粗评分，必须标注“宽口径代理” |
| D | 制造业总体或跨行业公开值 | 只做敏感性参考，不作为基准情景 |

企业行业映射应优先依据主导产品和实际经营活动，再与登记行业交叉核对。无法取得四位行业数据时，可以退到最邻近的大类行业，但必须记录国标行业名称、年份、统计范围和退阶原因。

公开代理分与主管部门系统分必须同时保留。报告应至少给出：

1. 直接事实与统计局代理构成的保守分。
2. 对系统专属指标采用有据代理后的基准粗评分。
3. 关键证书或口径成立时的条件情景分。

不得把上述任何一档写成官方得分。

## 缺失处理

八项行业代理评分的最小三年财务字段为：营业收入、营业成本、销售费用、管理费用、利润总额、资产总额、负债总额、年平均从业人数。年平均人数无法取得时可用年末人数代理并明确口径。

完整政策评分另需：主营业务收入、主导产品收入、净利润、研发费用、研发人员人数，以及审计口径和年度。财务费用为辅助字段，不影响本技能当前八项代理分。
