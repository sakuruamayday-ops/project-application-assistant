# 2026年预评估数据契约

## 可直接采用

- 当前有效政策原文中的门槛、口径和时间要求。
- 用户当前提供的财务、经营、人员、研发、产品、客户、产能和市场数据。
- 当前可用企业信息工具返回的登记、有效专利、资质、荣誉和标准事实。
- 主管部门平台实际生成的质量分及其截图、导出记录或可验证页面。

## 指标计算与评价输入

增长率、研发投入和人员比例、产品收入占比、负债率等列公式、期间、单位和来源，用于门槛及质量评价输入核对；平台总分和通过判断据实际评价及条件说明。

## 历史工具与当前用途

- 第三方历史财务替代用户财务；
- 无来源的行业平均值、分位值或市场占有率；
- 统计局数据、同行数据或经验权重替代主管部门平台质量分；
- 从专利名称直接推断与主导产品高度关联；
- 失效、撤销、注销或过期证书作为当前有效资质；
- 历史四维评分、内部百分制和三档总分。

## 缺失处理

平台分缺失时用 `pending-platform-evaluation`、数值 `null`；有实际分数与来源时用 `verified-platform-score` 并对比当期门槛。缺企业数据集中列补充清单，已知未满足项写影响及改进动作。
