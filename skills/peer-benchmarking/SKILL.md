# 同行对标

找企业或单家可比性查询直接给命中对象、依据和来源；完整对标按请求组织分析。

## 方法

1. 识别项目、年度、地区、行业、产品及目的。
2. 使用当前知识服务中的政府公示、认定、复核和原文，结合可用官方来源补齐；路由参考[名单与主体来源说明](../_runtime/recognition-source-routing.md)。
3. 用企业全称锚定主体，字段待明时参考[企业数据源说明](../_runtime/enterprise-source-fallback.md)。
4. 按同项目、政策版本、地区、细分行业、产品和规模评估可比性。
5. 分列公开事实、计算、推断、未知。获评记录对应年度认定事实，具体评分和申请条件使用其公开依据。
6. 跨年比较核对范围与指标变化，按一致部分比较，其他列历史背景或差异。

## 输出

给出对象、来源和可比依据；报告可展开事实对比、政策差异、可比程度与待核项。规则见 `references/peer-comparability-rules.md`。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
