# 同行对标

## 商业定位、MCP 双态与黑板接力

本技能为 **WorkBuddy 免费公开数据 MCP 入口（申报同行对比）**，遵循 [WorkBuddy 商业分层与 MCP 规范](../_runtime/workbuddy-core/mcp-routing-and-tiering.md)：

- **免费只读公开事实**：围绕同产品/同批次已认定同行官方名单事实与分组筛选（正式认定进直接组，拟认定单列）返回带原文定位的结构化事实，不携带商业模板或私有案例正文。
- **MCP 双态处理**：已配置免费数据 MCP 时优先查权威只读库（`origin: mcp_verified`）；未配置时基于本机导入清单或公开来源说明覆盖范围并提示开通免费数据 Key；已配置但鉴权失效/限流/超时时显式报错不静默蒙混。
- **主体隔离黑板接力**：将核验命中的主体认定记录写入工作区 `.facts/<企业标识>.facts.json` 供下游评估与收费撰写无缝复用。

找企业或单家可比性查询直接给命中对象、依据和来源；完整对标按请求组织分析。

## 方法

1. 识别项目、年度、地区、行业、产品及目的。
2. 使用当前知识服务中的政府公示、认定、复核和原文，结合可用官方来源补齐；路由参考[名单与主体来源说明](../_runtime/recognition-source-routing.md)。
3. 用企业全称锚定主体，字段待明时参考[企业数据源说明](../_runtime/enterprise-source-fallback.md)。
4. 用 `scripts/classify_peers.py` 核对主要对标范围及分组。正式认定列直接组，公示拟认定等同认定，分组标签沿用原件。再按政策版本、地区、细分行业、产品和规模评估可比性。
5. 分列公开事实、计算、推断、未知。获评记录对应年度认定事实，具体评分和申请条件使用其公开依据。
6. 跨年比较核对范围与指标变化，按一致部分比较，其他列历史背景或差异。

## 输出

给出对象、来源和可比依据；报告可展开事实对比、政策差异、可比程度与待核项。规则见 `references/peer-comparability-rules.md`。

报告表达采用[报告写作规则](../_runtime/report-writing.md)。
