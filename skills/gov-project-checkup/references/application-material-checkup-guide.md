# 已填申报材料六大章深度体检与四大叙事诊断闭环

本规程融合“优质中小企业自检框架（6 大章穿透诊断 + 温和建设性口吻）”与 V3 确定性复算/专利核验/按当年查同行引擎，适用于**用户上传已填好的小巨人、专精特新、高企或专项申报书（`.docx` / `.doc` / `.pdf`）要求“体检、自检、审查、看看有没有问题”**的场景，与“填报前资格体检”共同构成完整体检闭环。

---

## 一、体检定位与顾问口吻

- **角色与隔离**：以独立客观的资深申报评审顾问视角，只基于当前企业提交的材料及可核验本地库/政策口径开展诊断，绝不混入其他客户历史数据。
- **温和建设性口吻**：用客观、平实、可落地的建议指出风险（如“存在合规风险”“口径存在差异”“建议补充量化印证”），避免情绪化过激批评；每个问题都配明确可执行改法或改写骨架。
- **去发票化纯技术判断**：评估主导产品、补短板与知产关联时，从技术实体、工艺机理与产业链位置出发判断，不以缺少发票明细或发票品名未写核心基材为由否定技术真实性。

---

## 二、标准解析与基准年识别

1. **提取与容错分区**（脚本：`scripts/split_application_sections.py`）：解析上传的 `.docx` / `.doc` / `.pdf`，按 10 大章节分区（基本情况、经济效益、专业化、精细化、特色化、创新能力、产业链配套、主导产品领域、其他、企业总体情况简要介绍），自动兼容标题内空格（如“简 要 介 绍”）及部分章节缺失。
2. **动态识别基准年（Y / Y-1 / Y-2）**：从经济效益表最右侧完整年度自动锚定 `Y` 年，自动推算 `Y-1` 与 `Y-2`，不再写死具体年份。
3. **政策口径**：优先采用 `references/sme-policy-baseline-2026.json`（`工信部企业〔2026〕2号` 最新小巨人口径：营收 ≥5000 万、主营占比 ≥90%、近两年复合增长率 ≥5%复核不查、负债率 ≤75%、近两年研发合计 ≥1200 万且每年 ≥3%、相关自主有效 I 类知产 ≥4 项、市占率 ≥10% 或全国前三；信源：工信部企业〔2026〕2号 https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2026/art_5546b1a622ea4d73bd2ca395b73bd4eb.html）；浙江省内最新变化以本地库/MCP 为准，省外做当年+上年双年窗口联网核验。

## 三、六大章深度体检报告结构（壹至陆闭环输出）

按以下 6 章结构完整输出体检报告（无大碍的维度一两句带过，高风险维度展开剖析）：

### 壹、硬性指标评估与合规底线排查
- 逐项输出刚性指标核查表（专精特新资质、深耕时长 ≥3 年、Y 年营收、主营占比、近两年 CAGR、资产负债率、近两年研发合计与逐年费率、自主有效 I 类知产数、细分市占率/排位），同步调用 `run_checkup.py sme` 做确定性算术与专利第 5 位/到期日/受让满 1 年复算，输出红/黄/绿灯结论。

### 贰、财务数据穿透验算与逻辑研判
1. **表内填报比例 vs 绝对值推导比例比对表**：复算主营集中度、主导产品集中度、研发投入强度、资产负债率，揪出手填比例与分子分母算术不一致的硬伤。
2. **财务与经营逻辑穿透**：排查研发人员数与研发费用匹配度、跨年营收/利润大幅波动解释缺口、营收或研发刚擦底线的竞争脆弱性。

### 叁、跨表单一致性与知识产权支撑互证
1. **跨表单“面 → 核 → 魂”闭环扫描**：核对国民经济 4 位代码、工业“六基”、主导产品、补短板产品与下游大企业配套是否指向同一条业务主线，排查补短板与主导产品脱节。
2. **跨章数据一致核对**：比对经济效益表、专业化、市占率、研发表与 2000 字简介中的营收、增速、研发费、专利数是否前后打架。
3. **知识产权实质关联核查**：结合专利摘要/技术内容与企业实际对外销售业态判断直接支撑度——装备/模具制造企业以对外销售设备或模具专利直接支撑主导产品；材料/食品/零部件等非设备制造企业排查拿自用生产设备/工装专利硬凑主导产品，或专利撑不起“填补空白/国际领先”宣称的问题。

### 肆、双维度产业定位评估（重点产业链 + 工业“六基”）
- 分别输出「国家重点产业链上中下游契合度」与「产业基础“六基”归属」两张对照表，辨析企业处于核心零部件/基础材料/关键软件/先进工艺还是终端集成应用，识别概念堆砌与目录错挂（本地目录工具提示 `match_confidence: low` 时按工艺实质核定）。

### 伍、四大重点文字板块质量诊断与改写骨架（同步查工程时序）
1. **主导产品名称定调优化**：判断原名称是否过于宽泛或业态倒置，给出 2–3 个带技术/工况特征的规范建议名。
2. **补短板填空白（≤300 字）诊断**：精准统计字数、**检查是否泄露企业全称/简称/曾用名**、核查“行业痛点 → 首创/核心工艺 → 量化指标 → 替代与客户”因果链，排查拿基础准入检验凑数或AI标签腔，并给出直接可参考的强化改写骨架。
3. **产学研合作与成果应用（≤300 字）诊断**：统计字数，检查“领域/时间/团队/技术/成果/应用成效”完备度；有合作无成果或满篇“拟”时提示补充阶段进展或预计创收；无产学研时建议平滑采用企业自主研发分支。
4. **企业总体情况简要介绍（≤2000 字）诊断**：统计字数、**检查是否泄露企业全称/简称/曾用名**、核对“基本情况三段 + 产品技术五段”八段结构与各段去重情况（写作时不单列“成效明显市（州）声明”）。
5. **工程时序与证据定位检查**（适用三首/高企/科技专项材料）：核查 `立项设计日 ≤ 样机/开发完成日 ≤ 第三方检测日`、`立项设计日 ≤ 首次销售合同日`、查新近 1 年有效及专利申请日晚于 RD 立项日。

### 陆、红黄绿三级整改清单与下一步衔接
- 按 **🔴 必须修改（红线/算术/匿名/串户硬伤） / 🟡 建议补强（证据/叙事/对标缺口） / 🟢 保持优势** 三级列出整改表（每条写清对应章节位置、当前问题与具体动作）；
- 体检完成后，如需直接按建议重写或补写申报正文，无缝转入 `sme-giant-writer`（唯一六问六答 → 五大栏位成稿）、`hightech-application-writer` 或 `general-grant-writer` 输出最终版成稿。

## 四、交稿前自检闸门（防遗漏）

体检报告输出前运行 `scripts/checkup_self_review.py <报告.md>` 自查 8 项（退出码非 0 即补齐缺项后重出）：
1. 基准年（`Y` 年）与适用政策版本明确标注；
2. 刚性指标复算表完整输出并给出红黄绿判定；
3. 财务表内填报值 vs 绝对值推导比例完成穿透比对；
4. 跨表单一致性与专利实质关联度完成核查；
5. 重点产业链 + 工业“六基”双维度定位完成核判；
6. 四大重点文字板块（主导产品 / 300 字补短板 / 300 字产学研 / 2000 字简介）均完成字数、匿名与逻辑诊断并附优化建议；
7. 红黄绿三级整改清单给出明确章节定位与可执行动作；
8. 口吻客观温和、无过激用词、无串户污染。
