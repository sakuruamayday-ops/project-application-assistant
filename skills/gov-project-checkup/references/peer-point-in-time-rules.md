# 同行对标“按申报当年回溯”执行规范

开展政府项目同行对标与通过率评估时，必须执行以下时点对齐铁律，杜绝用当前静态快照反推往年申报门槛：

1. **锚定申报基准日（`T_apply`）**：优先取当期申报截止日；其次取年初公示按 `认定年度 - 1` 年末、年中/年末公示按认定当年锚定。
2. **严禁跨届与复核混算**：调用 `run_checkup.py peers --benchmark` 时必须按认定年度与“新认定 / 复核”严格拆分，不得把老批次复核企业与新认定企业合并求中位数。
3. **事前与事后资质分离**：伴随项目（如省首台套、浙江制造精品、研发机构）必须按首次认定年 `<= apply_year` 拆分事前已有与事后取得，严禁将获批后才取得的资质算作申报前置条件。
4. **核心竞品与抽样必回溯**：对重点对标竞品及目标区县最近一批获批样本，须按专利授权公告日与荣誉发布日 `<= T_apply` 精确还原当年真实有效数，并通过 `run_checkup.py cache-ingest` 沉淀至独立侧挂库 `timeline_cache.db`（与只读主库物理隔离）。
5. **对外报告表达要求**：面向客户的报告如实标注样本覆盖范围（不把局部样本写为全量），用“常见区间 / 中间水平 / 超过 X% 同行”等自然表达替代 `P25`/`P86` 等统计缩写，且不暴露内部数据库与脚本路径。
