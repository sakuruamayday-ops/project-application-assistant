# 非财务三项评价要求与证据核验

## 目录

1. 缺陷与差距
2. 知识产权
3. 科技成果转化
4. 研发组织管理
5. 证据复核

## 1. 缺陷与差距

对照政策原文与评分表结构（`references/hightech-policy-baseline-2026.json`），将企业缺陷记入 `items`。

| 要求 | 企业现状 | 证据 | 差距 | 补强动作 | 优先级 |
|---|---|---|---|---|---|
| 适用条款及实际核查点 | 已确认事实及状态 | 可定位的原始材料 | 实际缺少的数量、比例、事实或材料 | 证据补齐或实际建设 | 先处理硬门槛、真实性冲突与证据缺项 |

1. 逐项标出已满足、明确不满足或缺证据，分别写当前事实和证据出处。
2. 数量与关键技术链分别核对，证据按关联性、真实性和时间线核查。
3. 筛选待补项时保留适用条款、实际差距和补强顺序。政策表内分值用于解释评审结构。

### 1.1 证据覆盖与资格核对

- 逐维度列已覆盖项目与 `missing_evidence`。既有评价底稿接入旧接口时，`coverage` 按有依据的评价点权重占该维度权重计算，范围 0 至 1。
- 成长性由销售收入增长率和净资产增长率组成。在既有接口显式登记 `scores.growth.coverage` 时，两项等权，覆盖率为 0、0.5 或 1。仅覆盖一项时，在 `scores.growth.missing_evidence` 写另一项完整名称。
- `items` 逐项列缺少的事实、数量或材料，成长性保留可复算指标及档位边界。创新能力资格按适用的正式结果核对政策合格线（`references/hightech-policy-baseline-2026.json`），缺正式依据时保留未知。

## 2. 知识产权

### 2.1 技术先进程度

| 工作指引分档 | 评审关注的证据情形 | 典型证据 |
|---:|---|---|
| 7—8 | 解决明确行业问题，方案有实质创新，关键效果经验证并可与既有技术比较 | 权利要求、研发报告、试验或检测数据、工艺验证、公开技术基线 |
| 5—6 | 改进明确且有量化效果，但行业比较或验证链不完整 | 技术说明、内部试验、产品指标 |
| 3—4 | 一般结构、配方、参数或流程优化，效果主要依赖企业说明 | 专利文本、产品说明 |
| 1—2 | 改进轻微，指标与效果对应待核 | 零散说明 |
| 0 | 无有效知识产权或与申报技术无关 | — |

核对技术问题、权利要求特征、指标、验证结果和相对改进，逐项列差距。

### 2.2 对主要产品的核心支持作用

| 工作指引分档 | 评审关注的证据情形 |
|---:|---|
| 7—8 | 权利要求覆盖主导产品核心机制，并与主要高新收入形成闭环 |
| 5—6 | 支撑关键模块、工序或部分主要型号，收入映射仍有缺口 |
| 3—4 | 主要用于外围结构、辅助工艺或少量产品 |
| 1—2 | 主题相关，技术因果待补充 |
| 0 | 无实质关联 |

建立：

`知识产权 → 研发项目 → 核心技术 → 成果转化 → 高新产品或服务 → 收入`

以一件核心Ⅰ类 IP 为主轴，其他权利按结构、工艺、软件和应用关联程度选用。

### 2.3 数量

按当期指引分类统计适格有效权利，与要求对照并列出数量缺口。审中、失效、权属或使用待核项单列状态。官方数量分档见政策基线（`references/hightech-policy-baseline-2026.json`）。

### 2.4 获得方式

| 取得方式的细分参考分值 | 评审关注的证据情形 |
|---:|---|
| 6 | 自主研发，发明人、项目、人员、费用、试验和专利时间线完全一致 |
| 4—5 | 自主研发成立，但项目、人员或费用链存在非关键缺口 |
| 2—3 | 受让取得，但有真实消化吸收和产业化 |
| 1 | 仅有受让手续，与企业研发活动关联弱 |

检查专利申请时间是否落在项目实施过程中，避免“专利先取得、项目后补立”等时间线倒挂。

### 2.5 知识产权补强

证据补强：

- 权利要求—核心技术特征对照表；
- 技术问题—方案—指标—效果说明；
- 研发项目、人员、费用、试验、定型和量产时间线；
- 检测、试验、生产或客户应用记录；
- 知识产权法律状态、权属和Ⅱ类使用记录；
- 与高新产品和收入的映射。

Ⅱ类使用记录区分：

- 曾在未通过的高企申请中使用：仍可再次使用；
- 曾在通过认定中使用：标为已使用，后续评价选择符合使用规则的其他权利。

事实补强：

- 开展真实对比试验、检测或生产验证；
- 形成与主营产品核心技术匹配的新知识产权；
- 完成受让技术的消化吸收和产业化记录。

未授权 IP 按实际状态列入后续布局，当前资格及数量对照使用适格有效权利。

## 3. 科技成果转化

### 3.1 四段证据链

每项成果至少核对：

1. 成果来源：专利、技术诀窍、配方、软件、研发项目成果或工艺；
2. 转化过程：试制、中试、工艺验证、部署或生产导入；
3. 转化载体：产品、工艺、材料、服务、样机、软件或装备；
4. 应用成效：检测、生产、销售、验收、客户应用或降本增效。

### 3.2 按证据计数

| 状态 | 处理 |
|---|---|
| 四段闭环、边界与时间清楚 | 计 1 项 |
| 有成果、载体和应用，过程证据稍弱 | 可计 1 项并标记中等证据 |
| 只有证书、照片或自述 | 转化实施证据待核，先列布局与补证 |
| 同一成果形成多个型号、产品或地区应用 | 原则上只计 1 项 |
| 同一专利用于多个产品 | 按同一成果归集，分别说明应用 |
| 一个项目产生多项独立成果 | 技术边界和应用载体独立时分别判断 |
| 计划研发、尚待应用 | 列未来转化任务 |

先计算近三年有效成果数量和年平均数。按官方分档的数量边界（`references/hightech-policy-baseline-2026.json`）列尚差的有效成果项数，单列证据链缺环、成果重复或跨表口径冲突及对应补强动作。

### 3.3 成果转化补强

证据补强：

- 项目结题、成果确认和技术评审；
- 试制单、中试记录、样品和生产任务单；
- 工艺变更、配方版本或软件上线记录；
- 检测、验收、生产和销售材料；
- 首次应用时间及成果独立性说明。

事实补强：

- 完成新的研发成果、试制、验证和生产导入；
- 形成可追溯的首次应用和成效记录。

同一成果统一归集，转化年度、次数和应用按实际记录统计。

## 4. 研发组织管理

按“制度—执行—结果”核验，列缺失的制度、执行记录或结果材料。

### 4.1 研发管理与投入核算

内部参考拆分：

| 核查点 | 参考上限 |
|---|---:|
| 制度正式发布、职责清楚 | 1 |
| 真实立项、评审、过程和结题管理 | 2 |
| 研发核算体系和辅助账 | 2 |
| 项目、人员、费用、成果对应 | 1 |

### 4.2 研发机构、条件与产学研

核查研发机构、固定人员、场地设备、试验条件、合作协议、付款、技术交付和验收。只有挂牌或框架协议时，列实际运行和履约材料缺口。

### 4.3 成果转化与激励

核查转化制度、成果确认、奖励办法、实际奖励记录及开放创新活动。制度未执行时列实际执行任务和最早能形成的证据。

### 4.4 人才培养与绩效

核查培训计划、签到和结果，人才引进，研发人员绩效办法、真实考核和奖励。

### 4.5 组织管理补强

证据补强：

- 组织架构、岗位职责和人员名单；
- 立项、评审、阶段检查和结题记录；
- 研发辅助账及项目费用归集；
- 研发设备及使用记录；
- 产学研技术交付和验收；
- 成果奖励、培训和绩效执行记录。

事实补强：

- 建立并持续运行项目管理、辅助核算、产学研、奖励、培训和绩效机制；
- 从当前日期开始真实留痕。

新建制度注明建立日期；历史执行按当时真实记录说明。

## 5. 证据复核

模拟三类审查：

1. 技术专家：质疑先进性、核心支持作用、成果独立性和应用效果；
2. 财务及材料审查：核对研发费用、高新收入、销售、人员和成果时间线；
3. 合规审查：核对权属、法律状态、Ⅱ类使用、重复成果和制度真实性。

逐项记录争议所涉事实和证据定位，写明补证动作及其优先级。
