# P1 检索与法律分析

## 输入

- 技术材料、申请文件或现有权利要求；
- 法域与基准日；
- 检索目标：查新、无效风险、FTO、审查意见或布局。

## 流程

1. 生成 `technical-feature-map/v1`，提取客体、必要特征、效果和出处；待核特征先进入候选及补证清单，正式文本使用有支持的特征。
2. 按单项、组合和分类号生成检索单元，同义、外文、IPC/CPC、申请人与发明人分字段记，推荐分类标候选。
3. 中国专利首轮优先用 `scripts/cnipa_epub_search.py`，按接口每次发送1至8个脱敏短技术词。结果作为发现线索，新颖性、创造性、FTO 和法律状态另据原文及专项证据判断。
4. 目标法域官方原文核公开日、文本、附图和状态；其他库补外国文献、同族、引证及全文，分别注明来源。
5. 保存数据库、检索式、访问日、数量、浏览器策略和覆盖范围；依赖、验证码、改版及超时分别记为提供器状态。
6. 将命中文献按公开日过滤，并回到权利要求、说明书段落和附图核对。
7. 生成权利要求引用图、必要技术特征树和 claim chart；把申请文件特征编号与证据图特征编号保持可追溯对应。
8. 新颖性按单一文件逐项判断；创造性记录最接近现有技术、区别特征、技术效果、实际技术问题和技术启示。
9. FTO 分析目标市场有效或待决权利要求，说明检索覆盖和具体法律复核需要。

## 输出

每条结论附公开文本定位、权利要求号、段落号、附图标记、法律状态来源和查询日期。未命中时写“当前检索范围未命中”。

国知局提供器的安装、输出字段、HTTP 隐私边界和人工降级规则见 [国知局公布公告首轮检索提供器](cnipa-epub-provider.md)。
