# 项目导向专利布局规划

按项目、产品路线、现有专利及公开技术反推布局，各候选注明真实技术点、证据与验证动作。

## 固定流程

1. 锁定目标项目及版本、产品路线、计划申报时间、法域、预算、公开计划和希望阻止竞争者复制的环节。
2. 由 `policy-retrieval` 核验知识产权类型、数量、取得方式、时间、关联性和有效状态口径。
3. 由 `ip-assessment` 建立现有知识产权底稿，区分有效授权、审中、失效、转让取得和转出。
4. 按产品、子系统、材料、工艺、配方、控制、检测、应用场景和替代方案建立技术与证据树。
5. 结合 P1 现有技术检索和 P2 专利点挖掘，形成候选方向、重叠风险、说明书支持缺口和公开风险。
6. 设计核心专利、外围改进、工艺或控制、应用和防御公开的组合，并与产品发布、客户交付和项目申报节点对齐。

## 候选方向评价

逐项记录成熟度、差异证据、产品项目关联和商业阻断价值；未知标 U，维度齐备时计算加权参考值，授权前景另据检索分析。

## 固定输出

1. 项目知识产权口径与来源；
2. 企业现有 IP 底稿和状态冲突；
3. 技术特征树与覆盖矩阵；
4. 候选方向及证据缺口；
5. 立即启动、补证后启动、观察储备三层组合；
6. 申请与公开节奏；
7. 每个方向的一页式交底卡，包括技术问题、方案骨架、必要特征、替代方案、效果证据和待研发项；
8. 重复申请、权属、提前公开、说明书支持、项目认可和 FTO 风险。
