# 专利 Word 回归验收核对

## 适用范围

单份 Word 核稿按需检查批注、完整性和渲染；脱敏夹具及提供器回归用于实现变更。已给完整对比文件时，直接完成独立核稿并交付。

## 必测对象

1. 原始真实文件副本：验证真实排版、现有表格、文本框、附图和附图标记。
2. 批注或结构处理实现变更时，使用脱敏结构副本验证可共享回归，不含原技术内容和个人元数据。
3. 批注或结构处理实现变更时，使用受控增强夹具：在脱敏副本中加入 OMML 公式、合并单元格表格和唯一定位锚点。

## 通过条件

- 输入与输出均能通过 ZIP 完整性检查。
- 输出保留输入全部非预期删除的 ZIP 部件、媒体和关系。
- 每条批注在 `comments.xml` 有正文，在 `document.xml` 有 start、end、reference 三类锚点。
- 批注目标文本与审查 JSON 的 `context`、`highlight_text`、`occurrence` 一致。
- `review_adder.py` 跳过数量为 0。
- `verify.py` 三项验证全部通过。
- 表格数、文本框数、公式数、Drawing 数和媒体数达到夹具清单预期。
- 渲染生成所有页面 PNG，逐页检查无截断、重叠、缺字、表格破坏或附图错位。
- 批注结合渲染和 OOXML 结构审计核对位置、内容及完整性。

## 国知局提供器变更回归

提供器变更按影响范围回归；实际在线调用区分运行状态、命中数及业务结果，问题随稿说明并继续独立部分。

- 回归覆盖结果卡、复选框、去重、发现级证据、敏感输入、零结果及提供器状态。
- 国知局实时核对至少覆盖发明、实用新型和外观设计各一条公开记录，并对其中一条回到官方详情或全文核对公开号和公布日。
- 国知局提供器使用独立临时浏览器配置并保持 Chromium 沙箱；验证码或页面异常返回结构化状态。

## 失败处理

审查版 Word 根据当前文件的批注、完整性和渲染实核结果定稿；发现问题保留产物与诊断，修复后复验受影响项。提供器候选根据实际回归结果发布；单份核稿继续独立完成，依赖失败检索的结论标明缺口并先交付成立部分。
