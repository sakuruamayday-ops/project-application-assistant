# P3 浙江双中心预审推荐

候选中心固定为浙江省知识产权保护中心和杭州市知识产权保护中心，但单件案件只推荐一个主目标中心。

## 证据链

1. 申请主体完整登记名称、注册地址和查询日期。
2. 逐中心登记本案备案证据，缺本案证据记“未核实”。
3. 独立权利要求保护客体、必要技术特征和初拟 IPC。
4. IPC 判断依据及适用的 IPC 版本。
5. 两中心清单的发布日期、文件哈希、官方或存档来源。
6. 技术主题与中心产业领域的直接匹配度。
7. 中心命中结果、排除理由和唯一推荐。

## 推荐原则

- IPC 命中列准入候选，实际受理据中心规则和决定。
- 注册地、备案、IPC 和产业领域同时满足。
- 杭州来源附件无法从官网取得时，可使用用户或维护方提供的微信公众号页面存档作为有来源标识的存档证据，并明确其证据状态。
- 候选并列时说明差异与待核事实，周期和通过情况据可靠来源。
