# P3 浙江双中心预审推荐

候选中心固定为浙江省知识产权保护中心和杭州市知识产权保护中心，但单件案件只推荐一个主目标中心。

## 证据链

1. 申请主体完整登记名称、注册地址和查询日期。
2. 两个中心备案状态；默认按主人确认的“均已备案”运行，正式提交前复核。
3. 独立权利要求保护客体、必要技术特征和初拟 IPC。
4. IPC 判断依据及适用的 IPC 版本。
5. 两中心清单的发布日期、文件哈希、官方或存档来源。
6. 技术主题与中心产业领域的直接匹配度。
7. 中心命中结果、排除理由和唯一推荐。

## 推荐原则

- IPC 命中是准入候选条件，不等于预审必然受理。
- 注册地、备案、IPC 和产业领域必须同时满足。
- 杭州来源附件无法从官网取得时，可使用主人提供的微信公众号页面存档作为有来源标识的存档证据，并明确其证据状态。
- 证据并列且无法唯一判断时，保留候选并列出缺口，不编造审查速度或通过率。
