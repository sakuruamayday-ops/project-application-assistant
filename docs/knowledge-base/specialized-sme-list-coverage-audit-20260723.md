# 全国专精特新中小企业名单覆盖审计

审计时间：2026年07月23日

## 当前结论

当前生产知识库不能判定为全国覆盖完整。

生产索引中有311份标准项目名为“专精特新中小企业”的相关文档，结构化名单中有87,991条通用项目企业行；另有59份“浙江省专精特新中小企业”文档和4,082条企业行。上述数字包含重复附件、公示与认定并存、复核名单、地市名单及地域未识别记录，不能直接当作全国企业数或完整名单数。

按32个省级组织单元核对标题、标准项目名和已识别地区，吉林、江苏、安徽、福建、山东、广西、重庆、陕西、甘肃、宁夏和新疆暂未形成可直接确认的省级完整覆盖记录。部分地区存在地市名单或标题不带省名的附件，例如扬州、滁州、南宁等，但不能替代省级最终认定名单。

## 完整覆盖标准

2022年以后每个省、自治区、直辖市及新疆生产建设兵团按年度、批次建立矩阵，每个单元至少记录以下一种官方证据：

1. 正式认定名单；
2. 复核通过名单；
3. 取消或撤销名单；
4. 官方明确说明当年未组织或未公布该批次。

公示、推荐和拟认定名单只能作为过程证据，不能替代正式认定名单。地市名单不能自动上升为省级名单。2022年前各地原有“专精特新”称号单独进入历史库，不与全国统一梯度培育口径混算。

## 后续采集顺序

1. 先补齐11个尚不能确认省级完整覆盖的地区。
2. 再核对其他地区2022年至今是否每年或每批均有最终名单或无批次说明。
3. 对地域为空的附件回查原通知、发文机关和官方链接，补录省份、年份、名单状态。
4. 对企业名称、统一社会信用代码、曾用名、迁址和复核状态建立跨年关联。
5. 完成省份年度矩阵后，才允许对外表述“全国覆盖完整”；此前统一表述为“当前已收录范围”。
