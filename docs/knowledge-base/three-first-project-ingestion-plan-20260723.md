# 浙江省三首项目知识库增量方案

核对时间：2026年07月23日

## 已核对页面

- 浙江省制造业首台（套）装备：企策顾问项目页 `projectId=12`，页面累计展示1,223家；2025年度公示详情展示241项产品。
- 浙江省首版次软件产品：企策顾问项目页 `projectId=10`，页面累计展示312家。
- 浙江省首批次新材料：企策顾问项目页 `projectId=11`，页面累计展示202家。

上述累计数字仅用于确定采集规模，不作为官方统计结论。项目页只提供公司名称、登记地区、行业和获批年份，不能满足产品对标、档次判断和正式认定核验。

## 建议目录

```text
50_名单与对标/
└── 浙江省三首项目/
    ├── 首台套装备/
    │   └── 省级/年度/公示或认定文档/
    ├── 首版次软件/
    │   ├── 省级/年度/公示或认定文档/
    │   └── 市级/城市/年度/公示或认定文档/
    └── 首批次新材料/
        └── 省级/年度/公示或认定文档/
```

每份文档目录保存原文件、规范化Markdown、逐行JSONL和来源元数据。Markdown用于全文检索，JSONL用于企业、产品、档次和地区精确查询，原文件用于证据核验。

## 采集流程

1. 读取三个项目页，取得历年企业和年度发现索引。
2. 按年度进入公示、认定或目录详情页，提取官方原文链接和附件。
3. 将官方附件逐行结构化，不只保存项目页中的企业汇总。
4. 对首版次另行采集各设区市市级名单，层级字段固定为市级并保存城市，不并入省级名单。
5. 公示与正式认定分别入库；正式认定发布后建立替代关系。
6. 用企业、产品、项目层级、年度和档次去重，并保留同一企业同年多个产品。
7. 完成抽样复核后重建名单索引，再增量同步云端。

## 首批实施建议

先采集2022年至今的省级三首项目；首版次同步覆盖杭州、宁波、绍兴、金华、嘉兴、湖州、温州、台州、舟山、衢州和丽水的市级名单。首批验收至少覆盖：

- 企业名称与产品名称抽样准确率；
- 年度、地区、行政层级和名单状态完整率；
- 首台套类别与国际、国内、省内档次；
- 首版次省级与市级零混淆；
- 首批次材料名称、类别和档次可检索；
- 企策顾问发现页与政府官方原文均可追溯。

## 检索示例

- “某公司历年有哪些首台套产品，分别是什么档次？”
- “杭州2024年国内首台套装备有哪些？”
- “某软件是否进入浙江省首版次，还是只进入杭州市首版次？”
- “与某材料同类别的省内首批次产品和企业有哪些？”

回答必须返回产品级事实。只有企业和年份而没有年度明细时，输出“已发现候选记录，待展开年度官方名单”，不得补造产品名称或认定档次。
