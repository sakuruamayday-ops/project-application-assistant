# 政府项目与知识产权 V3 十个技能包使用速查卡

适用平台：Antigravity / WorkBuddy（10 个独立打包、即装即用、无繁琐哈希校验）  
核心原则：**摸底体检只核客观硬门槛与短板补强（不测主观分、不保通过）；写作类直接输出可用最终版成稿（不编造财务和专利号、不写草稿口吻）。**

## 二、常见业务场景串联口诀（按顺序用，不打架）

1. **新客户进门摸底**：先跑 `09 企业全景尽调` 或 `01 政府项目免费体检`（自动把核验过的企业事实记进同一份主体档案，后面写作直接复用，不串户）。
2. **写小巨人 / 专精特新**：先 `01 体检` 核客观硬门槛 → 再 `04 专精特新撰写`（方向卡 → 六问六答 → 五大栏位直出终稿）→ 最后 `02 材料质检` 终审。
3. **写国家高企**：先 `01 体检` 核财务研发与专利底线 → 再 `03 高企申请书撰写`（15+ 研发表、年均 5+ 成果转化一一对应、回填 Word）→ 最后 `02 材料质检` 终审。
4. **写浙江省级企业研究院 / 首台套 / 技改 / 绿色与智能工厂**：直接用 `05 通用政府专项申报` → 交付前用 `02 材料质检` 扫一遍。
5. **拿到客户旧稿要做体检**：直接丢给 `01 政府项目免费体检` 出六大章体检与红黄绿整改清单；只想知道两版改了哪里、有没有错别字或串户，用 `02 材料质检`。
6. **专利与标准**：挖掘/查新/预审找 `07 专利战略`，审已有专利 Word 稿找 `06 专利核稿`，写标准找 `08 标准起草`。

## 三、开箱直接复制的典型口令（10 句）

1. **体检摸底**：「帮我给这家制造业企业做一次免费项目体检，核对财务研发和专利，看看今年适合报高企、小巨人还是省级企业研究院。」
2. **已填申请书体检**：「这是客户写好的小巨人申请书 Word，帮我做六大章深度体检，查字数、匿名、算术和逻辑硬伤。」
3. **提交前终审 / 两版对比**：「对比这两版申报书 Word 改了哪些数字和段落，并全篇扫一遍有没有占位符、串户或免责套话。」
4. **小巨人成稿**：「按这套企业资料做 2026 版小巨人前期培育方向卡，走六问六答并直接输出主导产品、市占率、成果、补短板和 2000 字简介终稿。」
5. **高企整本**：「按企业审计报告、人员和专利清单，帮我规划近三年 15 个以上研发项目并生成高企申请书 Word 终稿。」
6. **浙江研究院 / 专项**：「按浙江 169 号文给这家企业写一份省级企业研究院建设方案（六大章），输出可编辑 Word 成品。」
7. **专利核稿**：「核稿这份发明专利申请文件 Word，逐条标出保护范围影响并输出带批注的副本。」
8. **专利挖掘与预审**：「根据这份技术方案挖掘 3 个高价值发明点，并判断走浙江还是杭州知识产权保护中心预审。」
9. **标准起草**：「帮我按 GB/T 1.1 起草一份企业标准草案和编制说明，并检查引用标准和试验方法是否完整。」
10. **尽调与财税**：「给这家拟合作制造企业做一份合作前全景尽调报告，顺便测算它有没有触发新公司法实缴红线。」

## 四、团队统一使用铁律（避坑备忘）

- **不测主观分、不保通过**：所有体检只核客观硬门槛（营收、主营占比、研发强度、有效授权专利、成立年限、无重大事故等）并给补强动作；专家评分与平台评价分一律不预测、不承诺获批。
- **按对外卖什么定专利归属**：卖设备/模具的装备厂，设备专利直接作为主导产品专利直挂；卖材料/食品/零部件的企业，厂里自用的生产设备工装专利只放制造工艺支撑，不抢主导产品名额。
- **真数字绝不编、缺检测务实写**：财务金额、专利号、证书号、高校专家名绝不编造；缺第三方检测报告时，写稿按企业实际体量用行业常见水平自然落笔，不写“设计控制目标为……”草稿腔。
- **政策口径省内外分流**：浙江省内以本地知识库/政策接口为准（如省级高企研发中心入口已取消，省级研究院仅留重点企业研究院和企业研究院两档）；省外项目联网查「当年 + 上年」最新官方通知即可。
- **小巨人 2000 字总述精简结构**：固定写“基本情况三段 + 产品技术五段”共八段，全程匿名不出现企业名，不再单写“成效明显市（州）声明”。
