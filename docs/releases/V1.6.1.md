# V1.6.1 正式发布说明

V1.6.1 是企业全生命周期助手当前对外发布版本。本版本在 V1.6.0 的 Grounded 证据交付与跨平台最小行为 Hook 基线上，增加人才创业落地区域预评估、企业数字身份血缘与主题反查，并收敛服务器历史发布槽。

## 本版本包含

- 人才项目按真实履历、项目阶段、团队与落地需求形成区域预评估；政策例外通道必须有官方依据，人才券、算力券等只作条件式分析。
- 企业数字身份按现名、曾用名、统一社会信用代码和合并主体建立血缘，可从名称或信用代码反查并展示冲突路径。
- 当前生产企业身份基线为 15,837 个主体，其中 11,882 个已核验；3,955 个待核验主体明确保留为后续增量，不冒充已闭合。
- 主题分类词典现有 3,312 条，统一反查继续按产品、行业、企业主营业务和正式认定证据交叉过滤。
- 应用发布槽和索引代际的活动目录只保留 `current` 与 `previous`；更早代际先移入系统回收站并记录精确路径，不在发布事务中永久删除。
- V1.6.0 的 Grounded 回执、否定作用域、来源访问状态、Word 元数据检查和 Windows 原生 EXE Hook 完整保留。
- 一键安装保持一次复制粘贴、保留其他 MCP、只替换 `mcpServers.jiaotang-kb` 并重载一次。

## 清单事实（发布门禁逐字记录）

- V1.6.1 发布人才创业落地区域预评估、企业身份血缘与主题反查，并将服务器活动发布槽收敛为当前版和上一版。企业数字身份证属于外部数据门禁，不进入插件包。
- 统一来源登记、稳定编号、主张映射、计算血缘和最小披露规则，保留各文档类型的原生页面结构。
- 市场占有率采用固定乘除链、六同校验和 A 至 D 分级；D 级可生成明确限制用途的报告，但不得冒充可对外使用的精确结论。
- 正式 Grounded 交付必须产生与当前 turn_id 绑定的确定性验证回执；Stop Hook 不再把空 validator_receipts 判为已完成。
- Windows 将已明确请求的输出文件与作为输入的工作簿分开；离线、禁上传等限制不得取消正向报告交付意图。
- Windows 与 macOS 的正式交付否定只在否定词实际支配生成、输出或撰写等交付动作时生效；来源披露限制和生成器描述不得覆盖先前的正向交付请求。
- 来源登记增加 obtained 与 reference_only 访问状态；未取得原文的链接不得声称检索日期或伪装成用户文件。
- Word 交付拒绝模板默认修改时间、空最后修改者和生成器元数据，并交叉校验台账与成品的来源访问状态。
- Windows UserPromptSubmit、Skill 激活与 Stop 继续由原生 EXE 处理，状态写入用户级 .workbuddy/state/jiaotang-behavior。
- 本地 XLSX 只读检查提供无第三方依赖路径，不得为读取用户文件临时联网安装依赖。
- 未经用户明确授权不得把输入或交付文件上传到 COS、云渲染或其他外部服务。
- 分析报告来源位于文末，Excel 来源位于最后工作表，PowerPoint 来源位于最后一页；标准正文保持规范性引用文件结构并另附来源说明。
- 注册表、调用图、共享夹具、影响图和双端回执按批次同步更新。
- 前期培育报告先完成企业现有方向、用户给定方向和建议新增方向三类方向卡，再进入政策适配、成熟度和专利布局。
- 专利路由继续使用已核验的专利检索、挖掘、预审、布局和交付规则，不把企业数字身份证或索引数据打入插件。
- 人才项目增加基于真实履历、项目阶段与落地需求的创业区域预评估；例外通道必须有官方依据，人才券与算力券只作条件式分析。
- 服务端建立现名、曾用名、统一社会信用代码与合并主体的身份血缘，并支持按名称或信用代码反查冲突路径。
- 当前生产企业身份基线为 15,837 个主体，其中 11,882 个已核验、3,955 个明确保留为后续增量；主题分类词典现有 3,312 条。
- 应用槽与索引代际的活动目录只保留 current 和 previous；更早代际先移入系统回收站并记录精确路径，不在发布事务中永久删除。

## 数据与插件边界

企业数字身份证不进入插件包。企业数字身份证、主题词典和知识索引属于服务端代码与数据发布，不进入通用 Skills、macOS WorkBuddy 或 Windows WorkBuddy ZIP。V1.6.1 插件包只包含 49 项 Skills、必要参考资料、业务脚本与最小行为 Hook。

当前 15,837 个主体作为本次可验证基线先发布；后续身份核验和主题词扩充按增量方式更新，不要求重新安装 Skills。

## 平台验收边界

V1.6.1 Windows WorkBuddy 与 V1.6.1 macOS WorkBuddy 使用同一套 49 项 Skills 与业务规则。结构、签名、确定性 Hook 和安装包门禁在发布前执行；Windows Authenticode 与两端真实设备结果由主人在发布后补录，不作为本次发布前置阻断。

## 回滚

- 插件异常时恢复上一正式版本的 Skills 与插件目录，并保留用户 MCP 配置和项目资料。
- 应用和索引异常时把 `current` 指针切回 `previous`。
- 历史代际仅移入可恢复的系统回收站；未经精确授权不永久清空。
