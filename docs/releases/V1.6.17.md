# 共创研究院企业全生命周期助手 V1.6.17 正式发布说明

V1.6.17 以 V1.6.16 为上一版本。V1.6.17 完善任务指令、通用运行时、文档读取、专业交付有界收束和独立客户端同源技能投影。正式发布物为一份可验证的通用签名 Skills 包；共创独立客户端使用同一签名技能源，不再维护分叉候选。

## 一、本版本新增功能

- 文档读取按真实内容类型处理常见 Word、Excel、演示文稿、WPS 兼容格式、PDF、ODF、RTF 和文本格式，并逐页报告 OCR 缺口。
- 专业交付校验最多自动修正一次；仍不满足时形成待完善、等待用户或失败终态，保留已有内容和可执行缺口，不再强制无限续跑。
- 修正高企研发文案回填、产业目录命中统计、双报告模板分页与字体嵌入，并补齐相应确定性测试。
- 首次配置改为读取当前运行时实际能力，不再要求安装特定第三方宿主，也不重复安装已有文档与联网能力。
- 任务沿用用户当前选择的模型与推理档位；既有授权范围内直接执行，高影响缺口只暂停依赖部分。
- 通用运行时按宿主提供的技能实际路径执行；签名与发布者指纹异常继续硬失败，辅助偏好异常只降级受影响能力。
- 自动记录、归档与持久化授权分离，未获授权时不写入长期记忆或用户资料目录。
- 通用签名包与独立客户端内嵌投影使用同一有效技能清单，技能数量由验签清单派生。
- V1.6.17 继承 V1.6.16 的绿色工厂版本识别、硬门槛、评分证据矩阵和指标一致性校验。

## 二、原有核心功能

- 检索现行政策、历史文件、申报通知、项目条件、认定名单和相似案例，并区分事实、计算、推断与待核验信息。
- 根据企业情况匹配可申报项目，开展单项目可行性分析、多项目综合评估和申报路线规划。
- 支持专精特新前期评估与后期体检、小巨人申报分析、高新技术企业预评估及申请书撰写。
- 支持首台套、首批次、首版次、数字化、绿色制造、技术改造、质量品牌、科技、人才、农业、商贸和区域专项分析。
- 支持企业画像、同行对比、企业分析报告和制造企业财税风险分析。
- 支持专利检索、专利布局、侵权风险分析、技术交底、申请文件核稿及知识产权项目分析。
- 支持申报材料、标准文件、版本对比、一致性检查、证据台账与成果归档。
- 支持 Word、Excel、PowerPoint、PDF 等常用交付格式，并对正式文件执行内容、数据、来源和版式检查。

## 三、分发与兼容

- V1.6.17 只构建一个通用签名 Skills 包，并为共创独立客户端生成同源的内嵌签名投影。
- macOS 与 Windows 客户端分别消费同一签名技能身份；客户端安装包、更新和回滚仍按各自发布事务验收。
- 通用包不携带用户凭据、客户资料或本地知识索引。企业数字身份证不进入插件包或技能包。

## 四、发布验收范围

正式包必须通过根技能测试、模板真实解析与渲染、逐技能清单和 Ed25519 签名、通用包隔离安装与本地安装后完整性核验。客户端内嵌投影、客户端安装包和双端实机结果由客户端发布事务分别记录，不以技能包签名代替客户端上线证明。
