# 共创研究院企业全生命周期助手 V1.6.4.2 功能简介

V1.6.4.2 将专精特新前期评估收敛为五至八页四部分谈单版，把本地技能对账扩展到全部可见技能根目录，并为高企汇总表增加字段粒度、WPS逐页验收和最终哈希闭环；正式打包继续唯一读取 `skills/suite-manifest.json`。

V1.6.4.2 提供通用 Skills、macOS WorkBuddy 与 Windows WorkBuddy 三个平台签名包。企业数字身份证不进入插件包，企业数字孪生和知识索引也不属于插件构建输入，本版本不切换知识索引。

## 机器可读版本事实

V1.6.4.2 将专精特新前期评估收敛为五至八页四部分谈单版，把本地技能对账扩展到全部可见技能根目录，并为高企汇总表增加字段粒度、WPS逐页验收和最终哈希闭环；正式打包继续唯一读取套件清单。

- 专精特新前期评估固定为五至八页四部分：结论、项目申报路径、主导产品与专利、财务简析；用于前期谈单，不改变后期申请书体检路由。
- 后台继续保留完整政策项目池和十二字段路径，前台仅投影项目、年度、申报条件、企业值、差距、动作六列简表；缺数据严格区分待定与待补强。
- 变更边界锁定为 sme-score-preassessment，不修改企业分析报告版本，也不修改尖兵领雁、市级重大和科技计划类分析。
- 本地技能对账从名称前缀扫描扩展为全部可见技能根目录；每个非正式技能必须登记来源、责任方、分类、归并目标或排除原因。
- 正式技能数量、门户展示、安装提示和发布测试统一动态读取 suite-manifest.json；归并项、共享运行时、管理员工具和外部能力不会进入普通用户插件包。
- 高企知识产权、PS和科技成果转化汇总表固定一项一行的简写粒度；正式交付必须经过原模板字节复制、字段校验、WPS Office逐页截图验收和最终文件 SHA-256 闭环。

## 本版本变更

- 专精特新前期评估固定为五至八页四部分：结论、项目申报路径、主导产品与专利、财务简析，面向前期谈单使用。
- 后台保留完整政策项目池和十二字段路径，前台仅投影项目、年度、申报条件、企业值、差距、动作六列简表；缺数据严格区分待定与待补强。
- 变更边界锁定为 `sme-score-preassessment`，不修改企业分析报告版本、尖兵领雁、市级重大、科技计划类分析；后期已成型申请书继续路由 `sme-development-projects`。
- 本地技能对账从名称前缀扫描扩展为全部可见技能根目录。每个非正式技能都要登记来源、责任方、分类、归并目标或排除原因，未登记新增项直接阻断候选。
- 正式技能数量、门户展示、安装提示和发布测试统一动态读取 `suite-manifest.json`；已归并技能、共享运行时、管理员工具、外部能力和本地扩展不会误入普通用户插件。
- 高企知识产权、PS和科技成果转化汇总表按一项一行的简写粒度校验；正式交付按“原模板复制—字段粒度检查—WPS Office逐页验收—最终文件 SHA-256 核对”闭环执行，Pages、LibreOffice和快速预览不能代替WPS验收。
- 继续包含企业数字孪生增量修正和局部重放能力。主人点名的 `34fbaf4` 与当前祖先提交 `020473c` 补丁等价，目标脚本和测试文件逐字节一致，因此不重复 cherry-pick。

## 兼容与边界

- 正式技能的数量和名称继续以 `skills/suite-manifest.json` 为唯一机器可读基线，不因本机额外安装的工具或外部技能改变。
- 既有企业前期评估完整政策梯度仍保留在后台；本版本仅改变专精特新前期谈单报告的客户可见结构。
- `enterprise-checkup`、`expert-dual-assessment`、`financial-statement-analysis-zh`、`patent-layout-planner`、`sme-checkup`、`srxgj-qa` 等旧入口继续按归并映射处理；品牌能力使用共享运行时，不重复增加顶层技能。
- `arxiv`、`bigquery-patent-search`、`dogfood` 和其他宿主或外部能力明确排除出正式插件；`skill-release-manager` 等发布工具只供管理员使用。
- 本版本不覆盖 V1.6.4.1 标签；GitHub、门户、服务器和本地正式技能提升均须执行二阶段确认，候选阶段不得提前执行，也不得切换知识索引。

## 回滚

- 代码候选可恢复到 V1.6.4.1 正式提交；本地技能对账快照单独记录源提交和 SHA-256。
- 签名包为不可变候选，不覆盖既有 V1.6.4.1 正式包；未获正式确认时不得进入下载入口。
- 回滚不覆盖客户项目资料、知识索引、个人偏好、其他 MCP 或系统凭据。
