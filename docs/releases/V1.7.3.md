# V1.7.3 报告生成与企业全景分析修复

- 明确全景分析和全景报告由企业全景技能承接，同行对比只作为其中的子章节。
- 连续分析新企业时保留已确认报告模式，重新核验新企业资料，不沿用前一家企业事实。
- 单独输入企业名称且没有已确认任务时，先明确分析范围，不擅自改为同行对比。
- 分析和体检报告默认交付PDF；申请书、表单、可编辑数据及明确指定的Office文件仍保持原格式。
- 项目报告母版程序化回填后直接输出静态HTML，不由模型重新抄写正文，也不需要先落盘中间Word。
- 共创客户端统一执行PDF生成、校验、真实品牌、逐页视觉和文件交付；其他宿主继续使用其已有PDF流程，不冒用客户端回执。
- 企业全景A版保留共创知识产权报告人及免水印规则，B版和其他专业报告使用实际共创研究院品牌检查。

保留 V1.7.2 的报告模板、财务计算及知识产权事实处理规则，不增加业务评分或交付前置条件。

提供同一份通用签名 Skills ZIP，Windows 与 macOS 客户端使用验签后的套件投影。技能包不包含知识索引、企业数字身份证或用户凭据。
