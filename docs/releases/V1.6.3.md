# 共创研究院企业全生命周期助手 V1.6.3 正式发布说明

V1.6.3 是共创研究院企业全生命周期助手当前对外正式版本。本版本统一公开品牌、增加 Word 用户模板原样填充门禁，并在同一发布窗口单独更新企业数字身份证索引。

## 本次变更

- 用户提供 Word 模板并要求按原格式生成时，默认只允许替换模板已有正文文字节点。
- 禁止使用 `python-docx` 重建段落、表格或版式；禁止自建“看起来相似”的模板。
- 字体、字号、颜色（包括红字）、抬头、页眉页脚、表格网格、列宽、行高、合并关系、边框、节属性、页面边距和媒体必须保持不变。
- 新增机器可执行的模板保真校验器；交付还必须完成逐页视觉检查。文字过长时压缩文字，不通过改字号、行距、边距或重新排版解决。
- 只有用户明确要求增加或删除 RD、PS 等重复表格时才进入结构扩展模式；扩展必须深拷贝模板完整同类 OOXML 片段，并单独记录结构变化。
- 通用 Skills、WorkBuddy 市场、插件、运行目录和公开附件统一使用“共创研究院”；远程 MCP 兼容名称 `jiaotang-kb` 保持不变。
- Windows 原生 Hook 同步使用共创研究院市场和行为状态路径。Windows Authenticode 仍在正式发布后补测，不作为发布前阻断项。
- 企业数字身份证通过独立索引发布纳入 903 条画像补采，其中 902 条完整画像进入同行对比，1 条部分画像保留缺口；同名注销主体冲突继续阻断跨信用代码归并。

## 发布物

V1.6.3 同步发布三套包含同一组 49 项 Skills 的安装包：

- 通用 Skills ZIP；
- macOS WorkBuddy ZIP；
- Windows WorkBuddy ZIP。

公开附件不包含知识索引、企业数字身份证、个人 Token、设备凭据、本地 MCP 服务或客户资料。企业身份画像与主题词通过服务端签名索引单独发布，不是插件包构建输入。

## 验收边界

发布前执行源代码测试、门户测试、签名验证、解压安装自检、公开品牌扫描、模板保真回归及 Windows 原生 Hook 确定性回归。最终 ZIP 的 Windows 与 macOS 真实设备安装结果由主人在发布后补录。

Windows Authenticode 不作为本次发布前置条件，Ed25519 发布签名和 SHA-256 绑定不能冒充 Authenticode 系统级核验。

## 回滚

客户端安装失败时恢复上一正式 Skills 或 WorkBuddy 快照，不覆盖用户项目、个人偏好或其他 MCP 配置。门户、应用代码和签名索引分别保留 current 与 previous；任一层失败只回滚对应指针。
