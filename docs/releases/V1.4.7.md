# 企业全生命周期助手 V1.4.7

发布日期：2026年8月2日

V1.4.7 是一次安装识别、发布编排和网站界面的联合修复。49 项 Skills 与用户级远程 HTTP MCP 的简化安装边界保持不变，算法程序化执行继续作为后续独立项目。

## 完整版本事实

V1.4.7 修复 WorkBuddy 原生 Skill 注册与 Hook 闭环，优化发布编排，并完成门户黑金体系收口。

- 修复 WorkBuddy 包中行为 Hook 被写到 YAML frontmatter 之前的问题，49 个 SKILL.md 均以合法 frontmatter 开头，name 与目录一一对应且全套唯一。
- 发布端和门户下载端新增 Skill 原生注册静态门禁，错误前置内容、名称错配、重复名称或 Hook 位置异常都会在正式发布前阻断。
- 最小行为 Hook 的激活记录绑定 Skill、规则版本、轮次 ID 和时间；正式业务交付零 Skill 激活时返回 NO_ACTIVE_BUSINESS_SKILL，普通问答及 Hook 内部异常仍失败开放。
- Hook 会话只保存提示词摘要和契约信号，不再持久化完整用户提示词；算法程序化执行继续保留为后续独立项目。
- 知识发布固定为索引先发布并切换、应用后部署；复用 Acceptance Harness 收据，统一 manifest 路径，拒绝候选回落到可变 current 目录，并记录逐阶段耗时。
- 退役独立 Skills Manager、PWA 路由和专属发布流程，网站分发统一回到 Skills 中心与一次复制粘贴安装。
- 门户删除被黑金主题覆盖的第二套浅色组件 CSS，将仍在使用的规则迁入黑金语义层，并保留桌面与移动端回归门禁。
- 继续保持 49 项 Skills、用户级远程 HTTP MCP、自动填入个人 Token、只替换 jiaotang-kb、保留其他 MCP 和一次重载的简化安装边界。

## WorkBuddy 原生 Skill 注册

- 修复行为 Hook 被注入到 YAML frontmatter 之前的问题。包内 49 个 `SKILL.md` 现在都以 `---` 开头。
- 每个 frontmatter 的 `name` 必须与目录名完全一致，49 项名称必须唯一。
- 发布器、候选校验器和门户下载校验器都会阻断前置内容、名称错配、重复名称和 Hook 位置异常。
- Hook 激活记录绑定 Skill、规则版本、轮次 ID 和时间。
- 正式业务交付若没有激活任何 Skill，停止阶段返回 `NO_ACTIVE_BUSINESS_SKILL`；普通问答和 Hook 内部异常仍失败开放。
- Hook 会话只保存提示词 SHA-256 摘要与契约信号，不保存完整提示词。

## 发布编排与耗时

- 统一发布顺序为先发布并切换新索引，再部署新应用，避免新应用先读取旧索引表结构。
- Acceptance Harness 收据绑定的输入未变化时直接复用，不再重复执行相同 SQLite 完整性检查。
- `JIAOTANG_MANIFEST_PATH` 与兼容变量必须解析到同一路径；候选根目录不能回落到可变 `current` 目录。
- 发布脚本记录构建验收、OSS 对象上传、索引切换和应用部署的独立耗时，后续不再只显示任务总时长。
- 应用部署失败时，应用槽和本轮预先切换的索引都回滚到 `previous`，失败 release 保留供审计。

## 网站与分发

- 退役独立 Skills Manager、PWA 页面、专属测试和发布流程，统一从 Skills 中心分发通用包与 WorkBuddy 包。
- 删除被黑金主题完全覆盖的第二套浅色组件 CSS，仅保留基础重置、风险令牌与备案页脚。
- 仍在使用的表格空态、任务状态、上传框和检查清单已迁入黑金语义层。
- 桌面端、390px 移动端、无浅色白底、字号、Sticky 退化和 JavaScript 语法继续由发布门禁覆盖。

## 安装边界

- 用户仍只需从登录门户复制一段完整指令给 WorkBuddy。
- 指令安装或更新 49 项 Skills、启用最小行为 Hook、只替换 `mcpServers.jiaotang-kb`、保留其他 MCP、重载一次并调用 `knowledge_service_status`。
- 公共包不包含个人 Token、本地 MCP 服务、Node 启动器、bootstrap、设备绑定、钥匙串、DPAPI 或用户侧目录哈希校验。
- V1.4.6 的 Windows 与 macOS 双端实机验收结果作为兼容基线；V1.4.7 新包仍需按同一完成标准做发布后复验。

## 回滚

- 应用回滚到 V1.4.6 对应的上一不可变生产槽。
- 索引使用 OSS `previous` 世代和服务器本地 `previous` 指针回滚，不删除失败候选。
- WorkBuddy 升级失败时恢复安装前插件目录和用户 MCP 配置备份，不覆盖其他 MCP 与用户项目资料。
- Skills Manager 退役内容已保存在系统回收站的 `Skills-Manager-cleanup-20260802` 目录，可按需恢复审计。
