# 企业全生命周期助手 V1.3.2

发布日期：2026年7月27日

## 发布定位

V1.3.2是V1.3.1之后的Windows WorkBuddy安装器兼容性热修复版本。技能总数、业务能力、知识库连接器和凭据边界保持不变。

## 修复内容

- Windows PowerShell安装器统一使用带BOM的UTF-8编码，兼容Windows PowerShell 5.1中文系统。
- 显式传入CodeBuddy CLI路径或设置`CODEBUDDY_CLI`后立即采用该路径，不再被后续注册表扫描阻断。
- 在`Set-StrictMode -Version Latest`下安全读取卸载注册表的`DisplayName`、`InstallLocation`和`DisplayIcon`属性。
- 修复PowerShell变量后紧邻中文文字或全角标点时的变量边界解析问题。
- 增加Windows安装器变量边界、CLI优先级、注册表安全访问和UTF-8 BOM回归门禁。

## 安全边界

- 继续禁止`ExecutionPolicy Bypass`、`Invoke-Expression`和网页动态命令。
- Ed25519发布签名、逐文件SHA-256、ZIP安全解压、插件级MCP签名和敏感配置边界保持不变。
- 若组织策略禁止运行PowerShell脚本，仍须由管理员按组织安全策略放行；安装器不会绕过系统策略。

## 兼容性

- macOS沿用原固定安装器。
- Windows固定安装器面向Windows PowerShell 5.1及更高版本生成。
- WorkBuddy安装在非标准目录时，可通过`-CodeBuddyCli`或`CODEBUDDY_CLI`提供内置CLI路径。

## 版本一致性

- 产品标签、套件清单、插件清单、网站展示和GitHub Release统一使用V1.3.2。
- 语义版本统一为`1.3.2`。
- V1.3.1及其既有哈希保留为历史版本，不做同版本覆盖。
