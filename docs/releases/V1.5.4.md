# 企业全生命周期助手 V1.5.4

发布日期：2026年8月3日

V1.5.4 是当前对外发布的唯一最新版本。

V1.5.4 同时交付双平台 Hook、正式交付误阻断修复、管理员调用统计、备份与 OSS 保障、多项目路由、产品或行业反向发现、三首组合查询、中文权威名单参数与多项目算法入口。

## 本次发布

- 多项目自然语言解析不再只取最长或第一个命中。数字化车间与智能工厂、高企与专精特新与小巨人、绿色工厂与单项冠军等组合会保留全部明确项目，并按用户原始顺序处理。
- 地区解析不再把“查询”“帮我查”或“杭州市和宁波市”整体吞成一个地区；多地区进入覆盖台账，不静默只取第一个。
- 三首统一入口支持一次查询首台套、首版次和首批次中的多个项目，产品名真实进入权威产品专表，并按项目与地区分组返回分页、覆盖和截断状态。
- 权威名单工具继续明确英文枚举，同时兼容“小巨人”“专精特新中小企业”“三首”“首台套”“首版次”“首批次”等中文参数。
- 新增统一 `recognition_search`：自然语言一次解析全部项目、产品或行业、地区、年度和认定状态；按“确切、相关、待核验”三档返回，并附覆盖与分页台账。旧名单工具继续兼容。
- 新增网站助手与 WorkBuddy 共用的 `enterprise_lifecycle_decision` 入口；多项目通过 `project_context.projects` 逐项执行，返回 `requested/processed/skipped/is_truncated` 覆盖台账。
- `knowledge_case_pack` 已在正式源真实注册；本次只补契约测试，不重复实现旧工作树已过期的缺口。
- 正式源当前包含 30 个算法包且均标记为 `rules-confirmed`；服务端仍逐包返回 `coverage_status` 与 `formal_algorithm_decision_available`，防止把其他工作树的旧统计当作生产事实。
- WorkBuddy 继续使用 macOS 与 Windows 两个独立签名包，49 项 Skills 和共享 Python 行为核心保持逐字节一致。
- 明确否定生成报告或正式材料以及只解释、只回答时，普通答疑不运行正式交付模板门禁。
- 新增 `subject_taxonomy`、`recognition_records`、`enterprise_subject_evidence` 三张统一查询索引表，从现有权威名单与知识证据回填，不改变原始事实表。
- 本次索引变更单独执行一次分阶段全库构建与签名指针发布；随后的代码与 Skills 发布使用 `code` 模式，不重复扫描知识库。

## 查询边界

- 三首专表支持产品与行业字面反查；调用方应显式提供产品和行业同义词。
- 小巨人及省级专精特新先从当前知识证据发现候选，再回查权威名单。当前知识证据未覆盖的企业、地区、年度或同义词必须明示。
- `exact_results` 需同时具备明确主题证据与权威认定事实；`related_results` 只证明相关方向；`pending_results` 只能作为待核验线索。
- 未命中只能表述为“当前检索层未命中”，不得推导为“不存在”或“没有企业获批”。

## 用户是否需要更新

- Windows 用户必须更新，以取得原生 CMD Hook、轮次状态和本次统一查询能力。
- macOS 用户建议同步更新，以保持共享行为核心、Skill 契约和服务端工具一致。
- 已安装旧版本的用户不需要手工删除插件；一键安装会清理活动搜索路径中的旧版并保留其他 MCP 配置。

## 验收标准

- 通用、macOS WorkBuddy 与 Windows WorkBuddy 三个包各含 49 项可识别 Skills，版本均为 1.5.4。
- 两个平台包的共享 Python 行为核心 SHA-256 相同；Windows 包使用原生 CMD 启动器。
- 高频项目规则两两组合自动测试不少于 300 组，两个明确项目均被保留。
- “浙江省和江苏省智能水表相关首台套和首版次”同时返回两个项目、两个地区的分组覆盖台账，不只返回第一个。
- `authoritative_list_search(list_type="首台套")` 自动归一化为三首权威专表。
- 产品或行业反向发现结果严格区分已核验认定事实与待核验候选，并明确非全国穷尽。
- 多项目算法决策逐项目返回，覆盖台账 `processed` 与有效请求数一致，无静默截断。
- `不要生成报告，只解释申报条件`正常回答；普通政策答疑不运行正式交付模板门禁。
- 自动化发布门禁与 Windows CI 通过后即可正式发布；macOS、Windows WorkBuddy 实机验收由主人在发布后补录，不阻断正式发布。

## 回滚

- Skills 安装失败时恢复搜索路径外的安装前插件快照和原 MCP 配置。
- 代码部署失败时把生产 `current` 指针切回上一应用槽；索引发布失败时单独恢复上一签名索引指针，并恢复备份与轻量校验定时器。
- V1.5.4 产物按版本和哈希不可变；同名版本已存在不同内容时停止，不覆盖。
