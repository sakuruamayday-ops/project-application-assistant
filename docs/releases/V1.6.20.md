# V1.6.20

本版用于共创企业助手升级整合。

- 简化当前任务的执行提示，明确查询与专业交付的边界。
- 统一认定来源路由、政策申报路径和已确认的项目判断规则。
- DOCX 输出 XML 部件、段落和字符位置，支持可核对的引用定位。旧 PPT 与专有 WPS 保留现有解析，无法读取时提供另存格式提示。
- 保留此前财税报告计算、来源、全部技能模板及签名验证能力。

源码验证：444 项通过、3 项跳过、18 项子测试通过；DOCX 五个定位场景在打包 Python 实跑通过。已完成签名候选验签、隔离安装和客户端真实 DeepSeek 文档读取及旧会话续聊验证。

实现与证据见 [整合记录](../product/2026-09-21-client-skill-integration.md)。

macOS 与 Windows 客户端消费同一签名技能身份，各自安装包独立验收。通用包不携带用户凭据、客户资料或本地知识索引，企业数字身份证不进入插件包或技能包。

V1.6.20 客户端整合候选：简化实际任务执行，补齐文档读取定位与项目判断规则。

明确按当前任务执行检索、判断和交付，保留专业证据核验、签名与权限边界。

统一认定来源路由与政策申报路径，保留已确认的项目版本、材料事实及产品技术判断方法。

DOCX 读取结果增加可复核的 XML 部件与段落位置，覆盖表格、页眉、文本框和截断场景；旧 PPT 与专有 WPS 无法读取时提示另存支持格式。

保留 V1.6.19 财税报告完整计算与来源输出，以及原有技能、模板和正式发布保护。
