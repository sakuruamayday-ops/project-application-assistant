# V1.7.2 计算与报告内容可靠性修复

macOS 与 Windows 客户端消费同一签名技能包。通用技能包不包含知识索引、企业数字身份证、用户凭据或客户资料。客户端与技能包独立版本化；发布状态以正式渠道回执为准。

- 财务同比只比较连续年度。缺少上一年度时明确缺口，不把跨年增长当作同比。
- 高企增长率按十进制输入精确比较门槛，避免临界值被浮点误差降档。
- 专精报告移除具体评分时保留技术事实、普通技术比值，以及PCT、质量管理、认证和数字化的定性补强价值。
- 主导产品或同行内容缺失时明确未完成项，不把空栏目包装为完整定稿。
- 局部产品与PS命名不预设有效专利数量、不编造专利映射；明确遵循指定输出字段和单一缺项清单。
- 高企申请书增加分节回填与写作模板，保留RD、PS结构；单点修改不重写无关字段。预评估按总收入分母计算，缺少输入时不以营业收入替代。
- 长篇Word生成支持从本地内容文件读取，减少长参数导致的生成失败；细化独立来源说明与正文边界。
- 修复Word相邻表格和宽表分页、字体与页眉品牌处理，财务报告统一展示金额口径。
- 政策、人员、知识产权、投资、目录与资格说明区分已知事实、缺口和候选状态；报告不再强制夹带内部审查过程段落。
- 修复索引更新和中文状态筛选，避免旧关系或失效条目继续进入结果。
- 杭州研发机构技能与服务端已确认的2026年度通知保持一致，修正软件企业设备门槛、普通院误套重点院评分及旧草案路由；保留转载来源的核验边界。
- 补齐专精科技奖励豁免的近三年范围，修正办法施行日期及省研发机构原则性前置条件；规则卡重建直接读取现行技能政策说明。
- 保留既有模板、品牌、证据来源、权限、签名完整性及回滚机制。
