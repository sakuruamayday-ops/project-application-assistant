# 共创研究院企业全生命周期助手 V1.6.16 发布说明

V1.6.16 完善绿色工厂自评价报告的版本识别、硬门槛、评分证据矩阵和指标一致性校验。

## 本次变化

- 绿色工厂任务先建立项目层级、年度、导则、通知和模板版本卡；国家、省、市、区及零碳类项目不得混用规则。
- 基本要求和必选项未通过、待核或证据冲突时阻断推荐；评分同时区分确认分和条件分。
- 逐项评分绑定正文位置、原始分、权重、确认分、证据与附件编号，并校验单位、分母、统计期和跨表口径。
- 新增绿色工厂台账确定性校验器和脱敏回归，拦截无证据得分、非法档位、计算错误、单位漂移和违规推荐。
- V1.6.16 继承 V1.6.15 的有限专业修正、企业数据源降级和全量模板发布门禁。

## 自评价报告与评分边界

绿色工厂自评价报告按当期项目层级和有效政策建立版本卡。历史导则只用于预研，不直接生成资格或推荐结论。基本要求和必选项先于总分判断；确认分只接收已核验证据或可复算指标，尚待取得、已经过期或存在冲突的材料进入条件分或待核。

评分证据矩阵保持指标、正文、计算、证据和附件双向可追溯。企业自述、行业对标和绩效数据仍须按事实、计算、推断和待核验边界分别处理；未取得可比行业基准时保留企业指标值，但不把前百分之二十或前百分之五写成确认得分。

## 数据与隐私

本次规则来自两份用户授权样本的脱敏缺陷归纳。公共技能、测试和发布包不包含样本企业名称、联系方式、经营数据、附件内容或原始报告。企业数字身份证不进入插件包，平台包不携带用户凭据或本地 MCP。

## 兼容与打包

- V1.6.16 Windows 平台包继续只包含 Skills、最小行为 Hook 和远程知识服务配置。
- V1.6.16 macOS 平台包继续只包含 Skills、最小行为 Hook 和远程知识服务配置。
- 通用 Skills、macOS 平台包和 Windows 平台包使用同一套件清单、同一发布者身份和独立产物哈希。

## 验证范围

发布事务运行完整技能测试、政策时效检查、知识门户测试、逐技能清单刷新、三套件解压安装自检、敏感信息扫描和 Ed25519 签名验证。绿色工厂专项回归覆盖基本要求阻断、正向得分证据、离散档位、单位一致性、比例复算和推荐边界；任一步失败均不形成正式版本。
