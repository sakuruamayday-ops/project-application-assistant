# V1.7.9 文档操作去耦与A版分页修复

本版基于 V1.7.8 通用技能源。共创客户端的执行与分页改进需升级至0.7.8及以上版本；仅更新技能包不会替换旧客户端程序。固定操作保留原操作名、脚本、结构化参数、签名、权限和路径边界；调用不再取决于模型是否先加载所属业务技能。Word 转换复用本次真实正文或已确认的同源 HTML，不要求专业预校验、画像准入或 formal 回执。

V1.7.9 由 Windows 和 macOS 客户端消费同一套验签技能投影，客户端自身构建、安装及升级分别验收。技能包不包含知识索引、企业数字身份证或用户凭据。

`client-runtime-operations.json`、共享任务边界和客户端技能投影同步说明上述行为。来源、计算、待核事项、专用模板优先级、品牌和真实文件检查继续生效，文件生成不代表业务结论已经审定。

A 标准销售版沿用既有橙色封面、字体、图标、表格和免水印母版，针对容器续排、提示框及表尾孤页进行实际 Chromium/PDF 验证。既有归集文件保持原样，本次改进用于新版生成流程。

通用技能、网站更新源与客户端内置投影使用同一批内容，正式分发版本以团队门户及GitHub正式发布记录为准。
