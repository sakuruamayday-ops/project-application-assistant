# 企业全生命周期助手 V1.2

## WorkBuddy 安装与安全

- WorkBuddy套件增加macOS与Windows一键安装器，自动发现宿主内置CLI、安全解压并验证市场清单。
- 安装前完整展示来源、SHA-256、CLI、插件版本、目标路径、固定命令、联网与凭据边界、MCP影响和撤销命令；仅在用户输入`INSTALL`后执行。
- 安装链路使用真实`marketplace add → install → enable`，随后触发轻量技能验证插件能够实际工作，不再把“已启用”等同于安装成功。
- MCP连接器纳入签名WorkBuddy插件，通过原生`userConfig`接收敏感引导地址，不再执行网页返回的动态命令，也不写入宿主级MCP配置。
- 安装器拒绝路径穿越、绝对路径、符号链接、重复条目和哈希不一致；Windows启动器不绕过组织PowerShell执行策略。

## 发布与兼容性

- 通用技能套件与WorkBuddy插件套件统一使用V1.2和语义化版本`1.2.0`。
- macOS WorkBuddy 5.3.3真实隔离安装、启用和技能触发回归已纳入发布门禁。
- Windows安装器的生成、静态安全对抗和完整性测试已纳入门禁；未取得Windows真实宿主证据前继续标记为结构兼容。
- 增加macOS与Windows双宿主自动发布矩阵；任一真实宿主缺失、签名身份不可用或技能触发失败时阻断对应正式发布结论。

## 知识与检索

- WorkBuddy插件只内置一个签名`jiaotang-kb`连接器，安装与升级不得重复创建知识库MCP。
- 增加首批次新材料、首台套和首版次目录及公示数据的结构化检索、身份映射与金标准回归。

## 版本纪律

- 未收到明确发布指令时，只维护源码和修改记录，不生成签名、哈希发布件或递增发布版本。
- 正式发布前必须先确认套件清单、发布包、网站展示和下载文件使用同一版本号。
