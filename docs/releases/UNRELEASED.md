## 待发布修改

### 2026-07-30 · 政策降级检索与交付契约门禁

- 增加“发文机关原文 → 下级政府官网明确引用 → 当前有效管理办法”的政策检索降级链；管理办法仅可恢复稳定门槛和准备方向，不得生成当年度截止时间、批次或材料要求。
- 纳入浙江省经信厅 2026 年高新技术企业认定正式通知，并区分省级主管部门推荐截止时间与企业属地提交截止时间。
- 将旧版 29 个项目中的 108 个未分类 `_met` 汇总叶子逐项迁移为原生 `all/any`，或显式登记为证书、单一断言、评价结论型原子证据；源码与生成包任一侧出现未分类汇总叶子均阻止正式判断。
- 增加 WorkBuddy 交付契约：Skill 模板必填段、政策选择、同行对比和四问复盘缺失时，`Stop` 钩子持续阻止结束，直到补齐。
- 将 WorkBuddy 交付契约扩展为可机读交付 profile，覆盖全景 A 标准销售版、B 深度顾问版与 C 两版、制造企业金税财务报告、专精特新前期评分工作簿和后期申请书体检报告；逐项登记必填章节、来源、证据台账、内置表格、产物格式与哈希、指定验证器和品牌/免水印审计。
- 交付契约失败时生成精确到章节、表格、产物角色和品牌审计的补写或重跑任务，并要求验证记录绑定同一产物 SHA-256，不能用完成说明替代产物验收。
- 纳入会话连续性前置检查：只在决定冲突、遗漏既有限制、切换话题仍有未决事项等信号出现时提醒或生成四字段检查点；高影响冲突阻止形成依赖性结论，持久化重要决定前仍需确认。
- 增加“当年申报前准备”政策时间模式：当年度申报尚未开放，且征求意见稿已核验并明确替代旧政策时，以草案作为准备与差距评估主基线；草案状态不得改写为正式生效，亦不得沿用旧年度截止日。
- 将杭州、宁波、绍兴、金华研发平台统一展示为“市级研发中心（四市属地版）”，保留原项目 ID 与旧名称别名，兼容既有检索、API 和历史记录。
- 区级绿色工厂增加属地来源硬门禁：省级规则仅作为上位依赖，正式判断必须命中企业所在城市或区县的官方规则；未命中时返回属地规则未解析，不得用省级门槛代替区级结论。
- 算法页改为展示 28 类常规项目的正式阈值规则包，并移除公开的四市政策路由明细表。
- 上述修改会改变签名插件中的 `delivery-contracts.json` 和共享执行口径，必须由后续新版本重新构建、验收和签名；不得覆盖或原地重签 V1.3.1.6。
- 当前仅进入未发布源码与测试层；按照本文件发布约定，尚未修改正式套件版本、生成产品套件或宣称 WorkBuddy 用户端已升级。
