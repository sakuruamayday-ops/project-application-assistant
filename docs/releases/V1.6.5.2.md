# 共创研究院企业全生命周期助手 V1.6.5.2 候选功能简介

V1.6.5.2 是 V1.6.5.1 的候选补丁版，不改变企业分析报告 A、B、C 版，也不改变尖兵领雁、市级重大及科技计划类的既有资格、技术、团队、预算、里程碑和验收分析逻辑。

本补丁不新增第二套报告骨架，只将原有十二类受控模板的候选验收串成一条闭环。

## 候选流水线

1. 技能树外的私有夹具恰好映射十二类真实客户资料，每份原件绑定 SHA-256 和可命中的原文锚点。
2. 源码模板逐类生成前期评估与可行性分析共二十四份完整 Word 成稿和 PDF，对每页渲染并运行报告画像门禁。
3. 只生成 macOS WorkBuddy 和 Windows WorkBuddy 两个未签名候选 ZIP，不接触正式签名私钥。
4. 对两个最终 ZIP 执行安全解压，运行包内选模器，再完成十二类两类报告共四十八次成稿回归。
5. 自动逐页渲染后，前期评估抽首页，可行性分析抽中间条件页，形成十二类二十四格联系表进行视觉抽检。自动回执保持待复核，只有联系表哈希和二十四项缺字、裁切、重叠、表格、层级与水印检查通过后才生成视觉收口回执。

## 隔离与证据边界

- 客户原件、客户名称、本机绝对路径、客户成稿和私有夹具都不进入公共技能树或候选 ZIP。
- 企业数字身份证不进入插件包，本次也不把企业身份数据放入 ZIP。
- 原文锚点未命中、模板哈希漂移、成稿仍存占位符、结构或水印门禁失败、ZIP 路径不安全或候选包命中客户信息时立即阻断。
- 源码测试、模型检查和 ZIP 回归不代替 WorkBuddy 真实宿主回执。未进行真实安装、触发和交付时，macOS 与 Windows 分别保持 `pending-real-host-receipt`。
- ZCode 明确不在本候选流水线范围内：不生成候选包，不写入发布清单，不给出测试通过状态。

V1.6.5.2 当前仅是待完成候选流水线、差异审阅和主人审批的源码候选。不提升为 GitHub Latest，不发布到门户，不切换知识索引，不覆盖本机正式安装。
