# 共创研究院企业全生命周期助手 V1.6.5.2 功能简介

V1.6.5.2 是 V1.6.5.1 的正式补丁版，不改变企业分析报告 A、B、C 版，也不改变尖兵领雁、市级重大及科技计划类的既有资格、技术、团队、预算、里程碑和验收分析逻辑。

本补丁不新增第二套报告骨架，只将原有十二类受控模板的候选验收串成一条闭环。

V1.6.5.2 在 V1.6.5.1 受控模板基础上新增私有真实客户资料锚点成稿器，并将十二类双报告完整成稿、逐页渲染、macOS与Windows WorkBuddy未签名候选发包、最终ZIP选模回归及视觉抽检固化为一条候选流水线。

## 正式版本事实

- 新增项目前期评估报告与项目申报可行性分析报告两类正式交付，前者服务谈单，后者逐项拆解现行条件、评分表、证据和补强任务。
- 高企、专精特新、小巨人、三首、研发中心、制造精品、单项冠军、绿色工厂、数字化及科技计划自动切换项目专属核心评估对象。
- 所有项目报告建议形成国内产品技术水平评价咨询报告和国际产品技术水平评价咨询报告；证据形成前不得承诺国内领先或国际先进。
- 专精线新增数字化转型诊断报告补强，核验五个一级维度、全国与同行对标、优势短板及提升路径。
- 高企新增研发费用加计扣除规范化服务，贯通立项、人员设备、工时领料、小试中试、结题、专利关联、月度分配、辅助账与明细账。
- 两类报告统一使用共创红色水印并输出可编辑 Word 与 PDF；无法只加密水印且保持正文可编辑时不设置编辑限制。
- 企业分析报告 A、B、C 版以及尖兵领雁、市级重大和科技计划类既有分析逻辑保持不变。
- 内置高企、专精特新、小巨人、三首、研发中心、制造精品、单项冠军、绿色工厂、数字化和科技计划二十四份 Word 母版，命中时先选版再回填。
- 模板索引对项目别名执行最长命中，对未知、冲突、哈希变更或覆盖现有文件一律拒绝。
- macOS 与 Windows Stop Hook 一致识别完成交付语义和对象定向否定，并强制当前轮次的章节、表格、Word、PDF、哈希及红色水印验证回执。
- 新增真实客户原文锚点成稿器：客户原件必须位于公共技能树之外，原文锚点未命中或成稿仍有占位符时拒绝交付。
- 新增十二类候选流水线：产出二十四份Word/PDF完整成稿、逐页渲染，构建macOS和Windows WorkBuddy两个未签名RC ZIP，再从最终ZIP执行四十八次选模成稿回归。
- ZCode不在本候选流水线内，不生成候选包、不写入发布清单、不给出测试通过状态。

## 候选流水线

1. 技能树外的私有夹具恰好映射十二类真实客户资料，每份原件绑定 SHA-256 和可命中的原文锚点。
2. 源码模板逐类生成前期评估与可行性分析共二十四份完整 Word 成稿和 PDF，对每页渲染并运行报告画像门禁。
3. 只生成 macOS WorkBuddy 和 Windows WorkBuddy 两个未签名候选 ZIP，不接触正式签名私钥。
4. 对两个最终 ZIP 执行安全解压，运行包内选模器，再完成十二类两类报告共四十八次成稿回归。
5. 自动逐页渲染后，前期评估抽首页，可行性分析抽中间条件页，形成十二类二十四格联系表进行视觉抽检。自动回执保持待复核，只有联系表哈希和二十四项缺字、裁切、重叠、表格、层级与水印检查通过后才生成视觉收口回执。

## 隔离与证据边界

- 客户原件、客户名称、本机绝对路径、客户成稿和私有夹具都不进入公共技能树或候选 ZIP。
- 企业数字身份证不进入插件包，本次也不把企业身份数据放入 ZIP。
- 原文锚点未命中、模板哈希漂移、成稿仍存占位符、结构或水印门禁失败、ZIP 路径不安全或候选包命中客户信息时立即阻断。
- 源码测试、模型检查和 ZIP 回归不代替 WorkBuddy 真实宿主回执。未进行真实安装、触发和交付时，macOS 与 Windows 分别保持 `pending-real-host-receipt`。
- ZCode 明确不在本候选流水线范围内：不生成候选包，不写入发布清单，不给出测试通过状态。

V1.6.5.2 经主人确认后进入受控正式发布。本版本只发布通用技能包、macOS WorkBuddy 与 Windows WorkBuddy 包；ZCode 不生成、不测试、不发布。技能包发布不切换知识索引。
