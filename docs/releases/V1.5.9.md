# V1.5.9 Windows 行为 Hook 热修

V1.5.9 是面向 Windows WorkBuddy 的平台热修版本。macOS 继续使用已正式验证的 V1.5.8 包；通用 Skills 包和知识索引不变。

本版本修复 Windows 原生 Hook 对中文列举项和逗号的否定作用域误判：`禁止调用 MCP、读取文件、生成测试报告` 会保持为一个否定请求，不再因为拆分列举项而误触发正式交付门禁。意图只在句号、分号、问叹号、换行或明确转折处重置；否定、未来计划、概念解释和插件技术验收仍不会启动正式交付门禁，明确的当前生成请求继续按原规则检查。

发布范围：

- Windows WorkBuddy 原生 EXE Hook，规则版本 `4-scoped-delivery-intent`；
- 49 项 Skills、远程 `jiaotang-kb` MCP 和最小行为 Hook 保持 V1.5.8 契约；
- 门户同时提供 macOS V1.5.8 与 Windows V1.5.9，按操作系统分别下载；
- 本版本不修改知识内容、主题词典或索引结构，仅走 code 发布模式。

验收范围：固定 Go 工具链双次构建哈希一致；Windows 包 49 项 Skills、插件清单、远程 MCP 配置和行为 Hook 静态门禁通过；目标语义回归测试全部通过。Windows 实机 D 组复测可在发布后补充，不影响本次已授权的正式发布。
