# 企业全生命周期助手 V1.3

发布日期：2026年7月27日

## 专利体系

- 专利工作统一为两个顶层入口：焦糖专利总路由和中国专利申请文件核稿。
- P1查新与创造性分析、P2挖掘与交底、P3预审与中心推荐作为总路由内部阶段运行，不重复触发。
- 增加权利要求引用关系图、独立权利要求技术特征树、区别技术特征与现有技术对照表。
- IPC判断、查新、创造性分析和双中心预审推荐形成可追溯证据链。
- 浙江省与杭州市知识产权保护中心采用候选池机制，逐案输出唯一主目标中心建议。

## 申请文件核稿

- 重建Word申请文件解析、核稿、批注定位和完整性验证链路。
- 支持摘要、权利要求书、说明书、表格、文本框、脚注、尾注、OMML公式、嵌入对象、附图及关系文件检测。
- 批注优先锚定到跨文本运行的精确字符范围，无法精确定位时才降级到段落锚点。
- 已使用真实中国发明专利申请书完成端到端回归，验证文本、表格、附图与包内资产在批注前后保持完整。

## MCP与发布治理

- 加固知识库MCP访问边界、发布校验和门户回归。
- 正式套件收敛为48个Skills，套件清单、依赖关系、下载包和门户展示采用同一机器可读基线。
- 通用包与WorkBuddy包统一使用V1.3和语义版本`1.3.0`，继续执行SHA-256、Ed25519签名、临时解压与安装自检。

## 已知边界

- 复杂OLE公式、脚注、尾注和文本框组合仍需专项样例持续扩充回归。
- 超长权利要求中的嵌套并列、择一引用和马库什结构会自动拆分，但复杂案件仍需人工复核特征边界。
- 语义等同但用词完全不同的技术特征，必须结合原文、附图和本领域技术含义判断。
