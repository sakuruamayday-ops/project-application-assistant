# 企业全生命周期助手 V1.5.0

发布日期：2026年8月2日

V1.5.0 是首个面向外部用户的正式版本。此前发布产物继续作为内部演进、审计和回滚历史保留，不覆盖、不改写。

## 本次发布

- 一键安装同时检查 `.workbuddy` 与 `.codebuddy`。焦糖旧版、旧名称和重复副本先移出活动插件搜索路径，在 `plugins` 之外保留一个可恢复快照；验收后其余旧副本进入系统回收站。
- 活动搜索路径最终只允许一个 `plugins/marketplaces/jiaotang`，Hook 根目录发现只接受该固定市场，不会误选备份目录。
- 保持 49 项 Skills、最小行为 Hook、用户级远程 HTTP MCP、个人 Token 自动填入、只替换 `mcpServers.jiaotang-kb`、保留其他 MCP 和一次重载。
- 专精特新前期评估只保留 2026 政策分支。新申报仅做硬门槛、质量评价输入和平台质量分核验；平台分缺失时保持待平台评价，不再生成历史四维评分、内部百分制、三档总分或通过概率。
- 2026 年小巨人复核仍遵守 2026 当期通知明确的过渡例外，但不恢复历史评分引擎，也不扩展到新申报或未来年度。
- `public_list_search` 兼容未包含 `subject_type` 列的历史名单表。
- 政府项目计算验证器从字段完整性升级为公式语义复算，能拒绝 `1+1=999999` 一类伪计算。
- 高企成长性固定使用三年公式；2026 年认定后的正常到期重新认定节点为 2029 年。
- 国产替代、补短板和填空白判断中，外部型号、客户证明和第三方检测是增强证据，不是企业自述成立的强制前提。

## 发布类型

本次是代码与 Skills 包发布，不改变知识索引内容，因此不运行全库索引扫描。网站应用、通用 Skills 包和跨平台 WorkBuddy 包使用同一 V1.5.0 版本事实。

## 验收标准

- 通用包与 WorkBuddy 包各含 49 项可识别 Skills，版本均为 1.5.0。
- WorkBuddy 包不含已停用的专精特新评分脚本、工作簿和统计局折算资产。
- 一键安装指令明确处理旧版、重复副本、回滚快照、系统回收站和失败恢复。
- `tools/list` 枚举 `knowledge_search`、`knowledge_document`、`knowledge_service_status`，状态调用返回 `connected: true`。
- 其他 MCP 条目不被覆盖，Token 不进入公共包、公共代码或最终回复。
- 历史发布文件和 GitHub Release 不被覆盖。

## 回滚

- 代码部署失败时把生产 `current` 指针切回部署前 V1.4.9 应用槽，不改变知识索引指针。
- Skills 安装失败时移走失败的新目录，将 `plugin-backups` 中的回滚快照恢复到原活动位置，并恢复原 MCP 配置。
- 发布包按版本和哈希不可变；V1.5.0 已存在不同内容时停止，不覆盖。
