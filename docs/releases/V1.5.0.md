# 企业全生命周期助手 V1.5.0

发布日期：2026年8月2日

V1.5.0 是首个面向外部用户的正式版本。此前发布产物继续作为内部演进、审计和回滚历史保留，不覆盖、不改写。

V1.5.0 是首个对外正式版本：安装时清理活动路径旧版，只保留2026年专精特新预评估，并修复名单兼容、公式语义校验与Hook目录误选。

## 本次发布

- 一键安装同时检查 `.workbuddy` 与 `.codebuddy`。焦糖旧版、旧名称和重复副本先移出活动插件搜索路径，在 `plugins` 之外保留一个可恢复快照；验收后其余旧副本进入系统回收站。
- 活动搜索路径最终只允许一个 `plugins/marketplaces/jiaotang`，Hook 根目录发现只接受该固定市场，不会误选备份目录。
- 保持 49 项 Skills、最小行为 Hook、用户级远程 HTTP MCP、个人 Token 自动填入、只替换 `mcpServers.jiaotang-kb`、保留其他 MCP 和一次重载。
- 专精特新前期评估只保留 2026 政策分支。新申报仅做硬门槛、质量评价输入和平台质量分核验；平台分缺失时保持待平台评价，不再生成历史四维评分、内部百分制、三档总分或通过概率。
- 2026 年小巨人复核仍遵守 2026 当期通知明确的过渡例外，但不恢复历史评分引擎，也不扩展到新申报或未来年度。
- `public_list_search` 兼容未包含 `subject_type` 列的历史名单表。
- 政府项目计算验证器从字段完整性升级为公式语义复算，能拒绝 `1+1=999999` 一类伪计算。
- 高企成长性固定使用三年公式；2026 年认定后的正常到期重新认定节点为 2029 年。
- 国产替代、补短板和填空白判断中，外部型号、客户证明和第三方检测是增强证据，不是企业自述成立的强制前提。

## 机器清单对应的完整版本事实

- V1.5.0 作为首个对外正式版本独立发布，V1.4.9及更早产物保持不可变历史。
- 一键安装同时检查 .workbuddy 与 .codebuddy，把旧版、旧名称和重复副本移出活动搜索路径，在搜索路径外保留一个回滚快照，验收后其余副本移入系统回收站。
- Skill 与 Hook 根目录发现只接受固定 jiaotang 市场，不再使用会命中备份市场的通配搜索。
- 专精特新前期评估只保留2026政策：核验硬门槛和平台质量分，删除历史四维评分、内部22项百分制、统计局折算与三档总分引擎。
- public_list_search 兼容缺少 subject_type 列的历史名单表，不再因旧结构直接失败。
- 项目计算验证器新增公式语义复算，拒绝字段齐全但结果伪造的计算；高企三年成长性口径和2026至2029重新认定时间线固化为回归。
- 国产替代、补短板和填空白的外部型号、客户证明与第三方检测只作为增强证据，不再被设为企业自述成立前提。
- 插件级 UserPromptSubmit 与 Stop Hook 使用同一套跨平台根目录发现逻辑，不再单独依赖宿主环境变量。
- Skill 激活成功回执新增 root_source、state_persisted、active_skills_after 和 active_skill_count，可直接证明激活状态已经持久化，无需依赖宿主未公开的 active_skills 查询接口。
- 49 项生成后 Skill 已在默认 WorkBuddy 市场布局中逐项执行激活回归，最终同一会话状态精确记录 49 项。
- 继续保持 49 项 Skill 首字节 YAML frontmatter、真实名称原生加载、正式业务零 Skill 激活阻断和提示词只存摘要的既有边界。
- 继续保持 49 项 Skills、用户级远程 HTTP MCP、自动填入个人 Token、只替换 jiaotang-kb、保留其他 MCP 和一次重载的简化安装边界。
- 管理员单页导航恢复为项目算法包、API 与用户、Skills、健康看板的稳定页面顺序，并修复移动端导航滚动定位偏移。
- 门户 MCP 状态改为依据当前用户的实际 MCP 调用和安装验收记录，不再依赖已经停用的设备绑定状态。
- 安装成功后新增插件包评价与常用指令入口，覆盖专精特新前期评估和后期体检、高新申请书、标准撰写、企业分析三种交付与金税四期分析报告。
- 网站助手默认采用动态 12 轮、复杂任务最多 16 轮，并同时执行总时长、工具调用次数和连续无进展停止条件，不使用无限循环。

## 发布类型

本次是代码与 Skills 包发布，不改变知识索引内容，因此不运行全库索引扫描。网站应用、通用 Skills 包和跨平台 WorkBuddy 包使用同一 V1.5.0 版本事实。

## 验收标准

- 通用包与 WorkBuddy 包各含 49 项可识别 Skills，版本均为 1.5.0。
- WorkBuddy 包不含已停用的专精特新评分脚本、工作簿和统计局折算资产。
- 一键安装指令明确处理旧版、重复副本、回滚快照、系统回收站和失败恢复。
- `tools/list` 枚举 `knowledge_search`、`knowledge_document`、`knowledge_service_status`，状态调用返回 `connected: true`。
- 其他 MCP 条目不被覆盖，Token 不进入公共包、公共代码或最终回复。
- 历史发布文件和 GitHub Release 不被覆盖。

## 回滚

- 代码部署失败时把生产 `current` 指针切回部署前 V1.4.9 应用槽，不改变知识索引指针。
- Skills 安装失败时移走失败的新目录，将 `plugin-backups` 中的回滚快照恢复到原活动位置，并恢复原 MCP 配置。
- 发布包按版本和哈希不可变；V1.5.0 已存在不同内容时停止，不覆盖。
