# 企业全生命周期助手 2.2.0

发布日期：2026-07-19

## 本次更新

- 发布通用用户使用手册，网站登录、注册和工作台均可直接打开。
- 团队知识检索固定使用云端 API 与 MCP，不再依赖团队本地知识库镜像。
- 正式团队包包含53个Skills。
- 加入 `manufacturing-tax-risk-analysis` 与 `jiaotang-legal-regulations`。
- 加强首次配置、自进化、四问复盘和宿主通用能力提示的安装验收。
- 发布门禁排除 `agents` 元数据、macOS `._` 文件、Python缓存、本机绝对路径和旧依赖名。

## 升级方法

1. 登录团队网站，进入 Skills 下载。
2. 下载并解压最新版 ZIP。
3. 使用新的 `skills` 文件夹替换旧版标准 Skills，保留个人项目资料和本地政策规则。
4. 在 Agent 中输入“请检查企业全生命周期助手是否安装完整，并启动首次配置向导”。

## 配置要求

- 团队知识库：网站生成的 API、MCP 地址和个人调用凭据。
- 企业数据：企查查为可选增强。
- 专利数据：BigQuery Patents 或其他合法专利数据源为批量检索增强。
- OCR、PDF、Word、Excel、PPT和联网检索：由宿主 Agent 提供。
