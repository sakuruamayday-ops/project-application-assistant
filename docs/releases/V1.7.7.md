# V1.7.7 交付格式与官网发布修复

制造企业财税报告按用户请求交付PDF或Word。默认仍为PDF报告、HTML正文、指标JSON和企业财务事实JSON；明确只要Word时，以同正文Word替代PDF，保留其余底稿。明确需要两种报告时才要求两种格式。金色品牌审计跟随实际交付格式，来源、计算及文件真实性要求不变。

门户按画像中已声明的advisory规则呈现四问提示，缺项不会单独阻断交付，其他实际缺项仍如实报告。

官网发布继续使用GitHub、门户、真实隔离安装及客户端技能更新的签名事务。默认不调用本机技能及知识索引同步，不同步OSS；已有本机同步程序保留，只在显式指定`--local-release-sync-script`时加入该签名事务并执行。通用ZIP与客户端独立更新ZIP保持各自格式。

V1.7.7由Windows和macOS客户端消费同一验签技能投影，客户端自身版本单独管理。技能包不包含知识索引、企业数字身份证或用户凭据。配套客户端安装、原生升级与正式公网下载以本次实际回执为准，不沿用上一次Windows未验证升级的例外。
