# 企业全生命周期助手 V1.5.5

发布日期：2026年8月3日

V1.5.5 是当前对外发布的唯一最新版本。本版本修复 Windows WorkBuddy Hook 的实际执行器兼容问题，补全正式版本历史展示，并把三首产品名称与小巨人来源行业分类编入可持续扩充的中文主题词典。

## 本次发布

- Windows WorkBuddy 的 HookExecutor 实际由 PortableGit Bash 执行。`hooks.json` 现只调用最小 Bash 桥接脚本，由桥接脚本完成路径转换并进入原生 CMD 适配器，不再把 CMD 条件表达式直接交给 Bash 解析。
- Windows 桥接器优先使用宿主传入的插件根，兼容 `.workbuddy` 与 `.codebuddy` 活动路径；找不到变量时回退到脚本所在插件目录。共享 Python 行为核心、正式交付判断和 macOS 启动器不变。
- 管理员和普通成员均可在门户查看全部正式历史版本、发布时间及发布说明。历史记录只读，不提供旧版安装按钮；通用包和两个 WorkBuddy 安装入口始终指向最新版。
- `subject_taxonomy` 从包内两组静态词典升级为“静态基线加索引动态词典”：已核验三首产品名称自动提取中文产品主题，小巨人企业按来源 `industryName` 生成受控行业主题。
- 产品主题保留原始产品名、被移除的容量、版本和用途等属性及对应认定证据；行业主题明确标记为来源行业分类，不写成官方主营业务。
- “其他未列明”、研究试验、技术推广等宽泛行业分类不会提升为精确主题。统一检索仍严格区分确切、相关和待核验结果。
- 本版本包含索引结构与内容变化，因此执行一次分阶段全库扫描和索引发布；后续纯代码变更继续使用 `code` 模式，不重复全库扫描。

## 用户是否需要更新

- Windows 用户必须更新，旧版内联 CMD Hook 在 WorkBuddy 的 PortableGit Bash 执行环境中可能无法输出合法 Hook JSON。
- macOS 用户建议同步更新，以保持版本、Skills 契约和服务端查询能力一致。
- 已安装旧版本的用户不需要手工删除插件；一键安装会清理活动搜索路径中的旧版并保留其他 MCP 配置。

## 验收标准

- 通用、macOS WorkBuddy 与 Windows WorkBuddy 三个签名包均包含 49 项 Skills，版本统一为 1.5.5。
- Windows `hooks.json` 不含内联 `cmd.exe /d /s /c` 条件表达式，只调用包内 Bash 桥接脚本；桥接器再进入原生 CMD 适配器。
- 发布候选的 macOS 与 Windows 共享 Python 行为核心逐字节一致，两个平台包不混入对方启动器。
- 管理员和普通成员都能看到从 V1.5.0 起的全部正式历史版本，且旧版没有下载或安装入口。
- 索引中的动态主题词可覆盖已核验三首产品头和可用的小巨人来源行业分类；宽泛行业不进入精确主题。
- `recognition_search` 优先读取索引内主题词典，旧索引缺表时安全回退到包内静态词典。
- 自动化代码、索引和封包门禁通过后正式发布；macOS、Windows WorkBuddy 实机验收由主人在发布后补录，不作为发布前阻断项。

## 回滚

- Skills 安装失败时恢复活动搜索路径外的安装前插件快照和原 MCP 配置。
- 代码部署失败时把生产 `current` 指针切回上一应用槽；索引发布失败时单独恢复上一签名索引指针。
- V1.5.5 产物按版本和哈希不可变；同名版本已存在不同内容时停止，不覆盖。
