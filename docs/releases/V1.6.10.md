# 共创研究院企业全生命周期助手 V1.6.10 发布说明

V1.6.10 将“识别专业领域”和“决定回答深度”拆开处理。企业名称、项目名称、专业术语或输入篇幅只用于选择合适的专业技能，不再自动把单点问题扩写成完整报告。

## 回答深度

- 单点问答：只回答用户提出的问题，给出结论和最小必要依据。
- 限定分析：围绕用户明确指定的若干维度展开，不自动补齐评分、材料清单、年度规划或完整企业画像。
- 正式交付：仅在用户明确要求报告、申请书、正式材料，或选定企业全景 A、B、C 模式时启用完整专业结构和交付门禁。

单项专利适配默认收敛为技术关联、近似专利、授权前景和差异化建议。项目名称仍会改变判断口径，但不会把问题扩展成该项目的全量评估；除非用户追问，不重复说明拟申请专利尚未授权。

## 保留能力

正式交付继续执行企业主体、政策、证据、计算、来源、文件验收和签名完整性要求。企业全景 A、B、C 仍是三种报告业务模式；每份正式报告默认只生成 Word，用户明确要求时再从同一正文生成 PDF。

## 验证

发布前必须通过回答深度路由、误触发对抗用例、正式交付合同、完整技能测试、套件签名、下载解压和安装自检。正式包与共创企业助手 V0.2.4 使用同一套已验签 V1.6.10 技能投影。

V1.6.10 Windows 平台包与 V1.6.10 macOS 平台包使用同一业务合同和各自隔离的最小行为运行时；企业数字身份证不进入插件包。共创企业助手 V0.2.4 的 Windows 与 macOS 客户端由独立客户端发布事务生成，技能版本和客户端版本不混写。
