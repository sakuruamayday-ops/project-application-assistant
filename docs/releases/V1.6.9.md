# 共创研究院企业全生命周期助手 V1.6.9 候选说明

V1.6.9 调整专业报告的默认交付格式，以减少重复生成造成的模型调用和用户 Token 消耗。报告业务模式保持不变；变化只发生在默认文件产物。

## 候选能力

- 企业全景 A／B／C 继续分别表示公开合作快评、证据增强尽调和用户材料深度尽调，不表示 Word／PDF 格式。
- 项目预评估报告、可行性报告以及两者同时出具的业务模式继续保留。
- 每一份已选报告默认只生成一个可编辑 DOCX。
- 只有用户明确要求 PDF 时，才从同一份定稿内容导出 PDF，不重新调用模型生成第二份正文。
- HTML 仅可作为 PDF 导出的未发布中间源，不进入默认交付物列表。
- PDF 渲染、正文校验、品牌处理和视觉回归能力继续保留，不因默认 Word 交付而降级。

## 验证状态

企业全景、项目可行性、总控技能、交付契约、报告技能注册表和套件清单的定向测试已通过。签名通用包、平台包、共创企业助手 V0.2.0 内嵌投影和真实 DOCX／按需 PDF 回执尚待形成，因此本文件不构成正式发布声明。

## 回滚边界

如候选验收失败，继续使用 V1.6.8 正式技能包；不得覆盖用户企业空间、客户材料、账号凭据、签名私钥或本地知识索引。
