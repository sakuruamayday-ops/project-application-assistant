# V1.7.1 专精评估与培育推荐

macOS 与 Windows 客户端消费同一签名技能包。通用技能包不包含知识索引、企业数字身份证、用户凭据或客户资料。

- 专精特新中小企业与小巨人前期评估使用五章行动型报告，固定章节、表头与品牌格式，支持Word直接编辑。
- 主导产品给出具体建议及适用边界，同行对照围绕真实产品与能力展开。
- 围绕专精申报提供研发机构、工业新产品和适用三首项目培育建议，不把推荐等同已经符合全部申报条件。
- 补强任务与两年软提升同步说明PCT、质量管理、产品权威认证及数字化的评价作用与业务价值，不展示具体分数。
- 研发设备推荐按固定资产50%进行程序化档位筛选，使用已核实适用政策档位；缺固定资产不以总资产替代，估算金额不进入客户报告。
- 保留原有文件来源、签名、完整性与授权机制。本次更新技能包，不更改客户端程序版本。
