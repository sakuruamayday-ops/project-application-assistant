# 企业全生命周期助手 V1.3.1.1

发布日期：2026年7月27日

## 本次更新

修复 WorkBuddy MCP 配置问题，增加两阶段自动接入与手工配置兜底。

- WorkBuddy MCP 接入改为两阶段流程，确认阶段保留 macOS 或 Windows 平台信息。
- API 与用户页、Skills 管理中心增加手工配置入口，自动接入失败时仍可完成连接。
- 通用、macOS WorkBuddy、Windows WorkBuddy 三类产物统一使用同一版本、技能清单和知识库接入协议。

## 安装与验收

- 通用 Skills：导入 `skills` 目录后启动首次配置向导。
- WorkBuddy：审阅透明安装计划后输入 `INSTALL`，再完成技能清单与 MCP 接入验收。
- 自动接入未完成时，从 API 与用户页或 Skills 管理中心复制手工配置内容交给本地 Agent。

## 兼容边界

- 通用 Skills 已验证。
- macOS WorkBuddy 已完成真实安装、启用、Skill 触发和 MCP 接入验收。
- Windows WorkBuddy 仍为结构兼容，真实 Windows 宿主证据尚未补齐。
