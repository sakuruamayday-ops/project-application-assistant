# 企业全生命周期助手 V1.4.3

发布日期：2026 年 7 月 31 日

V1.4.3 是一次端到端安全与可靠性版本，覆盖技能包、WorkBuddy 插件、受控发布、网站身份与下载链路、OSS 索引和生产健康检查。49 项业务 Skills 的主体规则和交付契约与 V1.4.2 保持一致，旧政策效力核验的主路由优先级得到进一步明确。

在正式发布前的真实 WorkBuddy 对抗门禁中，旧年度或已截止政策的效力核验曾被领域技能错误占用主路由，部分用例还因输出业务分析而超过轮次或时限。V1.4.3 已明确：仅核验政策版本、效力和完整文件链时，`policy-retrieval` 必须作为主技能；11 个可能竞争旧政策任务的领域技能同步声明该排除边界。路由门禁只加载最少技能并输出单行结构化结果，且主技能必须真实激活。对抗用例改为四路隔离并行，缩短完整门禁反馈时间而不减少 108 条用例。

## 发布与供应链

- 通用 Skills 与 WorkBuddy 包固定官方 Ed25519 发布者身份，校验完整签名文件集和逐文件 SHA-256。验签工具缺失、签名异常、缓存异常或文件篡改均失败关闭。
- ZIP 读取拒绝反斜杠、绝对路径、父目录、盘符、NUL、符号链接、重复条目和大小写碰撞。
- 内置秘密扫描支持 Unicode 归一化，并递归检查嵌套 ZIP，不能再通过空策略文件关闭基础扫描。
- 安装器只有在回滚副本成功建立后才替换技能目录；升级中断会恢复原目录，不覆盖项目资料、偏好或系统凭据。
- 发布门禁绑定 Git commit、tree、跟踪源码摘要、套件清单、发布管理器、工具链和最终包哈希，从仓库外启动也检查同一仓库根目录。
- 49 项 Skills 全部纳入行为覆盖门禁。WorkBuddy 候选包必须通过真实宿主全技能激活及对抗路由测试；宿主 CLI 缺失直接判定失败。
- 门户 Python 依赖拆分为人工输入、生产全传递锁、测试全传递锁和构建工具锁，全部使用精确版本及逐制品 SHA-256。CI 在 CPython 3.12 上生成 Linux x86_64 wheelhouse 和 main 分支依赖发布记录；生产部署拒绝 PR 制品、ABI 不匹配、额外文件、哈希漂移及联网解析安装，并把六项依赖身份与发布记录哈希暴露在 `/build`。

## 门户与账号

- 邀请改为一次性原子消费的 v2 令牌，移除姓名加手机号后四位的旧注册路径，避免已知成员资料被用于接管账号。
- 登录、注册、问答接口增加可信来源限流；登录页会清理前一账号残留的会话级模型密钥。
- 自带模型接口仅允许 HTTPS、公网解析和受控端口，不跟随重定向，并限制响应体、并发和超时。
- 问题明文按 24 小时保留策略由后台周期任务清理，低流量时也不会无限期保留。
- 候选包在入库和下载时同时核验数据库 SHA-256、固定发布者签名和同一稳定文件内容，阻断无效包抢占最新版、验签缓存复用及校验后换包。
- CSP、缓存头、搜索引擎策略、存活探针、就绪探针和构建身份接口统一收紧。

## OSS 与生产运维

- 索引发布改为不可变 release 与签名 current 指针，使用条件写入、SHA-256、CRC 和对象白名单阻断覆盖及半成品提升。
- 服务器仅在完整验证 release、签名、对象集合、哈希和 SQLite 结构后切换 current，并保留 previous 世代用于索引级回退。
- 应用运行配置与 OSS 运维配置分离；生产健康检查覆盖服务状态、失败单元、磁盘、TLS、索引世代、备份新鲜度和构建身份。
- 本版本没有执行备份恢复演练，也没有对历史 OSS 对象、暂存目录或部署备份实施清单、隔离、恢复验证或处置。

## WorkBuddy 兼容性

| 宿主 | V1.4.3 状态 |
|---|---|
| 支持完整 Skills 目录的 Agent | 通用签名包与安装回滚门禁 |
| WorkBuddy 5 macOS | 同一跨平台包；发布前须通过真实宿主全技能激活及对抗路由门禁 |
| WorkBuddy 5 Windows | 结构、签名和跨平台启动器门禁；真实 Windows 安装、绑定和重启仍需实机验收 |

插件根目录 `.mcp.json`、`plugin.json` 相对声明、跨平台 Node 启动器和 setup 运行时继续全部进入固定发布者签名清单。已经完成绑定的 V1.4.x 设备升级后复用原设备标识、Ed25519 密钥、API Token 和 `jiaotang-kb` 身份。

## 已知边界

- 本版本不包含备份恢复到临时实例、登录及查询演练，因此不声明新的 RPO 或 RTO 实测值。
- 本版本不处置历史 OSS 对象、既有暂存内容或历史部署备份。
- Windows WorkBuddy 的真实安装、系统凭据保存和重启仍需受控实机验收。
- 独立异地备份桶、云端 RAM 角色和跨区域复制需要对应云资源与权限，本版本只提供配置、校验和告警能力，不凭空创建生产资源。
