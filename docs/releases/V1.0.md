# 企业全生命周期助手 V1.0 历史说明

发布日期：2026年07月21日

## 本次发布

- 正式发布53个 Skills，保留受控自进化、纠错记录、影响分析和任务结束四问复盘。
- 团队知识检索统一使用云端 REST API 与 Streamable HTTP MCP，不依赖成员本地知识库镜像。
- 更新杭州、宁波、金华、绍兴政策与公示资料的归档、后台来源路由和自动核验状态。
- 首次配置默认政策地区只需填写到省、市；市级项目默认使用当地城市，区级项目在任务中按企业注册区确认，不长期保存区县。
- 强化政策版本识别、废止或替代依据、政策同源簇、人工拆分合并、撤销、别名确认、核验预览和关键条款差异对比。
- 加入制造企业金税四期风险分析、新公司法企业合规自查和工作相关法律法规动态路由。
- 注册支持管理员名单内成员使用中文真实姓名和企业微信手机号后四位自助注册，不要求单独邀请链接。
- 每位用户保留一个可反复显示和复制的个人访问凭据，支持REST、MCP、本人用量和调用记录。

## 升级方法

1. 登录团队网站，进入“Skills 下载”。
2. 下载并解压V1.0 ZIP。
3. 使用新的 `skills` 文件夹替换旧版标准 Skills，保留个人项目资料和本地政策规则。
4. 在 Agent 中输入“请检查企业全生命周期助手是否安装完整，并启动首次配置向导”。
5. 让 Agent 执行REST与MCP五步端到端验收。

## 配置要求

- 团队知识库：网站提供的REST Base URL、MCP URL和个人访问凭据。
- 企业数据：企查查为可选增强。
- 专利数据：BigQuery Patents或其他合法专利数据源为批量检索增强。
- OCR、PDF、Word、Excel、PPT和联网检索：由宿主 Agent 提供。
