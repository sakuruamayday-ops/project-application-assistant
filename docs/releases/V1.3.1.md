# 企业全生命周期助手 V1.3.1

发布日期：2026年7月27日

## WorkBuddy与知识库连接

- WorkBuddy插件只保留一份签名`jiaotang-kb`连接器；源码目录继续作为打包输入，但不再以共享路径重复复制到最终套件。
- 使用DeepSeek自定义模型完成WorkBuddy真实登录、市场安装、插件启用与Skill触发回归。
- 网站不展示源码使用许可正文；许可文件只随源码与发布包提供。

## 凭据安全

- 首次配置脚本不再收集团队知识库Token。
- 团队知识库Token与设备私钥只允许进入macOS Keychain或Windows凭据管理器，不写入`credentials.env`。
- 升级时自动清理旧版明文文件中的团队知识库Token，同时保留天眼查、企查查等第三方供应商配置。

## 发布与版本治理

- 通用包、WorkBuddy包、插件清单、网站展示和GitHub Release统一使用V1.3.1与语义版本`1.3.1`。
- 发布脚本支持补丁版本，并从套件清单动态校验技能数量，不再硬编码数量或自动追加补丁位。
- 正式发布继续执行SHA-256、Ed25519签名、临时解压、安装自检和两阶段确认。

## 市场地位与产业链价值证据

- 新增跨项目“细分市场边界与产业链价值证据闸门”，统一核验官方分类、商业对象、市场测算和替代证据，但保留专精特新、小巨人、隐形冠军及单项冠军各自的正式阈值。
- 明确海关编码、行业标准和协会分类只作辅助交叉验证，不得代替项目指定分类或用于人为缩小市场分母。
- 补短板、锻长板、填空白和国产替代分别建立证据链；国外企业、产品型号、客户采购时间和第三方检测按已取得事实记录，缺失时标记待补，不得补造，也不得把第三方检测误设为所有项目的通用硬门槛。

## 高新技术企业认定申请书

- 新增高企正式申请书专用技能，使用脱敏空白母版完成企业信息、知识产权、RD、PS、创新能力和成果转化内容的撰写、回填与核稿。
- RD、PS表支持按实际项目数量安全扩缩：缩表默认关闭，只有显式授权后才能删除末尾完全空白表；任何名称、周期、正文、经费、收入、知识产权或勾选值都会阻断整个删除操作。
- 扩缩后自动连续编号并生成JSON审计记录；输出继续执行字体字号、占位符、表格结构和逐页视觉检查。

## 继承自V1.3的能力

- 正式套件为49个顶层Skills，专利工作收敛为两个顶层入口和总路由内部三个阶段。
- 加固专利查新、创造性分析、挖掘交底、双中心预审、申请文件核稿及知识库MCP访问边界。

## 已知边界

- Windows WorkBuddy安装器已通过生成、静态安全与完整性测试；未取得Windows真实宿主证据前仍标记为结构兼容。
- 复杂OLE公式、超长权利要求和语义等同技术特征仍需结合原文与人工专业判断。
