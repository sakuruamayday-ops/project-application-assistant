# 共创研究院企业全生命周期助手 V1.6.8 功能简介

V1.6.8 是 V1.6.7 的完整性修复版：补齐通用技能包中 `skills/_runtime/jiaotang-kb/` 的知识服务运行入口，同时保留十二类项目报告最简提示词、同行本地知识库优先和“深度澄清”等能力。macOS 与 Windows 平台包仍只包含 Skills、最小行为 Hook 和远程知识服务配置，不携带本地 MCP 运行入口。

## 正式版本事实

- 企业名称加现有资料即可启动十二类项目前期评估或可行性分析；主体缺口按天眼查、企查查和官方来源补齐，无法核验字段如实标为待核验。
- 高企、专精特新和小巨人等常用短提示词进入专业报告路由，普通“给朋友出报告”等非专业对话不误触发。
- 同行及获评企业检索固定本地知识库 → 天眼查 → 企查查 → 官方网页或联网搜索，禁止首步直接联网。
- 用户明确选择或明确要求后可启用“深度澄清”，按依赖分轮确认并在共同理解获得用户确认后实施；签名技能禁止隐式调用，自动建议与拒绝状态仅由共创客户端负责。
- 通用技能包恢复完整源文件投影并在下载解压门禁中逐字节核对知识服务运行入口；V1.6.7 缺件包不得继续作为最新版使用。
- V1.6.8 汇总 V1.6.7 的共创精选、国知局专利首轮发现、十二类双报告母版和共创客户端专业执行合同，同步提供签名通用 Skills 包与 macOS、Windows 平台包。

共创客户端运行合同固定 DeepSeek Harness `0.1.0-rc.8` 上游提交 `141eb6fef83422698aef7a981029e843e8161531`；更换底座后必须重新执行客户端全量 GUI、类型、技能加载和双架构安装包验收。

## 最简使用方式

报告任务只需提供“企业名称＋现有资料＋项目或报告类型”。例如：

- `杭州示例科技有限公司，现有资料如下，出具专精特新双报告。`
- `杭州示例科技有限公司，做高企前期评估。`
- `杭州示例科技有限公司，做绿色工厂可行性分析报告。`

同行查询可直接写产品和项目，例如：

- `做阀门手轮的浙江省专精特新企业帮我查。`

团队知识库连接正常时，先从已核验认定名单和原文开始检索。知识库未命中、覆盖不足或不可用时，才按天眼查、企查查、官方网页和联网搜索的顺序补齐。第三方信息仅用于主体线索与官方来源定位，不能替代认定事实。

## 交付边界

- 企业数字身份证不进入插件包；客户资料、知识索引、账号凭据和签名私钥也不进入通用 Skills ZIP 或客户端安装资产。
- 用户未提供的财务、研发、客户和经营数据不由第三方过期信息补造；无法核验的字段在报告中标为待核验。
- 项目结论仍以当期政策、正式名单和可追溯证据为准，不承诺获批。

## 发布范围与回滚

V1.6.8 发布签名通用 Skills 包以及 macOS、Windows 平台包。通用包包含知识服务运行入口；平台包继续使用最小行为 Hook 和远程知识服务配置，禁止携带用户凭据或本地 MCP。共创企业助手在独立客户端更新链路中校验同一签名技能资产，客户端版本不随本次技能包版本自动变更。

如需回滚，恢复 GitHub 与门户上一正式版的通用 Skills 包，并重新执行安装完整性与签名校验；不得覆盖用户企业空间、个人项目资料、政策规则、偏好或系统凭据。
