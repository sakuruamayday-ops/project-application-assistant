# 企业全生命周期助手 V1.3.1.5

发布日期：2026 年 7 月 29 日

本版本修复 WorkBuddy 两步自动安装的受限下载校验，并将运行时知识库连接验证设为首次配置完成门槛。

## 修复内容

- 第二阶段安装协议改用一次性受限下载地址，避免登录页 HTML 被误下载为插件包并触发 SHA-256 不一致。
- 协议、下载包和引导清单固定到同一已审查 WorkBuddy 发布资产，继续执行 SHA-256 与 Ed25519 双重完整性校验。
- 首次配置必须确认 jiaotang-kb 已进入当前 WorkBuddy 运行时并成功调用 knowledge_service_status，之后才提示安装 OCR、PDF、Word、PPT、Excel 和联网检索 Skills。
- 门户明确区分自动两步流程与手工配置：自动流程由 Agent 下载、校验并安装，无需用户预先下载插件包。

## 安装流程

1. 在门户复制第一步审查说明并发送给 WorkBuddy。
2. 核对后回到门户复制第二步安装确认，并发送给同一个 WorkBuddy 会话。
3. Agent 使用一次性受限地址自动下载固定的 V1.3.1.5 WorkBuddy 发布包，校验 SHA-256 和 Ed25519 签名后安装。
4. Agent 检查 jiaotang-kb 是否进入当前运行时，并实际调用 knowledge_service_status。
5. 只有状态调用成功后，首次配置才结束，随后提示安装 OCR、PDF、Word、PPT、Excel 和联网检索 Skills。

自动两步流程不要求用户提前下载插件包。只有主动选择“手工配置”时，才从 Skills 中心下载签名包。

## 兼容性

- 已正常连接的既有用户无需重新绑定或重新安装。
- macOS 与 Windows 继续共用同一个签名 WorkBuddy 包。
- V1.3.1.5 继续兼容 V1.3.1.4 的两阶段设备激活事务。
- WorkBuddy 应用内真实安装与技能触发由主人在正式提升后执行验收。

## 安全与发布门禁

- 未确认阶段不暴露插件下载地址；第二步只生成绑定当前已确认安装码的一次性受限地址。
- 安装协议禁止动态命令，只允许下载已核验发布资产、校验完整性和完成 WorkBuddy 应用内插件配置。
- 发布包继续使用 Ed25519 插件级签名、逐文件 SHA-256、解压回归与安装自检。
- GitHub 与知识门户继续执行“正式发布中 → 主人独立确认 → 正式提升”的两阶段发布流程。

## 回滚

- 正式提升前失败：V1.3.1.4 保持网站当前正式版本，V1.3.1.5 只保留为预发布证据。
- 正式提升后需要回滚：恢复 V1.3.1.4 下载指向；已经完成的设备绑定保持有效。
- 本地回滚：在 WorkBuddy 中停用或卸载 V1.3.1.5，再按需安装 V1.3.1.4；不得手工替换签名包内文件。
