# V1.7.6 报告Word转换与打印修复

用户要求Word时，将已确认的同一份HTML正文转换成可编辑DOCX，保留标题、表格、数字、来源和草稿状态。制造企业财税Word报告继续使用原画像和金色品牌，并按Word实际格式完成交付校验。财税报告打印分页区域不再裁切正文。默认报告仍只交付PDF。

本版与客户端V0.7.3共同交付。企业全景A版浙江巨能固定模板、彩色圆点、来源校验和已有签名完整性检查保持有效。正式下载由团队网站提供，不同步OSS；签名通用包、内嵌技能投影、安装升级与公网回读以本次实际发布回执为准。

源码和合成文件已验证同正文转换、六张原生表格、八页Word及十七页财税PDF。合成测试不代表客户财税结论；正式签名和实际客户端升级结果单独验收。
