# 共创研究院企业全生命周期助手 V1.6.12 发布说明

V1.6.12 收敛深度澄清流程，避免用户已经无法补充新决定或外部能力不可达时继续重复提问和调用。该版本继承 V1.6.11 的三档回答深度、默认 Word 交付、按需 PDF、旧式 XLS、结构化操作回执、证据合同和专业文件可打开性探测。

## 本次变化

- 用户在深度澄清任一轮都可以按推荐继续、跳过澄清或取消任务；高影响选择仍需明确确认。
- 连续两轮没有确认、排除、新增或解锁任何决策分支时，停止重复提问，不发起第三轮相同问题。
- 工具、权限或外部条件不可达时不重复调用，保留已确认结果并只阻塞真实依赖该条件的分支。
- V1.6.12 继承 V1.6.11 的三档回答深度、Word 默认交付、文档操作、证据合同、共创精选、本地知识库优先路由与共创客户端专业执行合同。

## 兼容与交付

- 套件继续包含 51 项 Skills 和共享签名运行时。
- 通用 ZIP、macOS WorkBuddy 套件和 Windows WorkBuddy 套件使用同一业务规则；企业数字身份证不进入插件包，平台包也不携带用户凭据或本地 MCP，账号身份继续由客户端宿主管理。
- V1.6.12 不改变默认 Word、按需 PDF、企业全景 A／B／C 报告模式或正式专业交付规则。
- 共创企业助手通过独立客户端发布事务嵌入并验签本版本；技能发布完成不等于客户端版本已经发布。

## 验证范围

发布事务执行深度澄清定向测试、全套技能与行为测试、政策时效与停用规则检查、51 项逐技能清单刷新、三套件解压安装自检、敏感信息扫描、Ed25519 签名验证、服务端发布和本机正式同步。任何一步失败均不形成正式版本。
