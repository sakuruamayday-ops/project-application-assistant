# V1.7.5 格式拆分候选

状态：开发候选，尚未签名、安装或正式发布。正式技能仍以GitHub Latest为准。

V1.7.5 继续提供同一份通用签名 Skills ZIP，供 Windows 与 macOS 客户端消费验签后的套件投影。本次对应客户端候选为 V0.6.5，两端均须重新构建和验收，不将技能候选版本当作客户端已发布版本。技能包不包含知识索引、企业数字身份证或用户凭据；外部 MCP 与登录授权仍由宿主和服务配置层管理。

## 范围

- 高新、专精及小巨人分析报告使用固定HTML模板直接生成PDF，不读取或序列化Word报告母版。
- 专精行动体检报告保留固定五章、19块、补强任务和局部修改，直接生成HTML供客户端导出PDF。
- 企业全景 A 标准销售版按主人确认的浙江巨能样式使用中性固定母版，业务 JSON 经现有技能操作填入独立橙色封面、原章节图标、两列工商表及摘要、双卡和评级卡。核验状态用真圆点，风险严重程度保留彩色底标签；随包只含中性 PDF 与真实页面预览，不包含原客户报告或其事实，既有正文、来源及免水印检查继续执行。
- 高新、专精申请书保留独立的可编辑Word回填入口，不附带PDF。
- 模板教学说明不进入报告，改写表头保留文字颜色与强调。
- 报告格式或表格输入错误返回单一JSON失败说明；退出码2不是通过，失败不生成文件，不以重启替代修正输入。

22项定向测试、111项报告及高新申请书关联测试、63项操作与业务约束测试通过。8份合成报告使用现有客户端原生PDF渲染器运行，六份普通报告以r3为最终结果，两份行动报告使用r1未受影响结果，共55页；正文、品牌、同源视觉和文件变化拒绝通过。合成样例不代表真实企业结论或完整员工业务验收。
