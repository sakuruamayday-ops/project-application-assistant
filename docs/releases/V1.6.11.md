# 共创研究院企业全生命周期助手 V1.6.11 发布说明

V1.6.11 修复旧式 Excel 文档读取、结构化操作回执和客户端专业证据校验中的可达问题。该版本继承 V1.6.10 的单点问答、限定分析和正式交付三档回答深度，不扩大普通问题的回答范围。

## 本版变化

- 签名文档提取操作新增 `.xls`，保留工作表名称、中文正文、百分比、日期、布尔值和错误值；共创客户端随包固定 `xlrd 2.0.2`，用户无需临时安装。
- 需要机器读取的签名操作声明 stdout JSON schema。退出码为零但只输出警告、空正文或错误结构时，客户端明确拒绝，不再把它当成可用证据。
- 客户端读取 XLSX 正式文件时解析共享字符串、富文本、工作表关系和单元格样式，数字证据使用用户实际看到的值，不再使用共享字符串索引或百分比原始值。
- 数字证据绑定排除标准编号、手机号和身份证号；同一百分比不因显示符号反复要求补证。
- 企业画像主体锚定和高企四栏完整合同只适用于明确正式交付。单点问答与限定分析仍按用户要求的维度收敛。
- 专业正式文件绑定后，必须完成真实文件可打开性探测才允许调用发布工具。

## 兼容与边界

- V1.6.11 Windows 平台包与 V1.6.11 macOS 平台包使用同一业务合同和各自隔离的最小行为运行时；共创企业助手 V0.2.5 的 Windows 与 macOS 客户端由独立客户端发布事务生成，技能版本和客户端版本不混写。
- 企业数字身份证不进入插件包；客户资料、知识索引、账号凭据和签名私钥也不进入通用 Skills ZIP、macOS 平台包、Windows 平台包或客户端安装资产。
- 正式报告默认只交付可编辑 Word；只有用户明确要求时才生成 PDF。
- 企业全景 A、B、C 仍是报告业务模式，不是 Word/PDF 格式选择，保持原有入口。
- 现有证据、计算、来源、签名、权限、内容、品牌、视觉和回滚措施继续保留；本版没有新增普通开发门禁。
- 客户端版本与技能版本独立。共创企业助手 V0.2.5 内嵌本版签名技能套件。

## 验收重点

发布前验证真实 `.xls` 显示值、XLSX 共享字符串和百分比、结构化 stdout 的成功与拒绝路径、限定问答合同、标准号与隐私号码排除、专业文件发布前探测，以及 51 项技能签名和三套分发包完整性。

## 发布清单版本事实

V1.6.11 修复旧式 XLS 文档提取和客户端结构化操作回执，减少文件读取与证据校验中的无效重试。

- 文档提取操作新增旧式 XLS 支持，并保留单元格显示百分比、日期、布尔值和错误值；客户端内置 xlrd 2.0.2 运行时，不再要求用户临时安装解析依赖。
- 需要机器读取的签名操作声明 stdout JSON schema；客户端拒绝警告文本或空正文冒充成功，并继续接受明确的业务拒绝状态。
- 客户端对 XLSX 正式文件按共享字符串、富文本、样式、百分比和日期提取用户可见值，不再把内部索引或原始存储值当作业务数字。
- 专业数字证据排除标准号、手机号和身份证号等非业务量化标识；百分比的显示符号不再导致同一数值反复补证。
- 限定问题继续执行 V1.6.10 的最小充分回答深度，不因企业画像或高企术语强制套用完整报告合同；正式文件仍保留完整结构、证据、验签和发布门禁。
- 正式文件通过专业校验后必须完成真实文件可打开性探测，未探测文件禁止发布。
- 新增单点问答、限定分析、正式交付三档回答深度；企业名、项目名、专业术语和输入长度只选择领域技能，不再自动升级为完整报告。
- 单项专利适配默认只回答技术关联、近似专利、授权前景和差异化建议；除非用户追问，不额外展开完整高企评估或重复提示拟申请状态。
- 收窄企业画像、专精特新、高企、企业全景等正式合同触发词，避免普通接口版本、通用申请书审核和术语解释被误路由。
- 明确要求报告、申请书、正式材料或选定企业全景 A、B、C 模式时，继续执行原有专业结构、证据、计算、来源、签名和交付门禁。
- 每份正式报告默认只交付 Word，用户明确要求 PDF 时才从同一正文生成 PDF；PDF 渲染能力继续保留。
- V1.6.11 继承 V1.6.10 的共创精选、国知局专利首轮发现、十二类报告母版、本地知识库优先路由、深度澄清与共创客户端专业执行合同。
