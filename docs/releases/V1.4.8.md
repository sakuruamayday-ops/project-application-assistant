# 企业全生命周期助手 V1.4.8

发布日期：2026年8月2日

V1.4.8 热修 WorkBuddy Skill 激活登记，保留 49 项原生加载与远程 MCP 简化安装边界。

## 完整版本事实

- Skill 激活块优先使用宿主稳定注入的 CODEBUDDY_PLUGIN_ROOT，并仅在可用时回退 CODEBUDDY_SKILL_DIR，不再因 Skill 目录环境变量缺失而静默跳过登记。
- 激活脚本从插件根目录和 Skill 名称确定性解析真实目录，成功后复读会话状态确认持久化，并返回 activation_ok、Skill 名称和轮次 ID。
- 激活失败返回可审计的错误码，不再与成功共用无差别 continue 回执；普通问答与 Hook 内部异常仍保持失败开放。
- 继续保持 49 项 Skill 首字节 YAML frontmatter、真实名称原生加载、正式业务零 Skill 激活阻断和提示词只存摘要的 V1.4.7 修复。
- 继续保持 49 项 Skills、用户级远程 HTTP MCP、自动填入个人 Token、只替换 jiaotang-kb、保留其他 MCP 和一次重载的简化安装边界。

## 修复范围

- 不修改 49 项业务规则正文。
- 不修改知识库 MCP 协议、Token 填充和用户级 MCP 合并逻辑。
- 不恢复用户侧签名校验、目录哈希、设备绑定、钥匙串或本地 MCP 启动器。
- 不包含 49 项业务算法化改造。

## 验收标准

- 49 项 Skill 继续以真实名称原生枚举并可按名加载。
- Skill 加载回执明确包含 `activation_ok=true`、真实 Skill 名称与轮次 ID。
- Hook 会话状态的 `active_skills` 包含本轮实际加载的 Skill。
- 激活失败返回明确错误码，不得伪装为激活成功。
- 三个知识服务工具继续枚举，`knowledge_service_status` 返回 `connected=true`。

## 兼容与回滚

- macOS 使用发布后的新会话复验 Skill 激活登记。
- Windows 保持结构兼容，发布后由受控 Windows 设备补做实机激活验收。
- 升级失败时恢复安装前插件目录与用户 MCP 配置备份，不覆盖其他 MCP 条目或用户项目资料。
