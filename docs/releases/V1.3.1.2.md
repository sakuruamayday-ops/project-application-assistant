# 企业全生命周期助手 V1.3.1.2

状态：待正式发布。

V1.3.1.2 是仅面向 WorkBuddy Windows 的安装热修复。技能总数、技能内容、知识库连接器、设备凭据协议和 macOS 安装包保持不变。

## 修复内容

- Windows 用户解压签名包后，直接双击 `install-jiaotang-workbuddy.cmd` 进入固定安装流程。
- 安装器在执行插件 CLI 前检查 `WorkBuddy.exe`。检测到 WorkBuddy 正在运行时，明确提示用户保存工作并完全退出，不再无输出地卡在本地端口冲突。
- 等待 WorkBuddy 退出最长 60 秒；仍未退出时安全终止，不执行市场登记、插件安装或启用。
- 门户的 API 与 Agent 接入区域新增“生成并复制 bootstrap_url”操作。用户完成公开安装说明审查并明确确认后，一次性引导地址会直接复制到剪贴板。
- 修正独立客户端发布后的渠道回退逻辑，Windows-only 新版不会被误识别为通用 Skills 或 macOS 新版。

## 发布范围

- 本次仅发布 WorkBuddy Windows。
- WorkBuddy macOS 继续使用 V1.3.1.1，无需下载或更新。
- 通用 Skills 继续使用最近一次正式通用版本。
- 49 项技能内容没有变化。

## 兼容性

- 已安装旧版本的用户可以继续使用，现有插件、设备绑定、系统凭据和 `jiaotang-kb` MCP 连接不会被撤销或强制升级。
- 服务端保留原有安装协议和设备接口；新增按钮只复用现有两阶段确认接口，不改变旧客户端调用方式。
- Windows 用户只有在需要重新安装或解决安装卡住问题时才需要升级到 V1.3.1.2。
- macOS 用户不受本次修改影响。

## Windows 安装

1. 从门户下载 V1.3.1.2 WorkBuddy Windows 签名包并解压。
2. 双击 `install-jiaotang-workbuddy.cmd`。
3. 核对来源、SHA-256、本地改动、凭据边界和回滚命令后输入 `INSTALL`。
4. 若安装器提示 WorkBuddy 正在运行，保存当前工作并完全退出 WorkBuddy，再输入 `CONTINUE`。
5. 安装完成后重新打开 WorkBuddy。
6. 在门户的 API 与 Agent 接入区域完成审查确认，点击“生成并复制 bootstrap_url”，将其粘贴到插件敏感配置项。

## 安全边界

- 不自动结束 WorkBuddy 进程，不清理用户目录。
- 不执行网页返回的动态命令。
- `bootstrap_url` 仍为一次性敏感配置，不进入普通 `settings.json`。
- 私钥继续只在用户本机生成并保存，服务端只登记公钥。
- 所有正式文件继续由 Ed25519 签名和逐文件 SHA-256 清单保护。
