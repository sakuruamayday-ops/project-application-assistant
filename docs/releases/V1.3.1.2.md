  `81fe184d9bd0f1e9332a04bc10ab20c0a9db0c6d6231f0fa61922f166a53a482`。

  浏览器拒绝剪贴板权限时保留手工复制兜底。

## 安装

1. 从门户下载 V1.3.1.2 跨平台 WorkBuddy 包并核对 SHA-256。
2. 解压 ZIP，完整保留 `jiaotang` 目录。
3. 在正在运行的 WorkBuddy 中输入 `/plugin`。
4. 添加本地市场，选择解压后的 `jiaotang` 目录。
5. 安装并启用 `jiaotang-workbuddy-skills@jiaotang`。
6. 从门户复制一次性 `bootstrap_url`，粘贴到插件敏感配置。
7. 新建会话，确认 49 项 Skills 可见，并完成一次 MCP 工具调用或知识检索。

## 兼容性与既有用户

- 已安装用户不被强制升级；已有插件、设备绑定、系统凭据、MCP 接入和项目资料不变。
- 同一台 Mac 或 Windows 已绑定焦糖知识库时，正常复用本机已有设备凭据，不需要更换设备。
- 通用 Skills 包继续独立维护；本次没有发布新的通用 Skills 内容版本。
- 原 V1.3.1.2 Windows 专用资产保持不可变，仅作为历史发行证据保留；
  门户当前 WorkBuddy 下载入口切换到新的跨平台通道。
- 回滚只在 WorkBuddy 插件管理中停用、卸载插件并移除本地市场，不自动清理用户目录。
