# V1.6.1.1 本地修复候选说明

V1.6.1.1 仅用于 Codex 本地回归与 WorkBuddy 实机验证，不是 GitHub Latest，不替换已安装的正式版。

## 本轮修复

- 国家小巨人、省级专精特新等非三首权威名单不再静默忽略 `product_name` 或 `industry`。服务端明确拒绝这类无效参数，主题词反查转入 `recognition_search`。
- `local-knowledge-retrieval` 分别报告 `coverage_complete` 和 `truncated`，覆盖不完整时禁止“全部闭合”、“确认不存在”等超证据表述。
- 新增 WorkBuddy 真实宿主 JSONL 收据生成器，只根据真实 Skill 事件、MCP 尝试、外网调用和写入事件计数。
- 知识服务状态从当前活动索引指针解析发布编号，避免 `index_release_id` 因环境变量缺失而返回空值。

## 数据边界

企业数字身份证不进入插件包。主题词典和知识索引同样由服务端与 OSS 独立管理，不进入插件 ZIP。本轮已核对本地、云端活动索引与 OSS 基线的企业身份核心表数量一致。

## 平台验收边界

- macOS WorkBuddy：本地候选包生成后执行显式加载、隐式路由、负向边界和功能交付四维复验。
- Windows WorkBuddy：本轮不重编原生 EXE，延用 V1.6.1 Hook；须在 Windows 真实宿主补做系统级签名与运行验收后才能闭环。

## 回滚

本地候选异常时，恢复 V1.6.1 正式市场目录和原有 MCP 配置。只使用可恢复的系统回收站管理旧技术副本，不永久删除用户资料。
