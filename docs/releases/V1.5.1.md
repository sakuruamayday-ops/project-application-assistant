# 企业全生命周期助手 V1.5.1

发布日期：2026年8月3日

V1.5.1 修复正式交付的主业务Skill识别、模板误触发和Stop Hook机器回执，并合并门户性能优化；V1.5.0继续作为首个对外正式版本保留。

## 本次发布

- 49 项 Skill 全量划分为主业务、辅助业务、质量闸门和基础设施四类。正式业务交付必须激活主业务 Skill，单独激活 `consistency-check`、`policy-retrieval` 等辅助或质量 Skill 不能绕过交付门禁。
- 交付合同删除“报告、分析、材料、比较”等泛词触发，改为项目可行性、企业全景、金税四期、专精特新前期预评估与后期体检等业务特征组合。
- Stop Hook 成功与失败均返回结构化机器回执，包括已激活角色、适用合同、通过项、缺失项和错误代码。
- N/A、不适用、未生成、未运行和未通过等否定表述不能冒充交付要求完成。
- 门户对不可变技能目录、知识索引统计和签名产物展示校验增加安全缓存；下载与正式发布仍逐次执行完整快照、哈希和签名校验。
- 本次不修改知识索引，代码发布只校验签名回执、当前应用指针和现有索引绑定，不运行全库扫描。

## 机器清单对应的完整版本事实

- V1.5.0 作为首个对外正式版本独立发布，V1.4.9及更早产物保持不可变历史。
- 一键安装同时检查 .workbuddy 与 .codebuddy，把旧版、旧名称和重复副本移出活动搜索路径，在搜索路径外保留一个回滚快照，验收后其余副本移入系统回收站。
- Skill 与 Hook 根目录发现只接受固定 jiaotang 市场，不再使用会命中备份市场的通配搜索。
- 专精特新前期评估只保留2026政策：核验硬门槛和平台质量分，删除历史四维评分、内部22项百分制、统计局折算与三档总分引擎。
- public_list_search 兼容缺少 subject_type 列的历史名单表，不再因旧结构直接失败。
- 项目计算验证器新增公式语义复算，拒绝字段齐全但结果伪造的计算；高企三年成长性口径和2026至2029重新认定时间线固化为回归。
- 国产替代、补短板和填空白的外部型号、客户证明与第三方检测只作为增强证据，不再被设为企业自述成立前提。
- 插件级 UserPromptSubmit 与 Stop Hook 使用同一套跨平台根目录发现逻辑，不再单独依赖宿主环境变量。
- Skill 激活成功回执新增 root_source、state_persisted、active_skills_after 和 active_skill_count，可直接证明激活状态已经持久化，无需依赖宿主未公开的 active_skills 查询接口。
- 49 项生成后 Skill 已在默认 WorkBuddy 市场布局中逐项执行激活回归，最终同一会话状态精确记录 49 项。
- 继续保持 49 项 Skill 首字节 YAML frontmatter、真实名称原生加载、正式业务零 Skill 激活阻断和提示词只存摘要的既有边界。
- 继续保持 49 项 Skills、用户级远程 HTTP MCP、自动填入个人 Token、只替换 jiaotang-kb、保留其他 MCP 和一次重载的简化安装边界。
- 管理员单页导航恢复为项目算法包、API 与用户、Skills、健康看板的稳定页面顺序，并修复移动端导航滚动定位偏移。
- 门户 MCP 状态改为依据当前用户的实际 MCP 调用和安装验收记录，不再依赖已经停用的设备绑定状态。
- 安装成功后新增插件包评价与常用指令入口，覆盖专精特新前期评估和后期体检、高新申请书、标准撰写、企业分析三种交付与金税四期分析报告。
- 网站助手默认采用动态 12 轮、复杂任务最多 16 轮，并同时执行总时长、工具调用次数和连续无进展停止条件，不使用无限循环。
- 49 项 Skill 全量划分为主业务、辅助业务、质量闸门和基础设施四类；正式业务交付必须激活主业务 Skill，辅助 Skill 与质量闸门不能替代。
- 删除交付合同中的报告、分析、材料、比较等泛词触发，改为项目可行性、企业全景、金税四期、专精特新前评后检等业务特征组合。
- Stop Hook 成功和失败均返回主业务 Skill、辅助 Skill、质量闸门、适用合同、通过项、缺失项和错误代码等机器可读字段。
- N/A、不适用、未生成、未运行和未通过等否定表述不能冒充交付要求已完成。
- 门户缓存不可变目录、知识索引统计和签名产物展示校验，代码下载与正式发布仍逐次执行完整快照、哈希和签名校验。

## 验收标准

- 通用包与跨平台 WorkBuddy 包各含 49 项可识别 Skills，版本均为 1.5.1。
- 49 项 Skill 均有且仅有一个合法角色，正式业务交付没有主业务 Skill 时返回 `NO_PRIMARY_BUSINESS_SKILL`。
- Stop Hook 成功和失败均包含 `delivery_check_ok`、角色清单、适用合同、通过项、缺失项与 `error_code`。
- WorkBuddy 包不包含本地 MCP、设备绑定、钥匙串、DPAPI、bootstrap 或用户侧目录哈希阻断器。
- `tools/list` 枚举三个知识工具，`knowledge_service_status` 返回 `connected: true`，且其他 MCP 条目未被覆盖。
- V1.5.0 与更早的发布包和 GitHub Release 不被覆盖。

## 回滚

- Skills 安装失败时恢复搜索路径外的 V1.5.0 回滚快照，并恢复安装前 MCP 配置。
- 代码部署失败时把生产 `current` 指针切回部署前应用槽，知识索引指针保持不变。
- 发布包按版本和哈希不可变；V1.5.1 已存在不同内容时停止，不覆盖。
