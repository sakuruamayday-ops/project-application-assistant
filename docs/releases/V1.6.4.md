# 共创研究院企业全生命周期助手 V1.6.4 功能简介

V1.6.4 将中文自然化改写纳入第 50 项正式 Skill，把企业体检、产业定位、财务分析、专利布局、专精特新写作、税务核验和统一品牌能力归并到既有主技能，并增加企业数字孪生增量重放及本地技能与正式清单对账。

V1.6.4 同步发布 macOS 与 Windows WorkBuddy 包；企业数字身份证不进入插件包，外部企业数字身份证和知识索引继续由服务端单独管理。

## 本版本变更

- 新增 gongchuang-humanizer-zh 正式技能，中文自然化改写先锁定数字、名称、政策、知识产权、技术参数和引用，再处理模板腔与机械节奏。
- 企业体检、产业定位、三表分析、现金流与营运资金、专利布局、专精特新后期体检和税务计算方法归并到正式主技能，旧外部技能不再作为运行依赖。
- 吸收 Charlie 中适用于制造企业的十三周现金流、现金安全垫、现金转换周期、情景分析和资本开支回收期方法，排除 SaaS 与美国市场固定阈值。
- 统一品牌运行时扩展到 PDF、Word、Excel 与 HTML，并保留文件级交付闸门。
- 新增本地技能与正式技能清单对账门禁，任何新增本地同品牌技能必须明确登记为正式、已归并或排除。
- 新增企业数字孪生增量重放，可按目标企业局部修正和重建，避免每次重跑全量企业画像。
- arxiv、bigquery-patent-search 和 dogfood 不进入正式包，也不成为正式技能依赖。

## 兼容与边界

- 正式清单由 49 项增至 50 项，原有技能名称和调用边界保持兼容。
- `gongchuang-humanizer-zh` 只处理表达层，不替代项目资格、政策、法律、财务或证据判断；正式材料改写后仍执行一致性检查。
- `artifact-template-gb-t-1-1`、`artifact-template-sme` 和 `artifact-template-v1-3-1` 的模板资产及规则进入对应正式主技能，不再要求单独安装模板技能。
- `enterprise-checkup`、`expert-dual-assessment`、`financial-statement-analysis-zh`、`jiaotang-branding`、`patent-layout-planner`、`project-quick-reference`、`sme-checkup`、`srxgj-qa` 和 `china-tax-compliance` 的可复用方法已按职责归并，不作为独立正式入口。
- 企业数字孪生增量重放属于服务端维护能力，不进入插件ZIP；名单证据、工商身份、企业画像和认定产品仍按分层规则更新。
