# 网站安装包下载中心发布说明

发布日期：2026 年 7 月 28 日

## 发布结论

产品入口回滚为网站分发。原生 Skills Manager 和 PWA 管理器停止分发，
知识门户统一提供通用 Skills 包与不同平台的增强包。

## 本次变化

- 移除 Skills 页面中的“双端管理器”入口。
- `/skills-manager`、原生客户端三个下载地址和客户端 Word 手册地址统一跳转到
  “Skills → 版本与下载”。
- 原生客户端 v0.2.0 清单改为 `retired`，保留历史 SHA-256 和 GitHub Release
  审计记录，但所有产物标记为不可用。
- 旧 PWA Service Worker 清理本地缓存后自行注销。
- 网站明确区分“通用版”与“平台增强版”，并说明平台增强版已包含通用 Skills。
- WorkBuddy 跨平台增强包继续正式提供。
- TRAE、Qoder、通义灵码、Kimi Code 和 Cherry Studio 展示官方能力基线与适配状态；
  在完成真实宿主验收前不提供专用包下载，可先下载通用版。
- 未生成新的 Skills 内容版本，未修改 49 项 Skills。

## 对既有用户的影响

- 已安装的通用 Skills、WorkBuddy 插件、Hooks、jiaotang-kb MCP、设备绑定和系统凭据
  均不会被网站回滚操作修改。
- WorkBuddy macOS 与 Windows 仍共用当前 V1.3.1.2 插件市场包，不需要因本次网站发布更新。
- 已经下载的原生客户端不会被远程删除，但不再提供更新或正式支持。

## 验收门禁

- 网站只为通用包和已验证的 WorkBuddy 包显示正式下载按钮。
- 五个平台专用卡片均显示适配状态，不能伪装成已发布。
- 原生客户端入口与历史下载地址不再转发 GitHub 资产。
- 旧 PWA 不再缓存离线管理页面。
