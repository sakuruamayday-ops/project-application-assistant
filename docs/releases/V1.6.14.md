# 共创研究院企业全生命周期助手 V1.6.14 发布说明

V1.6.14 收敛常见 Office／WPS 兼容资料和高新技术企业申请书处理中旧式 DOC、合并单元格、批量回填的长时间试错路径。该版本继承 V1.6.13 的 XLSX 结构读取、V1.6.12 的深度澄清收敛及既有专业执行合同。

## 本次变化

- 文档提取先按真实内容识别规范 OOXML、OLE、ODF、RTF、PDF 和 UTF-8-SIG／GB18030 文本，不再按后缀选择解析器；扩展名错误但内容为受支持容器时仍可读取。
- DOCM、XLSM 等宏文档只读取正文或缓存值，不执行宏、公式或外链；ODS 重复行列、ZIP 成员、解压大小、压缩比、XML 实体和最终 JSON 字节数均有硬上限。
- 高企资料先执行一次格式与能力盘点。旧式 DOC 只允许签名提取器尝试一次，当前宿主不能读取时只请求一次转换；输入未变化时第二次停止，不重复尝试 COM、临时安装解析器或编码猜测。
- 真专有 WPS／ET、加密、损坏、未知或超出安全上限的文档返回明确状态和一次性动作，不以通用异常触发循环。
- 含纵向合并与跨列合并的申请书表格按物理 `w:tc` 单元格和语义标签定位，不再依赖网格展开代理对象、固定行号或对象地址去重。
- 同一批次一次写入全部 RD 的两项核心技术、两项创新点和四项阶段成果，写入后重新打开 DOCX 并逐项核对。
- “限 400 字”统一执行不超过 400 字的硬上限，不再为满足虚构的最低字数而填充正文。
- V1.6.6 历史发布哈希改为核验当时的 Git 对象，后续正常演进不再破坏旧版本审计。

## 兼容与交付

- 套件继续包含 51 项 Skills 和共享签名运行时。
- 通用 ZIP、macOS WorkBuddy 套件和 Windows WorkBuddy 套件使用同一业务规则；企业数字身份证不进入插件包，平台包不携带用户凭据或本地 MCP。
- 原始 DOC、DOCX、XLS、XLSX、WPS／ET 兼容文件和既有输出均不原地改写；写入失败时保留可恢复输出。
- 共创企业助手仅在本版本完成正式签名与发布后，才通过独立客户端发布事务嵌入并验签本技能套件。

## 验证范围

发布事务执行 399、400、401 字边界、纵向合并与跨列合并、旧式 DOC 一次提取与无进展停止、错后缀 OOXML、宏文档只读、RTF、ODS／ODT、CSV／TSV、专有 WPS、损坏容器、压缩炸弹和 UTF-8 输出字节边界测试，再运行全套技能测试、51 项逐技能清单刷新、三套件解压安装自检、敏感信息扫描和 Ed25519 签名验证。任一步失败均不形成正式版本。
