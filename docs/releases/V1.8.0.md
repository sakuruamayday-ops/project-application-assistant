# V1.8.0 本地发布候选

文档校验依赖解耦与固定PDF路径兼容。

本页记录本地候选范围，不表示网站、GitHub 稳定版或本机正式技能已经更新。配套客户端目标为 V0.8.0；Windows 与 macOS 的功能、安装和升级由客户端发布任务另行验收。

## 本次变化

- Word、Excel和HTML校验不再无用加载PDF原生库，保留品牌与真实文件检查。
- 固定经典PDF命令避免启动未使用的版面分析和模型模块，正文、品牌与像素校验继续执行。
- 技能按需读取，不恢复强制预加载或业务资料齐全门禁。
- 客户端专有执行与官方工具呈现的兼容改进由V0.8.0交付；通用技能包继续保持宿主中立。

## 交付范围与边界

只生成宿主中立的通用签名 ZIP。独立客户端消费同一批验签技能投影，不生成特定宿主插件包。通用包不包含知识索引、企业数字身份证、客户资料、连接密钥或个人配置。知识索引独立发布。

保留真实文件生成、可打开性、品牌、正文和像素检查。可选模型模块不参与经典 PDF 路径；这不等于已经证明所有设备上的原生库故障均已解决。候选是否通过以同批签名门禁、真实 ZIP 解压及隔离安装回执为准。

本轮不提升线上版本、不更新网站、不修改本机已安装技能，也不把本候选版本当成本机工具运行时的元版本。
