# 企业全生命周期助手 V1.4.6

发布日期：2026年8月2日

V1.4.6 是一次联合稳定性发布，同时收口 WorkBuddy 连接、MCP 忙循环、网站健康自愈、知识索引治理和发布门禁。V1.4.5 的 49 项 Skills 与简化安装边界保持不变。

## 完整版本事实

V1.4.6 联合修复 WorkBuddy 连接、网站健康自愈和知识索引治理，并精简默认发布门禁。

- 门户一键安装指令同时完成 49 项 Skills 安装或覆盖升级、最小行为 Hook 启用、用户级远程 MCP 合并、一次重载和 knowledge_service_status 验收。
- 登录用户的手工配置页自动复用有效个人 Token；无有效 Token 时自动生成，并直接填入完整 MCP JSON。
- WorkBuddy 包不再内置本地 jiaotang-agent.mjs、.mcp.json、run-node 启动器、bootstrap、设备密钥、钥匙串或 Windows DPAPI 流程。
- 用户安装阶段不再执行安装包签名审查、用户侧签名校验或每轮插件目录哈希检查；受控发布链仍在服务器侧校验候选产物。
- 49 项 Skills 均有行为覆盖门禁；WorkBuddy 包只保留业务 Skills、插件清单、最小行为 Hook、必要参考资料和业务脚本。
- 49 项顶层 Skills 的业务规则、路由和交付契约与 V1.4.3 保持兼容。
- 旧版用户通过同一段指令自动覆盖插件、移除旧本地 MCP 连接，仅替换 jiaotang-kb，并保留其他 MCP 条目。
- 新增简化安装端到端验收，覆盖新装、旧版覆盖、Token 复用、保留其他 MCP、工具枚举和真实状态调用。
- Windows 明确写入 %USERPROFILE%\.workbuddy\mcp.json，macOS 写入 ~/.workbuddy/mcp.json，不再误写 WorkBuddy 托管的 .mcp.json。
- MCP 中间件在重放请求体后继续等待真实断开事件，避免单 worker 忙循环拖垮网站。
- 生产健康检查改为每分钟执行，连续两次失败自动重启，30 分钟最多 3 次并熔断 60 分钟。
- 知识索引重建隐私白名单、旧资料生命周期和案例包关系，验收收据绑定全部关键索引产物。
- 小巨人与浙江省专名单改用官方发布事件口径，认定、认定公示、复核公示和复核通过分开记录，地域约束使用事件发生时归属。
- 默认发布门禁收敛为快速静态、一次主测试、必要产物验收和主机验收四层，相同输入使用内容寻址收据避免重复运行。

## 连接与安装

- Windows 固定将自定义连接器写入 `%USERPROFILE%\.workbuddy\mcp.json`，macOS 写入 `~/.workbuddy/mcp.json`，禁止修改 WorkBuddy 托管的 `.workbuddy/.mcp.json`。
- 覆盖升级前将旧插件目录移入带时间戳的可恢复备份，防止旧 `.mcp.json`、`bin` 或本地 `mcp` 启动器残留。
- 只合并 `mcpServers.jiaotang-kb`，保留其他 MCP；连接器出现后仍由用户在 WorkBuddy 界面手动信任。

## 网站稳定性

- MCP 中间件重放已缓存请求体后，后续读取恢复等待真实 ASGI 事件，使下游能正常收到 `http.disconnect`，避免单 worker 忙循环。
- 健康探测每分钟执行；连续 2 次失败自动重启门户。
- 30 分钟内最多自动重启 3 次，达到上限后熔断 60 分钟；熔断期间不累计连续失败。

## 知识索引

- 重建隐私白名单，所有机密和受限资料均禁止对象存储与语义上云。
- 已废止的杭州市专利试点示范资料只作历史参考，当前检索转向知识产权强企。
- 杭州市旧未来工厂资料不再作市级现行入口，当前检索转向 AI 工厂；浙江省未来工厂体系保持现行。
- 补齐案例包、案例文档和文档关系三张表，受限或机密文档不得标记为可上云。
- 库存索引每轮都从已冻结 manifest 重建；验收收据同时绑定全文索引、库存索引、政策版本库和上云白名单。

## 权威名单与地域约束

- 小巨人名单以官方发布事件决定企业是否入选，现有企业身份库和企策数据只用于补充地市、区县与更名链，不反向改写历史名单。
- 2022 年宁波第四批按官方逐企名单锁定为 101 家，不再使用 99 家的跨口径倒算值。
- 浙江省专将认定、认定公示、复核公示和复核通过分开建模；宁波按计划单列市口径独立归并。
- 地域检索优先使用名单事件发生时的省市区县归属，避免后续迁址或更名造成历史批次误归。
- 权威来源清单、事件覆盖审计、金标准和结构化表校验纳入同一索引流水线。

## 发布门禁

- 默认路径收敛为快速静态检查、一次主测试、必要产物验收和主机验收四层。
- Harness 依赖与内容寻址收据用于复用完全相同的验收结果；任一绑定输入变化都会失效收据。
- 隔离安装验收继续保留签名、路径、Hook 和用户资料保护边界。

## 回滚

- 应用回滚到 V1.4.5 对应的上一个不可变生产槽，恢复原环境指针。
- 索引回滚使用 OSS `previous` 世代和服务器本地 `previous` 指针，不删除 V1.4.6 候选或历史 release。
- WorkBuddy 安装回滚恢复时间戳备份中的原插件目录与用户 MCP 配置，不影响其他 MCP 和用户项目资料。
