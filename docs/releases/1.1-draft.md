# 企业全生命周期助手 V1.1 候选更新说明

状态：待主人确认，尚未发布

## 本次新增

- 新增标准撰写能力，按现行GB/T 1.1及适用专项规则支持国家标准、行业标准、地方标准、团体标准和企业标准的立项、起草、审查与修订。
- 新增浙江省企业身份时间轴，区分统一社会信用代码、历年名称、认定时地区和当前地区。
- 首次配置向导增加天眼查MCP能力检测。

## 本次优化

- 企业画像与企业全景分析改为天眼查首轮分诊、企查查补齐缺失和高影响字段、官方来源裁决冲突。
- 团队知识检索在企业跨年名单、复核和城市归属问题中优先查询企业身份时间轴。
- 企业关系图增加企业状态、风险标签和证据等级三层标识。
- 商业企业数据库调用增加串行、缓存、限流记录和断点续传要求，不再猜测未公开额度。

## 数据与知识更新

- 浙江省首版身份库收录7,379家企业和10,695条认定事件。
- 身份库中的认定年度、批次、状态和认定时地区来自名单侧；当前工商身份由企业数据源逐步核验。
- 两日工作方法复盘已进入团队知识库，不包含原始对话、密钥或排除任务内容。

## 升级说明

1. V1.1发布后下载最新版压缩包。
2. 使用新版标准Skills替换旧版官方核心。
3. 保留个人项目资料、个人政策规则和结构化个人偏好。
4. 运行首次配置向导，确认团队知识库、天眼查、企查查及其他可选能力状态。

## 已知边界

- 浙江省身份时间轴目前仅1家完成天眼查实证核验，其余企业保留待核验状态，不推算统一社会信用代码。
- 天眼查测试中连续6次企业数据调用未触发上限；这不能证明永久免费或无限调用。
- 供应商权限、并发限制和工具字段可能变化，批量补全须执行限流、缓存和断点续传。
