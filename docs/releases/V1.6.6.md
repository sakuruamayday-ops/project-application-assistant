# 共创研究院企业全生命周期助手 V1.6.6 功能简介

V1.6.6 在 V1.6.5.2 正式基线上新增共创精选业务入口、国知局公布公告中国专利首轮发现提供器，并把自有客户端的签名、Hook 生命周期、失败关闭、升级与回滚要求固化为机器可读发布门禁。

V1.6.6 保留 V1.6.5.2 的十二类双报告、真实资料锚点、WPS 逐页验收和最终 ZIP 回归。本版本只发布签名通用 Skills 包，并作为共创企业助手 V0.1 的内置专业能力基线；不再生成 WorkBuddy 专用包。

## 正式版本事实

- 新增共创精选：以十二个中小企业业务成果卡片组织底层正式 Skills，客户端点击添加只建立企业空间能力组合，不重复下载内置技能。
- 内置魔搭 Skills 与 SkillHub 社区入口；第三方技能必须先经过来源、许可证、恶意代码、网络与命令、平台兼容和摘要锁定审查，不能从网页直接绕过门禁写入正式技能目录。
- 专利总路由新增国知局公布公告首轮发现提供器，保留 Chromium 沙箱，仅发送脱敏短技术词，发现结果在官方全文、权利要求和法律状态复核前不得进入查新、FTO 或法律结论。
- 国知局提供器新增有界重试、零结果与提供器失败分离、发明实用新型外观设计三类实时验收和 MIT 上游署名。
- 新增自有客户端运行门禁合同：SessionStart、UserPromptSubmit、Skill 激活、工具前后置和 Stop 由签名宿主插件执行；门禁缺失或崩溃时失败关闭，不以模型自觉遵守代替强制执行。
- 专业聊天结果新增本地候选正文校验：按当前 Skill 检查证据状态、来源类型、可复算计算、高企四栏和去 AI 味事实锁，并将通过校验的正文摘要绑定到当前轮次；最终输出发生变化时必须重新校验。
- 自有客户端固定 DeepSeek Harness 上游提交，升级必须重跑 Windows 与 macOS 等价决策、篡改拒绝、签名升级和回滚门禁；未完成双端签名与真实设备回执前不得称为正式客户端。
- 新增项目前期评估报告与项目申报可行性分析报告两类正式交付，前者服务谈单，后者逐项拆解现行条件、评分表、证据和补强任务。
- 高企、专精特新、小巨人、三首、研发中心、制造精品、单项冠军、绿色工厂、数字化及科技计划自动切换项目专属核心评估对象。
- 所有项目报告建议形成国内产品技术水平评价咨询报告和国际产品技术水平评价咨询报告；证据形成前不得承诺国内领先或国际先进。
- 专精线新增数字化转型诊断报告补强，核验五个一级维度、全国与同行对标、优势短板及提升路径。
- 高企新增研发费用加计扣除规范化服务，贯通立项、人员设备、工时领料、小试中试、结题、专利关联、月度分配、辅助账与明细账。
- 两类报告统一使用共创红色水印并输出可编辑 Word 与 PDF；无法只加密水印且保持正文可编辑时不设置编辑限制。
- 企业分析报告 A、B、C 版以及尖兵领雁、市级重大和科技计划类既有分析逻辑保持不变。
- 内置高企、专精特新、小巨人、三首、研发中心、制造精品、单项冠军、绿色工厂、数字化和科技计划二十四份 Word 母版，命中时先选版再回填。
- 模板索引对项目别名执行最长命中，对未知、冲突、哈希变更或覆盖现有文件一律拒绝。
- 共创企业助手 macOS 与 Windows 版由同一签名专业执行链识别完成交付语义，并强制当前轮次的 Skill、章节、表格、Word、PDF、哈希及红色水印验证回执。
- 新增真实客户原文锚点成稿器：客户原件必须位于公共技能树之外，原文锚点未命中或成稿仍有占位符时拒绝交付。
- 新增十二类候选流水线：产出二十四份 Word/PDF 完整成稿、逐页渲染，并从通用候选包和客户端内置技能资产执行选模成稿回归。

## 共创精选

共创精选不是再复制一套技能，而是把底层正式技能按中小企业可理解的成果重新组合为十二张业务卡片。企业申报体检、政策检索、项目可行性、高企、专精特新与小巨人、制造业升级、企业公开信息、知识产权与专利、财税核验、正式材料写作、材料一致性以及知识库联网检索均由签名清单映射到现有正式技能。

魔搭 Skills 与 SkillHub 作为社区浏览入口嵌入客户端。第三方项目只有在本地隔离区完成来源、许可证、恶意代码、网络与命令、平台兼容及摘要锁定检查后，才能由用户一键加入；网页不能直接写入正式技能目录。

## 国知局首轮发现

专利总路由优先以国知局公布公告页面发现中国专利题名、公开号、结果页摘要与公布日线索。入口当前为 HTTP，只允许发送脱敏短技术词；浏览器保留沙箱，不复用用户日常配置，不破解验证码。发现结果固定为 `prior_art_eligible=false`，必须回到官方全文、权利要求、附图和法律状态来源升级证据。

## 自有客户端防漂移门禁

自有客户端固定 DeepSeek Harness 上游提交 `47f943859bef60e4160492346772ded9b24f765a`。签名桌面宿主先验证运行时、策略和受控 Cordis 配置；原生 Cordis 门禁插件在首个可等待的 `agent/pre-step` 之前完成会话状态初始化，并执行用户提示轮次重置、Skill 激活登记、工具前后置政策和 Stop 交付门禁。专业任务还必须调用本地确定性校验器，最终回答与已校验候选不一致时继续阻断。中央工具代理阻止第三方插件绕过文件、网络、命令或浏览器政策。门禁缺失、崩溃或校验失败时拒绝启动或阻断当前动作，不能依赖模型自觉遵守。DSH 的 Codex Hook 兼容桥仅用于迁移旧配置，不作为正式强制边界。

企业数字身份证不进入插件包，客户资料、知识索引、账号凭据和签名私钥也不进入技能 ZIP 或客户端安装资产。

技能插件包与独立客户端分层发布。V1.6.6 只包含一个签名通用 Skills 资产；共创企业助手 V0.1 内置同一内容并额外验证技能索引、专业执行合同和宿主策略。独立客户端只有取得 macOS 签名与公证、Windows Authenticode、全新设备安装、真实专业执行链、升级及回滚回执后，才进入正式发布。
