# 企业全生命周期助手 V1.5.3

发布日期：2026年8月3日

V1.5.3 是当前对外发布的唯一最新版本。

V1.5.3 修复 WorkBuddy Hook 真实误阻断和 Windows 启动失效，补齐管理员用户调用统计、备份定时器恢复与 OSS 轻量校验。

## 本次发布

- WorkBuddy 改为 macOS 与 Windows 两个独立签名包，49 项 Skills 和共享 Python 行为核心保持逐字节一致。
- Windows 包使用原生 CMD 启动器，依次选择 py -3、python 和 python3，检查 .workbuddy 与 .codebuddy 活动路径，不依赖 Bash 或 PowerShell。
- 明确否定生成报告或正式材料以及只解释、只回答时，Hook 将 formal_business_delivery 设为 false，不再误触发正式交付门禁。
- 主业务 Skill、政策四项、同行对比和正式报告章节检查统一以 formal_business_delivery=true 为前提，普通政策答疑不再被误阻断。
- 管理员调用统计按用户 ID 合并多台电脑，分别展示今日、7日、30日业务调用和 MCP 连接、工具列表、检索、文档调用及最后活跃时间。
- MCP 连接和 tools/list 独立计数，不计入业务调用；管理员页面不展示完整个人 Token。
- 代码部署成功或回滚后都会重新启用备份定时器，避免部署流程停止定时器后未恢复。
- 生产环境新增每小时 OSS 签名指针与元数据轻量校验；仅在远端版本变化时下载并执行完整索引验证。
- 网站为 macOS 与 Windows 分别下发对应安装包，统一入口不再含糊返回跨平台 ZIP。
- 本次不修改知识索引；纯代码与 Skills 发布不运行全库扫描。

## 用户是否需要更新

- Windows 用户必须更新，V1.5.2 的 Hook 入口可能没有在实际 WorkBuddy 环境执行。
- macOS 用户建议同步更新，以取得本次误阻断修复和统一版本。
- 已安装旧版本的用户不需要手工删除插件；一键安装会清理活动搜索路径中的旧版并保留其他 MCP 配置。

## 验收标准

- 通用、macOS WorkBuddy 与 Windows WorkBuddy 三个包各含 49 项可识别 Skills，版本均为 1.5.3。
- 两个平台包的共享 Python 行为核心 SHA-256 相同；Windows 包含原生 CMD 启动器且不依赖 Bash 或 PowerShell。
- `不要生成报告，只解释申报条件`正常回答，不触发正式交付门禁。
- `请生成政府项目报告`仅加载 consistency-check 时触发 `NO_PRIMARY_BUSINESS_SKILL`。
- `简单解释申报条件`仅加载 policy-retrieval 时正常回答，不要求政策四项。
- `请生成政府项目可行性报告`加载 project-feasibility 但缺少行动清单时触发模板缺项阻断。
- 管理员统计按用户合并设备，并分别显示业务与四类 MCP 调用，页面不出现完整 Token。
- 生产备份与 OSS 轻量校验定时器启用且活动；远端索引未变化时不执行全库扫描或下载。
- 自动化发布门禁与 Windows CI 通过后即可正式发布；macOS、Windows WorkBuddy 实机验收由主人在发布后补录，不阻断正式发布。

## 回滚

- Skills 安装失败时恢复搜索路径外的安装前插件快照和原 MCP 配置。
- 代码部署失败时把生产 `current` 指针切回上一应用槽，知识索引指针保持不变，并恢复备份与轻量校验定时器。
- V1.5.3 产物按版本和哈希不可变；同名版本已存在不同内容时停止，不覆盖。
