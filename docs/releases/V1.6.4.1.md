# 共创研究院企业全生命周期助手 V1.6.4.1 功能简介

V1.6.4.1 新增统一的前期评估政策申报路径合同，要求企业前期评估与培育报告完整保留相关政策梯度，并以十二字段路径卡呈现能力建设、前置条件、申报节点、主管部门和材料闭环。

V1.6.4.1 同步发布 macOS 与 Windows WorkBuddy 包；企业数字身份证不进入插件包，外部企业数字身份证和知识索引继续由服务端单独管理。

## 本版本变更

- 新增前期评估政策路径总闸门，所有企业前期评估、培育规划、多项目矩阵和年度路线图必须先形成与企业相关的完整政策项目池。
- 统一合同同步到 project-matching、project-feasibility、sme-score-preassessment 和 sme-development-projects，研发机构、绿色工厂、数字化、知识产权和质量品牌等相关路径不得因当前不具备、暂不需要或优先级低而删除。
- 每个相关项目强制使用十二字段路径卡，覆盖政策状态、企业起点、能力建设、梯度依赖、申报节点、主管部门、证据材料、停项与重启条件及责任动作。
- 新增正常、边界和拒绝案例及交付自检，目标年度通知未发布时只按规划参考处理，并设置当期通知发布后的整体重检节点。

## 兼容与边界

- 正式技能数量和名称不变，继续以 `skills/suite-manifest.json` 为唯一机器可读基线。
- 本补丁只改变企业前期评估、培育规划、多项目矩阵和年度路线图的输出合同，不改写企业事实、政策原文或项目资格结论。
- “完整路径”限于与企业地域、行业、产品、经营实质和规划目标具有合理关联的项目；无关项目应排除并写明边界，不能扩张为跨行业政策百科。
- 企业数字身份证、企业数字孪生和知识索引均不进入插件包，本次发布执行服务器纯代码部署，不切换知识索引。
