# 共创研究院企业全生命周期助手 V1.6.19 发布说明

V1.6.19 修复制造企业财税报告计算过程与来源条目被截断的问题。

- 制造企业财税报告完整保留确定性计算指标和补充来源，不再按前八项或前十项静默截断。
- 计算过程与来源超过单页容量时自动续页，保留每项公式、输入与来源；总页数由实际生成结果返回。
- 技能说明和输入规范采用生成器返回的页数，不再将所有报告固定为十七页。
- 保留 V1.6.18 的确定性计算、专业交付有界修复和统一签名通用技能包能力。

共创独立客户端内嵌同一验签技能投影，客户端与技能包分别版本化。既有用户材料、个人偏好和连接凭据不因技能更新而覆盖。

macOS 与 Windows 客户端消费同一签名技能身份，各自安装包独立验收。通用包不携带用户凭据、客户资料或本地知识索引，企业数字身份证不进入插件包或技能包。

源码验证：财税报告 16 项测试及 16 个子测试通过；19 条合成计算与来源完整进入 18 页 PDF，续页与品牌水印验证通过。对应测试为 `tests/test_financial_facts.py` 与 `tests/test_portable_report.py`。
