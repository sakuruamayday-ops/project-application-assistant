# 企业全生命周期助手 V1.1

## 运行时维护

- WorkBuddy整包改用一份插件级共享运行时，不再在56个技能目录中重复复制运行时和安装检查器。
- 插件完整性校验增加短时缓存与文件状态失效机制，减少每次对话重复读取全部文件和调用验签进程。
- 文件哈希、签名或发布者身份异常继续阻断；偏好缓存、文件锁和可选环境能力异常改为警告降级，不再卡死正常会话。
- 偏好迁移器取消动态`exec()`，改为受控模块加载。

## 本次更新

- 团队标准 Skills 由53个扩展为56个，新增高企申报前评估、专精特新与小巨人申报前评分、标准撰写能力。
- 发布通用 Skills ZIP 与 WorkBuddy 插件 ZIP，两个版本包含相同业务能力。
- 增加56个 Skills 调用关系审计，明确总入口、内部路由、领域技能、质量门禁和受控自进化链路。
- 压缩便携运行门禁，保留首次配置、自进化、四问复盘和质量门禁，减少重复上下文。
- 增加高风险脚本单元测试，覆盖申报前评分、财务核验、项目检索金标准和标准起草审查。
- 发布元数据统一从 `suite-manifest.json` 生成，技能数量、版本、安装说明和双包清单不再手工维护。
- 增加政策新鲜度清单说明，明确政策版本、替代依据、核验状态和更新流程。
- 修复 WorkBuddy 安装说明中技能数量仍显示54个的问题。

## 升级方法

1. 登录团队网站，进入 Skills 下载。
2. 下载 V1.1 通用包或 WorkBuddy 插件包。
3. 使用新版官方 `skills` 替换旧版官方核心，保留个人项目资料、本地政策规则和结构化个人偏好。
4. 输入“请检查企业全生命周期助手是否安装完整，并启动首次配置向导”。
5. 完成团队知识库连接与宿主能力检查。
