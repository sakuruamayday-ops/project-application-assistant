# 共创研究院企业全生命周期助手 V1.6.5.1 候选功能简介

V1.6.5.1 是 V1.6.5 的候选补丁版。它不改变企业分析报告 A、B、C 版，也不改变尖兵领雁、市级重大及科技计划类的既有资格、技术、团队、预算、里程碑和验收分析逻辑。

本候选版为十二类常规政府项目内置“项目前期评估报告”与“项目申报可行性分析报告”二十四份可编辑 Word 受控母版，并增加项目别名选型、母版哈希、禁止覆盖、Word 与 PDF 双格式结构以及共创红色水印验证。

本候选版同步生成通用 Skills、macOS WorkBuddy 和 Windows WorkBuddy 签名候选包。企业数字身份证不进入插件包，企业数字身份证和知识索引继续由服务端独立管理，本次候选发包不切换知识索引。

## 候选变更

- 高企、专精特新中小企业、小巨人、首台套、首批次、首版次、企业研发中心、制造精品、制造业单项冠军、绿色工厂、数字化及科技计划类各内置两份 Word 母版。
- 命中受控项目时，Skill 必须先根据项目别名和报告类型选择母版，再回填企业与当期政策事实。
- 母版只固定结构、表格、项目专属核心对象和补强入口，不将占位条件作为现行政策证据。
- 所有 Word 母版保持正文可编辑，统一使用共创红色水印；不设置文档加密或编辑限制。
- macOS 和 Windows Stop Hook 统一识别完成交付语义和对象定向否定，并要求当前轮次的报告画像验证回执。
- 报告画像回执校验必备章节、必备表格、Word、PDF、文件哈希和共创红色水印；仅有对话中的“已完成”不能通过。

## 保持不变

- 企业分析报告 A、B、C 版不变。
- 尖兵领雁、市级重大和科技计划类既有专属分析逻辑不变，科技计划只复用双报告呈现与补强清单。
- 专精特新已形成申请书后的体检仍使用后期体检路由。
- 正式技能数量和打包范围继续唯一读取 `skills/suite-manifest.json`。

## 候选边界

V1.6.5.1 当前仅是已测试、已签名的候选发包目标。未经用户另行确认，不提升为 GitHub Latest、不发布到门户、不切换知识索引、不覆盖本机正式安装。
