# 共创研究院企业全生命周期助手 V1.6.5 功能简介

V1.6.5 为十二类政府项目统一建立“项目前期评估报告”和“项目申报可行性分析报告”两类交付，同时保留每类项目自己的政策条件、评分方法和证据逻辑。

本版本提供通用 Skills、macOS WorkBuddy 与 Windows WorkBuddy 三个平台签名包。企业数字身份证不进入插件包，企业数字身份证和知识索引继续由服务端独立管理，本版本不切换知识索引。

## 机器可读版本事实

V1.6.5 为十二类政府项目建立前期评估与可行性分析双报告路由，新增专精线数字化转型诊断和高企研发费用加计扣除补强，并统一共创红色水印与 Word、PDF 双格式交付。

- 新增项目前期评估报告与项目申报可行性分析报告两类正式交付，前者服务谈单，后者逐项拆解现行条件、评分表、证据和补强任务。
- 高企、专精特新、小巨人、三首、研发中心、制造精品、单项冠军、绿色工厂、数字化及科技计划自动切换项目专属核心评估对象。
- 所有项目报告建议形成国内产品技术水平评价咨询报告和国际产品技术水平评价咨询报告；证据形成前不得承诺国内领先或国际先进。
- 专精线新增数字化转型诊断报告补强，核验五个一级维度、全国与同行对标、优势短板及提升路径。
- 高企新增研发费用加计扣除规范化服务，贯通立项、人员设备、工时领料、小试中试、结题、专利关联、月度分配、辅助账与明细账。
- 两类报告统一使用共创红色水印并输出可编辑 Word 与 PDF；无法只加密水印且保持正文可编辑时不设置编辑限制。
- 企业分析报告 A、B、C 版以及尖兵领雁、市级重大和科技计划类既有分析逻辑保持不变。

## 本版本新增功能

- 前期评估报告面向首次接洽和谈单，先给结论，再列现行核心条件、企业已有数据、差距、补强动作和申报节点。
- 可行性分析报告面向合作后的实施决策，逐项拆解现行条件或已公布评分表、证据状态、确定分与条件分、补强材料、完成标准和年度倒排计划。
- 高企、专精特新、小巨人、首台套、首批次新材料、首版次软件、研发中心、制造精品、单项冠军、绿色工厂、数字化及科技计划自动切换核心评估对象。
- 普通项目的省、市、区县版本会改变规则且输入模糊时进行一次最小确认；三首项目由系统先评估国际、国内、省内或市级档次并给出首选和备选，不要求用户先选档。
- 当年度项目必须列完整截止日期；已截止或临近截止的复核、重新认定和在审项目转为通过保障、补正、审核闭环或下一批次安排。
- 所有项目建议形成国内产品技术水平评价咨询报告和国际产品技术水平评价咨询报告；目标可设为国内领先、国际先进，但证据形成前不得承诺结论。
- 专精线新增数字化转型诊断报告补强，覆盖总体水平、发展战略、业务创新转型、新型能力、系统性解决方案、治理体系、全国及同行对标、优势短板和提升路径。
- 高企新增研发费用加计扣除规范化服务，覆盖立项可研、人员设备、工时、领料、小试中试、项目变更、结题、专利关联、月度分配、研发辅助账和明细账，并与高企 RD、专项审计及纳税申报口径一致。
- 两类报告统一使用共创红色水印并输出 Word 与 PDF。标准权限无法只加密水印而保持正文完全可编辑，因此不设置文档编辑限制。

## 保持不变

- 企业分析报告 A、B、C 版不变。
- 尖兵领雁、市级重大和科技计划类既有资格、技术、团队、预算、里程碑及验收分析逻辑不变；科技计划仅复用双报告呈现和补强清单。
- 专精特新已形成申请书后的体检继续使用后期体检路由，不由前期谈单报告替代。
- 正式技能数量和打包范围继续唯一读取 `skills/suite-manifest.json`。
