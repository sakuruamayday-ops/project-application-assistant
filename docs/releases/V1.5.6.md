# 企业全生命周期助手 V1.5.6

发布日期：2026年8月3日

V1.5.6 是当前对外发布的唯一最新版本。本版本收敛 Windows WorkBuddy 行为 Hook，修复正式交付意图误判，并让生产代码发布具备可恢复的阶段回执。

## 本次发布

- Windows `hooks.json` 直接调用独立 `workbuddy_hook_windows.ps1` 处理 `UserPromptSubmit` 和 `Stop`，不再经过 Bash、CMD、路径转换或 Python 解释器发现，也不使用 `ExecutionPolicy Bypass`。
- Skill 内联激活继续由共享 Python 核心执行，并与 PowerShell Hook 读写同一 schema 3 状态：每条新提示重置轮次和 Skill，同轮激活持续累计，旧 `activation_fallback` 会被新提示覆盖。
- 正式交付意图改为确定性分句判断。否定、条件和引号讨论只影响所在分句，后置明确交付动作可以重新触发；业务领域词本身不会触发正式交付。
- 主业务 Skill、政策四项、同行对比和正式模板检查统一以 `formal_business_delivery=true` 为前提。普通询问申报条件或明确要求只解释时不再误阻断。
- 生产应用部署改为服务端事务、持久阶段回执和断线续验。控制端断线或长时间优雅退出后可继续核验同一事务，避免“生产成功、控制端误报失败”。
- 本版本没有知识内容或索引结构变化，生产只执行 `code` 模式；不运行全库扫描，也不切换知识索引。

## 用户是否需要更新

- Windows 用户应更新，旧 Bash→CMD→Python 链由独立 PowerShell Hook 替代。
- macOS 用户建议同步更新，以取得一致的正式交付意图规则和版本基线；macOS 启动链不变。
- 已安装旧版本的用户不需要手工删除插件。一键安装会把旧版移到活动搜索路径之外的回滚快照，只保留一个 V1.5.6 活动市场，并保留其他 MCP 配置。

## 验收标准

- 通用、macOS WorkBuddy 与 Windows WorkBuddy 三个签名包均包含 49 项 Skills，版本统一为 1.5.6。
- Windows 包含 `workbuddy_hook_windows.ps1`，不包含旧 `.sh` 或 `.cmd` 适配器；Windows Hook 命令不调用 Python，也不包含权限绕过参数。
- PowerShell Hook 与 Python Skill 激活使用同一 schema 3 状态协议，失败时返回单行失败开放 JSON，不把未执行写成检查通过。
- 否定、后置肯定、条件句、引号讨论、简版指代和普通政策答疑回归全部通过。
- 代码发布事务能够持久记录阶段、恢复轮询并核验生产 `current` 指针；知识索引指针保持不变。
- 自动化代码与封包门禁通过后正式发布；macOS、Windows WorkBuddy 实机验收由主人在发布后补录，不作为发布前阻断项。

## 回滚

- Skills 安装失败时恢复活动搜索路径外的安装前插件快照和原 MCP 配置。
- 代码部署失败时把生产 `current` 指针切回上一应用槽，并保留事务回执、日志与失败槽供复核。
- 知识索引未参与本次发布，不需要执行索引回滚。
- V1.5.6 产物按版本和哈希不可变；同名版本已存在不同内容时停止，不覆盖。
