# 专精行动型体检报告

版本：V1.7.1。状态：2026-09-29 已正式发布，GitHub、网站和客户端技能更新源已同步。

## 定位与范围

面向企业申报顾问，为专精特新中小企业和小巨人提供企业现状评估、产品定位、同行比较、培育路径与补强安排。保留五章19个内容块，程序固定表头和品牌格式；不替代完整申请书逐字段审查。客户资料不进入公开代码或技能包。

## 流程与实现

使用 project-feasibility.generate-report，report_layout为sme-action。具体流程见技能 references/sme-action-workflow.md。程序负责设备档位计算、文档结构与呈现；政策适用、企业事实及技术判断由经核验资料支持。

研发机构推荐使用固定资产元值的50%作为内部设备测算上限，与已核实适用的政策档位比较。该比例不是认定政策，不替代设备实际原值，不以总资产补位。缺值保留培育建议，估算不进入报告。产品项目围绕专精佐证作用推荐工业新产品及适用三首方向。
