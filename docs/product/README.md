# 企业全生命周期助手产品文档

更新日期：2026年7月28日

本目录是产品判断和版本规划的统一入口。发布说明、用户手册和技术文档继续保留在原目录，但产品定位、阶段目标、版本范围和优先级以本目录为准。

## 当前产品判断

企业全生命周期助手已经不是“待验证的 Skill 点子”，而是由 49 个 Skills、团队知识库、门户、REST API、MCP 和发布治理组成的可运行产品。当前最重要的问题不是扩充能力数量，而是让用户能够从一个真实业务问题出发，稳定完成从任务澄清到证据、判断、交付和复核的闭环。

当前阶段的唯一主线：

> 一个入口，一份项目档案，一条可验收闭环。

## 文档事实来源

产品基线优先按以下顺序核对：

1. `skills/suite-manifest.json` 中的正式套件版本、Skill 数量和依赖关系。
2. `docs/releases/` 中的正式发布说明。
3. `docs/user-guide/企业全生命周期助手用户使用手册.md` 中的当前用户可见能力；历史客户端 Word 手册只作发行审计。
4. `services/knowledge-portal/README.md` 中的门户、API、MCP 和安全边界。
5. 代码、测试和生产验收记录。

若 README、历史分发目录或旧规划文件与以上来源不一致，先标记为文档漂移，不静默选择对产品更有利的口径。
