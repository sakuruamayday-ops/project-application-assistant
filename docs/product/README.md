# 企业全生命周期助手产品文档

更新日期：2026年7月26日

本目录是产品判断和版本规划的统一入口。发布说明、用户手册和技术文档继续保留在原目录，但产品定位、阶段目标、版本范围和优先级以本目录为准。

## 当前产品判断

企业全生命周期助手已经不是“待验证的 Skill 点子”，而是由 56 个 Skills、团队知识库、门户、REST API、MCP 和发布治理组成的可运行产品。当前最重要的问题不是扩充能力数量，而是让用户能够从一个真实业务问题出发，稳定完成从任务澄清到证据、判断、交付和复核的闭环。

当前阶段的唯一主线：

> 一个入口，一份项目档案，一条可验收闭环。

## 文档地图

- [产品基线与定位](product-brief.md)：回答产品为谁服务、解决什么问题、当前已经做到哪里，以及哪些边界不能突破。
- [V1.2 PRD Lite](prd-v1.2.md)：定义下一阶段要解决的核心问题、范围、需求和验收标准。
- [产品路线图](roadmap.md)：明确当前阶段优先级、暂不推进项、发布节奏和评审条件。
- [外部产品与研发技能评估](external-tools-evaluation.md)：记录本轮对 pm-workbench、Spec Kit、UI UX Pro Max 及研发类 Skills 的核验与采用结论。

## 文档事实来源

产品基线优先按以下顺序核对：

1. `skills/suite-manifest.json` 中的正式套件版本、Skill 数量和依赖关系。
2. `docs/releases/` 中的正式发布说明。
3. `docs/user-guide/企业全生命周期助手用户使用手册.md` 中的用户可见能力。
4. `services/knowledge-portal/README.md` 中的门户、API、MCP 和安全边界。
5. 代码、测试和生产验收记录。

若 README、历史分发目录或旧规划文件与以上来源不一致，先标记为文档漂移，不静默选择对产品更有利的口径。

## 文档状态

本轮形成的是可评审的产品基线和 V1.2 建议稿。V1.2 尚未自动进入开发或发布；确认 PRD 后，再按 Spec Kit 的顺序形成 `spec.md`、`plan.md` 和 `tasks.md`。
