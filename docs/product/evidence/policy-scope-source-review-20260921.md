# 复核范围文字修改核验

本次文件差异只有复核范围段落：删除对整个批次已经结束的静态推定，改为按通知期间、指定对象及任务已确认版本判断。工信部[当期通知](https://wap.miit.gov.cn/jgsj/qyj/wjfb/art/2026/art_83857a4773ac4583bd1540eeb78bcbcb.html)全文已读取，分别列明指定复核对象、填报期间、标准过渡规则及名单印发前后的称号状态。新表述与这些限定一致，不恢复历史估分工具，不声称当前仍可新申报。

来源摘要更新仅绑定已审阅的文字变动；清单中其余政策条目的原核验日期及下次复核日期不延长，未将局部核验写成所有条目重新核验。
