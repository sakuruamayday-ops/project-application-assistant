# 三年财务自动评分链路

## 输入

优先接收 `assets/专精特新与小巨人客户评分_三年财务底表模板.xlsx`。字段等价的客户表也可先转换到该模板，不改变原始数值。

固定输入位置：

| 单元格或区域 | 内容 |
|---|---|
| B3 | 企业完整名称 |
| B4 | 统一社会信用代码，可空 |
| B5 | 主导产品或核心产品，可空，由企查查与企业资料补齐 |
| B6 | 行业提示，可空 |
| B7 | 近一年对应的实际财务年度 |
| B8 | 拟评估版本，可暂不填；评分前必须由用户明确确认 |
| C11:E19 | 营业收入至负债总额 |
| C21:E24 | 年平均从业人数及可选研发、主营、主导产品收入 |

金额单位统一为万元，人数为人。
三列固定表示近三年、近两年、近一年，按时间先后填写；模板不写死具体自然年度。

客户保存时必须把文件名改为“企业完整名称_三年财务底表.xlsx”。评分脚本会核对文件名是否包含 B3 的企业完整名称；不一致时停止，避免客户资料串档。

## 自动步骤

1. 版本确认：用户回传底表后，先确认使用省级专精特新中小企业版还是专精特新“小巨人”版；未确认时停止。将用户确认值通过 `--project-level` 传入，覆盖底表中的空白或暂存值。
2. 主体锚定：企业名称不是完整登记名时，先用企查查实体识别；多候选由用户确认。
3. 公开核验：查询登记行业、经营范围、产品线索、有效专利、资质、荣誉和标准。将结果整理为事实 JSON，不把企查查财务数据写入客户财务底表。
4. 行业映射：优先按主导产品实质匹配 `assets/nbs_industry_map.json`，其次参考经营范围和登记行业。输出行业代码、名称、依据和置信度。
5. 统计局刷新与地域路由：
   - B8 为省级专精特新中小企业时，结构指标和同比增长均采用浙江省统计局口径；结构指标来自浙江统计年鉴“按行业分的规模以上工业企业主要经济指标”，增长指标优先采用浙江省同地域分行业年度快报，未发布时采用最近两期浙江统计年鉴同口径计算。
   - B8 为专精特新“小巨人”时，结构指标和增长指标采用国家统计局全国口径；年鉴结构指标来自国家统计局表 13-2。
   - 不得在同一组八项指标内把浙江结构值与全国增长值拼接。浙江目标行业未命中时停止自动评分并报告地域数据缺口，不静默切换全国基准。
   - `scripts/zhejiang_fetch.mjs` 默认读取浙江统计年鉴目录，识别已正式发布的最近三个年鉴版本，并直接解析官方网页嵌入的分行业结构数据。
   - `scripts/nbs_fetch.mjs` 默认使用 `--years auto` 读取国家统计局年鉴目录，识别已正式发布的最近三个年鉴版本，并从编者说明识别表内数据期。报告必须同时显示“结构数据期”和“年鉴版本年份”。
   - `scripts/nbs_fetch.mjs` 下载官方 JPG，调用 macOS Vision OCR，按固定列位解析，并与 41 个行业名称逐行校验。
   - 最新年度快报URL由当轮检索国家统计局官方发布页取得，通过 `--annual-url` 与 `--annual-year` 传入。快报用于营业收入和利润增长率。
   - 官方新年鉴尚未发布时，使用最近完整年鉴，并在报告中显示结构数据期和年鉴版本年份；不得把年鉴标题年份当作表内数据期，也不得伪造当年结构值。
6. 八项计算：运行 `scripts/run_score.sh --mode score`，计算人均营业收入、净资产收益率代理、成本利润率代理、销售和管理费用率、毛利率代理、营业收入增长率、利润增长率、净资产增速。
7. 三档判断：
   - 高值更优指标：企业值达到行业值的 120% 为领先档；达到行业值为达标档；其余为追赶档。
   - 销售和管理费用率：不高于行业值的 80% 为领先档；不高于行业值为达标档；其余为追赶档。
   - 行业增长率为负时，企业转正为领先档；仍为负但不低于行业为达标档；其余为追赶档。
   - 得分比例依次为 100%、60%、40%。八项满分合计 29 分。
8. 目标反推：
   - 费用率：目标费用额＝最新营业收入×下一档目标费用率；改善金额＝当前销售费用与管理费用合计－目标费用额。
   - 毛利率：目标成本＝最新营业收入×一减下一档目标毛利率；改善金额＝当前营业成本－目标成本。该金额也等于收入不变时所需增加的毛利。
   - 利润增长率：目标利润总额＝上年利润总额×一加下一档目标增长率；改善金额＝目标利润总额－本年利润总额。
   - 追赶档的下一目标为达标档，达标档的下一目标为领先档；已经领先时显示保持领先，所需改善金额为零。
   - 反推是静态情景，不把收入、销量、价格和产品结构同时变化造成的二阶影响伪装成精确预测。
9. 总分合成：全指标评分底稿固定22项、满分100分；财务八项与非财务十四项逐项求和形成保守、基准、条件三档总分。条件未完成前不得并入保守档。
10. 验收：扫描公式错误，检查文件名、三年资产不低于负债、必填字段完整、统计局行业存在、年份不晚于企业财务年度，并渲染全部工作表做视觉检查。

## 执行方式

先通过工作区依赖加载器取得 Node 与 node_modules 路径，再设置：

```zsh
export SME_SCORE_NODE_BIN="<loader-provided-node>"
export SME_SCORE_NODE_MODULES="<loader-provided-node_modules>"
```

生成标准输入模板：

```zsh
scripts/run_score.sh --mode template --output "<output.xlsx>"
```

生成评分报告：

```zsh
scripts/run_score.sh \
  --mode score \
  --input "<三年财务底表.xlsx>" \
  --facts "<企查查与非财务计分.json>" \
  --benchmark "assets/nbs_benchmarks_2022_2025.json" \
  --zhejiang-benchmark "assets/zhejiang_benchmarks_latest.json" \
  --output "<企业_自动评分.xlsx>" \
  --preview-dir "<预览目录>"
```

项目层级以用户回传底表后明确确认的版本为准，并使用 `--project-level "省级专精特新中小企业"` 或 `--project-level "专精特新“小巨人”"` 传入。底表 B8 仅作暂存；未取得用户确认时不得自行采用。确认版本必须写入报告总览和校验页。

刷新浙江省行业缓存：

```zsh
node scripts/zhejiang_fetch.mjs \
  --output "assets/zhejiang_benchmarks_latest.json"
```

## 异常与回退

- Vision OCR 不可用时，优先调用当前可用的 PP-StructureV3 或 PP-OCR 工具解析官方图片，并按同一 41 行、14 列结构写入缓存。
- 国家统计局年鉴目录暂时不可访问时，不覆盖原缓存；沿用上次已核验缓存，并在校验页显示缓存的数据期、年鉴版本和访问日期。
- OCR 行业匹配少于 35 行、目标行业缺字段或列位异常时，不覆盖原缓存；明确报告“统计局刷新失败，沿用最近已核验缓存”。
- 最新年度快报未覆盖某行业时，增长率退回最近两期年鉴同口径计算，并在采用值说明中标注。
- 浙江省尚未发布更晚的完整分行业结构表时，继续采用最近一期浙江统计年鉴，并显示结构数据期和发布滞后；不得把全国当年值写成浙江值。
- 行业映射置信度低且两个候选会造成明显不同结果时，输出两种敏感性情景并请求用户确认，禁止擅自选高分行业。
