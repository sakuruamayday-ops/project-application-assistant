# 标准撰写技能来源记录

## 规范依据

- GB/T 1.1-2020《标准化工作导则 第1部分：标准化文件的结构和起草规则》。
- 全国标准信息公共服务平台显示该标准为现行，2026年1月8日复审结论为继续有效。
- 官方查询：https://std.samr.gov.cn/gb/search/gbDetailed?id=A24AF19F41445C2EE05397BE0A0A5E0D

Skill未打包或再分发国家标准PDF全文，仅将执行标准起草任务所需的流程、结构门禁和核验规则重新组织为原创工作流。执行具体任务时仍需核验标准现行状态并读取合法取得的原文。

## 自有培训材料

- 共创集团《企业标准撰写》培训文件。
- 权利归属：用户自有。

Skill吸收了培训材料中的企业产品标准结构、条款助动词、要求与试验方法对应、检验规则及编制实务，由本项目重新编排为标准设计、正文起草、编制说明和自动审查流程。
