# 项目申报助手用户使用手册

## 1. 下载与安装

### 下载 Skills

1. 打开团队管理员提供的知识服务网站。
2. 注册或登录团队账号。
3. 进入“Skills 下载”，下载最新版 ZIP。
4. 解压 ZIP，将其中的 `skills` 文件夹拖入当前 Agent 支持的 Skills 目录或工作区。
5. 重新打开 Agent 对话，输入：

```text
请检查项目申报助手是否安装完整，并启动首次配置向导。
```

项目包只提供平台无关 Skills，不包含 Codex、Claude Code、Hermes或其他平台的专属适配文件。如果当前 Agent 不能直接识别 `SKILL.md`，应使用该平台自己的 Skill 导入或转换能力。

### 补齐通用能力

首次安装完成后，在当前 Agent 对话框输入：

```text
帮我安装OCR、PDF、Word、PPT、Excel和联网检索这几个Skills
```

PDF、Word、Excel、PPT、OCR和联网检索由用户所在 Agent 平台提供，项目申报助手不重复打包。

## 2. 注册与登录

1. 打开团队知识服务网站的注册页。
2. 登录账号使用英文，长度为 3 至 32 位，可以包含数字、点、下划线和连字符。
3. 输入公司全称 `共创集团` 完成团队验证。
4. 密码至少 9 位。
5. 登录时可选择“七天自动登录”。公共电脑不建议启用。
6. 页面右上角提供“退出登录”，用于切换账号。

英文账号只用于登录网站。生成个人调用凭据时必须填写使用人的中文真实姓名。

## 3. 配置云端知识库

### 生成个人调用凭据

1. 登录后进入“API 与用户凭据”。
2. 填写使用人的中文真实姓名。
3. 再次输入公司全称 `共创集团`。
4. 点击“验证并生成”。
5. 复制网站一次生成的完整接入配置。

标准配置包括：

```text
JIAOTANG_KB_ENDPOINT=https://knowledge.example.com
JIAOTANG_KB_MCP_URL=https://knowledge.example.com/mcp/
JIAOTANG_KB_TOKEN=个人访问凭据
```

网站生成的是个人调用凭据，不是模型 API。该凭据用于团队知识库 API、MCP、使用统计和最新版 Skills 查询。

### 运行首次配置向导

输入：

```text
请运行 first-run-configuration，检查团队知识库、企查查、专利数据、联网检索、OCR和文档能力。
```

向导会输出已配置能力、缺失能力、可用降级方式和需要用户完成的授权步骤。不同 Skills 不应重复要求配置同一供应商。

## 4. 日常使用方法

### 直接描述任务

日常使用不需要记忆 Skill 名称。直接说明企业、地区、项目、资料和希望得到的结果，总入口会选择适合的 Skills。

例如：

```text
分析宁波北仑力盛机械有限公司目前能申报哪些项目，并给出未来五年规划。
```

```text
检查这家企业申报专精特新和小巨人还缺什么，并匹配产业链和工业六基分类。
```

```text
查一下这家企业的同行中有没有已经认定的小巨人企业。
```

```text
分析这项产品是否存在专利侵权风险，并给出专利布局方向。
```

### 项目申报分析

推荐提供：

```text
企业名称：
所在地区：
主营产品：
计划申报项目：
已有材料：
希望输出：资格判断、差距、材料清单和时间计划。
```

系统按企业画像、地区和项目识别、政策原文核验、资格计算、风险判断和材料建议的顺序工作。未取得可靠数据时不推算企业财务，不承诺企业一定符合或一定获批。

### 企业全景分析

输入：

```text
请对某某有限公司做合作前企业全景分析，输出销售版和深度顾问版报告。
```

系统根据当前可用能力查询工商、股权、风险、知识产权、产品、行业、同行和项目线索。无法取得的字段列为资料缺口，不得补造。

### 专精特新与小巨人体检

输入：

```text
请按当前申请书版本体检这家企业的专精特新或小巨人申报材料。
```

使用前必须识别申请书项目类型和版本，并由用户确认审核版本。主导产品、补短板、填空白和国产替代分别给出“保留、替换、补证后保留”结论。

产业链和工业六基匹配严格依据包内《产业链架构》和《产业基础创新发展目录（2021年版）》。没有直接命中时，输出一个相似分类和一个分析判断分类，并说明依据。

### 专利工作

可以直接提出：

- 检索某项技术的相似专利。
- 分析权利要求保护范围。
- 比较公开文本和授权文本。
- 对产品进行 FTO 初筛。
- 制定年度专利挖掘和布局计划。
- 审查交底书、权利要求书或说明书草稿。
- 对标龙头企业专利布局和技术路线。

专利任务应区分有效授权、审中、失效和转让取得。审中专利不得作为授权成果用于申报判断。

### 制造企业金税财务体检

输入：

```text
请分析这家制造企业近三年审计报告，复算财务指标，筛查税务风险，并输出90天整改路线。
```

建议提供近三年审计报告、纳税申报表、发票、银行流水、存货台账、合同和研发辅助账。只提供审计报告时，可以完成财务趋势和风险信号分析，但不能替代交易级税务核验或税务鉴证。

### 法律法规检索

输入：

```text
请按国家、浙江省、杭州市和具体区县，检索这家企业申报某项目涉及的法规、管理办法和合规风险。
```

建议同时说明基准日期、企业地区、行业、产品、具体行为、项目类型和结论用途。正式判断必须核验现行官方原文及当期申报通知。

### 本地政策规则维护

团队成员可以使用 `project-rule-manager` 在自己的工作区维护所在地区政策规则，包括新增、修改、停用政策和调整来源说明。

本地政策规则只影响当前用户，不会自动写入团队云端知识库。正式申报判断仍需回到政府官方原文核验。

## 5. 外部能力配置

### 企查查

企查查用于企业工商、股权、风险和知识产权画像。需要用户自行注册并按供应商规则配置 API 或 MCP。

注册链接：`https://agent.qcc.com/invitation?code=3ZRZPHF7Q5MH4&ch=LINK_COPY`

企查查数据不能替代合作客户提供的现行财务资料，也不能替代专利登记簿和政府政策原文。

### 专利数据

批量专利检索可以配置 BigQuery Patents 或其他合法专利数据源；单件核验可以使用国家知识产权局、欧洲专利局等官方服务。

专利数据源未配置时，系统应输出检索计划和人工核验路径，不得伪造检索结果。

### 企策顾问和网页采集

企策顾问用于发现项目和政策线索，需要用户自行注册。站内结果只能作为发现线索，正式条件、金额、日期和名单必须回到政府原文核验。

当前网页任务使用宿主浏览器、Playwright或用户合法配置的网页能力。

## 6. 云端权限和接口

所有团队成员使用统一知识读取权限。普通成员不能向团队云端知识库上传、修改或删除资料；云端资料由管理员统一维护。

知识库接口：

```text
POST /v1/search
GET  /v1/documents/{id}
GET  /v1/me
GET  /v1/usage
GET  /v1/skills/latest
GET  /v1/skills/latest/download
MCP  /mcp/
```

## 7. 自进化与四问复盘

项目申报助手安装完成后，受控自进化、经验记录和任务结束四问复盘默认启用。

系统可以记录用户纠正和失败原因、检查受影响的 Skills、累积改进候选并给出回滚范围，但不得未经审批直接修改或发布正式团队 Skill。

复杂分析、客户项目、正式材料或重要规则变化结束时，应回答：

1. 眼下最没有把握的事情是什么。
2. 最大的遗漏是什么，还有什么没有意识到。
3. 对当前成果最有价值的创新改进是什么。
4. 可以怎样提高本次任务效率。

## 8. 常见问题

### 为什么没有自动调用知识库

检查是否运行了 `first-run-configuration`，以及团队知识服务地址、MCP地址和个人调用凭据是否已经写入当前 Agent 的安全配置。

### 为什么不能上传政策到云端

普通成员只有读取权限。个人地区政策使用 `project-rule-manager` 保存到当前工作区；团队云端资料由管理员维护。

### 为什么不能直接生成Word、Excel或PDF

项目包不重复提供通用文档 Skills。请先在宿主 Agent 中安装对应的 PDF、Word、Excel、PPT 和 OCR 能力。

### 为什么政策结论提示需要再次核验

知识库可能保留历史政策和候选版本。项目条件、截止日期、金额和效力状态必须回到当期官方通知核验。

### 更新版本会不会覆盖个人政策规则

标准 Skills 更新包不应覆盖用户工作区中的个人政策规则、项目资料和交付成果。升级前仍建议备份当前工作区。
