# 飞书配置

飞书通道通过用户自建应用或Hermes现有网关接入。官方入口：[飞书开放平台](https://open.feishu.cn/)。

## 配置

```text
FEISHU_APP_ID=用户自己的应用ID
FEISHU_APP_SECRET=用户自己的应用密钥
```

用户需要在开放平台完成应用创建、机器人能力、事件订阅、权限申请和发布。权限应限制到实际需要的消息范围。

## 验证

1. 检查应用授权状态。
2. 向测试会话发送一条确认消息。
3. 接收一条测试消息。
4. 验证附件大小、Markdown和长消息处理。

## 安全边界

- 未经确认不主动发送。
- 不默认群发。
- 不在日志输出App Secret和完整消息原文。
- 客户材料发送前再次确认目标会话。

## 撤销

禁用配置、删除环境变量，并在飞书开放平台撤销应用权限或轮换密钥。
