# 政府网站与浏览器配置

用途：检索管理办法、当期通知、指南、公示和官方答疑。

具体网页导航、动态筛选、翻页、下载和登录态操作统一使用 `web-task-operator` 的安全执行规则；本文件只说明政府来源配置。

## 配置方式

优先使用宿主平台浏览器、官方网页检索或用户配置的Playwright/MCP。登录网站必须由用户亲自授权。

## 验证

1. 打开一个政府部门首页。
2. 检查HTTPS、域名和主管部门名称。
3. 搜索一条公开通知。
4. 验证标题、发布日期、文号和附件链接。

## 规则

- 政府官方来源优先于第三方平台。
- 控制访问频率和下载量。
- 不绕过验证码和访问控制。
- 下载文件记录官方URL、获取时间和SHA-256。

## 降级

浏览器不可用时使用平台网页搜索；仍不可用时要求用户提供政策原文。
