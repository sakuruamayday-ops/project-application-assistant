# 企查查配置

用途：查询企业工商、股权、经营风险、知识产权、资质和荣誉。用户必须通过企查查官方或合法授权方式取得访问权限。

官方入口：[企查查企业信息](https://www.qcc.com/)；本项目不提供账号、Token或代理接口。

## 配置

```text
QCC_MCP_TOKEN=用户自行取得的凭据
```

在宿主平台配置企查查MCP后，将 `config/common.yaml` 中的 `providers.qcc.enabled` 改为 `true`。

## 最小权限

- 默认仅查询。
- 不允许项目申报助手修改企查查数据。
- 调用前提示可能消耗接口次数或积分。

## 验证

1. 检查MCP连接状态。
2. 使用无敏感性的企业名称做一次最小查询。
3. 检查返回字段、限额和错误信息。

## 降级

未配置或额度不足时，使用用户提供的企业材料和政府公开来源。不得使用过期缓存补造企业现状。

## 隐私与撤销

不把Token和企业原始敏感数据写入日志。停用时删除环境变量、移除MCP配置，并在企查查侧撤销或轮换凭据。
