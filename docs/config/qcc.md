# 企查查配置

用途：查询企业工商、股权、经营风险、知识产权、资质和荣誉。用户必须通过企查查官方或合法授权方式取得访问权限。

智能体数据平台邀请入口：[登录企查查智能体数据平台](https://agent.qcc.com/invitation?code=3ZRZPHF7Q5MH4&ch=LINK_COPY)。本项目不提供账号、API Key、Token或代理接口。

## 宿主平台连接步骤

1. 通过上方邀请入口登录企查查智能体数据平台。
2. 在平台中获取个人 API Key。
3. 将 API Key 配置到宿主平台要求的凭据位置、环境变量或连接器配置中。
4. 通过宿主平台支持的官方连接器、MCP或用户自建合法接口，使用一家非敏感企业做最小查询测试。
5. 确认企业基本信息、知识产权等授权字段能够正常返回后再正式使用。

如执行查询时尚未登录，网页任务执行Skill应打开企查查官方登录页面并显示浏览器。用户亲自输入账号密码、扫码或完成验证码，确认登录后再继续；Agent不得读取或保存登录凭据。

平台额度、计费和权限以企查查智能体数据平台实时页面为准。

## 配置

```text
QCC_API_KEY=用户从企查查智能体数据平台自行取得的API_Key
```

宿主平台完成合法连接后，将 `config/common.yaml` 中的 `providers.qcc.enabled` 改为 `true`。具体变量名以所使用连接器的官方说明为准，不要求连接器必须读取上方示例变量。

## 最小权限

- 默认仅查询。
- 不允许企业全生命周期助手修改企查查数据。
- 调用前提示可能消耗接口次数或积分。

## 验证

1. 检查MCP连接状态。
2. 使用无敏感性的企业名称做一次最小查询。
3. 检查返回字段、限额和错误信息。

## 降级

未配置或额度不足时，使用用户提供的企业材料和政府公开来源。不得使用过期缓存补造企业现状。

## 隐私与撤销

停用时移除对应环境变量或MCP配置，并在企查查侧撤销或轮换凭据。
