# 模型服务配置

项目申报助手优先使用当前宿主平台提供的模型。只有用户主动选择外部API时，才读取对应环境变量。

## 可选变量

```text
OPENAI_API_KEY
ANTHROPIC_API_KEY
OPENAI_BASE_URL
ANTHROPIC_BASE_URL
```

不要把真实值写入 `config/*.yaml`、技能、日志或Git仓库。优先使用系统钥匙串、平台原生密钥管理或仅对当前进程生效的环境变量。

## 验证

1. 检查变量是否存在，但不显示变量值。
2. 发起最小非敏感测试请求。
3. 显示模型名称、连接状态和可能产生费用的提示。

## 降级

外部API不可用时，回退到宿主平台当前模型。不得为了继续任务而读取其他用户的密钥。

## 撤销

删除环境变量或钥匙串条目，并在供应商控制台轮换或撤销密钥。
