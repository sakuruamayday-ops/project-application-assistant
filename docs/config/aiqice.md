# 企策顾问配置

用途：提供政策标题、项目分类和奖补企业线索。企策顾问只能作为检索索引或补充来源，不能替代政府官方政策原文。

入口：[企策顾问](https://aiqice.cn/)。用户自行注册、登录并遵守平台服务条款。

## 配置

推荐使用用户浏览器中的正常登录会话。确需自动化时，账号信息只通过安全环境提供：

```text
AIQICE_USERNAME
AIQICE_PASSWORD
```

不得将Cookie、账号或密码提交到Git仓库。

## 验证

1. 用户自行完成登录。
2. 读取项目列表或一条政策标题。
3. 提取来源部门和官方原文链接。
4. 回到政府网站核验全文。

## 使用限制

- 不绕过登录、付费、验证码或访问控制。
- 不高频抓取，不公开再分发登录页面全文或数据库。
- 访问方式以平台当期条款和用户授权为准。

## 降级与撤销

未配置时直接检索政府网站。停用时退出登录、清理本项目浏览器会话并删除环境变量。
