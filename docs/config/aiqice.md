# 企策顾问配置

用途：提供政策标题、项目分类和奖补企业线索。企策顾问只能作为检索索引或补充来源，不能替代政府官方政策原文。

入口：[企策顾问](https://aiqice.cn/)。用户自行注册、登录并遵守平台服务条款。

## 配置

使用用户浏览器中的正常登录会话，不要求在配置文件或环境变量中填写账号密码。

需要企策顾问登录态时，由网页任务执行Skill打开官方登录页面并显示浏览器。用户亲自输入账号密码、扫码或完成验证码，确认登录后再继续只读查询、筛选或索引任务。Agent不得读取或保存账号密码、验证码、Cookie和会话令牌。

企策顾问提供扫码登录时默认优先扫码。登录后若宿主无法操作页面，但用户本人仍能正常访问，则按照浏览器类型输出Safari、Chrome、Edge或Firefox开发者工具提示，在浏览器同源页面本地执行请求并下载业务数据。完整cURL、Cookie和认证Header不得发送给Agent。

## 验证

1. 用户自行完成登录。
2. 读取项目列表或一条政策标题。
3. 提取来源部门和官方原文链接。
4. 回到政府网站核验全文。

2026-07-13 已使用 macOS Safari 登录会话完成检索、类别筛选、详情读取、翻页和截图定位测试。运行时按“可访问性定位—截图定位—人工接管”三级路径执行，不保存固定坐标。

## 批量索引

批量索引必须先约定关键词、类别、地区、页数、频率、字段和输出位置。先验证一页样本，再逐页提取标题、地区、类型、发布日期、发文机构、文章来源、申报状态、详情链接和官方原文链接，并以详情页标识优先去重。

执行时先读取并去重列表字段，只对缺少正文、官方链接或必要字段的记录打开详情页。浏览器本地重放的分浏览器指引见 `skills/web-task-operator/references/browser-local-replay.md`。

详细执行协议见 `skills/web-task-operator/references/aiqice-browser-profile.md`。第三方页面和AI解读只作为索引；进入知识库前必须记录官方原文核验状态。

## 使用限制

- 不绕过登录、付费、验证码或访问控制。
- 不高频抓取，不公开再分发登录页面全文或数据库。
- 访问方式以平台当期条款和用户授权为准。

## 降级与撤销

未登录时直接检索政府网站。停用时退出登录并清理本项目浏览器会话。
