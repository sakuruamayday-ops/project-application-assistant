# 团队云端知识与本地规则配置

团队资料默认通过云端REST API读取，不再要求成员挂载本地知识库。成员自行增改的地区政策保存在当前工作区 `project-rules/`，不上传或覆盖团队云端资料。

## 配置

普通成员登录门户后点击“复制给 Agent”，再把整段文字粘贴到当前本地 Agent。Agent 自动完成设备公钥登记、系统安全存储、`jiaotang-kb` MCP 配置和连接验证。成员不需要复制 Token、设置环境变量或编辑 JSON。

管理员账号属于设备限制豁免账号，可继续使用门户提供的管理员 API Key。

## 索引规则

- 普通成员私钥只保存在本机：macOS 使用系统钥匙串，Windows 使用当前用户 DPAPI。
- 云端只保存公钥，并对请求时间、nonce、正文哈希和访问凭据指纹进行验签。
- 每个普通成员账号同时只允许一组有效设备公钥；换机前先在门户执行“更换绑定设备”。
- 云端命中必须保留文档ID、原文件路径和来源。
- 本地规则必须保留来源、版本和修改审计。
- 命中政策和案例后回到原文件或政府官方来源核验。

## 验证与降级

安装代理会先调用 `/v1/me`，再由 MCP 完成最小连接检查。云端不可用时使用用户本地规则、当前会话文件和政府官方来源，并明确当前检索层不可用。
