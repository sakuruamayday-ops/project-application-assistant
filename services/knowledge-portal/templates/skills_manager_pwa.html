01

两种交付方式

PWA由HTTPS门户承载；可选桌面客户端明确标注为未签名本机授权版，不冒充操作系统可信软件。

02

内容完整性

浏览器下载后重新计算SHA-256，只有与门户发布元数据完全一致才允许解包。

03

文件权限

File System Access权限由浏览器弹窗授予；网页无法扫描整台电脑，也不能越过用户选择的目录。

04

WorkBuddy边界

PWA只下载现有发布者签名包，不执行网页返回命令。Ed25519不是Gatekeeper或Authenticode信任；系统阻断时应停止，不提供绕过步骤。

浏览器与本机策略

目录同步需要桌面版Chrome或Edge。Safari和Firefox当前只提供包下载；未签名桌面客户端也可能被企业策略完全阻止。管理员权限只负责提权，不能替代 Developer ID 或 Authenticode。
