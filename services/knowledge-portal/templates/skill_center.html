手工配置 WorkBuddy

  1. 下载跨平台签名 WorkBuddy 插件市场包。
  2. 核对页面公布的 SHA-256 与包内 Ed25519 签名。
  3. 解压 ZIP，在 WorkBuddy 对话中执行 /plugin marketplace add <解压后的 jiaotang 目录>。
  4. 继续执行 /plugin install jiaotang-workbuddy-skills@jiaotang，然后按提示启用插件。
  5. 点击下方按钮生成并复制一次性引导地址；新建 WorkBuddy 会话，让 Agent 仅将它作为本地 jiaotang_kb_setup 工具参数调用一次。
  6. 确认工具清单出现 knowledge_search、knowledge_document 和 knowledge_service_status，并实际调用一个只读工具。
