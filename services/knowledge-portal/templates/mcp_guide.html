接入步骤

  1. 在工作台使用中文真实姓名生成个人 Token
  2. 在 Agent 平台新增远程 Streamable HTTP MCP
  3. 填写上方地址和 Authorization 请求头
  4. 先调用 knowledge_service_status 验证连接
  5. 使用 knowledge_search 检索，再用 knowledge_document 读取原文
