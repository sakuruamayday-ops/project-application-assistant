# 影响报告

## 风险判断

风险等级为受保护变更。候选触及全部正式 Skills 的运行协议与签名清单、首次配置、专业交付终态、模板和通用打包入口，因此必须绑定主人对 V1.6.17 的正式发布授权。签名私钥本身、用户凭据、生产知识索引和客户端业务代码不在本工作树修改范围。

## 影响范围

| 对象 | 处理 | 影响 |
|---|---|---|
| 51 项正式 Skills | 修改并重新签名 | 统一宿主中立 prepare、授权与有界执行语义 |
| 签名和发布者信任 | 保留并强化分层 | 内容或指纹冲突失败关闭；偏好故障不再冒充全局签名失败 |
| 首次配置 | 收窄 | 本轮已有能力直接复用，只配置实际缺失项 |
| 模型与推理档位 | 不写死 | 完全沿用用户在当前任务的实际选择 |
| SME 事实锁与写作结构 | 完整继承 | 五份来源资源保持版本确认、事实边界、三档判断及三段加五段结构 |
| 正式文档和模板 | 修复 | 扩展真实内容识别、分页与字体嵌入，并保留模板保真边界 |
| 通用包 | 唯一正式发布物 | 一份签名 ZIP，不生成平台专用插件包 |
| 独立客户端 | 只约束同源投影 | 使用本次签名包；客户端代码、安装包和双端验收由客户端主线完成 |
| 知识索引与企业身份 | 不变 | 不进入本次技能构建输入，也不执行索引切换 |
| 本机旧工作树 | 不变 | 保留原有未提交内容，全部发布工作在隔离工作树进行 |

## 失败与恢复

- 源码或清单测试失败：不提交、不打包。
- 逐技能签名或固定发布者核验失败：停止使用受影响候选，不降级绕过。
- 通用包隔离安装失败：保留签名候选与回执，不创建正式 Release。
- 本地安装后回归失败：恢复 V1.6.16 正式技能目录和 V1.15.7 发布管理器。
- 客户端投影不一致：客户端不得重新打包另一份 V1.6.17，必须重新消费本次精确 SHA-256。
