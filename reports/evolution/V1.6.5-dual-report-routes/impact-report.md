# V1.6.5 双报告路由影响报告

## 风险等级

中风险。变更跨越总路由、可行性主技能和七个项目领域技能，并新增两类报告交付合同；不修改权限、凭据、远程 MCP、知识索引、签名算法或安装运行时。

## 影响图

| 对象 | 处理 | 影响 |
|---|---|---|
| `project-feasibility` | 新增双报告合同 | 区分首次谈单与合作后实施分析，统一截止日期、证据状态、科技咨询补强和品牌交付 |
| `project-task-router`、`project-application-assistant` | 增加报告类型路由 | 统一骨架与项目领域技能组合执行，不要求用户记忆技能名 |
| 高企预评估 | 增加加计扣除补强 | 建立立项、过程、费用、税务和高企四关联证据链 |
| 专精预评估 | 增加数字化诊断补强和可行性报告分支 | 保留五至八页谈单版，合作后可输出完整条件或评分实施分析 |
| 三首、研发平台、质量品牌、绿色、数字化 | 增加双报告挂接 | 根据项目类型切换成熟度、评分表、市场、绿色绩效或数字运行证据 |
| `delivery-contracts.json` | 新增两类正式报告档案 | Word、PDF、来源、证据台账和默认红色品牌水印进入机器门禁 |
| 门户与发布说明 | 更新 V1.6.5 | 展示新报告分类和补强服务；不切换知识索引 |

## 客户资料与隐私

客户提供的数字化诊断报告只提炼五维、对标、优势短板和提升路径结构；研发费用归集压缩包只提炼十六类底稿和四条一致性链。正式技能不包含客户名称、金额、人员、项目、评价数值、排名、原图表或原模板文件。

## 回滚

发布前可回退至基线提交。正式发布后按受控发布事务恢复 V1.6.4.2 通用包和两个 WorkBuddy 平台包；客户交付物、偏好、知识索引和企业资料不随技能回滚覆盖。
